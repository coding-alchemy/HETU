## 2. 如何找到具体原文

从对应入口按下列动作定位，直到取得与问题匹配的当期正文、表／序列和方法／脚注，再作为证据记录；搜索摘要、机构首页、目录和 API 说明只能作为线索。以下动作不宣称所述产品或数据已取得，也不虚构统一接口。历史研究找截止时点可知的当期发布或对应版本，不能用当前最新修订值替代。
