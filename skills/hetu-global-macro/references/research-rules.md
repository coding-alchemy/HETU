# 研究规则

第一次取证前读取本文件，应用本次问题涉及的观察面、地区和机制。按问题选择具体统计表、序列、政策原文及方法说明，来源选择见[来源导航](sources.md)，记录字段见[报告约定](report-contract.md)。本文件的机制是待证条件，不是固定资产涨跌规则。

## 1. 观察选择

全景须回答增长、通胀、政策、金融条件及主要跨境风险；专题保留全部核心问题，选与问题直接有关的观察，并说明选用理由。全球包含中国，按冲击、需求、贸易、融资货币、政策及反馈关联选择经济体，不逐国遍历，不把下表或来源编号变成每次全取清单。保留当地统计定义，不将中国社融、美国 PCE 等直接套用于其他地区。

| 观察面 | 取证与判断要求 |
| --- | --- |
| 增长、就业与需求 | 核实际／名义 GDP、消费投资及需求结构、就业与失业、工时、实际工资收入、景气及总量订单。水平、方向、变化速度分开；增长改善先辨需求、价格、基数及统计修订，不能由同比转正直接推出需求恢复。就业数量不等于购买力改善；扩散指数不等于产出增速，调查与生产、支出、就业等硬数据交叉核对。 |
| 通胀、相对政策与曲线 | 核当地总体／核心物价、工资、分项贡献、通胀预期、央行决议及两侧政策利差。辨需求、供给、基数与定义变化；调查预期、盈亏平衡通胀及实际收益率分别使用，盈亏平衡还含风险与流动性溢价。政策决定、发言、市场解读分开；曲线分政策路径、通胀、期限溢价和债券供给，降息不保证长端下降。 |
| 流动性、美元融资与信用 | 核央行资产负债、准备金、公开市场操作、财政存款、回购、美元负债、跨币种融资基差、信贷标准与融资需求、部门杠杆及偿债压力。央行扩表不等于入市资金，宽货币不必然形成宽信用；政府／私人融资、供给／借款意愿及短期周转／长期支出分别判断。美元总借款不等于套利仓位。 |
| 财政与主权融资 | 核预算宣布、收支执行、税收转移、实际用途、债务币种与期限、利息、净发行和外汇储备。发债、拨付、实支、偿债与清欠是不同环节，不能重复计作刺激；融资不等于新增需求。本币与外币融资约束分开，结合再融资、储备及政策空间判断。 |
| 贸易、外部头寸与资金流 | 核贸易数量与价格、贸易条件、经常账户、国际投资头寸、跨境银行信用、证券流、外债、储备配置及汇率制度。区分估值、净交易和存量；持仓市值变化不直接等于净流入，储备、支付、持仓、交易额不能互代或相加。贸易顺差可被资本流出抵消。 |
| 供给、重大政策与长期结构 | 按问题核代表性能源食品价格、进口成本、供应链压力、通胀分项、正式政策的实施范围与时间，以及人口、劳动参与、生产率、资本形成和潜在增长估计。保持总量边界；成因未证时给条件情景，政策行为与动机推测分开，技术投入热度不等于生产率结果。 |
| 预期差、金融稳定与跨资产反馈 | 对照可追溯事前预测／调查、实际发布、历史修订、事件时点、融资利差、银行体系流动性与资本、融资工具使用及市场反应。改善与超预期分开；缺事前资料则不能判断预期差，不事后补造共识。价格受预期、仓位及流动性影响，价格波动或下跌不能单独证明系统性危机或具体出售原因。 |

## 2. 地区机制与中国外溢

同幅降息、扩表或财政变化先按当地金融结构解释传导强度与滞后，再比较结果。不能将政策幅度或同名指标当作等价冲击。

| 地区 | 必须辨别的机制 |
| --- | --- |
| 美国 | 美元作为国际融资货币会将美国融资条件传到境外美元负债；核美元融资成本、基差和跨境信用。财政发债、国库现金收支、Fed 操作与准备金共同影响货币市场，不能由单一余额算“入市资金”。资本市场融资与银行贷款的传导不同；固定利率住房贷款使存量借款人重定价与新增按揭、再融资的时间不同，不能由政策利率变化推定居民现金流同步变化。 |
| 欧元区 | 统一货币政策对应成员国分立财政，核各国财政执行及主权利差，而非仅看区域均值。主权持债变化可影响银行资产负债表与融资、信贷标准，再反馈主权与实体融资；银行融资条件、信贷需求和区内金融条件可能分化，同一政策利率不能推出成员国同等宽松。 |
| 日本 | 将国债供给、央行操作与债市流动性一并核对，区分曲线变化的政策与供给因素；核工资、物价、进口成本和实际收入的传导。日元融资条件与两侧政策、汇率及跨境融资相连，总借款不能直接还原套利仓位，也不能由日元变化单独认定去杠杆规模。 |
| 中国 | 自行取得内需、进口量价、出口量价、商品价格、人民币及资金流相关原始资料。沿“中国内部变化 → 外溢渠道 → 全球影响”辨内需与进口对全球需求和商品的作用、出口对贸易与价格的作用，以及人民币和跨境融资反馈；贸易顺差不等于同步结汇或资金净流入。按问题选择必要中国变量，不等待中国宏观或行业报告，也不展开另一套本土全景。 |
| 英国及其他目标经济体 | 按本次问题核财政与金融结构、银行／资本市场融资、按揭重定价、外币债务、资源依赖、汇率制度与政策空间；只展开相关机制。资源进出口身份、外币偿债与浮动／盯住制度可改变同一需求、利率或美元冲击的方向，不照搬美国、欧元区或日本机制，也不强制首期覆盖全部地区。 |

中国城投及地方债务只在有可定位证据表明显著影响全球需求、跨境融资或风险偏好时展开，指出内部变化、外溢渠道与受影响全球判断。展开时，城投债是平台融资的一部分；城投债、平台全部融资、地方政府债和政府隐性债务不得直接相加或相互替代，不因平台身份推定全部债务属隐性债务或由政府偿还。区分余额、发行、净融资、到期及偿还；置换、展期、降息和清欠分别判断主体、期限、成本、现金流或总额变化，不把置换当同额新增需求。公开覆盖不全则只讨论可核实范围与压力，不能制造精确全量或转入单券信用尽调。

## 3. 四资产与条件传导

每条主要判断连接“观察事实 → 成立条件与机制 → 宏观及资产影响 → 可观察反证或限制”，注明短、中或长期尺度及可能滞后、替代解释，区分传导、共同驱动、统计关系和反馈。区分事实、计算、假设、解释及实绩／估计／预测；解释不是已证因果。一个冲击在物价、贷款、利率和汇率中出现不能重复归因，同一笔资金或债务也不重复计数。

| 资产类别 | 必须说明的路径与分化 |
| --- | --- |
| 股票 | 宽基市场总量盈利预期、折现率及风险溢价分别受何影响；需求走弱压低盈利与降息降低折现率可相互抵消，净作用还取决于已计价程度及其他冲击，不能直接推出指数必涨必跌。 |
| 债券 | 主权名义／实际曲线、短长端、期限溢价、整体信用利差和供给分别判断。无风险曲线下降时信用利差仍可扩大；政策降息不保证长端或全部融资成本同步下降，保持总量边界。 |
| 商品 | 代表性价格／指数的总需求、美元、通胀与宏观供给冲击分别说明；供给收缩与需求走弱可给不同方向。黄金另辨实际利率、储备配置及避险渠道；成因未证保留条件，不扩展品种行业供需、具体合约交割或展期。 |
| 外汇 | 明确货币对与报价方向，核两侧增长、通胀、政策路径、外部融资、资本流及制度。加息不保证升值，盯住汇率稳定不代表无调整风险；远期点含利差与融资条件，不能当作未来即期预测。 |

逐类说明当前问题的条件、可能分化及限制，相关性弱或缺证时明示，不强行填方向、统一评分或永久股债对冲关系。比较前固定时点、币种、尺度和指标定义；官方参考汇率、拟合曲线、指数与实际成交价格分别标注，不据此计算具体工具的可实现回报。反证写成可观察变化，并指出其将改变哪项判断。

## 4. 证据、时点与冲突

具体证据保留原发布方、原始值／原文、正文及表／页／段／序列定位和本次取得状态。目录、搜索摘要、API 文档、来源旧状态或其他报告结论不能代替已取得的原始证据。取得与采用分开；公开、可下载、允许使用和已接入分别判断，不将“可找到”写成“已取得”。

比较时核经济体、期间、覆盖、单位币种、同比／环比、季调、实际／名义、累计／当期、流量／存量及本地统计定义。冲突先按这些口径及修订解释，不能盲目平均；仍无法解决则保留差异与受影响判断。同源转载只算一个底层来源，替代须适合当前用途、时点和许可，不能用其他地区数据代填。

PIT（时点可得性）以首次公开、修订公开及对应历史版本为依据，获取时间只说明本次何时拿到。历史研究只用 `as_of` 前已知事实；今天取得不证明历史当时可得，同日却无发布时间不能假定日内已公开。有 vintage 则保留对应版本；无 vintage 则找可定位的当期发布材料，仍缺则限制该历史判断，不能用最新修订序列冒充。未知时间／版本明确记未知，不从获取时间倒推；缺事前共识只限制预期差判断，不阻止说明已有依据的实际变化。

### 4.1 历史对照

支撑主要状态、趋势、驱动、风险或反证的周期性经济指标须作历史对照；专题只选与本题有关的指标和经济体。取数时在已有证据记录中注明频率、观察末期、窗口及比较口径，研究中新增主要指标同步纳入。一次性政策额度、事件日期和次要背景数字按其实际期间说明，不构造连续序列；不为填表增加无关指标。

| 频率 | 默认正文窗口 | 适用比较 |
| --- | --- | --- |
| 月度 | 从最新已发布观察月向前12个自然月 | 逐月数值、同比及适用环比；用户指定24个月等窗口时遵从，需要两年季节性／基数对照时可说明理由扩至24个月 |
| 季度 | 最近8个完整且已发布季度 | 逐季数值、同比及适用季环比，分别注明普通环比与环比折年率（SAAR） |
| 年度 | 最近5个完整已发布年度 | 逐年数值及同比；用户指定3年等窗口时遵从，年度不设环比 |
| 年内累计 | 本期与上年完全相同的累计期间并列 | 两期金额／水平、可比差额及同比；判断增速加快或放慢时并列两年同期增速及百分点变化 |

历史展示窗口与前瞻期限分别记录，不能由12个月历史自动推出12个月预测。各经济体、指标保留自己的最新观察期和发布滞后；跨国比较选共同可比期间并说明各自末期，不能把发布日期当观察期或把滞后值填作本期。自然年与财政年度明确起止，累计同期也须对齐。保留各地统计定义、季调、实际／名义和版本，名称相同不意味着口径相同。

流量用当月／单季，存量用期末，均值注明覆盖。仅有年内累计披露时保留累计口径并列上年同期；同口径、可加且版本兼容的累计绝对量可差分为当期，缺条件则注明单月／单季未得，不把8个累计点当作8个单季，不虚拆合并发布期。季度折年率与非折年率分开标注，必要换算注明公式；增长率序列可以比较百分点变化，不能把增速之差称为环比增速。

同比／环比优先采用官方适用口径；只有可比水平值时逐期计算，记录输入、公式、版本并标明计算值。比较所需基数可在展示窗口之外。已得两端兼容时仍须计算并展示，不因部分基数缺失省略其他可完成比较。价格指数可计算涨幅；PMI等景气指数用指数点，比率／增速变化用百分点，利率／利差用基点。零或负基数不强算增长率；环比注明季调，未季调比较交代季节性限制。仅有增速时展示增速序列，不补造绝对量或倒推精确原值。

当前研究使用截止前可比版本，不要求逐期恢复初值；历史研究仍遵守本节时点规则。金额复算与官方同比不符时回查表注和修订，保留已知差异，不强行改齐。缺期保留所选窗口并区分未发布、未取得、不可比与不适用；已读原文未提取、可算未算须先完成。表旁交代具体缺期、缺少的比较输入及判断限制，不补零、插值或静默缩窗。无可用工具或已尝试路径失败且无新增线索时，按第5节记录并停止重复探测，交付已得范围；完整历史覆盖仍未完成，不因个别缺值自动采购。

## 5. 缺口与有效旧结果

记录未取得或冲突资料、尝试来源、可用替代及其口径差异，指出直接受影响核心问题与尚不能成立的结论。缺口只限制相关命题，不连带否定已有充分依据的判断；关键资料不足时交付有依据的部分，但核心问题仍未回答就保持未完成，不能以结构齐全或来源数量判研究成功。

已通过结果继续对原时点有效。日期、版本、模型、路径、哈希、仓库或 `as_of` 变化本身不取消旧结果、不触发重跑，新时点结论也不追溯取消旧时点。只有可定位证据证明具体语义变化直接影响某判断时，说明影响并最小复查，保留原结果。哈希等只记录来源／时点或检测同一锁定产物是否被改写，不能用于跨运行过期、批次绑定、等价或追溯失效。重跑已通过项或整批重跑前，先说明直接影响证据、预计分析次数及成本，并取得用户针对本次重跑的明确批准。
