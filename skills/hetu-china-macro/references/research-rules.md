# 研究规则

## 1. 观察清单

全景逐面判断以下 C01–C12 的状态、重要性与证据缺口，尤其地方债、房地产、财政、银行信用和人民币制度，同时保留增长、就业收入、消费、通胀和长期结构。专题围绕核心问题选取并说明理由，不要求下载每个示例指标。同一事实不重复计数；缺关键资料不能静默删观察或改为不适用，表格填满不等于研究完成。

| 因素 | 核心指标与事实 | 条件化影响与分辨 |
| --- | --- | --- |
| C01 增长、需求结构与意愿 | 实际／名义 GDP、消费、投资、净出口、工业生产、PMI、信心与融资需求调查 | 区分实际需求、价格、基数及扩散指数；调查与硬数据共同判断支出意愿；增长贡献与私人支出按§1.3分辨，可比版本按§5.2核查 |
| C02 就业、收入与居民支出 | 就业、失业率、工时、实际收入、消费、储蓄、居民杠杆与偿债负担 | 就业数量不等于购买力；收入、财富与偿债变化共同影响消费持续性 |
| C03 通胀、预期与实际利率 | CPI、核心物价、PPI、工资、食品能源贡献、可追溯通胀预期与实际利率估计 | 区分需求、供给和基数；实际利率须说明通胀口径，缺少预期不能以当期 CPI 冒充；重要外部冲击按§1.5核国内缓冲 |
| C04 货币政策、曲线与流动性 | 正式政策决定、政策利率、准备金、央行资产负债、公开市场操作、财政存款、回购利率及国债曲线 | 政策、发言与市场解读分开；宽货币不必形成信用扩张，财政存款变化不等于股市流入 |
| C05 银行信用与政策性融资 | 社融结构、居民／企业贷款及期限、政府债融资、票据、政策性金融和结构性工具使用、政策利率／LPR／银行间利率、银行体系资本与流动性总量 | 区分政府融资与私人需求、短期周转与长期投资、信贷供给与借款意愿；观察政策是否形成有效信用扩张及金融压力 |
| C06 中央地方财政与实际执行 | 中央／地方收支、转移支付、一般公共预算、政府性基金、国债和地方专项债资金用途及实际支出 | 判断地方财政空间与实际需求增量；发债、拨付、支出、偿债和清欠分开，不重复计算同一笔资金 |
| C07 地方债、城投融资与化债 | 地方政府一般债／专项债余额与偿债、城投债到期及净融资、公开可核实的平台贷款及其他融资、置换／展期与清欠安排、区域融资成本 | 偿债与再融资影响地方可支配财力、公共投资、企业回款及银行信用；缓解流动性不等于债务实际减少 |
| C08 房地产、土地财政与资产负债表 | 住房销售与价格、交付与投资、土地出让收入、居民按揭及房地产融资总量 | 通过住房财富、居民支出、地方收入、投资和银行资产质量传导；仅分析总量，不做房企估值或项目供需 |
| C09 贸易、外部冲击与融资约束 | 贸易量价及伙伴结构、贸易条件、关税／限制原文、能源食品运输代表性价格、外债结构及外储 | 区分数量、价格与制度变化；判断外需、进口成本及外币融资压力，不由单一价格推断全部经济周期；冲击缓冲和外部边际变化按§1.5 |
| C10 人民币制度与跨境资金 | 国际收支、结售汇、跨境收付款、国际投资头寸、外债、中间价及境内外汇率、跨境融资与资本流动政策 | 汇率、资本流与政策空间相互影响；比较两侧基本面及政策，贸易顺差不等于同步结汇或资本净流入；政策决定后的相关信息按§1.5核查 |
| C11 人口、生产率与潜在增长 | 人口年龄、劳动参与、生产率、资本形成及潜在增长估计 | 解释中长期增长、物价及财政约束；区分估计和观测，技术投入热度不能替代生产率结果 |
| C12 预期、反证与市场反馈 | 发布前预测、政策预期、实际值及修订、宽基股指、主权曲线、整体利差、汇率与波动 | 改善不等于超预期；无事前材料不构造共识，价格与相关性不单独证明因果或系统性危机 |

### 1.1 银行约束与实际信用（C04／C05）

分别判断银行能否扩张、是否愿意承担风险、借款需求及实际投放／私人支出。能力核资本与流动性，重要资本政策核金额性质、对象、宣布／批准／到账；意愿结合息差、盈利、资产质量、可得银行调查或正式说明，息差下降本身不证明收紧供给。需求结合居民／企业调查、融资用途与投资支出，贷款需求指数不代审批标准。投放核分部门与期限、结构工具实际使用，政府融资、票据和政策项目不代私人资本开支。

资本补充增强吸损和风险资产承载能力，不是等额基础货币或贷款；资本率分辨分子与风险加权资产分母。估扩张空间须有监管与风险权重等假设，不用固定放贷倍数；体系总量不排除个体风险。保险使用偿付能力及其资本口径，不套银行核心一级资本。缺直接供给证据时保留供给与需求解释并指出区分所需资料，贷款净增量下降不单独证明惜贷或居民主动去杠杆。

### 1.2 居民支出的竞争性解释（C01／C02／C08）

全景比较收入就业、财富、偿债、意愿与不确定性四种解释或保留对应缺口；非消费驱动专题不强制全部展开。实际收入、构成／中位数、就业和消费交叉核对，失业率或单位工资不代表全体家庭购买力。住房量价不能直接换算全国财富损失或消费因果。偿债核明确居民部门的债务、收入、本息或有方法说明的调查估计；贷款净流量不是还本额，债务/GDP不是偿债率，私人非金融DSR不是家庭DSR。

储户／消费者调查与实际收支交叉，存款不代预防性储蓄，方向指数不代储蓄率。收入消费分化时继续找区分解释的调查、偿债或财富材料，不直接归因信心。调查与硬数据分别归期，早调查不解释后来事件，城市样本不推广全体。只有相关性就不写因果，不能确定主次就不编贡献比例。缺偿债率只保留对应未回答原因，不阻止有证的收入、融资与意愿判断。

### 1.3 总量盈利与收入、投资传导（C01／C02／C03／C12）

全景核查截止前可得的总量已实现利润与营收，专题在生产修复、企业投资或盈利传导相关时采用。先读已得运行发布中的相应原文，需要判断分布或原因时再补官方总量分组；它们是宏观证据，不展开公司财报或行业供需。

全景解释增长驱动，专题判断内外需贡献时，核适用期间的GDP需求贡献：沿运行发布、答问、需求分解或官方数据库查找。已得有限贡献范围也须采用，保持原精度，不反推未披露的精确分项。分别判断实际增长由什么贡献、哪些需求增速或边际偏弱、分化能否持续；内需贡献高可与私人投资弱并存，贡献率还受GDP增速分母影响，不直接等于需求加速。固定资产投资不代资本形成，名义进出口及海关顺差不代实际净出口贡献。外贸是主要支撑时，按判断需要核量价、伙伴或重要贸易限制；缺证限定为已核名义贸易或外向生产，不逐产品、伙伴或关税扫描。

沿需求／生产→名义营收利润→就业、居民收入和私人投资→资产影响，说明已证终点和下一环条件。生产、价格、营收与利润分别归期和核实际／名义；规上工业、规上服务业与上市公司覆盖不同。重要利润和营收变化无论支持或反驳原判断都须采用，并与订单、用工收入及非地产民间投资交叉；出现分化时按材料比较基数、分布、时滞和回报预期等解释，不预定主因。

重要分化影响季度判断时，用能区分解释的最小证据辨别周期时滞／回款摩擦和结构性传导较弱。按相关材料选择利润集中、资本密集、设备更新／扩产用途、部门就业结构或回报预期，先用已得总量和分组，需要时才补取。说明支持了哪种解释、哪些尚未区分及季度含义；高技术标签不证明自动化替代就业，“尚未扩散”不证明迟早全面扩散，也不反向认定结构性失灵。不量化无依据的原因贡献，不建立行业产能或就业弹性模型。

成本指数不代实际利润，利润总量上升不证明所有企业利润率提高或支出已扩张。区分已实现盈利、未来盈利推断和市场预期修订；缺前瞻盈利只限制对应预期／计价判断，缺分组只限制改善广度，不能丢弃已有总量事实。关键缺证按§5.2继续核查或保留局部未完成。

### 1.4 政策状态、已知安排与季度影响（C04／C05／C06）

全景核货币、财政的适用状态和展望期重要安排，专题按核心问题选择。读取截止前正式决定、操作公告、实施文件及必要执行报告：识别央行正式政策利率与变化，分别记录LPR、市场利率和工具实际使用；财政核对象、用途与执行阶段。旧季报解释历史框架，不能单独证明其后政策状态；未取得当前适用依据时保留时点限制，不要求逐日重建全部操作。

全景形成总体政策与季度需求基准前，分别核金融供给、居民／住房支出、地方可用财力与实际用途；专题只核直接相关渠道。从运行发布、正式政策发布和主管部门文件主动发现线索；无可核政策记录核查结果，不推定必有新增措施。房贷贴息、地方额度、税费／社保等评论或用户线索回正式文件，未证实保留身份和影响，不断言政策存在或不存在。有具体抵消措施线索也须核查；税收增长不代税负提高，额度不代支出，征缴变化不能未经核实就当全国收紧。

对主要政策核对象、金额性质、用途、适用期限及公布、生效和执行：截止前已公布、未来生效的安排可用于情景，但不当已执行效果。只列有公开依据的相关节点，未公布决定仅作有条件的研究假设，不编造日程或必然动作。展望跨年或跨已知到期节点时核覆盖期间和正式接续；未公布不等于刺激归零，也不自行编续期，给续接／到期条件及受影响环节。

全景及地方财政／化债专题展望跨年或跨已知化债额度变化、到期节点时，主动核原正式多年方案及附件的分年安排，再核截止前正式调整／接续和发行、使用披露。其他专题仅在影响核心判断时触发。已有多年文件覆盖下一年就是已知依据，不能只搜索新年度公告；未核新公告不等于原安排归零，也不编续期。

报告对照相关年度／阶段的政策类型、安排金额性质、适用期、已证执行、调整／接续及来源。分别解释新增支持、既有置换节息展期、当期偿债与可用财力，再将证据用于公共支出、清欠和相关资产条件。额度差额不等于同额财政紧缩，不无依据摊成1月资金断档；结转、剩余压力和其他支持有证才作抵消。未核接续时采用可核原安排并保留对应限制，不因局部未知抹去已有多年依据。复用E→J→正文及§5.2，不固定年份、金额、方向或另建债务模型。

将政策事实连接到成本、资本、信用供需、财政用途或居民收入，再给未来一季度的成立条件、约束和反证。按本次证据判断增长、物价、汇率、银行息差等相关约束；海外加息不机械等于国内无法降息。不同政策可能合力或抵消，净效果需要可比执行依据，不强制计算、不凭表态承诺效果。

明确政策针对融资、项目／借款需求、现金周转还是执行条件。已有资金而支出弱时，用证据区分尚未拨付、项目条件不足和受益者需求弱等解释，未知就保留未知，不自动归因缺钱或只说等待落地。说明季度内最先可观察环节、较后结果及时间限制；注资、贷款、投资、就业与消费不假定同季同步，也不编精确时滞。

房地产政策影响主判断且存在预售／现售、监管资金释放、土地付款或项目融资规则线索时，核正式文件的地区、新增／存量项目、生效与过渡范围。解释销售回款、可用现金及拿地／建设／交付的变化，调整适用观察指标；制度改变后旧预收款不机械作为唯一需求信号。未核制度保持线索，不推广全国、不采用评论固定周转年限，不展开房企或项目研究。

### 1.5 外部冲击与政策边际（C03／C09／C10）

外部能源或其他价格冲击是主要增长、通胀或资产风险时，核冲击→国内暴露与缓冲→实际传导→残余风险，价格下降同样适用。先采用适用当期的国内供给、价格、政策和发布解读，形成已有事实支持的有限判断，再判断是否需要定向补取关键机制。历史措施只解释其适用期间，不能替代当期缓冲证据。供给、替代、汇率、价格机制或临时调控按相关证据选择，不逐项强制下载。比较价格核币种、品种、观察期、税费和定义，国际基准油价与国内零售价之差不当吸收比例。

调控核正式范围、期限与机制；机制、承担主体或期限未知，只限制对应的原因、成本归属或持续性推论，不抹去已核当期事实。较低零售涨幅只证明对应价格传导有限，不能证明总成本消失。财政、供应企业、消费者或未来调整可能承担的部分有证才归属，否则未知；缓冲可能延迟传导，季度判断纳入已知到期条件。定稿按报告约定双向回查：这些当期事实须经E→J→正文实际约束风险方向、强度、范围或期限；不适用则在对应E／J说明具体原因。说明风险缓和到哪一环及残余压力，不强制净成本量化或行业经营分析。

外部利率或政策用于人民币、港股或国内政策空间的主要季度判断时，核最近决定后、截止前足以改变判断的基本面和正式政策信息。美元约束涉及就业通胀时查适用最新发布及正式信号；其他目标货币选对应经济体，不默认美元，也不扩为全球研究。这里的最新仅指本次截止可知版本，不使旧研究过期。

分开当前政策水平、基本面边际、市场政策预期与研究预测。无可核事前定价不编概率或市场转向，正式表态不代共识。论证相对收益／利差变化另核两侧可比日期、期限和产品，不拿政策利率减另一侧长债。冲突可支持水平仍高但继续收紧依据减弱等有限结论；仅有水平证据时限制边际和前瞻强度。

## 2. 债务与财政口径

1. 城投债只占平台融资的一部分；必须区分城投债、平台全部融资、地方政府债及隐性债务，不直接相加或相互代替。
2. 平台贷款和其他融资仅使用公开可核实资料；隐性债务依权威认定与披露口径识别，不因平台身份推定全部债务为隐性债务或政府偿还义务。
3. 分别记录余额、当期发行、净融资、到期量和偿还额；置换、展期、降息与清欠分别判断改变的是主体、期限、成本、现金流还是债务总额，不将旧债置换视为同额新增需求。
4. 保留预算／执行／决算及中央／地方口径；核对一般公共预算、政府性基金、转移支付和实际支出的资金关系，发债、拨付、支出、偿债与清欠不得重复计作刺激。
5. 资料不能覆盖全部平台、融资方式或地区时，输出覆盖范围、未取得项与可核验压力指标，不制造精确总额；结论停在地方财政、区域融资和金融稳定，不替代单券或平台评级。

跨年化债的多年安排、变更及采用按[政策状态§1.4](#14-政策状态已知安排与季度影响c04c05c06)核查。

先核全国中央／地方两本预算执行、偿债与土地收入，再追影响主结论的政策；不自动逐省扫描，地区佐证注明选择与覆盖。沿安排融资→拨付接收→实际用途→结果反馈核对：额度不等于融资，拨给平台不等于最终债权人或供应商到账，置换和节息不等于新增需求或支出实绩。连续环节不重复计刺激。每条关键链说明已证终点、下一环缺证，以及确认的是需求增量还是风险缓释。

口径、范围、期间明确的官方清欠完成额或到账披露可证明相应清偿，无需逐笔流水；只有拨付不能升级。到账不等于新增消费投资，同期改善不单独证明政策因果。预算／执行／决算和两本账、转移支付、债务资金核包含关系，不机械相加为净财政脉冲。累计差分须同口径相邻期，累计同比不能相减成单月增速。置换分辨主体、期限、成本及现金流，不凭法定债余额升降判成败。

### 2.1 财政支出结构（C06）

全景及财政、内需相关专题，在中央／地方两本账、债务与实际支付之外，读所用财政发布的主要收支科目。选取能解释总量判断的主要增长项、拖累项和付息约束，交代预算、范围、期间和作用对象，不逐项抄表。总量执行弱可与部分用途增长快并存，不能把总量方向推广全部分项。

社保就业、卫生教育及适用居民转移收入用于分析保障和消费渠道；功能科目不是居民现金到账，支出增长不证明储蓄意愿下降或新增消费。城乡社区、交通等科目结合项目结果分析公共需求；功能分类不全是资本支出，不能直接汇成基建投资，支付与实物工作量分开。付息与对应收入／支出核同层级、同预算、同期间，增长本身不证明挤出。正式税费或补贴变化若影响主判断，核对象和执行；税收增长不等于税负提高。

用途结构与实际效果分别判断；净作用须有可比依据，不机械相加两本账、税费、转移与融资得出净刺激，不强制财政乘数。

### 2.2 名义收入与债务负担（C01／C02／C06／C07）

核心问题或主要结论涉及债务可持续性、偿债能力改善、中期财政空间或低利率化债效果时，连接名义收入与债务负担；仅论接续或当期市场成本时保持有限结论，不强制长期模型。C01原有实际／名义增长观察仍执行。

按主体选分母：宏观债务背景用适用名义GDP／平减指标，政府付息用对应财政收入，居民沿§1.2。债务、收入和成本须同范围、可比期间，存量有效成本与新债发行利率分开。置换或降息改变期限、成本或现金流，不自动改善收入；增长与利率之差不能单独证明可持续性，还须考虑债务规模、财政收支和到期结构。缺必要输入保留相应未回答部分，不跨主体拼接。

## 3. 五条传导链

全景判断五链重要性；专题说明关键链证据支持到哪一步。路径中的未知环节保留条件，不因机制合理认定已经发生。

财政与地产链的政策组合、执行约束及制度线索按§1.4核查；外部链的国内缓冲及政策后续信息按§1.5核查，再判断各链已证终点。

| 起点 | 需要解释的路径 | 关键条件与反证观察 |
| --- | --- | --- |
| 地方债务与化债 | 到期／再融资压力→可支配财力与银行信用→公共投资、清欠及企业回款→总需求 | 成本或期限改善是否伴随实际支出、回款改善；债务置换本身不能证明增长增量 |
| 房地产变化 | 住房销售／价格／交付→居民财富与按揭、土地收入→消费、地方支出、投资及银行资产质量 | 住房、居民支出与财政执行须分别验证；价格稳定不保证交易和投资恢复 |
| 财政发力 | 预算与融资→拨付和用途→实际支出／偿债／清欠→需求及债券供给 | 区分用途与执行进度；融资扩张但支出未落地时保留传导缺口 |
| 货币信用变化 | 政策及市场利率→银行供给与借款意愿→融资结构→私人支出及物价 | 社融由政府债或短期融资驱动时，不能直接推出私人投资复苏 |
| 外部与人民币变化 | 两侧增长／政策和贸易条件→汇率及跨境融资→进口价格、需求和国内政策空间 | 结售汇、收付款与国际收支分别核对；资本流、干预和风险溢价可改变方向 |

每条主要关系注明经济机制、成立条件、时间尺度、证据、替代解释和下一观察点。区分传导、共同驱动及反馈；同一冲击在贷款、物价和汇率中出现，不重复归因。


## 4. 证据、历史时点与归因

逐证据记录机构、具体原文／表格／序列定位、地区覆盖、定义、数值单位、观察期、实际／名义、同比／环比或累计／当期、季调、首次公开、修订公开及取得时间。未知明确写未知，不填造元数据。政策另核适用范围、公布和生效日期；宣布未生效不能写成当期执行。

事实、计算、假设、估计、预测、政策表态和解释分别标识；计算保留输入与公式。水平、变化方向、速度与相对预期分别判断。无可追溯事前预测材料不构造共识或称超预期；当期 CPI 不冒充通胀预期。

历史研究仅采用截止前已公开的信息版本。今日取得不等于历史可知；后来修订和迟发数据只用于单列复盘。缺原始历史版本或无法确认公开时间时，明确该判断无法还原，不用最新值补齐或倒推初值。

冲突先核定义、期间、单位、季调和修订；可解释则保留差异，未裁决则分别列出并限制结论，不挑有利值或盲目平均。多站转载同一底层统计只算一个独立来源。未披露、未取得与数值零分别记录，缺证不等于无风险或无变化。

每项主要判断连接证据、机制、成立条件、时间尺度、支持程度、替代解释、反证和下一观察点。区分传导、共同驱动与反馈；价格相关性不能单独证明因果或系统性危机，同一冲击不在贷款、物价和汇率中重复归因。

既有有效结果继续适用于原时点。日期、模型、版本、哈希、路径和 as_of 仅记录来源与时点，不造成旧结果过期、隔离或整批重跑。变化先定位具体语义直接影响的判断，仅必要复核；新时点形成独立结果，不覆盖旧报告。

### 4.1 历史数据对照

支撑主要状态、趋势、驱动、风险及反证的周期性经济指标须提供历史对照，专题按本题选择，不因难取改变指标。默认月度最新已发布观察月向前12个自然月、季度最近8个已完成且已发布季度、年度最近5个完整已发布年；用户指定24个月、3年或其他期间时遵从。确需两年季节性或基数比较时可扩至24个月，取数前说明原因。各指标保留自身末期，不以发布日期代观察期，不按结果挑窗口。

流量用当月／单季，存量用期末，均值注明覆盖。仅有累计披露时按1—M月原口径呈现，年初重置不解释为骤降，1—2月合并不虚拆。季度流量可用同口径、可加、版本兼容的累计绝对量差分；不能取得单季时保留累计展示及单季局部未完成，不把8个累计点判为8个单季已齐。累计数据与上年完全相同期间并列；判断增速加快或放慢时比较两年同期增速及百分点变化。

同比／环比优先使用官方适用口径，自算保留两端输入、公式及版本，所需基数可超出展示窗口。按期间核两端输入；兼容两端已取得时，即使原表未给出变化，也计算并逐期展示适用比较。部分基数缺失只限制对应期间的比较，其余可算期间照常展示；不把计算结果当原发布数。依指标性质用增长率、金额或点／百分点／基点变化，负值或零基数不强算增长率。环比注明季调；未季调比较说明季节性限制。同比相减不是环比，累计增速不能相减得到单月或单季；PMI用指数点，比率用百分点，利率／利差用基点，年度不强制环比。原文给出本期水平与明确同口径变化量时，可按披露精度还原比较期，注明计算来源与精度；仅发布增速时展示增速序列，不补造绝对量或倒推精确原值。

当前研究可用截止前可比修订序列，不要求逐期恢复初值；历史时点仍禁止截止后数据。官方可比同比与两年表面总额不一致时核附注，不能强行改齐。缺期或不可比处保留，不填零、插值或猜值，不静默缩窗；区分未发布、未取得、不适用和不可比。按§5.2核适用路径后停止，明确实际覆盖、对应未完成及判断限制，已有事实继续使用。确需商业数据沿现有审批，不因个别缺值自动采购。

## 5. 实际覆盖与取证核对

全景每个观察面先明确核心问题与最低必要证据，再核对该问题涉及的其余指标；最低组合不替代完整观察与判断要求，不能因数据难取而改成无关。证据支持不到的传导环节保留为条件。
地方宏观研究区分全国法定债、地区财政、公开平台债券及其他披露融资；记录地区、识别依据、样本及期间，不能把未披露融资当零或将单省推广全国。
不得以不同久期、评级或币种简单相减造信用利差。
历史原文须保留观察期和初发／修订公开时间；复杂表格须核表头、行列、单位及表注，文字次序无法还原时补图像或同源证据，仍不能核对则不采用该数值。

### 5.1 市场实况、估值与预期（C12）

按研究问题先固定产品、币种、期限、价格定义与比较窗口，再取得变化依据；窗口按问题选择，不能按涨跌结果挑选。当前日频市场先查截止前最近已完成交易日的适用发布，月季资料按自身频率与公开版本使用。谈变化须有两个可比点或可核的官方变化值。股票区分 A股／港股、价格／全收益指数；谈估值或已计价须另有适用估值、盈利或事前预期依据。债券核同期限曲线与信用产品，斜率不当纯期限溢价，高等级代理不代全信用。商品核现货／期货／连续合约、币种、单位、频率，不由价格独断供需因果或具体回报。人民币固定货币对，中间价、参考价、即期和远期点分开，在岸／离岸差异需分别取价。

预测须早于相关公布且不晚于研究截止，核对象、样本和方法；单家只称该机构预期。事件后价格变化不单独证明因果、超预期或充分计价。旧月报按旧月描述，保留当前市场缺口。必要报价、估值或预测缺失只限制对应市场结论；宏观利好利空并存不能直接推出必然震荡，不强制目标、概率或排序。

### 5.2 必要观察的取证与停止条件

读取综合发布时按问题查看正文、相关答问、表注和附件，输出截断则续读相关段落。先核实际返回的机构、题名、期间及相关正文是否匹配；打开动作、页面题名或检索片段不代正文取得，搜索返回完整适用正文则可采用。对影响主判断的数值和政策用途，在对应E或允许的raw保留必要原文摘录及定位，连同指标名称、表头、单位、期间和适用范围逐项核对后才登记已取得；未返回对应内容则保持候选，不凭记忆填值。按问题从已得正文记录主要总量、分化、缓冲及相反事实，再形成驱动排序。统计事实、发布者评价和因果解释分开，原发布的归因也须核依据。

对核心问题所需的每项观察，在现有evidence.md覆盖清单中分别记录**全口径**与**有解释价值的公开子范围**的取得状态及证据。全口径缺失时继续核查可回答部分问题的公开样本，采用可核事实形成有限判断，剩余范围仍列缺口；不能以两者之一的状态代替另一个。

全景C07，以及以地方债务或区域融资为核心的专题，须实际核查公开城投债融资（发行、净融资或净偿还）、区域分化及适用评级/期限的利差资料。沿[地区公开债券汇总路径](sources.md#地区公开债券汇总的补充路径)寻找适用原文与表注；法定地方债接续、清欠个例和AAA中短票代理各证其用途，不替代该观察。其他专题仍按核心问题取舍，不自动逐省、逐平台扫描。

C01所需名义GDP缺基数时，查可见官方数据库、同期间核算发布、修订说明或已公布名义增速，记录实际路径与结果。核定义、期间和版本可比性，不要求同页或同日发布，不因发布日期不同直接判不可比。有可比依据才计算名义增速或隐含平减，不把缺乏可比依据的初值与修订值拼接。其他缺证不阻止此可达路径；本轮未取得不升级为公开不存在，也不因此强制长期债务模型。

将必要观察结束为“未取得”前，逐项核对已知适用路径：

- 先回到本轮已取得的综合原文、答问、原表及适用表注核对应期间和输入，不能只查解析表或摘要。区分原文未取得、已有原文尚未提取、需计算和口径不可比：已有原文先提取，兼容输入按§4.1计算，再登记真正缺失的输入及受影响比较；单项页面失败或解析缺字段不等于本轮未取得。有明确且尚未尝试的适用路径时，优先实读该路径及必要段落，再决定是否补检索；相近关键词查询不替代该读取，不把尚未打开写成已失败或不可得。
- 已取得适用证据：实际采用后停止该条重复探测；有限样本按上述来源路径记录分类、期间、地域、品种及方法限制。完整分类或算法缺失只限制受影响的覆盖、固定样本变化或精确偿还推论，不自动否定正文中可核的有限事实。
- 无可用工具，或适用渠道已失败且没有新增线索：停止无新增证据的重试，记录实际路径、可见工具返回、未取得原因、受影响判断和最小下一步，继续有证工作。工具明确报告额度耗尽或不可用时停止调用该能力；未保留返回就注明故障依据不能回查，不以自述冒充返回。原因分别标尚未查找、工具故障、访问限制、公开披露覆盖不足；失败不证明所有公开渠道不存在。

定稿逐项回查必要观察：应能定位到已采用证据，或上述失败/无工具依据及局部未完成判断。若只剩一句缺口说明、没有取证依据，或仍有未尝试的适用路径，返回入口第4步补齐后再定稿。此检查复用现有覆盖清单与E/J记录，不新增台账。
