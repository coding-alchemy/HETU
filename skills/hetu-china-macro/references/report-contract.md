# 证据与报告交付约定

## 1. evidence.md

只维护必要研究记录，局部 E、J 编号连接证据与判断，不建立全局注册表。

- 任务边界：核心问题、全景／专题、对象及地区、截止时点与时区、观察期间、传导尺度、目标币种与期限、披露默认值。
- 覆盖清单：观察面／本次问题／为何必要／主要指标的频率和所选窗口／证据定位／判断与缺口。全景 C01–C12 各有状态、重要性和缺口；专题说明选择；取证范围和状态按[研究规则§5.2](research-rules.md#52-必要观察的取证与停止条件)填写。
- 每条证据：机构、具体 URL／文档名与表格／段落／序列定位、地区覆盖、定义、数值单位、观察期、实际／名义、同比／环比或累计／当期、季调、首次公开／修订／取得时间；政策另记适用范围、生效日。未知项写未知，非适用项注明原因。
- 取得与采用：分别记入口、正文、数据取得、API 实测、接入和用途权限；候选、仅定位、失败和本次实际采用分开。历史截止可用性与版本另核；市场证据固定产品、币种、期限、价格定义和比较窗口，注明选择理由。
- 计算：输入 E、公式、单位转换、结果，区别原发布数值；缺输入不补值。
- 判断 J：关联观察面、证据 E、机制、条件、时间尺度、支持程度、替代解释、反证、缺口和下一观察点；交代传导已证终点、竞争性解释、区分它们的资料及缺证下一动作。注明重要事实支持、增强、修正或限制的具体命题及正文位置，复用E／J而非另建摘要表。事实、计算、假设、预测、估计、政策表态及解释分开。

## 2. report.md

依次交代：范围与时点 → 状态及核心驱动与重要性 → 国内制度传导 → 相关资产条件情景（按§3取舍） → 原始引用、替代解释、反证、缺口与后续观察。

全景呈现全部 C01–C12 的状态、重要性和缺口及五链重要性；专题说明选取范围并沿关键链交代已证和未知环节。报告自足，读者无需先读任何其他工具报告；关键限制必须在正文体现，不能只藏在 evidence.md。正文分别呈现经济事实、机制与实际市场反馈；银行供给能力／意愿／借款需求／实际投放与居民收入就业／财富／偿债／意愿解释按重要性展开，财政资金追到已证实际落点及下一环限制。每项主要判断连接未来一个季度的条件、反证和下一观察点。主张用 E／J 或原始定位回查，不把机制合理当路径已发生。

全景在增长、国内传导及资产判断中体现总量已实现盈利与私人支出的关系、财政用途分化、已知政策及季度条件；专题按核心问题选择。涉及债务承受能力时按研究规则连接名义收入与负担。重要支持与反向事实须用于判断，缺前瞻盈利不掩盖已实现盈利，资料缺失只限制对应命题，机制分析不强制另设长表，经济数据必须执行[历史对照要求](research-rules.md#41-历史数据对照)。

主要经济指标的完整所选历史窗口放在report.md相关分析附近，按主题合并，合并表仍逐期呈现适用比较，不能以最新或起终点变化代替完整窗口；并说明趋势如何支持或限制判断；不能只把历史表放在evidence.md。月／季表列期间、指标值、同比与适用环比；年度表列年度、数值及同比；累计表并列本年和上年相同期间的值，必要时列两年累计增速及百分点变化。指数、比率按点、百分点或基点呈现适用变化。表注统一注明地区、单位、实际／名义、当期／累计、季调及末期；来源可共用E或原表定位，混合版本须能回查对应行／区间。

表头可保留简写。对实际采用的缩写、简称及容易误解的专业指标，在表格上方或下方正文就近说明全称及其衡量对象；仅在理解需要时补充分母、正负含义、分界值或容易混淆的统计对象等关键读法。相邻一组表可共用说明，已有口径解释足够时沿用或补充；后文复用无需逐次重讲，跨章节容易失去上下文时就近简要提示。不要求解释普通词或另列长篇术语词典，不以长句表头代替正文说明，也不只放在evidence.md。指标定义与经济判断分开，不因释义新增无证因果或投资结论。

相关跨年化债表列年度／阶段、政策类型、安排金额性质、适用期、已证执行、调整／接续和来源，正文实际使用其条件，不能仅附录列数。

## 3. 四资产与比较口径

全景分别分析四类资产；专题只分析回答核心问题所需的资产。其他资产仅在有直接解释价值时作简要交叉核验，服务于本题判断，不另补齐各自独立的季度展望。

| 资产类别 | 中国宏观研究的落点 | 必须保留的分化 |
| --- | --- | --- |
| 股票 | 宽基市场总量盈利预期、折现率、风险溢价及金融条件 | 需求走弱和利率下降作用可能相反；不推出个股目标价或指数必然方向 |
| 债券 | 国债曲线、期限溢价、政府债供给、整体信用利差及区域融资环境 | 基准利率下降时信用压力仍可上升；不评价单一发行人或具体条款 |
| 商品 | 中国总需求、进口成本、人民币及外部供给冲击对代表性价格的作用 | 需求驱动与供给驱动须分辨；缺少成因证据时列条件情景，不补成行业供需报告 |
| 外汇 | 人民币相对目标货币的增长、通胀、政策、资本流及制度条件 | 不默认对手方只有美元；远期点含利差和融资因素，不当作未来即期预测 |

比较前固定时点、币种、期限、时间尺度和价格／曲线定义。官方汇率、拟合曲线、指数与成交价分别标注；市场实况须采用已得的可比变化；估值／预期判断另给依据，事实不替因果，局部缺价只限制对应结论。这里只解释宏观作用，不计算具体证券、基金或合约的可实现回报。


## 4. 保存、失败回退与完成

有文件能力默认保存到 .hetu/research/china-macro/<独立研究标识>/report.md 与 evidence.md；用户指定位置则遵从。目录标识仅区分任务，已有目录可能覆盖时换新标识，保留旧结果。仅把许可允许、有复核价值的原件存 raw/，不要求下载所有网站。

定稿从最终主要判断及J记录反查实际依赖的周期性经济指标，与evidence.md已有覆盖清单逐项核对。研究中新增、或从背景转为主要判断依据的指标，同样按[研究规则§4.1](research-rules.md#41-历史数据对照)确定频率、窗口和适用比较，补入原清单；初始选定指标不构成其他主要指标的历史表豁免。次要背景数字、一次性政策金额仍按该节范围处理，不扩大为所有数字都制长表。

按清单逐指标、逐期间回到本轮已取得原文及适用表注，提取所选窗口与比较所需输入，再按§4.1计算、制成正文历史表；完整序列未齐时仍展示已得期间及可完成的比较。缺输入按[研究规则§5.2](research-rules.md#52-必要观察的取证与停止条件)区分取得、提取、计算与可比性问题后核查和停止，表旁说明具体缺期、受影响指标及比较。随后从实际正文表格对照上述输入与计算，补入已得未用、漏列和漏算，同步E／J、覆盖清单与缺口；不能仅核已生成的表内数值。不得通过删除重要事实、静默降格为背景或缩短窗口避开要求。历史覆盖不足须明确局部未完成及对核心判断的影响。保存失败完整内联仍包括表格，不以披露缺口冒充完整覆盖。

保存前检查目标；写入失败或无文件能力时如实报告未落盘状态，当前会话完整内联 report 与 evidence 两部分，不只给摘要或不存在的链接。不删除既有文件以掩盖失败。保存失败与取证失败分别说明，完整内联不能把没读到的原文变成已取得。

定稿按[取证规则](research-rules.md#52-必要观察的取证与停止条件)回到原定位和必要摘录，逐项核主要数字、指标名称、政策用途、日期版本、债务财政关系及关键否定性主张。从实际输出的表格回查：按第2节核邻近正文是否已说明完整指标名称与衡量内容，不得仅以另一简称代替全称；适用比较未完成时，核表旁正文是否已交代缺哪期输入、影响哪些指标及比较、已展示哪些范围。遗漏则补齐说明，不以删除指标或省略比较绕过。修正数值、用途或取得状态时，同步对应E/J、正文、覆盖清单及缺口，核已得重要事实是否仍被误列未得。逐项执行该节必要观察回查，不满足时返回对应取证步骤。只修错误及其直接影响，元数据变化不否定旧时点结果。

双向核对：先从主判断核证据是否充分，再从已读原件中足以影响方向、驱动排序、范围、时间尺度或传导强度的重要事实核E→J→正文作用。新事实可以增强原观点，无须强行反转；仅在附录列数字而正文仍作不相容概括，须修正判断。重要事实未采用在对应E／J简述不适用依据，不能将已得未用记为不可得；不登记每个未引用指标，也不按是否符合初步观点挑事实。主要分化须以能区分解释的最小证据约束季度结论，缺证就改变强度或范围，不能只列原因和免责声明后沿用未经支持的单一解释。

充分证据下须实际回答有证问题，不因局部缺口令全篇失去判断。核心问题得到充分证据支持才称研究完成；可交付受限结果，但明确哪些已回答、哪些仍不能判断、最小缺证及对资产情景的约束，文件齐全不构成通过。最终消息提供完整内容或真实可打开的报告及证据位置。

## 5. 关键缺证与商业审批

evidence.md 对关键缺证记录：所需数据／用途／覆盖，实际公开尝试及返回，缺失类别，对核心判断的影响，下一动作。明确指标、地区、频率、历史区间与用途；商业审批段另记候选产品与覆盖依据、已知费用／许可／接入方式、未确认项、推荐与替代、用户决定及允许的具体操作。授权记录不保存凭据。
原件字节、浏览返回、文字摘录、计算转录分别标注；保留必要表头、表注及数值定位。未保存原字节不得称下载原件；关键表格无法可靠核对不得记作取得通过。
报告正文交代实际覆盖与受影响判断。已说明限制、提出采购建议或获准使用，均不等于关键证据已经取得。核心目标仍缺证时保留未完成项；用户明确接受有限范围时准确记录该范围，不称全部能力完整。
