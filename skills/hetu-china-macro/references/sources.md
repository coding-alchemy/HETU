## 2. 具体定位与本次核对

按问题选择以下条目；可以发现新的原发布渠道并核验，不因目录未列而拒绝取证。每条都须读到所用原表和附注，不只读下载说明或摘要。

| 条目 | 具体寻找方法及本次检查 |
| --- | --- |
| S01 | 在月／季度最新发布查国民经济、GDP、工业、零售、投资、就业、收入、CPI／PPI及PMI；数据库按指标与期间查表。核月度／累计、可比价／现价、同比／环比、季调、就业调查覆盖和修订；潜在增长是估计。 |
| S02 | 在调查统计查金融统计、社融增量／存量及结构表、贷款投向、银行家／居民问卷；在政策公告查具体利率、准备金、结构工具决定与操作。核主体、期限、票据、政府债、操作与使用、公布与生效；需要时补资产负债表、财政存款及市场利率。 |
| S03 | 国库统计查月财政收支正文及表注，预算／决算另查正式报告；政府债务栏目查地方债发行、余额、还本付息与用途。核中央／地方、一般公共预算／基金、转移支付及执行，发债不代替实际支出。 |
| S04 | 统计分类查国际收支、结售汇、跨境收付、IIP、外债与储备各自表格和说明；核月／季、初步／正式、流／存量、交易／估值与修订，不能互代。 |
| S05 | 海关查统计快讯、进出口主要商品量值、伙伴与贸易方式；贸易措施回正式公告，必要 WTO 查相关原表。核币种、量价、累计／当期和生效范围；自动获取未验证。 |
| S06 | Fed data 按本问题选政策决定、资产负债、信贷及贷款标准原发布；纽约联储市场操作选公告与实际使用。核频率、更新时间、操作额度／用量与政策生效。 |
| S07 | BEA 查 GDP／收入消费和 PCE 具体发布及修订表；BLS 查 CPI、就业、工资与生产率及方法脚注。注册与额度按说明核实，未实测 API，不以最新值代历史版本。 |
| S08 | TIC 查具体跨境证券流／持仓表，Fiscal Data 查政府债和财政序列说明，利率目录查期限与日期表。核流量／存量／估值、单位、拟合／参考值；访问失败如实记。 |
| S09 | ECB 查正式政策决定、生效日及统计表；Eurostat 按增长、HICP、就业、外部部门检索数据集和发布稿。核欧元区／欧盟范围、季调及版本；API 说明可读不等于调用，最新数据库不提供完整历史初值。 |
| S10 | BOE 查政策决定、数据库序列及曲线文件，ONS 查对应统计发布。核曲线拟合、期限、修订和 Beta API 覆盖。 |
| S11 | BOJ 时序库按利率、汇率、货币与信用查序列，政策／干预回对应机构原文。核频率与制度、JSON／CSV 说明不算实测。 |
| S12 | BIS 按部门杠杆、偿债、跨境信用、有效汇率与全球流动性选数据集及方法。核所在地／合并、借款部门、币种、估值、覆盖与发布滞后；不推算套利仓位。 |
| S13 | IMF／OECD／World Bank 只取问题需要的中国结构或对照表，查具体数据集、版本和方法。区分观测、估计、预测；不以别国数据代中国指标。 |
| S14 | EIA 按代表性能源基准与期间查原序列、单位与说明。注册／许可和 API 实测分别记；只用于宏观价格与供给冲击，不补行业成本报告。 |
| S15 | 政策库、目标部委／政府或海外公告查具体决定全文及附件；贸易与跨境限制核适用范围、公布／实施日期与过渡期。政策库仍为候选，不把动机猜测当官方行为。 |
| S16 | GSCPI 页找具体序列和编制说明，核频率、标准化、修订及覆盖；基线仅框架可读，未取得序列，综合指数不替代航运研究。 |
| S17 | 中国货币网查 LPR、中间价、回购及具体市场品种；中债查相应国债曲线／整体利差产品，股票宽基与代表性商品回原发布方。核曲线期限、拟合／成交／官方参考、指数定义、许可、覆盖与历史期；CFTC 持仓不是净资金流，待定产品不声称已接入。 |
| S18 | 金融监管总局找银行资本／流动性总量；目标地区财政找预算执行、决算、隐债认定、化债及清欠文件；债券原披露找发行、到期、偿还及净融资。核平台范围、贷款／其他融资是否公开、汇总包含关系及权限，不能由有限覆盖推出全国隐债总量。 |

S06–S14、S16 仅为中国问题所需海外参照，不启动全球全景或行业深研。核心资料不可得时仅尝试必要、合规、原发布替代渠道；仍缺则在 evidence.md 与报告同时约束结论。目录记录不自动授予无限抓取或再分发许可。

## 3. 核心用途的实测读取方法

下表记录2026-10-18开发时实际读到的发布类型和可用方法，不是当前研究的数据，也不把开发记录作为运行依赖。每次自行按问题寻找适用版本并读原表；核验日期不是刷新期限，旧时点有效结果不因此过期。年度/季度结构不硬配到当月，方法成功也不代表所有历史期可得。

|观察面|实际可用的发布/查找与读取|定义、频率/历史范围及限制|
|---|---|---|
|C01增长与需求|统计局“国民经济运行”“季度GDP初步核算”“统计公报”，精确题名+官方域检索，再打开所见完整URL；读取生产、需求、表头及核算说明。调查统计司“调查与分析”进入银行家/企业家/储户报告后点击PDF，读末尾历史表与编制说明。|月度工业/社零/固定资产投资与季度GDP/年度需求贡献分开；名义总量和可比价增速不同，GDP净出口不是海关顺差，固定资产投资不是资本形成。调查PDF保留样本及扩散指数方法；目录所列最新一期不证明别处没有新发布。|
|C02就业收入|运行发布查就业、调查失业及企业周工时；住户调查“居民收入和消费支出情况”读城乡、中位数、两张表与附注；金融统计原文另取住户存贷款，储户PDF另取意愿。|就业/工时覆盖按原说明，非全体家庭；住户收支季度抽样、实际增速用对应价格口径。单位工资与住户工资性收入不同。储蓄意愿不是储蓄率，存款不是全部储蓄。居民杠杆/偿债另取明确居民部门数据，BIS私人非金融DSR不能代居民DSR。|
|C03物价及预期|统计局CPI/PPI月发布和同日统计师解读一起读；分项影响取原句，工资取“城镇单位就业人员年平均工资”及官方解读；储户调查PDF物价预期含计算公式。|保留基期轮换、同比/环比、分项分类、工资调查范围；组合贡献不拆成未给出的能源总贡献。物价方向扩散指数不是预期通胀率；无同期限量化预期时，不计算伪前瞻实际利率。|
|C04政策与流动性|央行正式决定/操作公告与《中国货币政策执行报告》分读；报告按目录定位操作、准备金、结构工具及金融市场章节。统计数据→目标年份→货币统计概览→“货币当局资产负债表”，同列htm/pdf可互核，xls为可选取得形态。|政策公布/生效/操作额/余额分别记；资产负债月末存量表须有年月列、单位与脚注，空白不填零；财政存款变动不等于需求支出。回购DR001/DR007是不同期限；报告期均值不能冒充当前日值。|
|C05银行信用|金融统计正文查社融及部门期限/票据；社融增量/存量原表分取；货政报告查政策工具额度、合同、发放和余额、贷款价。金融监管总局统计查“商业银行主要监管指标”“银行业保险业主要监管指标数据情况”及原附件。|社融“其中”不必穷尽，贷款核销不当新增借款现金。NFRA动态页可能只有模板/403，须打开同源PDF/附件或明确注明原来源的完整转载并核样本脚注；只读到摘要不能称原表已核。资本/流动性总量不能推出每家银行无风险；LPR、政策利率和银行间利率分开。|
|C06财政落地|财政部国库统计月财政收支正文分别读一般/基金与中央/地方；年度预算、执行报告和决算另到预算/人大正式原文，不用月执行替预算或决算。政府债务栏目查发行、余额、还本付息及用途；地区回省财政/人大。|可用正文包含月累计及同比；累计差分需同口径相邻期及同比基数，不能相减累计增速。发债/转移/拨付/支出/清欠是连续资金环节；两本预算相加不自动成为净财政脉冲。公开报告存在但未取得数字时仍是缺证。|

## 4. 取得故障与商业候选

缺证原因按[研究规则§5.2](research-rules.md#52-必要观察的取证与停止条件)区分。DNS只说明该工具路径；浏览可读与下载失败可并存。PDF先读表头/行列/单位/表注，文字不可靠时用已获准图像或同源HTML；仍不能核对的数值不采用。检索引用可能错位，回核返回URL、题名、期间；从实际目录/检索所见完整地址查找，不根据数字模式拼造地址，保留失败和成功各自事实。

取得顺序为具体原发布及附件、同一原件的其他官方载体、原来源明确且可核的完整转载。必要观察的继续读取、停止及定稿回查执行[研究规则§5.2](research-rules.md#52-必要观察的取证与停止条件)。资料不可比先核定义、期间、版本和样本，未裁决不拼趋势；故障不直接转成采购理由。

公开资料确实不足且影响核心判断时，按入口规则及报告约定提交具体方案。可查产品原厂公开字段/许可说明，确认地区、频率、历史、分类、兑付事件、版本和导出范围；品牌、营销“全覆盖”、目录或获准使用均不能代替数据已得。公开浏览、研究内部使用、下载、机器处理、API和再分发权限分别核。只有实际授权覆盖的产品/用途/范围/动作才直接复用；未确认则等待具体决定，不自动采购、试用、联系供应商或增加连接器。
