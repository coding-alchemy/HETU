# Markdown 检查点

## 目的与位置

`checkpoint.md` 是 Agent 可读写的轻量任务记忆，不是 Python 状态机。默认位于
`.hetu/research/<证券>-<任务时间>/checkpoint.md`；恢复同一任务时与 `evidence.md` 一起读取。

## 必需内容

- 任务边界：用户输入的候选证券、待核验状态、正式证券及变更原因，`as_of`、数据模式、深度、
  关注点、交付物；逐项标记用户指定或默认来源，并记录默认值已向用户披露。
- 宿主能力：搜索、浏览、PDF、文件、计算、可选原子助手及已知限制。
- 工作包状态：W0–W10 和任何适用官方扩展的当前状态、允许终态与缺口影响。
- 研究摘要：当前关键事实、判断、反证、冲突、未知和失效结论。
- 替代路径：失败类型、已尝试的合法路径、结果、影响及可合法补充的最小条件。
- 用户决定：决定原文、时间、影响和继续后的剩余限制；接受限制不删除缺口或提升置信度。
- 编排与回访摘要：工作包选择、交错或并行、定稿、触发证据、递归重开、不受影响判断和重新定稿。
- 两轮自检摘要：研究自检和安全自检各自的完成标记、发现问题数量、未解决问题与处理结果。
- 下一研究意图：Agent 可修改的近期计划和可能回访包，不是机器下一动作。

## 更新时机

建立候选任务卡、形成正式任务卡、宿主能力变化、工作包状态变化、取得关键证据、出现冲突或缺口、
采用替代、获得用户决定、触发回访、暂停/恢复、进入 W10 及每轮自检后更新。不得为缩短文件删除
原失败、冲突、用户决定、失效结论或来源定位。

## 禁止内容

不得保存或展示隐藏思维链、完整内部推理、自检过程、secret、密码、验证码、个人敏感信息、受限
原始数据或无关材料。不得写入固定阶段游标、自动迁移规则、机器可执行的下一动作指令或由代码
消费的发布许可；“下一研究意图”始终由 Agent 重新判断。
