# W4 业务、治理与资本配置

## 研究目标

解释商业模式、收入和成本驱动，并筛查治理、审计、资本配置及相关基础风险。

## 适用边界

每次研究均适用，可用 `已覆盖`、`部分覆盖`、`无法取得` 或 `存在冲突` 定稿；包内不适用子项
需给出具体经营、会计或交易理由。主要业务与重大事项综合考虑收入、利润、资产、债务、控制权、
经营连续性和监管影响，不设统一收入占比阈值替代判断；收入很小但承担重大担保、债务或关键技术
的主体仍属必须处理范围。直接请求 quick 时本包交付披露的业务构成、股东结构与治理
审计等事实及内部模型适配（避免错算所需的方法识别），不输出经营解释、治理评价或投资判断；
适用方法只列本档指标。standard 追加主要经营、治理与资本动作评价；非核心分部逐项建模、完整
客户供应商网络和逐子公司穿透等深细专题后移到 deep，但本档已采用判断的必要证据不后移。

Standard 按当前主体、主要产品、重大事项和适用法域开展必要深入核验；治理、审计／内控、
控制关系、重大担保、关联交易及债务先筛查，不能由未筛查推成未触发。主要经营解释按核心驱动
选择变量，不机械套量价库存清单；管理层归因与已证原因分开，无法核验的部分保留限制。
产品监管事项的通常核对与条件触发的原件穿透，按[风险资料细则](../../material-risk.md)分别处理；
逐批件、受理号和完整新版说明书不作为 Standard 默认完成门槛。核对正式披露的来源、主体、
产品、法域、人群和阶段，保留重大风险责任，不把发行人披露称为独立药监核验。

## 依赖

开始前要求 W1 已定稿；无跨包定稿前依赖，可与 W2、W3、W5、W8 自由交错。

## 必须回答

- 主要产品或服务、客户价值、收入来源、成本结构和关键经营驱动。
- 控股股东、实际控制、董事会和管理层的关键治理事项。
- 审计意见、会计师变更、内控和影响可靠性的事项。
- 分红、融资、回购、并购、重大投资等资本配置。
- 担保、质押、资金占用、关联交易、重大交易及其他适用风险。

首次识别或修订公司经营模型时读取[公司经营模型规则](../../company-models.md)，在结果文件
“分析判断及事实依据”节形成模型画像，使用固定两列表（`字段 | 内容`），固定行：
主要经营模型、次要模型或适用分部、识别依据、核心经营、会计和监管特征、适用方法、
易误用或不适用方法、输入限制。六类最低模型无法充分解释公司时可用更贴切的自然语言模型，
但填写相同字段并说明与六类最低规则的关系。模型特有必需项在画像定稿后按职责
分配给 W1–W8 的实际 owner，由各 owner 写入自己的必需项表；
W4 本包必需项表只记录本包职责内的项目。W4 在模型画像定稿后按[资料覆盖与时效标准](../../material-coverage.md)补充模型特有要求，并交给实际 owner；不得代写其他包必需项。画像实质变化时按“回访触发”传播。
公司经营模型确实需要行业特定信息时，W4 条件性读取[来源合同](../../source-contracts.md)的适用条目，
负责检索、保存、分析和提交状态；不需要时不为形式完整强行扩展。药企临床登记由 W4 承接，W1 提供
已核验英文名、子公司和历史名称，其他工作包只引用 W4 已提交结果，不重复检索。ClinicalTrials.gov
当前仅适合人工研究：逐条核对 sponsor、collaborator 与 location 的实体关系，并固定披露“登记不等于
监管获批、疗效成立或商业化成功”。

Standard 对重大交易先核基本事实与风险，再按判断用途形成必要证据集合；各用途可同时触发：

| 用途 | 必要证据 |
| --- | --- |
| 重大交易基本事实／风险 | 标的、合并类型、控制关系、阶段、适用金额、付款／融资、承诺与重大风险 |
| 当期收入／利润并表贡献 | 控制权取得日、实际并表日、对应并表期间收入／利润、合并范围变化、可比基数 |
| 对价／商誉／减值 | 适用合并成本、取得净资产份额及计量、商誉勾稽、承诺／减值依据 |
| 实际采用的协同／长期回报主张 | 后续经营表现、可比基准、归因限制；无依据撤回可选主张，重大风险责任仍保留 |

每个实际采用字段仍逐实体绑定原文、日期、范围和口径。合并类型由附注标题层级与实体所在行共同
证明；同控／非同控分别适配，不把非同控商誉字段套所有交易。仅采用收入贡献不强制无关购买价
分摊细目，但已知重大商誉风险独立触发必要核验。标的全年收入不能替代实际并表期间贡献，控制权日
与并表日不同则分别记录；不跨实体串接。W5 负责数值与比较基数核验。

Quick 继续呈现披露事实。旧 Deep 保留以下原并购闭包要求，不适用 Standard 的用途简化：

评价并购贡献、协同、整合或减值风险时，先分别定位“同一控制下企业合并”和
“非同一控制下企业合并”等适用附注，再逐实体建立事实表。每行按适用性核对：标的名称、合并类型、原文定位、
取得控制权或交易完成日期、实际纳入合并财务报表日期、购买日前持股及其计量、标的全年公司数据、
购买日至报告期末的被购买方数据、合并成本、可辨认净资产和商誉，以及直接影响评价的业绩承诺或
减值信息。全年公司数据不能替代购买日至报告期末并表贡献；控制权日与并表日不同则分别记录。
未披露项目保留为缺口，不用另一口径补齐，也不得跨行或跨实体串接合并类型、日期、持股和金额。

在 `evidence.md` 用一组“并购事实闭包”逐项写明：控制权取得日、实际并表日、购买日至期末收入、
购买日至期末净利润、合并成本、取得的可辨认净资产公允价值份额、商誉，以及合并成本、可辨认
净资产和商誉的勾稽关系。每项都附来源原文定位；未披露项明确写“未披露”及其对评价的影响，
不能因文件已下载、主题已提及或其他金额已取得而省略。

每个实体的合并类型必须由附注标题层级与该实体所在行共同证明，并在同一实体记录中绑定日期、
合并成本、可辨认净资产和商誉。任一适用字段缺少原文定位时，该实体的并购核对不得关闭。

## 证据要求

优先使用定期报告、公司章程、审计报告、交易所和监管披露；关键关联关系、金额、期间和口径需
可定位。收入、成本、利润按维度分表核对，不加总重叠维度，不强拼分类断点；股东比较按对象与
股份类别分别核对数量与比例，配股、送股等股本变化同列呈现。发行人评价性陈述单独标识利益
关系。W4 按[公司资料细则](../../material-company.md)核验审计、治理及分部原文，保留自身用途判断。风险资料按[风险资料细则](../../material-risk.md)逐实体、产品、法域和事件核验。

## 主张边界

商业模式说明与竞争优势判断分开；不存在检索结果不能证明不存在担保、质押、占用或关联交易。产品／分部／控制历史按[公司资料细则](../../material-company.md)逐原文对应，不由当前快照回推。产品、HS、报关主体及中间商映射依[经营资料细则](../../material-business.md)提供可证输入，贸易采用由 W3 判断。W4 的客户、履约及领先指标依[经营资料细则](../../material-business.md)分层采用，不把合同或代理直接写成收入／订单／产量。W4 按[风险资料细则](../../material-risk.md)逐案／文号和法域／生效链采用，单法域筛查不当全部风险覆盖。

## 反证与冲突

检查审计保留、监管措施、治理争议、控股股东风险、资本配置失败和口径变化；与 W2 事件或 W5
财务证据冲突时保留冲突并传播影响。

## 缺口与降级

对每个适用风险说明已核对范围；无法取得时记录替代路径、缺口和不能得出的结论，不用“未发现”
替代实际覆盖。Standard 按实际用途保留未满足项，限制对应贡献、商誉或协同主张；重大风险不能因撤回可选主张关闭。旧 Deep 仍按原闭包核验。适用必要证据未完成时按影响标记 `部分覆盖` 或 `存在冲突`，删除或降级未闭合主张，
并重开受影响的 W5、W6、W7、W9 和 W10；这些工作包重新定稿前，W4 不得被 W10 视为已关闭。

## 回访触发

- W2: 公司经营模型变化新增或改变增量披露与重大事件必需项时，原事件核对范围失效。
- W3: 主要经营模型、次要模型或分部范围实质变化时，行业与竞争解释失效。
- W5: 业务口径、审计或重大交易改变财务解释时，财务验证失效。
- W6: 收入成本驱动、治理或资本配置改变前瞻变量时，预测与情景失效。
- W7: 资本结构、治理风险或业务口径改变估值输入时，估值结论失效。
- W8: 公司经营模型变化改变市场状态或股本相关必需项时，市场与交易核对范围失效。
- W9: 新治理、业务或资本配置证据改变核心论点时，论点综合失效。
- W10: 报告遗漏适用风险、审计边界或缺口影响时，报告与自检失效。
