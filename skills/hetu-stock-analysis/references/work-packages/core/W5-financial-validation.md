# W5 财务验证

## 研究目标

验证截至 `as_of` 可得的最新财报与至少三年核心趋势，并解释利润、现金、资产负债和经营驱动。

## 适用边界

每次研究均适用，可用 `已覆盖`、`部分覆盖`、`无法取得` 或 `存在冲突` 定稿。

## 依赖

开始前要求 W1 已定稿。与 W2 共享同一份不晚于 `as_of` 可得的“最新已用披露”，这不是顺序边；
采用或变更基准时必须同步复核 W2 的增量区间。

## 必须回答

- 基准披露的标题、期间、带时区发布时间或仅日期保守判断和可复用定位。
- 最新年度或季度财务，以及至少三年收入、利润、经营现金流和资产负债趋势。
- 收入口径、利润口径、现金流口径、单位、期间和可比性变化。
- 利润与经营现金流关系、明显异常及有证据约束的可能经营驱动。
- 无法解释的异常、未知和它们对预测、估值及论点的限制。

## 证据要求

优先使用定期报告、审计文件、交易所或监管 L0 来源；计算记录输入、单位、期间和公式。仅有
日期且与 `as_of` 同日的披露未获官方时间时，不得假定已经可得。

## 主张边界

数字列表、同比堆砌或技术完成不构成财务分析。可能经营驱动必须受证据约束；无法解释时明确
保留未知，不能编造原因。

## 反证与冲突

检查更正、审计意见、口径变更、合并范围、非经常性项目、现金与利润背离及资产负债异常；
来源冲突时比较版本、期间和口径，不能静默选取有利数字。

## 缺口与降级

合法替代后仍缺少期间或指标时逐项说明缺口、失败原因、趋势不可比性和下游影响；不能以用户
接受限制提高覆盖状态或置信度。

## 产物更新

在 `checkpoint.md` 与 `evidence.md` 记录共享基准、核心趋势、计算、异常、经营驱动、冲突和未知；
报告给出实质解释及不能得出的结论。

## 回访触发

- W2: 更晚披露、财务更正或基准变化时，原增量检索起点失效。
- W6: 财务趋势、现金质量或经营驱动变化时，预测与情景失效。
- W7: 财务输入、资本结构或口径变化时，估值与隐含预期失效。
- W9: 财务证据改变最强支持、反证、未知或失效条件时，论点综合失效。
- W10: 报告未实质解释趋势、利润现金关系、异常或缺口时，报告与自检失效。
