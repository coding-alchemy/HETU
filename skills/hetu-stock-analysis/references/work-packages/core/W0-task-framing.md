# W0 任务界定与约束

## 研究目标

把用户自然语言请求整理为候选任务卡，应用并披露安全默认值；证券核验后再更新为正式任务卡。

## 适用边界

每次研究均适用，只能以 `已覆盖` 定稿。候选证券允许标记为“待核验”，但研究对象、范围或
授权边界不能确定时必须暂停，不能用默认值猜测。

## 依赖

无开始前或定稿前依赖。本包定义其他工作包共同使用的任务边界，但不替代 W1 主体核验。

## 必须回答

- 候选证券及用户原文；证券核验状态、正式证券和任何变更原因。
- 带时区的 `as_of`、数据模式、研究深度、关注点和交付物。
- 当前宿主及搜索、浏览、PDF、文件、计算等能力边界。
- public 或 authorized 的授权范围、许可限制和用户明确授权。
- 每个字段标明“用户指定”或“安全默认”，并向用户可见披露实际默认值。
- 用户未指定时使用 `public`、`standard`、任务发起时点、基础全面覆盖和 Markdown 报告。

## 证据要求

保留用户原始请求、任务发起时间与宿主能力事实。授权只记录范围和许可事实，不记录原始秘密。

## 主张边界

候选任务卡不宣称证券身份已经确认。默认值不得扩大授权、提高结论强度或替用户作出范围选择。
W1 完成唯一核验前，候选任务卡只保留在 Agent 当前上下文，不创建正式研究目录或临时研究目录。

## 反证与冲突

主动检查用户表述中互斥的证券、时点、模式、交付物或授权要求；无法安全裁决时说明影响并暂停。

## 缺口与降级

模式、深度、关注点或交付物等非关键字段缺失时使用安全默认值继续。`as_of` 无效、位于未来，
或证券、范围、授权必须由用户选择时暂停并列出安全选项。

## 二期结果归属

- 固定输出：W1 唯一核验并创建正式研究目录后写入 `work-packages/W0-task-framing.md`，按[工作包结果公共结构](../../work-package-result.md)十二节独立提交。正式目录建立时一并创建 `artifacts/raw|normalized|derived|scripts/` 四类子目录、`manifest.json` 和 W0/W1 工作包文件；其他工作包首次开始时只创建自己的文件。
- 报告章节：1. 任务与时点（首页元数据表与重要声明）。报告记录实际分析模型：宿主实际暴露的模型标识，完整版本或推理深度未暴露时如实标记"未暴露"，不推测。
- 专属事实与判断：任务卡字段及来源、安全默认值披露、宿主能力与授权边界。
- 边界与自检输入：任务边界、时点或授权变化时按回访映射重开受影响工作包。
- 跨包内容：本包不产生业务事实；行业、财务与行情内容分别引用 W3、W5、W8 等实际 owner 的已提交结果。

二期实测运行的候选任务卡必须逐字包含以下提示，并保持其在 W0 文件中可见：

> **保留中间脚本：** 本次运行用于二期质量加固实测。凡为生成报告而创建或修改的采集、解析、
> 清洗、计算、校验、修复或补采脚本，均须把实际执行版本和失败版本保存到
> `artifacts/scripts/<work-package-id>/`，并在 `manifest.json` 登记用途、安全调用方式、输入输出、
> 环境与依赖、退出状态和哈希；不得删除、静默覆盖或只保留最终数据。保留不代表批准接入
> canonical Skill。

## 产物更新

主体核验前不落盘，候选任务卡、字段来源、默认披露、宿主能力和下一研究意图保留在 Agent 当前
上下文；W1 唯一核验后创建正式研究目录，并把 W0 候选任务、正式任务卡及变更原因一次写入
`checkpoint.md`、`manifest.json` 和 W0/W1 文件。恢复同一任务使用原目录，独立重试使用新的任务时间。

## 回访触发

- W1: 候选证券、范围或授权变化时，原主体核验失效。
- W2: `as_of`、模式或证券变化时，原增量检索区间失效。
- W3: 证券或关注点变化时，原行业与竞争范围可能失效。
- W4: 证券、范围或关注点变化时，原业务治理覆盖可能失效。
- W5: `as_of`、证券、模式或深度变化时，原财务基准与覆盖可能失效。
- W6: `as_of`、深度或关注点变化时，原预测与情景边界可能失效。
- W7: `as_of`、深度或交付边界变化时，原估值口径可能失效。
- W8: `as_of` 或证券变化时，原市场数据时点可能失效。
- W9: 任务边界变化时，原论点、反证与监控综合可能失效。
- W10: 任务边界或交付物变化时，原报告与自检结论失效。
