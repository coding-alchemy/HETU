# W2 增量披露与重大事件

## 研究目标

从与 W5 共用的最新已用披露基准起，检查截至 `as_of` 的公告、监管、诉讼和重大公司事件。

## 适用边界

每次研究均适用，可用 `已覆盖`、`部分覆盖`、`无法取得` 或 `存在冲突` 定稿；任何受限终态都
必须传播缺口和影响。

## 依赖

开始前要求 W1 已定稿。与 W5 共享同一份不晚于 `as_of` 可得的“最新已用披露”，这不是顺序边；
二者可以交错，但定稿时必须引用相同基准。

## 必须回答

- 基准披露的标题、报告期间、带时区发布时间或仅日期的保守判断、链接或文档定位。
- 基准之后至 `as_of` 的检索起止区间、覆盖渠道及无法覆盖的空档。
- 区间内公告、监管问询或处罚、诉讼仲裁、重大交易、资本动作及其他重大事件。
- 事件对业务、财务、预测、估值、市场状态和核心论点的影响。

## 证据要求

优先使用发行人、交易所和监管 L0 来源；关键事实记录事件时间、发布时间、采集时间和 `as_of`。
搜索片段只作线索。仅有日期且与 `as_of` 同日时，未获官方时间不得假定已经可得。

## 主张边界

`as_of` 后发布的材料不能补写时点内结论。公告缺失、搜索无结果或完成查询不能证明没有事件。

## 反证与冲突

检查更正、补充、撤回、不同版本和监管口径；重大事件说法冲突时比较时间、版本、范围和原始
生产者，无法裁决则保留冲突并收缩结论。

## 缺口与降级

网页、PDF 或工具失败时判断原因并至少尝试一种合法替代路径。仍失败则记录未取得项、失败类型、
已尝试路径、区间空档、结论影响和用户可合法补充的最小条件。

## 运行质量规则

记录检索起止日期、每个连续覆盖分段及其分页闭合结论。发现日期空档时先自动补查；仍不能闭合则以
`部分覆盖` 定稿，并把空档、失败原因和结论影响向全部受影响下游传播。

所有连续分段闭合后，把各段公告按稳定身份去重，形成唯一公告并集，并记录各段原始数量、重复数量
和公告并集总数。后续风险扫描、重大事件逐项核对、checkpoint 数量和报告覆盖说明必须使用
同一公告并集，不得只使用某个子窗口、旧索引或分段数量的简单口头汇总。

定稿前必须同时写明各段原始数量、跨段重复数量、去重后并集数量，以及风险扫描输入所指向的同一
公告并集；缺少任一项时不得宣称公告并集或风险扫描已经闭合。

## 二期结果归属

- 固定输出：`work-packages/W2-incremental-events.md`，按[工作包结果公共结构](../../work-package-result.md)十二节独立提交。
- 报告章节：4、8、9、11；基准日后重大事件进入第 4 章，影响市场与论点的增量进入第 8、9 章，筛查完整性进入第 11 章。
- 专属事实与判断：基准日至 `as_of` 的增量披露与重大事件事实；与 W5 共享最新已用披露基准。
- 边界与自检输入：检索窗口与分页完整性结论是下游时点判断的边界输入。
- 跨包内容：治理历史引用 W4、市场信号引用 W8 的已提交结果或请求回访，不得复制并取代。

## 产物更新

在 `checkpoint.md` 记录共享基准、覆盖区间、工作包状态和影响传播；在 `evidence.md` 记录事件
及来源；报告披露重大事件、空档和受影响结论。

## 回访触发

- W5: 出现更晚合格披露、财务更正或改变报告基准的事件时，财务验证失效。
- W6: 重大经营、监管或资本事件改变前瞻变量时，预测与情景失效。
- W7: 事件改变估值输入、方法适用性或基准日期时，估值结论失效。
- W8: 停复牌、股本变化或重大市场事件出现时，市场状态失效。
- W9: 新增支持、反证、未知或失效条件时，论点综合失效。
- W10: 报告遗漏新事件、区间空档或影响传播时，报告与自检失效。
