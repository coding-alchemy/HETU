# 资料覆盖与时效标准

## 读取与职责

W1 唯一核验后形成共通底线、请求深度及特殊状态必需项时读取本文；W4 形成经营模型后补模型特有内容。W1–W8 选择具体资料时只读取相关用途细则和来源合同，启动时不加载全部细则。公司披露、官方状态、业务与历史关系按需读取[公司资料细则](material-company.md)。经营、竞争、贸易和领先指标按需读取[经营资料细则](material-business.md)。研发、司法、跨境及债务按需读取[风险资料细则](material-risk.md)。市场、融券、指引及历史输入按需读取[市场资料细则](material-market.md)。W9/W10 消费实际 owner 最新定稿，不代造上游资料。

## 每个必需问题要明确什么

owner 在现有十二节及五列必需项表内说明：问题、要求来源、正文／表／附件、主体、期间、范围、单位、原文等级、生产链与独立验证、历史长度、新鲜度、合法首选及等价替代、投入依据、满足条件及不能得出的结论。本文只定义规则，不保存运行状态；manifest 只登记文件与输入采用，checkpoint 只保存质量摘要。

## 深度与投入

三档下界及模型按[报告指引](report-guidance.md)、[公司模型](company-models.md)和[研究质量规则](research-quality.md)。quick 包含主体状态、核心业务、最新财务、近期公告、股本行情、基础估值输入、支持、反证、未知、验证点和缺口。standard 追加控制关系、驱动、行业竞争、治理审计、资本配置、调整后多年财务及最新一期、情景与监控。deep 追加更长历史、完整年报与重要附注、分部产业链、更多独立来源、资本配置效果、敏感性、估值交叉及更细证伪条件；历史起点按周期、重大变化或方法说明，不虚构统一年数。

standard 保留非重复有效事实 ≥8，每项可回溯定位；序列 ≥5 组，含跨 ≥4 报告期且含最新季报的多指标财务主表；计算 ≥4，至少含一组估值倍数和一组三情景表；重要事件 ≥3，带日期或公告定位；反证 ≥5，明确列示并优先绑定监控／失效条件；监控 ≥6，表格含阈值、窗口、复查动作。报告指引原配套条件不变，不编造凑数，不把现有监控扩成完整监控。deep 全量继承上述 standard 数量下界及配套条件（非重复有效事实 ≥8、序列 ≥5、计算 ≥4、重要事件 ≥3、反证 ≥5、监控 ≥6），形成 deep 档必需项时逐项保留，不得因 deep 追加要求而省略或降低。

投入按用途、准备／收尾、失败及替代估算，继承 quick／standard／deep 外部调用 120／120／260、同类重试 3、并行度 3。不新增付费授权，不承诺实时精确计数、费用观测或请求内硬截断；时间目标超出仍继续必要研究，观测未知如实保留。

## 正文、附注与最新披露

找到文件、取得正文、取得本用途所需表／附注和完成分析分别判断。owner 核对目录与实际页级内容；文件存在或主表齐全不代表审计、分部或调整附注齐全。已知截至 as_of 有较新合格披露但未取得时，旧趋势不能满足最新财务用途；最后已得时点和缺的最新内容仍记入必需项及不能得出的结论。

年度与适用中期／季度资料用截至 as_of 最新合法披露；可比序列用当时最新正式调整后的列，并保留原列标题、合并／单体、期间和单位。事后更正值不作为旧 PIT 内容。部分补齐只改变内容实际满足的用途，不升级整份报告。

## 原文、等价替代与限定检索

事实原文和规定范围的检索是不同满足目标。需要监管／发行人正式原文的项目，L2 转述不能替代。替代取得须证明同一用途的主体、期间、范围、单位、时点、原文及独立性要求，不按网站或成功次数升级。

无只用于核验有界范围内不存在，且对象／已证别名、渠道、窗口、分页与总数、分段并集、查询词、正文及适用附件覆盖完整。标题层零命中、HTTP 404／403、WAF 或未闭合分页不能证明无风险；有标题命中却无正文仍待核实。未发现不满足，未抽取／定位不能改写为公司未披露；影响质量的否定结论须核对 owner 当前 adopted 产物主题词及同义词的全部命中。

## 按数据域判断时效

| 数据域 | 满足时点／覆盖的依据 |
|---|---|
| 公告及监管 | 最新已用基准至 as_of 的分段并集、分页、正文与重要附件 |
| 上市及交易状态 | 正式文件生效、后续变更与截至 as_of 的核验覆盖 |
| 行情及股本 | as_of 前当日或最近交易日的观测，价格时点与股本基准对齐 |
| 财务审计 | 截至 as_of 最新合法披露年度及适用中期／季度，附注按用途完整 |
| 行业及代理 | 原生产者发布日历、统计期、区域、方法，逐指标取最新适用版 |
| 登记司法制裁债务 | 登记／生效、修订、撤名、到期或兑付链及查询窗口 |
| 指引共识及历史估值 | 当时可得截面、成分、修订，价格股本和披露基准匹配 |

每用途记录更新日历、当前应覆盖期、新鲜度满足阈值、可接受延迟及实际依据；默认阈值为截至as_of最新已合法发布且满足用途的版本。官方／许可约定延迟或事件生效覆盖另有要求时按原机制解释；尚未到发布日不把未来期当缺失，已发布但未取得则未满足，不虚构统一天数。历史范围按周期、重大变化或方法说明，standard跨≥4报告期及最新季报下界保持。五类时间及同日只有日期的保守规则遵循[证据规则](evidence-rules.md)；晚于 as_of 的内容不能进入时点内采用。窗口断档、最新披露缺失、过期或历史版本不可证明，保留具体未满足用途，不追溯使旧时点结果失效。
