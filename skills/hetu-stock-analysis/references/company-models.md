# 公司经营模型规则

本规则是按需读取的 Prompt 资源，不保存运行状态。Agent 在 W4 首次识别或修订公司经营模型时读取；
W5–W7 需要核对方法与模型边界时回读。启动时不读取本规则。

## 读取时机与职责

- W4 首次形成或实质修订公司经营模型画像时读取本规则，用于识别主要经营模型、次要模型或分部差异，
  并补充模型特有的必需资料。
- W5、W6、W7 选择或复核方法时读取 W4 最新模型画像；需要核对某方法的适用边界或典型误用时回读
  本规则。
- 本规则只提供判断框架和方法边界，不给出任何公司的模型结论；识别结果由 Agent 基于证据判断。

## 输入与 W4 输出

输入：W1 核验后的主体与特殊状态、当前可得的 W3 行业证据、W4 已取得的业务、会计和监管事实。

W4 在工作包文件“分析判断及事实依据”节形成模型画像，使用固定两列表（`字段 | 内容`），固定行：

| 字段 | 内容 |
| --- | --- |
| 主要经营模型 | 对公司整体解释力最高的模型 |
| 次要模型或适用分部 | 仅在确有第二驱动或分部差异时填写；没有时写“无”及依据 |
| 识别依据 | 业务、收入成本、资产负债、现金流、生命周期和监管事实定位 |
| 核心经营、会计和监管特征 | 决定指标与方法选择的事实 |
| 适用方法 | 当前公司或分部适用的指标、预测变量、可比对象和估值方法 |
| 易误用或不适用方法 | 容易产生误导的方法及原因 |
| 输入限制 | 方法仍缺少的关键输入及影响 |

模型画像是 Agent 基于证据形成的研究判断，不是 Python 输出。六类模型无法充分解释公司时，Agent
可以使用更贴切的自然语言模型，但仍须填写相同字段，并说明它与六类最低规则的关系。

## 六类最低模型

六类是最低覆盖，不是封闭行业枚举；表中指标是选择依据，不是每家公司必须机械填满的固定清单。

| 模型 | 识别事实与特有资料 | 适用方法方向 | 典型误用 |
| --- | --- | --- | --- |
| 金融 | 利差、保费或手续费驱动，资产质量、负债成本、监管资本和偿付约束 | 按银行、保险、券商实际业务选择净息差、资产质量、资本充足、偿付能力、ROE、PB 等 | 把金融负债当普通工业净负债，机械套用工业自由现金流或统一 PE |
| 周期 | 产品价格、库存、产能、成本曲线、开工率、资本开支和周期位置 | 使用中周期盈利、成本曲线、产能与价格情景及适用的资产或企业价值参照 | 把当前高价、高利润或低库存永久外推 |
| 重研发 | 研发管线、技术节点、商业化里程碑、现金消耗、融资和稀释 | 使用里程碑、成功概率、现金跑道和受限情景；盈利后再选择相应估值 | 对未盈利或早期项目机械使用 PE，线性外推收入和利润 |
| 平台或订阅 | 用户、留存、ARPU、付费转化、抽佣率、获客成本和单位经济 | 使用留存、队列、单位经济、收入质量和平台变现变量 | 把 GMV 当收入、把用户增长直接当利润增长 |
| 资产或资本密集 | 资产寿命、利用率、维护和扩张资本开支、杠杆、资产质量 | 使用资本回报、资产质量、利用率、维护性现金流、NAV 或适用 DCF | 忽略维护资本开支、负债和资产减值，只看表面利润 |
| 混合业务 | 两个及以上分部具有不同驱动、会计或监管约束 | 分部选择方法；输入足够时使用分部参照或 SOTP，并说明汇总限制 | 用最容易分析的分部或一种指标代替整家公司 |

金融模型内部仍须区分银行、保险和券商；平台与订阅、资产与资本密集也须按实际业务取舍。不得把
大类名称直接变成结论。

## 混合业务与分部

识别为混合业务时，必须逐分部确认驱动、会计和监管差异，并逐分部选择适用方法；不能用一个模型
或一种指标代替整家公司。输入足够时使用分部参照或 SOTP，并说明汇总限制；分部资料不足时按分部
记录缺口和不能得出的结论，不汇总成单一确定结论。

## 方法选择、排除与输入不足

W5、W6、W7 对每项主要方法分别记录使用或排除理由、所需输入、实际输入、适用分部和限制：

1. 适用方法且关键输入充分：保留结果。
2. 适用方法但关键输入不足：不输出该方法结果，记录对实际深度和结论的限制。
3. 方法本身不适用：不输出结果，说明不适用依据；若有适用替代且足以回答问题，分析仍可标为
   “有效”。
4. 已使用的方法后来被证明不适用：删除该方法及所有受影响结论，重开 owner 和下游；不能只在
   报告旁加一句风险提示后继续交付。

## 证据、回访与禁止事项

- 模型识别和修订必须绑定 W1、W3、W4 的事实证据；证据变化时按 W4 回访规则传播。
- 主要模型、次要模型、分部范围或方法边界发生实质变化时，W4 至少重开 W3、W5、W6、W7、W9、
  W10；变化新增或改变 W2、W8 的必需项时，也重开实际受影响的 owner。
- 模型由 Agent 根据证据判断，不得由 Python 行业枚举、关键词分支或固定行业分类器接管。
