# 研发投入强度

标识 `rd_intensity`，定义版本 1。来源为《A股日线量化策略全景分析》§4.5。观察对象为单只证券，按所选交易日计算，结果单位为比例。

## 介绍、公式与口径

可比单季营业收入、归母净利分别与上年同季比较（本期−同期）/绝对值(同期)，同期为零给缺口，负基数标记；同一截止时点、同币种和范围下按未来两个相邻财年一致预期净利作同式增长比较；近四季研发投入/营业收入，披露口径和资本化范围随档。

使用本次所选信息截止时已知的版本，默认截止为所选交易日北京时间 15:00。所需事实表为 financial_reports。工作台显示本次实际参数；默认参数为 `{}`。

## 教学演算与易误读之处

四季研发投入累计终值 6、同期营业收入 50，得 .12，保留含资本化支出的披露口径

边界对照为 企业仅明示费用化研发 4、缺完整投入口径时标出具体缺口

## 代码、逻辑自测和效果

实际 Python 函数为 `hetu_quant.factors.statements.rd_intensity`。证据中的实际输入、组件和结果可随教学样例复算。真实源缺少表、期间或可知字段时按本次计算显示具体缺口。该读数可作为未来同类对象相对同期基准研究的候选解释量，目前效果未验证，证据引用为空。
