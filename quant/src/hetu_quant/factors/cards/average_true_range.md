# 平均真实波幅

标识 `average_true_range`，定义版本 1。来源为《A股日线量化策略全景分析》§4.1、4.8、4.12、§5.1。观察对象为个股、ETF、组合，按所选交易日计算，结果单位为元/股。

## 介绍、公式与口径

ATR 取最近 n 日 max(高−低、abs(高−前收)、abs(低−前收)) 的算术平均，OHLC 用可比价格尺度。实现波动复用 `realized_volatility`。给定组合收益序列计算波动后取 min(1,目标波动／(估计波动+ε))；ETF 正得分／(自身波动+ε)、策略风险预算／自身波动分别输出未归一比例。ε、单位、现金／上限与归一选择在示例中固定，因子库不产生委托。

使用本次所选信息截止时已知的版本，默认截止为所选交易日北京时间 15:00。所需事实表为 daily_bars、calendar、security_status。工作台显示本次实际参数；默认参数为 `{"window": 2}`。

## 教学演算与易误读之处

前收 9，首日高 12、低 10、收 11；次日高 11.5、低 10.5，真实波幅 3 与 1，ATR₂=2；首日前收改 11 后第一个波幅改 2，ATR₂=1.5。

已执行的公式反例为 复算时按测试修改 `daily_bars` 的原始记录，期望读数为 `1.5`。
