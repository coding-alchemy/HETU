# 配对价差

标识 `pair_spread`，定义版本 1。来源为《A股日线量化策略全景分析》§4.4。观察对象为两只证券（有序），按所选交易日计算，结果单位为对数价差。

## 介绍、公式与口径

两腿 N 对同步日收益的相关系数复用后表的滚动收益相关。以截至 T−1 的 N 对对数收盘估计含截距 OLS，输出 β 和辅助截距 α。当日价差为 log A−α−β log B，在同一固定 α、β 下按训练窗残差均值和样本标准差标准化。

使用本次所选信息截止时已知的版本，默认截止为所选交易日北京时间 15:00。所需事实表为 daily_bars、calendar、security_status。工作台显示本次实际参数；默认参数为 `{"window": 4}`。
