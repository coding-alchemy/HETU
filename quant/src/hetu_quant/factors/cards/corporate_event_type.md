# 公司事项类型

标识 `corporate_event_type`，定义版本 1。来源为《A股日线量化策略全景分析》§4.9。观察对象为个股、事件，按所选交易日计算，结果单位为类别。

## 介绍、公式与口径

提取当时原件确认的事项类型及阶段。历史成功率按固定同类队列中截至 T 已成功数／已知终局数估计，列观察区间、成功定义、未决数，终局不全不补成失败。估值影响的可复算代理为已披露交易对价或合同金额／披露前市值，类别和币种单列；金额占比本身不代表公允估值或利润增幅。

使用本次所选信息截止时已知的版本，默认截止为所选交易日北京时间 15:00。所需事实表为 events。工作台显示本次实际参数；默认参数为 `{}`。

## 教学演算与易误读之处

匹配原件“重大合同／已签署”，显示两项类别；同一事项上一个截止的“洽谈中”保留当时阶段，未确认的类型报缺口。

已执行的公式反例为 复算时按测试修改 `events` 的原始记录，期望读数为 `重大合同／洽谈中`。
