# 宏观基本面分析理论指南

> 文档版本：v1.0
> 文档性质：理论指引与来源参考
> 创建／修订日期：2026-10-18／2026-10-18
> 适用范围：全球与中国宏观基本面，及其对股票、债券、商品、外汇的影响

## 1. 研究对象与分析思路

宏观分析回答：**经济处于什么状态，哪些因素正在改变增长、通胀、政策和金融条件，这些变化通过什么路径影响股票、债券、商品和外汇，证据与反证是什么。**

中国宏观以中国经济及其内部传导为重点；全球宏观以全球共同驱动、主要经济体差异和跨境传导为重点。全球多资产是宏观影响的观察范围，不要求展开每家公司、每只债券、每个商品品种或具体交易合约。一次研究按问题选择核心因素，不以因素数量或材料覆盖率作为完成标准。

### 1.1 分析范围

核心内容包括增长、通胀、货币政策、信用、财政、外部收支、宏观冲击与预期，汇总各因素的观察指标、影响条件、传导关联和原始来源。研究使用共同宏观问题组织分析，并按经济体的制度、融资结构和政策工具选择具体指标。

公司经营、财报识伪、公司治理、法律尽调、企业资本配置与个股估值不在范围内；也不开展单券契约与偿付顺位、具体期货交割／展期、基金穿透或持仓损益分析。宏观解释所需的币种、期限和价格口径仍需明确。

外部材料用于定位研究线索；具体数字、时点判断和政策动机须核对原始证据，只采用与当前宏观问题有关的内容。

### 1.2 宏观与行业的分析边界

- **工业金属与关键矿产：** 宏观可观察代表性价格和贸易变化作为需求或通胀线索；矿山产量、品位、加工费、库存和替代材料研究归行业研究。
- **农产品、食品与养殖：** 宏观关注食品价格对 CPI、居民购买力与政策的影响；种植、天气对单产的影响、饲料、存栏和生物周期归行业研究。
- **航运与供应链：** 宏观可使用运价或供应链压力指数解释总量供给冲击；航线运力、港口、船型、交付、船队和运价形成机制归行业研究。
- **能源：** 宏观关注能源价格冲击对通胀、贸易条件和政策的作用；油气煤电的产能、库存、成本和供给细节归行业研究。

宏观研究可以直接读取这些价格或指数，不必先完成行业分析。若没有证据辨别涨价原因，应保留“需求／供给原因未确定”，分析条件情景，不自行补成行业结论。单一铜价、油价或运价也不能单独证明整个经济周期。

## 2. 通用宏观因素

以下通用因素用于组织研究，不要求每次全部展开；第 3–4 章说明中国及其他经济体的制度差异。影响均为有条件的机制，不是固定涨跌规则。A 编号用于关联，S 编号对应第 8 章。各经济体使用当地定义，保留统计范围和口径差异；中国社融、美国 PCE 等不能直接套到其他地区。

## 3. 中国宏观的制度与传导

中国宏观既要分析增长、就业收入、消费、通胀和长期结构，也要辨别财政、地产、银行与汇率制度如何改变这些变量之间的关系。以下五组机制是通用因素在中国的具体表现，不作为额外原因重复计数。

| 制度与观察面 | 主要指标与事实 | 宏观机制与分辨 | 关联因素 | 来源 |
| --- | --- | --- | --- | --- |
| 银行信用与政策性融资 | 社融结构、居民／企业贷款及期限、政府债融资、票据、政策性金融和结构性工具使用、政策利率／LPR／银行间利率、银行体系资本与流动性总量 | 区分政府融资与私人需求、短期周转与长期投资、信贷供给与借款意愿；观察政策是否形成有效信用扩张及金融压力 | A03、A06、A08–A11 | S02、S17–S18；政策性金融机构公开总量资料为补充候选 |
| 中央地方财政与实际执行 | 中央／地方收支、转移支付、一般公共预算、政府性基金、国债和地方专项债资金用途及实际支出 | 判断地方财政空间与实际需求增量；发债、拨付、支出、偿债和清欠分开，不重复计算同一笔资金 | A01、A08、A12–A13 | S03、S15、S18 |
| 地方债、城投融资与化债 | 地方政府一般债／专项债余额与偿债、城投债到期及净融资、公开可核实的平台贷款及其他融资、置换／展期与清欠安排、区域融资成本 | 偿债与再融资影响地方可支配财力、公共投资、企业回款及银行信用；缓解流动性不等于债务实际减少 | A09–A13 | S03、S17–S18；财政及公开发行、存续债券披露汇总 |
| 房地产、土地财政与资产负债表 | 住房销售与价格、交付与投资、土地出让收入、居民按揭及房地产融资总量 | 通过住房财富、居民支出、地方收入、投资和银行资产质量传导；仅分析总量，不做房企估值或项目供需 | A01–A02、A09–A12 | S01–S03、S18 |
| 人民币制度与跨境资金 | 国际收支、结售汇、跨境收付款、国际投资头寸、外债、中间价及境内外汇率、跨境融资与资本流动政策 | 汇率、资本流与政策空间相互影响；比较两侧基本面及政策，贸易顺差不等于同步结汇或资本净流入 | A14–A16 | S02、S04、S12、S15、S17 |

地方或行业资料在这里用于解释总量状态与区域分化，不自动延伸到逐省全覆盖、房企估值、项目供需或单一平台信用评级。

### 3.1 地方债务与财政的口径

城投债仅指地方融资平台发行的债券，是平台融资的一部分；城投债、平台全部融资、地方政府债和政府隐性债务不是同一口径，不得直接相加或相互代替。

平台贷款和其他融资只在公开可核实范围内使用；隐性债务须按权威认定和披露口径识别，不能因平台身份推定其全部债务属于隐性债务或均由政府偿还。

余额、当期发行、净融资、到期量和偿还额分别记录。置换、展期、利率下降及清欠须分别说明改变了债务主体、期限、成本、现金流还是债务总额，避免把旧债置换当成同额新增需求。

财政预算、执行、决算和中央／地方口径分别保留；一般公共预算与政府性基金、转移支付和实际支出按资金关系核对，不能将发债到支出的连续环节重复计作刺激。

公开数据不足以覆盖全部平台、融资方式或地区时，说明覆盖范围、未取得项及可核验压力指标，不制造精确总额。城投研究落在地方财政、区域融资与金融稳定，不替代单券或平台信用评级。

### 3.2 中国关键传导链与反证

| 起点 | 需要解释的路径 | 关键条件与反证观察 |
| --- | --- | --- |
| 地方债务与化债 | 到期／再融资压力→可支配财力与银行信用→公共投资、清欠及企业回款→总需求 | 成本或期限改善是否伴随实际支出、回款改善；债务置换本身不能证明增长增量 |
| 房地产变化 | 住房销售／价格／交付→居民财富与按揭、土地收入→消费、地方支出、投资及银行资产质量 | 住房、居民支出与财政执行须分别验证；价格稳定不保证交易和投资恢复 |
| 财政发力 | 预算与融资→拨付和用途→实际支出／偿债／清欠→需求及债券供给 | 区分用途与执行进度；融资扩张但支出未落地时保留传导缺口 |
| 货币信用变化 | 政策及市场利率→银行供给与借款意愿→融资结构→私人支出及物价 | 社融由政府债或短期融资驱动时，不能直接推出私人投资复苏 |
| 外部与人民币变化 | 两侧增长／政策和贸易条件→汇率及跨境融资→进口价格、需求和国内政策空间 | 结售汇、收付款与国际收支分别核对；资本流、干预和风险溢价可改变方向 |

每条主要关系注明经济机制、成立条件、时间尺度、证据、替代解释和下一观察点。区分传导、共同驱动及反馈；同一冲击在贷款、物价和汇率中出现，不重复归因。

## 4. 全球联系与经济体差异

全球宏观同时观察共同驱动与相对差异：全球需求、能源冲击和美元融资可能同时影响多个经济体，各国增长、政策及外部收支的差异又会改变利差、汇率和资本流向。全球包含中国，研究范围按问题确定，不需要每次遍历所有经济体。

| 地区 | 需要辨别的宏观机制 | 因素／来源 |
| --- | --- | --- |
| 美国 | 美元国际融资地位；财政发债、国库现金与 Fed 流动性相互作用；资本市场融资和固定利率住房贷款改变政策传导 | A06–A10、A12–A13、A16；S06–S08、S12 |
| 欧元区 | 统一货币政策与成员国财政分立；主权利差、银行持债及信贷条件反馈；区内金融条件分化 | A06–A07、A09–A13；S09、S12–S13 |
| 日本 | 国债供给与央行操作、债券市场流动性、工资物价传导、日元融资与进口成本 | A02、A04、A06–A08、A13、A15–A16；S11–S13 |
| 中国 | 内需及进口影响全球需求与商品价格，出口影响全球贸易和价格，人民币及资金流形成跨境反馈 | A01、A04、A14–A18；S01–S05、S12–S13、S17 |
| 英国及其他目标经济体 | 按问题识别财政与金融结构、外币债务、资源依赖、汇率制度和政策空间，不照搬其他经济体机制 | A06–A18；S10、S12–S13 及当地原发布方 |

中国城投与地方债务只在有可定位证据表明其对全球需求、跨境融资或风险偏好产生显著外溢时展开，说明“中国内部变化 → 外溢渠道 → 全球影响”，不默认每份全球报告都研究城投。

展开时仍须区分城投债、平台全部融资、地方政府债与政府隐性债务，不能直接相加或推定全部由政府偿还；公开资料不足时说明覆盖范围，不制造精确全量。中国本土制度的详细分析见第 3 章；在全球问题中按外溢渠道选择必要证据。

## 5. 传导关系与跨资产影响

### 5.1 核心传导链

| 起点 | 传导路径 | 必要分辨 |
| --- | --- | --- |
| 需求走弱 | 支出／就业→物价压力→政策预期→利率、风险溢价与汇率 | 盈利预期下降与折现率下降可能同时发生，净效果需分资产 |
| 供给冲击 | 能源／食品／运输成本→通胀及实际购买力→政策与贸易条件 | 暂时价格冲击和持续核心通胀不同；冲击来源未证时保留情景 |
| 信用扩张或收缩 | 融资条件→私人支出→增长／物价→偿债与再融资 | 贷款供给、借款意愿和政府融资需分别观察 |
| 财政变化 | 预算执行／融资→总需求与债券供给→增长、曲线和私人部门融资 | 财政支出与举债不重复算作两次刺激，偿债也不直接等于新增需求 |
| 相对政策变化 | 两侧政策路径→利差／融资条件→汇率与跨境流动→进口价格及外部收支 | 预期、风险溢价、资本管制与干预可能改变方向 |
| 融资压力 | 融资成本／抵押约束→去杠杆→市场价格→金融条件反馈 | 有限公开数据不能精确还原全球仓位或断言每次出售原因 |

每条关系说明起点、终点、经济机制、成立条件、时间尺度、支持证据和替代解释。区分传导、共同驱动、统计关系及反馈；同一冲击在物价、利率和汇率中出现，不当成三个独立原因重复计数。

### 5.2 跨资产观察保持在宏观层

| 资产类别 | 研究落点 | 典型分化 |
| --- | --- | --- |
| 股票 | 宽基市场的总量盈利预期、折现率、风险溢价及金融条件 | 需求走弱压低盈利预期，降息可能降低折现率；不直接推出指数一定上涨或下跌 |
| 债券 | 主权收益率曲线、实际利率、期限溢价、总量信用利差与债券供给 | 无风险曲线下降时信用利差仍可能扩大；不代替单只债券信用与条款研究 |
| 商品 | 代表性价格／指数反映的总需求、通胀、美元和宏观供给冲击；黄金的实际利率、储备与避险渠道 | 需求冲击与供给冲击可产生不同方向；具体品种价格形成归行业研究 |
| 外汇 | 双边相对基本面、政策路径、外部融资、资本流和汇率制度 | 同一增长数据对不同货币对的意义不同；远期点包含利差与融资条件，不能当未来即期预测 |

比较前固定经济体、时点、币种、时间尺度及市场指标定义。股票与债券的相关性可随增长或通胀冲击改变，不设永久对冲关系。官方汇率、拟合收益率曲线、价格指数和实际成交价格分别标注；这里解释宏观作用，不计算具体工具的可实现投资回报。

## 6. 证据、时点与归因

### 6.1 记录一条宏观观察

| 内容 | 记录要求 |
| --- | --- |
| 研究对象 | 经济体／货币区、宏观问题、分析时点、时间尺度与相关资产类别 |
| 指标 | 定义、数值、单位、观察期、同比／环比、实际／名义、季调、统计覆盖 |
| 时间与版本 | 首次公开、修订公开、获取时间；预测与实绩分别标注 |
| 影响与关联 | 作用路径、方向条件、可能滞后、共同驱动与反馈，避免重复归因 |
| 预期与反证 | 已有事前预期及来源、实际变化、替代解释、使判断改变的观察项 |
| 证据 | 机构、具体原文／表格／序列链接、计算口径、冲突、未取得项及结论限制 |

引用材料区分事实、计算、假设和解释。优先回到统计或政策原文；多网站转载同一数据只算一个底层来源。数据冲突先核对定义、期间、单位、季调和修订，不盲目平均。新日期或版本本身不使旧时点的有效结果失效，只对有直接语义影响的结论做必要复查。

### 6.2 从观测到解释

指标的水平、变化方向、变化速度和相对预期是不同问题。总量改善可能来自基数、价格或统计修订，不能仅凭同比转正判断需求已经恢复；真实改善也可能弱于事前预期。事前资料缺失时可以分析实际变化，但不能补造市场共识。

市场价格既反映对增长、政策与风险的预期，也会反过来改变融资和支出条件。价格与宏观指标同向不能单独证明因果；同一宏观变化可能同时影响盈利、折现率与风险溢价，最终资产表现取决于作用强度、已计价程度及其他冲击。

来源冲突、统计口径不一致和证据缺失应分别处理。缺少城投全量数据时，可以讨论可核实的到期压力和区域融资变化，但不能据此声称已测得所有隐性债务；缺少资金流资料时，也不能仅凭持仓市值变化还原净买卖。

## 7. 如何形成宏观判断

1. **确定问题与时点。** 明确全球、中国或指定经济体，区分全景判断和专题问题，固定观察期、分析时点、币种与时间尺度。
2. **识别状态和变化。** 从增长、通胀、政策、信用与金融条件中选相关因素，区分事实、计算、预测和解释。
3. **寻找关键机制。** 用原始统计及政策证据串联起点、路径和结果，说明制度背景、作用条件、滞后和反馈；检查是否重复归因。
4. **比较情景和资产影响。** 分别讨论股票、债券、商品和外汇的相关路径，说明可能分化；资料不足或相关性弱时保留判断，不强制单向预测或统一总分。
5. **保留反证和更新依据。** 给出替代解释、数据缺口以及哪些新事实会改变判断。新时点形成新的判断，不因日期或版本变化追溯否定原时点的有效结论。

一份可复查的宏观判断应能连接“当前状态—核心驱动—条件化传导—跨资产情景—来源与反证”。信息齐全不代表解释正确；解释成立仍需支持路径的证据，以及对相反证据的处理。
