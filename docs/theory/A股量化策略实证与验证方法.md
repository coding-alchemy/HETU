# A 股量化策略实证与验证方法

> 文档性质：面向个人研究者的文献综述与验证参考
> 整理日期：2026-11-07
> 适用范围：A 股日线数据、低频调仓及多头组合研究。本文汇总已有公开证据，未新增回测或收益验证。

## 1. 怎样理解公开实证

同一篇论文可能同时报告股票分组收益、多空因子收益和风险调整收益。用于个人多头研究时，应先确认结果属于哪一种，再核对样本、币种、权重、交易成本和执行约束。只有在目标市场和实际可交易口径下完成独立检验，才能评价本地组合的经济表现。

## 2. 已有实证与公开规则

### 2.1 低波动

Blitz、Hanauer、van Vliet 研究了 2000 年末至 2018 年的 A 股历史 MSCI 样本。论文用过去 36 个月的月收益估计波动率，按月排序，报告低波动组相对高波动组的优势，在大盘和较高流动性样本中也有支持。论文同时给出多头分组和含做空、杠杆调整的因子结果，收益以美元计量。若改用人民币、不同股票池或不同权重，须登记差异并单独检验。36 个月历史收益用于估计信号，实际评价窗口另计。 [Blitz 等，*The Volatility Effect in China*（2021）](https://link.springer.com/article/10.1057/s41260-021-00218-0)

### 2.2 价值、动量与反转

Liu、Stambaugh、Yuan 研究了 2000–2016 年的 A 股，样本筛选包括剔除市值最小的 30%。在论文比较的估值指标中，盈利收益率 E/P 更有解释力。其口径使用最近已报告的扣非净利润与总市值。研究应用须按当时可知的披露取值，最新市盈率或滚动十二个月盈利代表不同口径。该样本支持短期反转，未发现通常的中期动量效应。 [Liu 等，*Size and Value in China*（2019），第 4–5、10、18 页](https://rodneywhitecenter.wharton.upenn.edu/wp-content/uploads/2019/04/01-18-Stambaugh.Published.BlumePrize.pdf)

这篇论文的反转信号回看 20 个交易日。附录 A.2 每日重新排序、轮换五分之一仓位，持有五个交易日，主要结果是多空收益差。改为每周调仓的多头组合后，交易节奏和收益来源都发生变化，成本后表现须另行验证。 [同文附录 A.2，第 28 页](https://rodneywhitecenter.wharton.upenn.edu/wp-content/uploads/2019/04/01-18-Stambaugh.Published.BlumePrize.pdf)

国际研究可作对照。Jegadeesh 与 Titman 在后续样本中报告了动量收益。Moskowitz 与 Grinblatt 发现行业效应能解释相当一部分个股动量。研究 A 股行业轮动时，应明确行业分类版本、轮动信号和比较基准，并检查与个股动量的重叠。 [Jegadeesh 与 Titman](https://www.nber.org/papers/w7159) · [Moskowitz 与 Grinblatt](https://onlinelibrary.wiley.com/doi/10.1111/0022-1082.00146)

### 2.3 红利低波与多信号组合

中证红利低波动指数 H30269 的 v1.1 编制方法（2020 年 12 月）先按分红、规模和成交等条件筛选，再在三年平均税后股息率最高的 75 只中选过去一年波动率最低的 50 只，按股息率加权，单股上限 15%，每年 12 月定期调样。复现还须核对派息率、每股股利增长、缓冲区和临时调整规则。月度调样是单独的研究变体。本文引用的是该历史版本。 [中证指数官方编制方法](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/H30269_Index_Methodology_cn.pdf)

Robeco 的 Conservative Formula 提供了多信号组合的规则范例。从最大的 1,000 只股票中选三年波动率最低的 500 只，再结合净派息收益率与价格动量选 100 只，等权并按季度调仓。净派息收益率与现金股息率口径不同，改变市场、调仓频率或指标后应重新评价。 [Robeco 方法说明](https://www.robeco.com/files/docm/docu-20230222-guide-to-conservative-investing-us.pdf)

### 2.4 换手与交易成本

Novy-Marx 与 Velikov 发现，计入交易成本后，异常策略的收益与统计显著性会下降，高换手策略尤其敏感。区分买入与继续持有门槛可减少不必要的交易。该研究提供成本检验的方法依据，A 股实操仍需按适用的佣金、税费、滑点、停牌、价格限制和容量评价。 [Novy-Marx 与 Velikov，*A Taxonomy of Anomalies and Their Trading Costs*](https://www.nber.org/papers/w20721)

## 3. 从候选到可验证规则

| 候选 | 适合先核对的问题 |
| --- | --- |
| 低波动多头 | 月收益预热是否充足，低波组合的效果能否与行业、市值暴露区分。 |
| E/P 价值 | 盈利在信号时点是否已公开，修订是否可追踪，原文股票池和盈利口径能否复现。 |
| 红利低波 | 历史分红、资格及调样版本是否齐全，指数规则能否转成可成交组合。 |
| 短期反转 | 多头单侧是否仍有信号，换手、滑点和无法成交是否吞噬收益。 |
| 中期动量、行业轮动 | 窗口和分类是否事前确定，A 股样本外结果是否稳定，行业效应和个股效应是否重叠。 |
| 质量与价值组合 | 先定义质量指标、权重和比较基准，再检验相对单一价值规则的增量。 |

低波动和公开指数规则便于从已披露的方法起步。E/P 的可验证性更依赖历史财务版本。选择研究顺序时，可以把规则完整度、历史数据和执行成本分别比较。 [A 股历史时点数据核验方法](A股历史时点数据核验方法.md)

## 4. 验证报告至少要回答什么

1. **外部证据能支持什么。** 记录原始来源、样本、规则和局限，分别标出原方法与改写部分。
2. **测试前冻结了什么。** 写明股票池、信号、窗口、权重、调仓、成交、退出、基准和评价阈值。预热与评价分别计算，样本外阶段避免用结果反调参数。
3. **信号时点能知道什么。** 历史身份、行情、行动和所需财务按当时可知范围取值。行业轮动须使用历史分类与成员，当前标签只描述当前截面。
4. **实际能否交易。** 同时报告毛／净收益、相对可比基准的表现、回撤、风险、敞口、换手、费用和未成交。对高换手或低流动性组合，应检查成本和容量压力。
5. **结果如何影响后续判断。** 保存全部试验，区分有效负结果与证据不足。单一短窗口或正毛收益只支持有限结论，继续、调整或停止应对应事前标准和实际证据。
