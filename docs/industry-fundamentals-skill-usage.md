# 行业基本面 Skill 使用说明

`hetu-industry-fundamentals` 独立研究用户指定行业、品类及地区的供需、库存、价格、成本、竞争和景气。优先取得并展示相关可用数据，交付正文历史表、适用比较、表旁解释和实际折线图，再形成证据允许的判断；无需先生成宏观或个股报告。

## 安装与调用

将整个 `skills/hetu-industry-fundamentals/` 复制到目标项目的 `.agents/skills/hetu-industry-fundamentals/`，保持以下四个文件和相对位置：

```text
hetu-industry-fundamentals/
├── SKILL.md
└── references/
    ├── research-rules.md
    ├── sources.md
    └── report-contract.md
```

已有同名目录先保留并核对内容，再决定是否替换。在新会话使用 `$hetu-industry-fundamentals` 明确调用。当前Codex项目级发现已实际核验；其他宿主按其能力确认。个股安装命令不负责本包，不要求安装其他HETU Skill或仓库程序。

## 自然语言示例

```text
$hetu-industry-fundamentals
请研究美国原油近一年的供给、炼厂加工需求、商业库存和WTI现货价格，解释景气及相反事实，展示历史表与图。
```

```text
$hetu-industry-fundamentals
请比较指定地区、交货地及规格的现货报价在今年1至9月怎样变化，保留税运和报价口径。
```

```text
$hetu-industry-fundamentals
请根据我提供的行业资料研究能源成本如何传导，区分次月调价与季度固定价合同，并说明哪些利润判断还不能成立。
```

产品、地区或环节有影响选源和判断的歧义时会先澄清，不默认中国或全球。只展开与问题有关的维度，不机械遍历七维或整个产业链。同品同口径报价可以独立比较，不要求先取得无关成交量／品类权重；混合均价、销售额等问题才按需要分辨数量、价格和结构。公司估值、目标价、下单、单券条款及具体合约收益不在本包范围。

## 阅读与保存结果

报告在相关分析附近展示所选窗口内已取得的数据和适用同比／环比，累计量并列上年完全同期。表旁解释指标、单位、样本及报价／成交、月均／月末等读法；缺期和缺基数保留具体位置，不补零、插值或强算。

完整报告为 `report.md`，原始来源、计算和缺口在 `evidence.md`。关键序列图使用同组核验数据，缺期断线，实际图片放在 `charts/` 并由正文引用；移动或分享报告时保留图片目录。默认输出到 `.hetu/research/industry-fundamentals/<独立研究标识>/`，可指定其他目录，不覆盖旧报告。

文件回读确认后才提供实际路径。不能保存时应完整内联报告和证据；不能出图时仍交付完整表格和证据，说明图形未完成，文字描述不算图片。当前材料充分与报价专题的文件／图片交付已成立，严格无图只读环境的完整内联本轮未完成验证，不能据此承诺全部宿主均已认证。

## 数据与分析限制

企业自述、选择性客户样本和用户报告属于待核材料，不直接当作全行业份额、竞争优势或已证因果。规划产能不算当期有效供给，产量／渠道采购不代终端需求，仓库样本不代表全地区库存。未证实机制和具体数据缺口分别披露，不因额外归因未完成而拖延已有数据交付，也不把受限项登记为已取得。

需求明显依赖特定下游或项目时，会按问题核需求来源、集中依赖及投资与采购的实际兑现。利润、回款、扩产或融资传导问题会核资金周转，必要时以覆盖明确的企业样本作为行业证据；利润与现金背离需要解释，不能直接定性造假。以财务库存判断供给时，会核分类、实物量、账面计量和可交付状态。这些按问题触发，报价窄题仍保持原范围；新增来源定位线索均为候选，未做公网实测。

公开网页、下载和适用转载优先，API不是所有资料的前置条件。不会自动注册、试用、采购或联系供应商。实际来源覆盖见包内[来源导航](../skills/hetu-industry-fundamentals/references/sources.md)；目录候选不保证每次可以取到。需求、设计与当前验收边界统一见[行业基本面实现](../specs/2026-11-07-industry-fundamentals-implementation.md)。
