# 中国宏观基本面 Skill 使用说明

这款工具帮助你判断中国经济的状态、主要驱动和风险，解释财政、货币、信用、房地产、地方债与人民币之间的关系，并分析它们对股票、债券、商品和外汇的影响。

可以研究全国宏观，也可以聚焦某项政策或某个地区。无需先使用其他分析工具。研究范围是宏观经济，不包含个股估值、单一发行人评级、行业供需深研或具体证券的收益预测。

## 1. 开始使用

目前已在 Codex 中验证使用。

1. 将仓库中的 [skills/hetu-china-macro](../skills/hetu-china-macro/) 文件夹完整复制到目标项目的 `.agents/skills/hetu-china-macro/`，包括其中的 `references` 文件夹。如果目标位置已有同名文件夹，先确认是否需要替换。
2. 在该项目中新开一个 Codex 会话，输入 `$hetu-china-macro`，然后描述你的研究问题。也可以直接说“请使用中国宏观基本面工具……”来提问。

## 2. 可以这样提问

**中国宏观全景**

> 请分析当前中国经济的主要驱动和风险，以及未来一个季度对股票、债券、商品和人民币的影响。人民币相对欧元分析，请说明判断依据和可能改变结论的条件。

**地方财政与化债**

> 请研究江苏最近的财政执行、地方债偿债和城投融资变化，分析化债、清欠如何影响地方财力、企业回款和总需求。

**人民币专题**

> 请分析中国与欧元区的增长、通胀和政策差异，以及未来一个季度人民币相对欧元的走势条件与主要风险。

提问时，最好说明关注的问题、地区、分析日期和展望期限；涉及汇率时，说明人民币相对哪种货币。你也可以提供希望参考的资料。

未指定日期时，默认以发起研究的时点为准；继续同一研究时保留原时点。研究历史情况时，只采用当时已公开的信息，后续修订另作比较。

## 3. 你会得到什么

- **分析报告（report.md）**：经济状态、主要驱动、政策传导、相关资产在不同条件下的影响，以及风险、资料缺口和后续观察重点。
- **证据附录（evidence.md）**：数据来源、观察期间、统计口径和计算过程，便于回查。

报告会用表格展示主要经济数据的历史变化：月度默认最近12个月、季度最近8季、年度最近5个完整年，并对照本年与上年相同累计期间。你可以指定“月度看24个月，年度看3年”。表格会标出未取得或不可比的数据；跨年研究会说明地方化债安排的变化及其影响。

默认保存在项目的 `.hetu/research/china-macro/<研究标识>/` 下，完成后会提供文件链接。你可以指定其他保存位置；无法保存文件时，会在会话中给出完整内容。

## 4. 资料不足时怎么处理

工具优先使用公开资料。平台全部融资、清欠实际到账、银行风险分布等信息可能披露不全；网页访问或文件读取受限，也可能影响分析。报告会说明哪些判断已有依据、哪些问题仍无法回答，不把缺少数据解释为没有风险。

关键资料确实无法从公开渠道取得时，会向你说明数据需求、已查渠道、建议的商业产品、覆盖范围、已知费用与使用条件，供你审批。已有授权仅在原范围内使用；购买、开通试用或联系供应商需要相应的明确授权。你未批准或拒绝时，相关缺口会保留，其他可完成的分析继续。
