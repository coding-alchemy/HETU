# 全球宏观基本面 Skill 使用说明

## 是什么

`hetu-global-macro` 用公开或明确授权的原始资料研究全球宏观全景、经济体差异和跨境传导，解释宏观与资产、美元支付融资的双向作用。普通全景默认分析比特币、美元储备支持型稳定币、黄金、美债与汇率，无需逐项点名；同时保留增长、需求、通胀、政策、地区差异，以及股票和其他债券／商品分析。全球包含中国，按问题选择相关经济体，无需每次遍历所有国家。

它独立运行，不需要中国宏观、行业或个股 Skill，也不会自动读取它们的报告。公司财报与个股估值、行业供需、单券信用、具体交易合约和持仓收益不在范围内。

## 如何安装

在支持项目 Skill 的 Codex 中，将本仓库的整个 `skills/hetu-global-macro/` 目录复制到目标项目的 `.agents/skills/hetu-global-macro/`，保留以下四个文件及相对位置：

```text
hetu-global-macro/
  SKILL.md
  references/
    research-rules.md
    sources.md
    report-contract.md
```

若目标已有同名目录，先核对并保留现有内容，再决定是否替换。打开目标项目的新会话，以 `$hetu-global-macro` 明确调用。当前 Codex 已核验该项目目录的原生发现及独立加载；其他宿主的安装与工具能力需分别确认。个股安装命令不负责安装本包。

宿主需提供获准的搜索、正文阅读、必要计算和文件工具。本包是文本规则，不附带采集程序、数据库或商业数据权限。

## 三个提问示例

```text
$hetu-global-macro
请用公开资料分析当前全球宏观状态、主要地区差异与跨境风险，
说明股票、债券、商品和外汇的条件化影响，并解释选择哪些经济体。
```

```text
$hetu-global-macro
截至今天北京时间收盘，用公开资料研究美日增长、通胀、政策和融资条件差异，
如何影响未来一个季度的美元兑日元，以及相关股票、主权债券和黄金。
```

```text
$hetu-global-macro
请用公开资料研究美元稳定币发行和赎回如何影响银行存款、短期美债与美元融资，
区分已有资金重配和净新增需求，说明哪些证据支持判断、哪些问题仍受限。
```

窄专题只展开与问题相关的对象、经济体与渠道，不要求五项全展开。数字资产以比特币与美元储备支持型稳定币的代表样本为主，基金申赎和储备披露用于宏观判断，不提供产品选择、代币估值或交易策略。

可以指定信息截止时间及其时区、分析期限、经济体、币种或货币对、输出目录。历史日内截止或事件含糊且会改变结论时，研究者会先澄清；未指定截止时固定研究开始时点。你主动提供的报告可作为线索，主要事实仍须回查原来源。

## 得到什么

完整中文 `report.md` 依次说明范围与完成状态、核心驱动与地区差异、传导、资产情景与美元支付融资，以及来源、反证和缺口。`evidence.md` 提供主要判断的原始值、具体出处、公开时间与版本、口径、计算和限制。

报告会以实际事实、必要计算、相关规模与反向证据解释条件和反馈：例如区分基金规模与申购、发行与资金重配、储备估值与交易，以及短债需求与长债承接。缺少规模或资金来源时只限定对应影响，继续采用已有事实。

主要经济指标会在正文配历史对照表：月度默认最近12个月，季度最近8个季度，年度最近5年；也可以要求24个月或3年等窗口。“今年前三季度”会与“去年前三季度”并列，展示适用的同比、环比或百分点变化。各指标保留自己的最新已发布观察期，缺值和不能比较的部分在表旁说明。表头可用简写，附近正文会解释指标全称、衡量什么及必要读法，便于直接阅读。

支撑关键趋势、拐点和分化判断的时间序列会自动配折线图，图旁保留完整历史表及指标说明。缺值表现为断线，不能将断线读作零；相关指标可合图，不同尺度可能分成上下小图。

报告会把已取得的重要事实用于判断，并对主要经济指标展示历史值和可完成的同比、环比。某一项缺少基数时，会注明具体缺期；其他已得事实和可算比较仍继续使用。

比特币和黄金的价格观察窗口会与所问问题匹配；日内变化与季度背景分别解释。表格附近会说明季调年化水平、链式美元和折年增长率的读法。公开历史或方法未取得的部分会保留限制，不用短时成交或储备估值代替。

移动或分享已保存的报告时，请一起保留 `charts/` 图片目录。宿主不能出图时，仍会交付完整表格和文字，并明确标明图形未完成。

默认输出在 `.hetu/research/global-macro/<独立研究标识>/`，也可指定目录。已有产物应保留；文件保存并回读后才给出实际路径。没有写权限、保存失败或无法确认文件可读时，回复会说明落盘状态并内联完整报告及完整证据附录。

## 资料不足时

来源目录、搜索摘要和 API 文档不能代替具体正文或数据。历史版本、事前共识、资金仓位或融资资料缺失时，只限制相关判断；核心问题未回答仍标未完成，不因报告结构完整而声称成功。远期汇率不是即期预测，政策变化也不保证资产单向涨跌。

来源导航中的既有核验有各自时点与范围；一次研究不代表所有经济体、接口、行情或宿主均已验证。API、商业产品许可及未实际调用的方法不能据目录存在视为已接入。超出公开或已有授权的资料需求会先说明，不自行注册试用、采购、付费调用或联系供应商。

既有结果对原时点继续有效。日期、模型或文档版本变化不自动触发重跑；有直接影响的语义变化才需要说明并作最小复查。
