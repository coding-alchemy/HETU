# HETU 中国股票分析体系全景指南

> 文档版本：V2.0.1
> 文档状态：立项基线稿
> 适用范围：中国境内 A 股研究、投资决策支持、组合管理与复盘
> 资料更新日期：2026-07-12；数据源分层修订日期：2026-08-18
> 文档维护原则：交易规则、监管口径、指数方法、数据接口和授权条件均须记录来源、生效日与抓取时间，并以最新正式文件为准。

本文既是 HETU A 股研投工具的立项依据，也是产品、研究、数据和工程团队共同使用的方法规范。它回答五类问题：为什么建设、为谁建设、分析什么、数据从哪里来、系统如何实现和验收。

本文不提供个股推荐，不构成投资建议。工具输出属于研究辅助信息，不替代适当性判断、独立研究、合规审查或最终投资决策。

## 第一部分 项目总纲

### 1. 项目背景与问题定义

A 股研究通常面临以下结构性问题：

1. **信息分散**：公告、财报、政策、宏观、产业、行情、资金和舆情分布在不同平台，时间口径和证券标识不统一。
2. **研究不可复现**：结论常停留在文字观点，缺少假设、证据、数据版本、计算过程和失效条件。
3. **方法彼此割裂**：基本面、量化、技术、事件与组合风控各自运行，难以形成从线索到持仓的闭环。
4. **口径容易漂移**：复权、财报追溯、行业分类、指数样本、交易规则和数据供应商字段会变化，历史回测容易被污染。
5. **风险发现滞后**：财务异常、治理变化、股权质押、限售解禁、监管处罚和流动性恶化未形成统一预警。
6. **数据授权不清**：公开可见不等于可以抓取、缓存、再分发或商业使用，项目需要在设计阶段处理许可边界。
7. **输出不能直接行动**：很多工具给出大量指标，却没有说明证据强弱、预期差、买卖条件、仓位约束和复盘日期。

因此，本项目要建设的不是“更多图表”，而是一套以证据为基础、以假设为中心、以风险预算为约束、全过程可追溯的 A 股研投工作台。

### 2. 产品愿景

用一个统一工作流，把“发现线索、验证事实、形成预测、比较估值、制定交易、控制组合、跟踪证伪、复盘归因”连接起来，使每个结论都能回答：

- 使用了什么数据，来源和时点是什么？
- 采用了什么方法，适用条件是什么？
- 哪些事实支持，哪些事实反对？
- 当前价格隐含了什么预期？
- 结论在什么条件下失效？
- 对组合收益和风险意味着什么？

### 3. 建设目标与非目标

#### 3.1 建设目标

| 目标 | 说明 | 可验收结果 |
|------|------|------------|
| **统一研究入口** | 聚合证券、公司、行业、宏观、政策和组合信息 | 一个证券代码可进入完整研究页 |
| **标准研究流程** | 固化研究模板、证据链、预测、估值和风险清单 | 研究结论字段完整且可回溯 |
| **多策略协同** | 支持基本面、事件、趋势、因子、红利、周期等方法 | 同一标的可展示不同策略视角及冲突 |
| **数据可信可追溯** | 保存来源、发布时间、生效时间、抓取时间和版本 | 任一指标可定位到原始记录 |
| **持续监控** | 对公告、财报、价格、资金、治理和组合风险告警 | 重要事件在目标时延内进入待办 |
| **研究资产沉淀** | 保存假设、证据、模型、会议纪要与复盘 | 可以检索历史观点及其后续表现 |
| **合规可控** | 明确数据许可、访问控制、日志与 AI 使用边界 | 数据和输出满足内部合规检查 |

#### 3.2 非目标

- 不承诺预测短期股价或提供“必涨”信号。
- 不以单一总分替代研究员判断。
- 不在首期建设超低延迟交易、自动下单或高频撮合系统。
- 不采集内幕信息、未公开重大信息或来源不合法的个人数据。
- 不绕过验证码、登录限制、付费墙、反爬机制或数据许可条件。
- 不将大语言模型生成内容直接视为事实或正式投资结论。

### 4. 目标用户与核心任务

| 用户 | 核心任务 | 首要输出 |
|------|----------|----------|
| **基本面研究员** | 行业与公司研究、盈利预测、估值、跟踪 | 研究卡、预测模型、估值区间 |
| **量化研究员** | 因子构建、样本检验、组合优化、归因 | 因子报告、回测、暴露与换手 |
| **基金经理/投资决策者** | 比较机会、分配风险预算、做出交易决策 | 候选池、组合情景、决策记录 |
| **交易与执行人员** | 评估流动性、制定执行计划、监控成交 | 交易清单、成交偏差、限制检查 |
| **风险管理人员** | 监测集中度、回撤、流动性和事件风险 | 风险看板、压力测试、告警 |
| **投研负责人** | 管理研究覆盖、质量、协作与知识资产 | 覆盖地图、任务、质量指标 |
| **个人专业投资者** | 建立规范研究流程并减少认知偏差 | 检查清单、跟踪计划、复盘 |

### 5. 产品范围

#### 5.1 证券范围

首期覆盖：

- 上交所主板、科创板 A 股；
- 深交所主板、创业板 A 股；
- 北京证券交易所上市股票；
- 与股票研究直接相关的主要宽基、行业、风格指数和 ETF；
- 用于宏观与估值参照的利率、汇率、商品和主要海外指数。

后续可扩展：港股通标的、可转债、公募基金、股指期货期权、REITs 和新三板基础层/创新层。扩展品种必须独立评估交易制度、估值模型、权限和数据许可。

#### 5.2 业务范围

```text
研究发现 -> 数据核验 -> 假设形成 -> 盈利预测 -> 估值比较
        -> 交易计划 -> 组合约束 -> 持续监控 -> 归因复盘
```

工具覆盖研究与决策支持，不直接替代订单管理系统、交易柜台、财务会计系统和法定合规审批系统。

### 6. 核心原则

1. **事实、估计、观点分层**：界面和数据模型必须区分原始事实、计算结果、模型预测与主观判断。
2. **双时间管理**：同时保存事件实际发生时间和市场可获得时间，回测只能使用当时已公开信息。
3. **证据优先**：法定披露和监管文件优先于媒体转述，原始数据优先于二次加工结论。
4. **保留反方证据**：每个投资假设必须记录反证、争议和失效条件。
5. **模型适用性先于精度**：先判断行业和公司能否使用该模型，再讨论参数。
6. **风险预算先于目标收益**：个股判断必须落到组合集中度、流动性和最大可承受损失。
7. **可解释优先**：评分必须能拆解到因子、数据、来源和贡献，禁止输出不可追溯的黑箱总分。
8. **规则配置化**：板块涨跌幅、上市初期安排、风险警示、退市整理等规则按市场、品种和生效区间配置，不写死在代码中。
9. **人机协同**：机器负责采集、计算、比对、提醒和草拟，人负责定义假设、判断因果和承担决策责任。

### 7. 统一研究对象：投资假设卡

系统的最小研究单元不是一篇报告，而是一张可版本化的“投资假设卡”。

| 字段 | 含义 |
|------|------|
| **研究对象** | 证券、发行人、行业、主题或组合 |
| **策略标签** | 价值、成长、红利、周期、事件、趋势、因子等 |
| **一句话假设** | 为什么未来事实或市场定价会发生变化 |
| **市场隐含预期** | 当前价格大致隐含的增长、利润率、风险或估值水平 |
| **支持证据** | 支持假设的事实、数据和来源 |
| **反方证据** | 与假设冲突的事实、竞争解释和风险 |
| **关键变量** | 最能验证假设的 3 至 8 个可观测指标 |
| **盈利与估值情景** | 悲观、中性、乐观的假设、概率和估值结果 |
| **催化剂** | 可能促使市场修正定价的事件与时间窗口 |
| **失效条件** | 出现后需要降级、退出或重做研究的事实 |
| **组合含义** | 建议风险预算、相关暴露和流动性约束 |
| **责任与日期** | 作者、复核人、版本、下次复查日期 |

### 8. 项目成功标准

项目成功不以“指标数量”衡量，而以研究效率、证据质量和风险控制改善衡量：

- 核心标的的数据完整率和关键字段准确率达到验收阈值。
- 财报、公告与公司行动可以在既定时延内被识别、解析和关联。
- 研究结论 100% 带有来源、作者、版本、核心假设和失效条件。
- 回测具备点时数据、交易约束、费用和退市样本处理。
- 组合能够展示行业、风格、个股、流动性和事件风险暴露。
- 用户能在一个工作流中完成从线索到复盘的全链路操作。
- 系统不因 AI 摘要或低等级信息源自动生成可直接执行的买卖指令。

## 第二部分 全维度分析策略体系

### 9. 策略设计标准

每个分析策略都应实现为“策略卡”，至少包含以下字段：

| 字段 | 要求 |
|------|------|
| **策略目的** | 要解决的决策问题，而不是指标名称 |
| **适用范围** | 市场、行业、公司阶段、持有周期和排除条件 |
| **输入数据** | 字段、频率、来源层级、复权和时点要求 |
| **计算方法** | 公式、窗口、去极值、中性化、缺失值处理 |
| **输出** | 信号、评分、区间、证据或风险告警 |
| **验证方法** | 横截面、时序、事件研究、样本外或人工复核 |
| **交易约束** | T+1、涨跌停、停牌、流动性、容量和成本 |
| **失效模式** | 参数漂移、拥挤、制度变化、数据修订等 |
| **方法来源** | 学术论文、经典模型、监管规则或内部研究 |
| **版本记录** | 参数、代码、数据快照、生效与废止日期 |

### 10. 分析层级与联动关系

| 层级 | 决策问题 | 主要方法 | 典型输出 |
|------|----------|----------|----------|
| **宏观与制度** | 风险偏好、利率和信用环境如何 | 经济周期、流动性、政策事件研究 | 宏观状态、资产偏好、风险情景 |
| **市场与风格** | 哪类资产正在占优、是否拥挤 | 宽度、估值分位、风格因子、资金流 | 风格雷达、拥挤度、市场温度 |
| **行业与主题** | 景气来自哪里、能否持续 | 供需、库存、价格、产业链、政策映射 | 景气评分、利润池、主题阶段 |
| **公司与证券** | 企业质量、盈利和定价是否匹配 | 商业模式、财务、治理、预测、估值 | 假设卡、盈利预测、估值区间 |
| **交易与事件** | 何时行动、事件如何定价 | 趋势、波动、流动性、事件研究 | 入场区间、失效位、事件概率 |
| **组合与风险** | 持有多少、风险来自哪里 | 风险预算、优化、压力测试、归因 | 权重建议、暴露、回撤预案 |

### 12. 宏观、政策与市场策略

#### 12.1 宏观状态识别

采用“增长、通胀、信用、流动性、外部条件”五轴，而不是依赖单一 GDP 指标。

| 轴 | 代表指标 | 处理方式 | 对投资的用途 |
|----|----------|----------|----------------|
| **增长** | PMI、新订单、工业增加值、社零、地产销售、出口 | 同比、环比、扩散指数、趋势斜率 | 判断顺周期与防御方向 |
| **通胀** | CPI、PPI、生产资料价格、商品指数 | 上下游拆分、基数效应调整 | 判断利润率、利率和周期位置 |
| **信用** | 社融、信贷、政府债、企业中长贷 | 存量与增量、同比与结构 | 判断信用扩张是否进入实体 |
| **流动性** | 公开市场、DR007、Shibor、国债曲线、M1/M2 | 相对政策利率和历史分位 | 判断折现率与风险偏好 |
| **外部条件** | 美债、美元、人民币、海外 PMI、出口订单 | 汇率和利差联动 | 判断外资、出口与估值压力 |

系统输出应包括宏观状态标签、变化方向、数据意外、受益/受损行业和下次数据发布日期。宏观标签只能作为先验，不能直接替代公司盈利分析。

#### 12.2 政策传导策略

政策分析按以下链条执行：

```text
政策层级 -> 约束力 -> 工具类型 -> 资金或规则来源 -> 执行主体
        -> 受影响环节 -> 企业收入/成本/资本开支 -> 利润与估值
        -> 验证指标与兑现时间
```

政策策略必须区分：讲话与正式文件、意见与实施细则、目标与预算、中央部署与地方执行、短期刺激与长期制度变化。输出不得只做关键词匹配，应给出传导路径、关键条款原文定位、受益逻辑、反作用和验证里程碑。

#### 12.3 市场宽度与风险偏好

建议组合以下指标，而不是单看指数：

- 上涨/下跌家数、创新高/新低家数和个股中位数收益；
- 全市场成交额、换手率、涨跌停与炸板率；
- 指数实现波动率、下行波动率、偏度和相关性；
- 股债收益率差、ERP 代理指标与主要指数估值分位；
- 融资余额变化、ETF 份额变化和新发基金热度；
- 大小盘、价值成长、周期防御之间的相对强弱。

市场温度采用分项仪表盘，不建议压缩成唯一“恐惧贪婪指数”。

### 13. 行业、主题与公司策略

#### 13.1 行业景气跟踪

行业景气策略采用“量、价、库存、产能、订单、成本、政策”七变量框架。

| 变量 | 核心问题 | 常见数据 |
|------|----------|----------|
| **量** | 终端需求是否增长 | 销量、装机、客流、发电、货运、出口量 |
| **价** | 产品价格和折扣是否改善 | 出厂价、现货价、招标价、ASP |
| **库存** | 主动补库还是被动累库 | 企业库存、渠道库存、港口库存 |
| **产能** | 供给扩张和退出速度如何 | 资本开支、在建工程、产能利用率 |
| **订单** | 未来收入是否有前瞻支撑 | 新订单、合同负债、招投标、排产 |
| **成本** | 利润率是否改善 | 原材料、能源、运费、人工、汇率 |
| **政策** | 需求、供给或成本是否被改变 | 配额、补贴、集采、准入、关税 |

景气信号需记录领先/同步/滞后属性、历史修订频率和对公司收入利润的敏感度。行业景气上升不等于所有公司受益，必须继续分析产能、成本曲线和议价权。

#### 13.2 主题投资与叙事扩散

主题研究分为五个阶段：概念提出、政策确认、产业验证、盈利兑现、拥挤退潮。系统应跟踪：

- 主题定义及纳入/剔除标准；
- 主题与公司主营收入、订单或资本开支的真实关联度；
- 政策、专利、招投标、产品发布和业绩中的产业证据；
- 龙头、容量中军、弹性标的和纯概念跟随者的角色；
- 新闻热度、涨停扩散、成交占比和估值扩张；
- 叙事强度与盈利证据之间的缺口。

主题标签必须可解释，禁止仅因公告或新闻中出现关键词就认定公司受益。

#### 13.3 商业质量与护城河

商业质量策略至少拆解：需求刚性、市场空间、单位经济、客户集中度、供应商依赖、价格能力、复购与留存、资本强度、研发效率和竞争格局。

护城河必须由可观测证据支持。例如品牌对应提价与复购，成本优势对应单位成本曲线，技术壁垒对应客户认证、良率与产品代际，转换成本对应续约率和迁移周期。没有证据的“行业龙头”只作为待验证标签。

#### 13.4 盈利预测

预测采用“经营驱动因子 -> 三张报表 -> 现金流”的结构：

```text
收入 = 销量 × 单价，或 客户数 × ARPU，或 产能 × 利用率 × 单价
毛利 = 收入 - 数量 × 单位成本
净利润 = 毛利 - 期间费用 - 减值 ± 非经常项目 - 所得税
自由现金流 = 税后经营利润 + 折旧摊销 - 资本开支 - 营运资本增加
```

每个预测字段需标记历史事实、管理层指引、外部一致预期或研究员假设。系统保存预测版本、修订原因和误差，避免只保留最新数字。

### 14. 财务、治理与风险识别策略

#### 14.1 财务质量

财务质量使用趋势、同行和三表勾稽三种比较：

- 利润与经营现金流是否匹配；
- 应收、合同资产、存货与收入是否同步；
- 毛利率变化能否被产品价格和成本解释；
- 资本化、减值、政府补助和投资收益是否显著改变利润；
- ROE/ROIC 来自利润率、周转还是杠杆；
- 自由现金流是否足以支持分红、回购和扩张。

可实现 Piotroski F-Score、Altman Z-Score、Beneish M-Score、应计利润比例等辅助模型，但需注明行业适用性。金融机构、早期研发企业和重资产周期公司的阈值不能机械共用。

#### 14.2 法务、治理与资本配置

治理策略形成事件时间线，覆盖实际控制人、董事和高管变动、股权质押、关联交易、资金占用、担保、监管措施、诉讼仲裁、审计意见、会计师变更和承诺履行。

资本配置评估覆盖：经营再投资回报、并购价格与商誉、分红持续性、回购用途、股权激励摊薄、再融资必要性和大股东增减持。回购必须区分注销、员工激励和库存股用途。

#### 14.3 排雷规则

排雷分为三类：

| 类型 | 示例 | 系统动作 |
|------|------|----------|
| **硬排除** | 退市整理、重大违法强制退市进程、数据不可得、内部禁投 | 移出可投池并说明依据 |
| **强预警** | 非标审计、重大资金占用、债务逾期、高比例质押、连续处罚 | 阻断自动入池，要求人工复核 |
| **软预警** | 现金流背离、存货异常、频繁并购、管理层变动 | 降低置信度并加入跟踪清单 |

规则命中必须展示原始公告、规则版本和触发字段，允许复核但不得静默覆盖。

#### 14.4 ESG 与可持续风险

ESG 分析不以第三方总分为起点，而以“财务重大性 + 影响重大性 + 事件风险”识别对企业现金流、资产、融资和声誉有实质影响的议题：

| 维度 | 关键变量 | 财务传导 |
|------|----------|----------|
| **环境与气候** | 碳排放、能耗、水耗、污染物、环境处罚、极端天气 | 碳成本、环保资本开支、停产、保险与资产减值 |
| **产品与客户** | 质量、召回、数据安全、客户隐私、科技伦理 | 赔偿、监管处罚、客户流失与品牌价值 |
| **员工与安全** | 工伤、职业健康、流失、薪酬、培训 | 停工、赔偿、招聘成本与生产效率 |
| **供应链** | 供应商集中、负责任采购、海外合规、人权与制裁 | 断供、关税、客户准入与订单风险 |
| **商业行为** | 反腐败、反垄断、公平竞争、税务 | 处罚、资质、管理层与声誉风险 |
| **治理机制** | 董事会监督、目标、内部控制、鉴证与数据边界 | 信息质量、资本成本和风险应对能力 |

上交所和深交所可持续发展报告指引自 2024 年 5 月 1 日起施行，后续又发布编制指南；系统应跟踪适用主体、强制/自愿披露范围和指南版本。[sse-esg] [szse-esg] 对披露值应核对报告边界、单位、强度分母、基准年、是否鉴证和历史重述。第三方 ESG 评级只作补充，因为不同机构的议题、权重和缺失值处理可能不同。

### 15. 估值与预期差策略

#### 15.1 多方法估值

估值引擎至少支持 DCF/FCFF、DDM、剩余收益、PE、PB、PS、EV/EBITDA、P/FCF、SOTP 和行业专用方法。系统根据行业和生命周期推荐方法，但最终选择由研究员确认。

输出应包含：

- 悲观、中性、乐观三情景及概率；
- 关键参数敏感性，如 WACC、永续增长、利润率和估值倍数；
- 与历史、同行、行业和自身成长质量的比较；
- 当前价格反推的隐含增长或利润率；
- 上行空间、下行空间和风险收益比，而不是单一目标价。

#### 15.2 预期差

预期差不是“业绩增长”，而是实际路径与市场隐含预期之间的差。可以从以下角度识别：

- 实际财报相对一致预期和公司指引；
- 预测上调/下调的方向、幅度、扩散率和持续时间；
- 管理层文本语气和关键经营指标变化；
- 价格已提前反映的程度；
- 一次性项目与可持续经营改善的拆分。

没有合法、稳定的一致预期数据授权时，系统应以公开预测、内部预测分布和价格隐含预期替代，不得拼接来源不明的“市场一致预期”。

### 16. 技术、资金、事件与情绪策略

#### 16.1 趋势和价格结构

趋势策略用于执行和风险控制。输入必须采用正确复权口径，并同时保留原始价格用于涨跌停与真实成交判断。建议输出趋势方向、波动状态、关键高低点、成交确认和失效位置。

技术信号需要在滚动样本外检验，并计入印花税、佣金、滑点、冲击成本、停牌、涨跌停无法成交和 T+1 约束。参数在全样本最优通常意味着过拟合。

#### 16.2 资金与流动性

资金分析区分可观察事实与平台估算：成交额、融资融券、ETF 份额、公司回购、股东增减持和交易公开信息属于可核验数据；按大单划分的“主力净流入”属于算法估算，不能等同于机构真实买卖。

流动性输出至少包括日均成交额、换手率、价差代理、零成交比例、涨跌停占比、停牌、冲击成本估计和按组合规模计算的退出天数。

#### 16.3 事件研究

事件策略覆盖财报、业绩预告、分红、回购、增减持、解禁、定增、并购重组、重大合同、监管处罚、指数调样和政策发布。每类事件均需定义：

- 公告时间与可交易时间；
- 事件字段和标准化口径；
- 估计窗口、事件窗口和基准收益；
- 样本筛选与重叠事件处理；
- 事件后异常收益、成交和波动；
- 经济意义、交易成本和样本外稳定性。

#### 16.4 情绪分析

情绪数据按可靠度分层：市场成交和宽度最高，正规媒体与公告文本其次，社交媒体和搜索热度只作辅助。自然语言分析需处理否定、转述、模板化公告、同名实体和“旧闻重发”。

系统不得用情绪分数覆盖事实判断；对社交媒体内容必须保留出处、时间和删除风险，并遵守平台条款与个人信息保护要求。

### 17. 量化、组合与复盘策略

#### 17.1 多因子研究

因子研究标准流程：定义经济逻辑、构造点时样本、去极值与标准化、行业/规模中性化、分层和 IC 检验、换手与成本、样本外与子区间、拥挤度和容量评估。

因子结果至少展示覆盖率、IC/Rank IC、分组收益、单调性、最大回撤、换手率、行业暴露、风格暴露和不同市场状态下表现。禁止仅展示最优回测净值。

#### 17.2 组合构建

组合引擎支持等权、评分加权、风险预算、均值方差、最小方差、风险平价和基准约束优化。常用约束包括：

- 单票、行业、主题和实际控制人关联上限；
- 风格因子、Beta、跟踪误差和主动权重限制；
- 日均成交额占比、预计退出天数和停牌风险；
- 禁投、限投、ST/退市风险及公司事件限制；
- 换手、税费、冲击成本和最小调仓阈值。

优化器必须提供不可行原因和约束影子成本，避免把不合理输入包装成精确权重。

#### 17.3 压力测试与风险

至少覆盖历史情景、假设情景和反向压力测试：指数下跌、利率上行、人民币波动、商品价格冲击、行业政策变化、流动性折价、个股连续跌停和相关性趋近于一。

风险指标包括波动率、Beta、VaR/ES、最大回撤、集中度、边际风险贡献、流动性退出天数和事件敞口。VaR 不是最坏损失，必须与情景分析并用。

#### 17.4 归因与复盘

收益归因至少区分市场、行业、风格、选股、择时、交易成本和公司行动。研究复盘进一步区分：数据错误、逻辑错误、估值错误、时点错误、仓位错误、执行错误、纪律错误和不可预见事件。

复盘目的不是给结果找解释，而是更新策略先验、排雷规则、数据质量和研究流程。

#### 17.5 方法来源与适用边界

| 方法 | 主要来源 | 在工具中的使用 | 关键边界 |
|------|----------|----------------|----------|
| **安全边际与基本面估值** | Graham & Dodd《证券分析》 | 财务排雷、资产保护、估值折价 | 低估值不自动排除治理和盈利恶化 |
| **竞争战略与五力** | Michael Porter《竞争战略》 | 行业结构、议价权、进入壁垒 | 静态框架需加入技术、政策和生态变化 |
| **DCF/公司估值** | Damodaran 估值体系[damodaran] | FCFF、WACC、终值和敏感性 | 对早期、强周期企业只能做情景估值 |
| **杜邦分析** | DuPont 分解体系 | ROE 的利润率、周转和杠杆来源 | 金融机构需采用行业专用分解 |
| **财务困境 Z-Score** | Altman（1968）[altman] | 财务风险辅助预警 | 原模型样本与中国行业差异显著，不能作退市判定 |
| **财务质量 F-Score** | Piotroski（2000）[piotroski] | 价值股中的质量筛选 | 会计口径和金融行业适用性有限 |
| **盈余操纵 M-Score** | Beneish（1999）[beneish] | 财务异常线索 | 只提示进一步核查，不等于舞弊结论 |
| **应计异象** | Sloan（1996）[sloan] | 利润现金含量、因子研究 | 需行业中性化并处理报表时点 |
| **均值方差组合** | Markowitz（1952）[markowitz] | 组合优化和有效前沿 | 对预期收益和协方差误差高度敏感 |
| **CAPM** | Sharpe（1964）[sharpe] | Beta、资本成本和风险解释 | 单因子不能完整解释 A 股横截面收益 |
| **多因子模型** | Fama & French（1993、2015）[ff1993] | 风格暴露、归因、因子研究 | 因子定义需适配 A 股会计与交易制度 |
| **动量** | Jegadeesh & Titman（1993）[momentum] | 趋势和横截面动量 | 反转、涨跌停和交易成本影响大 |
| **四因子归因** | Carhart（1997）[carhart] | 基金与组合绩效归因 | 需要本地化基准与可交易因子组合 |
| **风险价值/预期损失** | Jorion 等风险管理体系 | VaR、ES 与压力测试 | 尾部、流动性和制度风险不能只靠 VaR |
| **事件研究** | MacKinlay（1997）[event-study] | 财报、政策、公司行动研究 | 事件重叠、信息泄露和公告时点需严格处理 |
| **行为金融** | Kahneman & Tversky；Shiller | 偏差清单、情绪和反身反馈 | 难以直接转成稳定择时信号 |
| **证伪式研究** | 科学方法与贝叶斯更新 | 假设卡、反证、置信度更新 | 置信度不是未经校准的主观百分比 |

方法来源用于明确模型来历和假设，不代表照搬原始阈值。所有进入生产的本地化模型都要有模型卡，记录样本、参数、适用范围、验证结果、负责人和停用条件。

## 第三部分 数据与信息源设计

### 18. 证据等级与来源优先级

所有进入系统的信息都要标记证据等级。等级表示可作为事实依据的强弱，不等于信息一定正确。

| 等级 | 来源 | 用途 | 处理规则 |
|------|------|------|----------|
| **L0 法定与监管** | 交易所公告、法定披露平台、监管决定、法律法规 | 事实基准、合规、公司事件 | 保存原文与附件，最高优先级 |
| **L1 官方统计与基础设施** | 国家部委、统计机构、登记结算、指数公司、行业主管部门 | 宏观、市场、行业和基准数据 | 保存统计口径、发布日期和修订 |
| **L2 发行人及授权数据** | 公司官网/IR、业绩会、许可数据商、交易所数据产品 | 经营补充、结构化行情和一致预期 | 区分法定披露与自愿披露，记录授权 |
| **L3 专业研究** | 券商报告、评级机构、行业协会、学术论文、专家访谈 | 方法、假设、交叉验证 | 不直接覆盖 L0/L1 事实，记录作者和利益关系 |
| **L4 新闻与另类数据** | 正规媒体、招投标、招聘、专利、渠道、搜索热度 | 线索、领先指标 | 需要交叉验证，处理实体、时点和样本偏差 |
| **L5 社交与传闻** | 论坛、自媒体、聊天记录、未经确认“小作文” | 仅作线索和情绪测量 | 明示低可信，不进入事实层或自动触发交易 |

发生冲突时，按“同一口径、同一时点、最高证据等级、最新有效版本”仲裁；无法判定时并列展示并创建数据问题，禁止静默择取更符合既有观点的数据。

### 19. 官方一级信息源目录

#### 19.1 监管、交易与披露

| 信息源 | 可用信息 | 建议用途 | 获取与注意事项 |
|--------|----------|----------|----------------|
| [中国证监会](https://www.csrc.gov.cn/) | 部门规章、监管政策、处罚、发行与并购审核 | 制度库、监管事件、规则版本 | 以规章库和正式发布页为准，保存附件 |
| [上交所](https://www.sse.com.cn/) | 沪市公告、规则、行情概览、交易公开信息 | 沪市公司与交易事件 | 规则须保存生效和废止日期 |

### 23. 核心口径规范

#### 23.1 证券与公司主数据

证券代码不能作为永久公司标识。系统至少分离发行人、法人主体、证券、上市地、股份类别和实际控制关系，并保存简称、代码、行业、上市状态和控制权的历史有效区间。

#### 23.2 行情与复权

- 原始 OHLCV 用于成交、涨跌停和事件时点；
- 前复权用于近期图表可比；
- 后复权或总回报序列用于长期收益研究；
- 现金分红、送转、配股、拆并股分别建模；
- 回测明确使用价格收益还是含分红总收益。

#### 23.3 财务报表

同时保留原始披露值、追溯调整值、标准化值和研究员调整值。财报记录必须带报告期、报表类型、合并/母公司口径、币种、单位、公告时间、更新序号和审计意见。

#### 23.4 行业分类

支持证监会行业、中证行业、申万行业及内部产业链标签，并保存分类版本和有效日期。回测不得用今天的行业分类回填历史。

#### 23.5 交易日历与制度参数

交易日历按交易所和品种维护。涨跌幅、申报价格范围、最小交易单位、盘后交易、上市初期安排、风险警示和退市整理规则均放入带生效区间的规则表。

截至本稿日期，上交所和深交所 2026 年修订交易规则已于 2026 年 7 月 6 日施行，主板风险警示股票涨跌幅限制调整为 10%；科创板、创业板、北交所及特殊上市阶段仍按各自现行规则处理。[sse-rule-2026] [szse-rule-2026]

### 24. 数据质量、对账与可观测性

| 维度 | 检查 | 示例 |
|------|------|------|
| **完整性** | 应到数据是否到齐 | 交易日行情、财报科目、公告附件 |
| **唯一性** | 主键是否重复 | 同一证券、时点、公告版本 |
| **准确性** | 与权威源和勾稽关系是否一致 | 资产=负债+权益、涨跌幅复算 |
| **及时性** | 是否在 SLA 内到达 | 公告解析、日终行情、月度宏观 |
| **一致性** | 多来源和多表是否匹配 | 总股本、分红、上市状态 |
| **稳定性** | 字段和分布是否突变 | API 字段变化、数量级跳变 |
| **可追溯性** | 指标能否回到原文和代码 | 报告数字点击查看来源 |

关键数据采用双源对账；差异超过阈值时进入隔离区，不自动覆盖生产值。每次重跑保留任务版本、输入快照、代码提交、参数和输出校验摘要。

### 25. 信息处理与引用规范

1. 结论附近展示来源，不只在报告末尾堆链接。
2. 原文引用控制在必要范围，长文以摘要和定位信息代替复制。
3. 事实使用陈述语气，估计使用区间和置信度，观点标注作者。
4. 转载文章尽量追溯到原始政策、公告、论文或数据发布方。
5. 网页被更新时保留抓取时间、内容哈希和允许保存的快照。
6. 信息更正或公告修订要触发下游指标和研究结论重新计算。

### 28. 核心领域模型

### 29. 研究与计算引擎

#### 29.1 财务引擎

支持财报标准化、同比/环比、TTM、杜邦、ROIC、现金流质量、同业比较、异常检测和三表预测。计算公式、科目映射和行业例外均版本化。

#### 29.2 估值引擎

支持多模型、情景、敏感性、反向估值和可比公司选择。估值结果必须关联预测版本和市场价格时点。

#### 29.3 因子与回测引擎

统一处理交易日历、股票池、点时数据、复权、停牌、涨跌停、费用、滑点、容量、退市和再平衡。研究环境与生产计算使用同一因子定义，减少“研究能跑、上线变样”。

#### 29.4 组合与风险引擎

提供持仓穿透、暴露、协方差、风险贡献、情景、优化和绩效归因。风险结果注明数据窗口与模型假设。

#### 29.5 规则与告警引擎

支持事件触发、定时触发、阈值、组合条件和状态机。告警分信息、关注、重要、紧急四级，并具备去重、抑制、升级、确认和关闭流程。

### 30. AI 与自然语言能力边界

AI 可用于：

- 公告、政策和财报的结构化抽取与带引用摘要；
- 同比变化、关键条款、风险词和多文档差异提示；
- 自然语言检索、研究模板草拟和反方问题生成；
- 把已计算的数据转成可读解释；
- 协助建立实体关系，交由规则或人工确认。

AI 不得：

- 在没有来源的情况下补造财务数字、公告内容或政策条款；
- 把推断显示为事实；
- 未经复核自动修改基础数据或正式研究评级；
- 读取超出用户权限的研报、持仓、个人信息或受限数据；
- 基于低等级传闻自动生成并执行交易指令。

每段 AI 输出保存模型、提示模板、检索文档、生成时间和用户确认状态。关键数字应由结构化数据引擎计算，AI 只负责引用和解释。

### 31. 关键页面与工作流

#### 31.1 首页/市场雷达

展示市场宽度、风格、行业景气、重要政策与财报日历、组合风险和待处理告警。首页服务重复决策，不做营销式信息堆叠。

#### 31.2 公司研究页

按“结论与变化、假设与证据、财务预测、估值、事件、治理风险、行情资金、文档”组织。任何分数可展开到字段、公式和来源。

#### 31.3 行业页

展示产业链、公司映射、关键景气指标、供需与价格、政策时间线、盈利和估值分布。支持自定义行业篮子和内部标签。

#### 31.4 组合页

展示收益、持仓、风险贡献、行业/风格暴露、流动性、事件日历、情景损失和假设状态。调仓前执行预交易检查。

#### 31.5 研究流程

```text
创建线索 -> 认领研究 -> 快速排雷 -> 建立假设卡 -> 关联证据
        -> 预测与估值 -> 同行评审 -> 决策记录 -> 监控证伪 -> 复盘归档
```

### 32. API 与集成要求

- 对证券、财务、行情、事件、指标、假设、组合和告警提供稳定 API；
- 所有响应携带 `as_of_time`、`source`、`version` 和权限信息；
- 支持按公告时间而非报告期进行点时查询；
- 批量导出受数据许可和用户权限控制，并写审计日志；
- 与身份系统、对象存储、任务编排、消息通知和代码仓库集成；
- 下游报告引用稳定对象 ID，不依赖会变化的网页标题或简称；
- 研究数据 API 与交易 API 必须分离授权，接入行情、财务或研究数据不得隐式获得账户、下单或持仓修改权限；
- TqSdk 等交易开发包只能在未来完成独立设计、数据与交易授权、账户隔离、风控和实测验收后接入，当前仅作为候选能力示例。

### 33. 非功能要求

| 类别 | 基线要求 |
|------|----------|
| **可用性** | 交易时段核心查询和告警服务具备明确 SLO 与降级方案 |
| **性能** | 常用公司页和组合页在目标数据规模下满足交互响应要求 |
| **可扩展** | 数据源、策略、字段、行业模型和规则可插件化扩展 |
| **安全** | 最小权限、单点登录、敏感字段加密、密钥托管、审计日志 |
| **可追溯** | 数据、模型、报告和决策形成完整版本链 |
| **可测试** | 公式单测、数据契约、回归样本、回测金标和端到端测试 |
| **容灾** | 原始数据可重放，关键配置和研究资产有备份恢复演练 |
| **可观测** | 任务、数据新鲜度、质量、API、告警和模型漂移可监控 |

具体数值 SLO 在技术方案阶段根据用户规模、数据授权和成本确定，立项阶段不虚设无法验证的高可用承诺。

#### 33.1 推荐技术基线

在没有既有技术约束时，MVP 优先采用可本地部署、易审计、研究与生产口径一致的组合：

| 层次 | 建议基线 | 选择理由 |
|------|----------|----------|
| **采集与研究** | Python、Polars/Pandas、PyArrow | 金融数据生态成熟，便于结构化和回测 |
| **任务编排** | Dagster、Prefect 或现有调度平台三选一 | 支持依赖、重试、资产和运行记录 |
| **事务与元数据** | PostgreSQL | 主数据、研究对象、权限和版本关系清晰 |
| **历史数据湖** | 对象存储 + Parquet | 保存原始与点时快照，成本可控、便于重放 |
| **分析查询** | DuckDB 起步；规模达到阈值后评估 ClickHouse | 避免 MVP 过早引入分布式复杂度 |
| **检索** | PostgreSQL 全文检索起步；需要时引入 OpenSearch | 公告和政策检索可渐进扩展 |
| **服务层** | FastAPI 或项目既有后端框架 | 便于暴露结构化研究与计算 API |
| **前端** | TypeScript + React 及既有组件体系 | 适合高密度研究工作台和交互图表 |
| **缓存与异步** | Redis/消息队列按实际负载引入 | 用于热点缓存、任务和告警，不作为事实库 |
| **部署** | Docker Compose/单集群起步，达到运维门槛再评估 Kubernetes | 保持可重复部署，控制早期运维成本 |
| **质量与观测** | 数据契约、pytest、任务指标、日志与错误追踪 | 让公式、数据和运行问题可定位 |

最终技术选型应在 P0 阶段通过小规模基准测试确认，重点比较数据量、并发、查询模式、团队能力、运维成本和许可，而不是仅按技术流行度决定。

### 34. 安全、合规与伦理要求

1. 遵守证券、数据安全、网络安全、个人信息、著作权和商业秘密相关要求。
2. 建立数据许可台账，限制下载、缓存、展示、衍生和再分发。
3. 对持仓、交易、内部评级、联系方式和访谈记录实施分级授权。
4. 研究员接触可能的未公开重大信息时，支持名单隔离和操作留痕。
5. 对程序化交易报告、交易所异常交易监控和内部交易限制保持规则更新。
6. 工具必须展示数据延迟、缺失、估算和模型风险，不制造虚假确定性。
7. 所有自动化输出保留人工复核、撤销和申诉机制。

### 35. 分期建设路线图

| 阶段 | 目标 | 核心交付 |
|------|------|----------|
| **P0 立项与治理** | 固化范围、口径、许可和架构 | 数据源登记、主数据方案、指标字典、原型、验收基线 |
| **P1 MVP** | 跑通公司研究最小闭环 | 证券主数据、公告财报、行情、公司页、假设卡、基础估值与告警 |
| **P2 研究增强** | 补齐行业、政策、事件和策略研究 | 行业景气、政策库、事件中心、筛选器、因子/事件研究 |
| **P3 组合闭环** | 从个股研究扩展到组合决策 | 持仓、风险暴露、压力测试、预交易检查、归因复盘 |

每阶段是否进入下一阶段，以数据质量和用户验收为门槛，不以功能清单“开发完成”单独判定。

### 36. MVP 范围

#### 36.1 必须具备

- A 股证券与发行人主数据及历史上市状态；
- 日行情、复权、交易日历和公司行动；
- 定期报告、临时公告、财务标准化与原文定位；
- 公司研究页、投资假设卡、证据和失效条件；
- 基础财务指标、同行比较、三情景估值；
- 自选池、研究任务、重要公告与财务风险告警；
- 数据来源、发布时间、版本、质量和授权元数据；
- 权限、日志、备份和基础运维监控。

#### 36.2 延后建设

- 分钟级全市场策略和复杂执行算法；
- 大规模另类数据与卫星数据；
- 自动交易和券商柜台直连；
- 期货、期权实时数据、模拟交易、程序化执行和真实交易柜台集成，TqSdk 等仅作为候选能力示例；
- 复杂衍生品定价；
- 无人工复核的全自动研报和评级。

### 38. 验收标准

#### 38.1 数据验收

- 抽样证券的代码、上市状态、总股本和公司行动与 L0/L1 来源一致；
- 财务报表关键科目可回到原公告，三表勾稽和单位校验通过；
- 行情复权在分红、送转、配股等金标案例上计算正确；
- 公告、财报和规则均保存事件时间、公开时间、采集时间和版本；
- 数据延迟、缺失和冲突在界面可见并能进入处理流程。

#### 38.2 研究验收

- 假设卡必填项完整，证据和反证可定位来源；
- 预测和估值结果可重算，参数敏感性可解释；
- 因子和回测无未来函数，包含交易成本、停牌、涨跌停和退市处理；
- 筛选、评分和告警可展开到公式、阈值和版本；
- 修改数据或模型后，受影响研究能被识别并提示复核。

#### 38.3 产品验收

- 用户可从线索完成研究、评审、决策、监控和复盘闭环；
- 公司、行业、组合页面在典型任务中无需跨多个外部平台反复比对；
- 权限隔离、批量导出、敏感操作和 AI 调用有审计记录；
- 核心任务失败有告警、重试、降级和人工处理入口；
- 新增一个数据源或策略不需要改造整个系统。

### 39. 运营与效果指标

| 方向 | 指标示例 | 防误用说明 |
|------|----------|------------|
| **数据** | 完整率、准确率、新鲜度、问题关闭时间 | 不用单一平均数掩盖关键字段缺失 |
| **研究效率** | 从线索到初稿时间、自动填充率、重复劳动减少 | 不以报告篇数鼓励低质量产出 |
| **研究质量** | 有效证据覆盖、预测误差、假设按期复查率 | 收益不是短期唯一质量指标 |
| **风险** | 告警发现提前量、重大风险漏报、组合集中度 | 控制误报，保留人工判断 |
| **使用** | 周活跃、核心流程完成率、检索成功率 | 不追求无意义停留时长 |
| **系统** | 可用性、查询延迟、任务成功率、恢复时间 | 按功能重要性分级统计 |

| **数据负责人** | 数据选型、口径、质量、血缘和授权 |
| **技术负责人** | 架构、工程质量、性能、安全和运维 |
| **合规/法务** | 数据许可、信息隔离、内容与交易合规 |
| **模型风险负责人** | 回测、估值、风险模型和 AI 模型的独立验证 |
| **用户代表** | 试用、场景验证、缺陷反馈和上线签收 |

建立数据委员会、策略评审会和版本变更流程。重大口径或模型变更需要说明影响范围、历史重算方案和回滚路径。

### 41. 主要风险与应对

| 风险 | 表现 | 应对 |
|------|------|------|
| **数据授权风险** | 接口可用但不允许生产或展示 | 立项即建许可台账，关键源准备替代方案 |
| **口径与时点污染** | 回测使用修订后或未来可得数据 | 双时间模型、点时快照、金标测试 |
| **范围膨胀** | 同时建设全部资产与全部策略 | 以公司研究闭环为 MVP，按门槛扩展 |
| **黑箱评分** | 用户只看总分，不理解风险 | 分项展示、来源和贡献解释，保留反证 |
| **模型过拟合** | 历史漂亮、实盘失效 | 样本外、走步检验、成本和稳定性测试 |
| **AI 幻觉** | 数字、政策或公告被错误概括 | 检索引用、结构化计算、人工确认 |
| **规则过期** | 交易制度和监管变化未更新 | 规则库带生效期，官方源监控和回归测试 |
| **告警疲劳** | 提醒过多导致关键风险被忽略 | 分级、去重、抑制、责任人和反馈学习 |
| **关键数据断供** | 供应商变更或接口停止 | 适配层、缓存策略、替代源和降级模式 |
| **研究同质化** | 工具让所有人得到同一结论 | 展示分歧、支持自定义假设与内部数据 |

### 42. 立项决策门槛

进入开发前应完成以下决策：

- [ ] 明确 MVP 用户、证券范围和前三个高频场景；
- [ ] 确认公告、财务、行情和主数据的合法生产数据源；
- [ ] 完成核心字段口径、证券主数据和点时模型评审；
- [ ] 确认部署方式、用户规模、预算和安全等级；
- [ ] 选定 20 至 50 只跨板块、跨行业的验收样本；
- [ ] 准备分红送转、停牌、风险警示、退市和财报修订金标案例；
- [ ] 明确研究结论、AI 内容和交易建议的合规边界；
- [ ] 确定项目负责人、数据责任人和最终验收人。

## 第六部分 A 股研究方法详解

### 一、核心框架：从“看懂股票”到“做出决策”

股票分析的目标不是把所有信息都看一遍，而是回答三个问题：

1. **这家公司或资产值不值得研究？**
2. **当前价格是否给出了足够的预期差和安全边际？**
3. **如果判断错了，如何控制损失并及时修正？**

因此，中国股票分析可以归纳为“六维闭环”：

| 维度 | 核心问题 | 主要作用 | 常见输出 |
|------|----------|----------|----------|
| **基本面** | 这是不是一门好生意？公司是否优秀？ | 判断长期价值来源 | 投资逻辑、竞争优势、成长路径 |
| **估值面** | 价格是否合理？赔率是否够高？ | 判断买入价格和安全边际 | 估值区间、情景假设、目标收益 |
| **技术面** | 何时买、何时卖、错了怎么退？ | 优化交易时点和风控执行 | 趋势、支撑阻力、止损位 |
| **资金面** | 谁在买卖？资金合力在哪里？ | 判断短中期边际力量 | 成交结构、机构行为、拥挤度 |
| **政策消息面** | 有什么催化或冲击？ | 判断预期差、制度变化和事件风险 | 催化清单、利空清单、事件日历 |
| **情绪与风控** | 市场是否过热或过冷？组合能否活下来？ | 防止人性和仓位毁掉判断 | 仓位计划、回撤控制、复盘机制 |

更简洁地说：

- **基本面决定方向**：长期赚钱来自企业价值创造。
- **估值面决定赔率**：好公司太贵也可能不是好投资。
- **技术面决定执行**：把“看对”变成“做对”。
- **资金面决定节奏**：短中期价格由边际资金定价。
- **政策消息面决定催化**：A 股尤其重视政策和事件。
- **风控决定寿命**：能活过错误，才有资格等到正确。

### 二、A 股市场的底层环境

分析中国股票，不能只套用海外成熟市场框架。A 股的制度、投资者结构和政策传导方式，会显著影响估值、交易和风险控制。

#### 2.1 主要板块与风格差异

| 板块 | 主要定位 | 典型公司 | 分析重点 |
|------|----------|----------|----------|
| **沪深主板** | 成熟企业、传统行业龙头、央国企和大型民企 | 金融、消费、制造、周期、公用事业 | 盈利稳定性、分红、周期位置、资产质量 |
| **科创板** | 硬科技、创新型企业 | 半导体、高端装备、生物医药、AI、材料 | 技术壁垒、研发转化、产业化进度、估值容忍度 |
| **创业板** | 成长型创新企业 | 新能源、医药、TMT、先进制造 | 增速质量、竞争格局、盈利兑现能力 |
| **北交所** | 创新型中小企业、专精特新 | 中小制造、细分龙头 | 流动性、治理质量、成长天花板、估值折价 |
| **ST/风险警示股票** | 财务或治理存在明显风险 | 亏损、违规、退市风险公司 | 保壳概率、资产重组真实性、退市风险 |

#### 2.2 A 股交易机制对分析的影响

| 机制 | 对投资分析的影响 |
|------|------------------|
| **T+1 交易** | 当日买入无法当日卖出，短线策略必须预留隔夜风险。 |
| **涨跌幅限制** | 极端行情下可能无法及时成交，止损和止盈不一定能按计划执行。 |
| **融资融券有限制** | 做空工具不充分，市场更容易呈现单边拥挤和题材炒作。 |
| **交易单位与最小报价单位** | 对低价股、北交所、小盘股的交易摩擦和滑点影响更大。 |
| **新股、重组、风险警示等特殊规则** | 价格限制、停复牌、临时停牌和信息披露要求可能不同。 |

截至 2026 年 7 月 12 日，常见涨跌幅框架可作初步认知：沪深主板普通股票和主板风险警示股票通常为 10%，科创板和创业板普通股票通常为 20%，北交所股票通常为 30%。其中沪深主板风险警示股票 10% 的新安排自 2026 年 7 月 6 日起施行。新股上市初期、退市整理、重新上市等情形存在特殊安排，工具应按交易所、板块、证券状态和生效日期查询规则表，不应只靠这段文字判断。[sse-rule-2026] [szse-rule-2026] [bse-rule]

#### 2.3 全面注册制后的分析重点

2023 年 2 月 17 日，证监会发布全面实行股票发行注册制相关制度规则，并同步实施配套制度安排。注册制强调以信息披露为核心，发行上市条件更包容，也意味着二级市场投资者需要更强的定价和筛选能力。[registration]

对投资者而言，注册制环境下需要特别关注：

- **供给增加**：上市公司数量和融资工具增加，壳价值下降，差公司更难长期依靠稀缺性维持估值。
- **分化加剧**：真正有竞争力的公司更容易获得资本支持，低质量公司更容易被边缘化。
- **退市常态化**：财务、交易、规范和重大违法退市风险都需要纳入研究前置检查。
- **信息披露质量更重要**：招股书、年报、问询函和监管函成为研究公司的关键材料。

#### 2.4 A 股的结构性特征

1. **政策传导强**
   产业政策、财政货币政策、资本市场制度改革都会影响市场风险偏好和行业景气。

2. **散户参与度高**
   情绪、题材、涨跌停、短线资金对阶段性价格影响明显。

3. **机构化趋势增强**
   公募、私募、保险、社保、ETF、外资和量化资金提高了定价效率，也带来了风格拥挤和调仓冲击。

4. **行业轮动快**
   A 股经常在政策、景气、资金和情绪之间快速轮动，同一行业的估值中枢会发生大幅变化。

5. **信息披露与实际经营之间存在时滞**
   财报是滞后信息，产业链价格、订单、库存、招投标、渠道反馈等高频数据常常领先股价。

### 三、标准研究流程

#### 3.1 从线索到决策的八步法

| 步骤 | 目标 | 关键问题 | 输出 |
|------|------|----------|------|
| 1. 线索来源 | 找到值得研究的对象 | 来自财报、政策、产业趋势、价格异动还是同行对比？ | 研究候选池 |
| 2. 快速排雷 | 避免把时间浪费在高风险公司 | 是否亏损恶化、现金流差、审计异常、控股股东高质押？ | 放弃或进入深研 |
| 3. 行业判断 | 判断赛道是否值得 | 行业空间、格局、周期、政策和技术路线如何？ | 行业景气判断 |
| 4. 公司质地 | 判断公司是否具备优势 | 商业模式、护城河、治理、执行力是否可靠？ | 核心投资逻辑 |
| 5. 财务验证 | 检验故事是否被数字支持 | 利润是否真实？现金流是否匹配？ROE 从何而来？ | 财务质量结论 |
| 6. 估值测算 | 判断赔率 | 乐观、中性、悲观情形下值多少钱？ | 估值区间 |
| 7. 交易计划 | 制定买卖和风控 | 何时买？买多少？错了在哪里退出？ | 仓位与止损计划 |
| 8. 跟踪复盘 | 持续修正 | 哪些变量验证或推翻了原假设？ | 持有、加仓、减仓或卖出 |

#### 3.2 一页纸研究模板

| 模块 | 需要写清楚的内容 |
|------|------------------|
| **一句话逻辑** | 为什么这家公司未来会比市场预期更好？ |
| **行业判断** | 行业空间、景气阶段、竞争格局、政策方向。 |
| **公司优势** | 成本、品牌、渠道、技术、规模、资源、管理、客户关系。 |
| **财务证据** | 收入、利润、毛利率、ROE、现金流、负债、周转、分红。 |
| **估值区间** | 悲观、中性、乐观三种情形下的合理市值或股价区间。 |
| **催化因素** | 业绩、订单、价格、政策、产品、并购、回购、分红等。 |
| **风险因素** | 需求、价格、成本、竞争、政策、治理、流动性、估值杀。 |
| **失效条件** | 哪些事实出现，说明原投资逻辑已经错了？ |
| **交易计划** | 买入区间、目标仓位、止损条件、跟踪频率、复盘日期。 |

#### 3.3 研究优先级

研究时间有限，优先研究同时满足以下条件的公司：

- 行业长期空间清晰，短中期景气有改善迹象。
- 公司具备可验证的竞争优势，而不是只有概念。
- 财务数据能支持商业逻辑，利润和现金流不背离。
- 估值没有透支所有乐观假设。
- 存在明确催化或预期差。
- 风险能被识别、定价和控制。

### 四、基本面分析：判断价值创造能力

基本面分析回答的是：**这家公司是否能持续创造现金流，以及这种现金流是否值得用当前价格购买。**

#### 4.1 宏观分析：判断大环境

宏观分析不是预测 GDP 的小数点，而是判断企业盈利、利率、流动性和风险偏好的方向。

| 变量 | 观察指标 | 影响路径 |
|------|----------|----------|
| **经济增长** | GDP、工业增加值、PMI、社零、固定资产投资 | 影响收入增速和需求强弱 |
| **货币信用** | M2、社融、信贷、LPR、存款准备金率 | 影响估值折现率、资金成本和风险偏好 |
| **通胀与价格** | CPI、PPI、大宗商品价格 | 影响成本、利润率和周期行业盈利 |
| **地产链** | 房地产销售、新开工、竣工、土地成交 | 影响建材、家电、金融、地方财政等 |
| **出口链** | 出口增速、汇率、海外库存、贸易政策 | 影响制造、电子、机械、纺织、航运 |
| **财政政策** | 赤字率、专项债、特别国债、基建投资 | 影响顺周期和政策支持行业 |
| **汇率与外部流动性** | 人民币汇率、美债收益率、美元指数 | 影响外资流向、出口利润和估值压力 |

宏观分析的实战原则：

- **看方向，不迷信点位**：大多数投资不需要预测具体数值，只需要判断改善、恶化或震荡。
- **看传导链条**：政策宽松不等于企业盈利改善，必须追踪信用是否进入实体需求。
- **看行业敏感度**：消费、医药、公用事业对宏观波动较低；地产、钢铁、化工、机械、券商更敏感。
- **看预期差**：宏观数据本身不重要，重要的是是否显著偏离市场预期。

#### 4.2 行业分析：判断赛道质量

行业分析要回答四个问题：

1. **需求从哪里来？**
   是人口、收入、技术替代、政策驱动，还是库存周期？

2. **供给是否受约束？**
   产能扩张难不难？准入门槛高不高？技术路线会不会快速迭代？

3. **利润留给谁？**
   上游、中游、下游谁更有议价权？龙头和二三线企业差距多大？

4. **估值中枢为何变化？**
   是成长性提升、确定性提升、利率下降，还是单纯情绪推动？

##### 行业分析框架

| 框架 | 用法 | 注意点 |
|------|------|--------|
| **生命周期** | 导入期、成长期、成熟期、衰退期 | 成长期重空间，成熟期重格局和现金流 |
| **波特五力** | 现有竞争、潜在进入者、替代品、供应商、客户 | 不要只看竞争对手，还要看上下游 |
| **PEST** | 政策、经济、社会、技术 | 适合政策和技术变化强的行业 |
| **产业链利润分配** | 判断上下游议价权 | 价格上涨不一定代表中游盈利改善 |
| **供需缺口** | 产能、库存、订单、价格 | 周期行业尤其重要 |
| **单位经济模型** | 单价、成本、毛利、复购、获客成本 | 消费、互联网、软件、连锁服务适用 |

##### 不同行业的关键变量

| 行业类型 | 核心变量 | 常见风险 |
|----------|----------|----------|
| **消费品** | 品牌力、渠道、价格带、复购、库存、毛利率 | 渠道压货、品牌老化、需求降级 |
| **医药** | 研发管线、临床进展、医保控费、集采、销售合规 | 政策降价、研发失败、专利到期 |
| **新能源** | 装机、渗透率、产能、技术路线、价格 | 产能过剩、价格战、补贴退坡 |
| **半导体** | 周期、国产替代、良率、客户认证、资本开支 | 技术迭代、库存周期、外部限制 |
| **周期资源** | 价格、库存、产能、成本曲线、供给约束 | 高点误判、需求下行、政策限产变化 |
| **银行** | 净息差、资产质量、拨备、不良、资本充足率 | 地产和地方债暴露、息差收窄 |
| **保险** | 新业务价值、投资收益、负债成本、偿付能力 | 利率下行、权益波动、产品转型 |
| **券商** | 成交额、两融、投行、资管、自营、资本市场政策 | 市场低迷、自营波动、监管变化 |
| **公用事业** | 利用小时、上网电价、煤价、资本开支、分红 | 政策定价、成本波动、负债率 |
| **软件/SaaS** | ARR、续费率、客户留存、毛利率、销售费用率 | 回款慢、定制化过重、盈利兑现难 |

#### 4.3 公司分析：判断竞争优势

好公司通常具备以下特征：

- **商业模式清晰**：知道钱从哪里来，成本由什么决定，增长靠什么驱动。
- **客户愿意持续付费**：不是一次性需求，也不是靠补贴或低价硬撑。
- **竞争优势可持续**：品牌、成本、渠道、技术、牌照、规模或生态网络能形成壁垒。
- **管理层可信**：战略稳定、资本配置理性、少讲大故事，多兑现承诺。
- **增长质量高**：收入增长能转化为利润和现金流，而不是靠赊销、补贴、并购堆出来。

##### 商业模式拆解

| 问题 | 解释 |
|------|------|
| **卖什么？** | 产品或服务是否刚需？是否容易被替代？ |
| **卖给谁？** | 客户集中度如何？客户议价能力强不强？ |
| **怎么卖？** | 直销、经销、电商、招投标、订阅、项目制？ |
| **怎么赚钱？** | 毛利率由什么决定？费用率是否可控？ |
| **怎么增长？** | 提价、销量、市占率、新品、出海、并购、产业升级？ |
| **怎么防守？** | 竞争者为什么不能轻易抢走利润？ |

##### 护城河的常见类型

| 护城河 | 典型表现 | 验证方法 |
|--------|----------|----------|
| **品牌** | 能提价、用户复购、渠道愿意推 | 毛利率稳定高于同行，广告费用率不过度上升 |
| **成本优势** | 同质产品下成本最低 | 单位成本、规模、供应链、能源或资源优势 |
| **技术壁垒** | 客户认证难、性能领先、专利积累 | 研发投入、良率、客户结构、产品迭代 |
| **网络效应** | 用户越多价值越高 | 用户留存、生态伙伴、平台交易密度 |
| **渠道壁垒** | 终端覆盖强、销售效率高 | 渠道库存、经销商质量、费用投放效率 |
| **牌照/资源** | 供给受行政或资源约束 | 政策文件、资源储量、许可证、配额 |
| **转换成本** | 客户更换供应商代价高 | 续约率、客户生命周期、迁移成本 |

#### 4.4 财务分析：让数字验证故事

财务分析的核心不是背指标，而是识别：**利润是否真实、现金流是否健康、增长是否可持续、风险是否被隐藏。**

##### 三张报表联动

| 报表 | 看什么 | 核心问题 |
|------|--------|----------|
| **资产负债表** | 资产、负债、权益的结构 | 公司家底是否扎实？负债是否危险？ |
| **利润表** | 收入、成本、费用、利润 | 公司是否真的赚钱？利润率趋势如何？ |
| **现金流量表** | 经营、投资、筹资现金流 | 赚到的钱是否变成现金？增长靠自身还是靠融资？ |

##### 杜邦分析

杜邦分析将 ROE 拆解为盈利能力、运营效率和财务杠杆：

```text
ROE = 销售净利率 × 总资产周转率 × 权益乘数

ROE = (净利润 / 营业收入) × (营业收入 / 总资产) × (总资产 / 股东权益)
```

| 指标 | 含义 | 高值说明 | 风险提示 |
|------|------|----------|----------|
| **销售净利率** | 每 1 元收入赚多少净利润 | 产品有溢价或成本控制强 | 可能受一次性收益或费用资本化影响 |
| **总资产周转率** | 资产转化为收入的效率 | 运营效率高、资产轻 | 低毛利高周转模式抗风险较弱 |
| **权益乘数** | 杠杆水平 | 借钱放大 ROE | 高杠杆在下行周期会放大损失 |

高 ROE 不一定代表好公司。必须追问：

- ROE 是来自高利润率、高周转，还是高杠杆？
- ROE 是否连续多年稳定？
- 高 ROE 是否伴随高经营现金流？
- 高 ROE 是否靠低资本开支维持，还是需要持续大量投入？

##### 关键财务指标

| 类别 | 指标 | 重点解释 |
|------|------|----------|
| **盈利能力** | 毛利率、净利率、ROE、ROA、ROIC | ROIC 更能衡量经营资产回报，适合比较资本效率 |
| **成长能力** | 收入增速、利润增速、经营现金流增速 | 增长要看质量，不能只看利润表 |
| **偿债能力** | 资产负债率、有息负债率、流动比率、速动比率、利息保障倍数 | 周期行业和重资产企业尤其重要 |
| **运营效率** | 存货周转、应收账款周转、应付账款周转、总资产周转 | 周转恶化可能领先利润下滑 |
| **现金流质量** | 经营现金流/净利润、自由现金流、资本开支/收入 | 利润长期高于现金流要警惕 |
| **股东回报** | 分红率、股息率、回购、每股收益增长 | 分红稳定性比单年高股息更重要 |

##### 财务质量红旗

出现以下现象时，应降低估值容忍度，必要时直接放弃：

- 净利润增长很快，但经营现金流长期显著低于净利润。
- 应收账款、合同资产或存货增速显著高于收入增速。
- 毛利率明显高于同行，却没有合理商业解释。
- 大额商誉、长期股权投资或其他应收款占比过高。
- 频繁并购、频繁更换审计机构、审计意见异常。
- 大量关联交易、资金占用、对外担保、控股股东高比例质押。
- 靠政府补助、投资收益、资产处置等非经常性收益撑利润。
- 研发费用资本化比例异常高，或费用率突然大幅下降。
- 少数股东损益与归母利润关系异常。
- 分红能力弱却持续大额融资，或一边融资一边高分红。

#### 4.5 公司治理与股东结构

A 股公司治理差异很大，治理风险往往比经营风险更致命。

重点观察：

- **实际控制人**：背景、信用、过往资本运作记录。
- **股权结构**：是否一股独大，是否存在控制权争夺。
- **股权质押**：质押比例、平仓风险、是否反复补充质押。
- **高管激励**：股权激励目标是否合理，是否真绑定长期业绩。
- **分红回购**：是否持续回报股东，回购是否注销。
- **关联交易**：价格是否公允，是否存在利益输送。
- **信息披露**：公告是否及时、清晰、可验证，是否频繁被问询。

### 五、估值分析：从“好公司”到“好价格”

估值不是算出一个精确价格，而是建立一个合理区间，并判断当前价格是否给出足够的赔率。

#### 5.1 估值的基本原则

1. **先定性，再定量**
   不理解商业模式，任何模型都只是数字游戏。

2. **用区间，不用单点**
   估值应包含悲观、中性、乐观三种情形。

3. **匹配行业和阶段**
   银行看 PB 和资产质量，消费看现金流和品牌，周期股看周期位置，科技股看技术路线和兑现概率。

4. **重视安全边际**
   安全边际来自低估、确定性、分红、资产保护或明确催化，而不是主观乐观。

5. **估值必须可复盘**
   买入时写清楚核心假设，未来根据事实修正，而不是根据股价涨跌改口。

#### 5.2 绝对估值：DCF 与现金流折现

DCF 的核心公式：

```text
企业价值 = Σ [FCFF_t / (1 + WACC)^t] + TV / (1 + WACC)^n

FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本开支 - 净营运资本增加
TV = FCFF_n × (1 + g) / (WACC - g)
```

DCF 的关键不是公式，而是三个假设：

| 假设 | 含义 | 常见错误 |
|------|------|----------|
| **自由现金流** | 企业未来能产生多少可分配现金 | 把会计利润当现金流 |
| **折现率** | 对不确定性的补偿要求 | 对高风险公司使用过低折现率 |
| **永续增长率** | 长期增长假设 | 永续增长率设得过高，导致终值虚高 |

DCF 适用于现金流相对稳定、商业模式可预测的公司，如高质量消费、公用事业、成熟制造、部分医药和软件公司。对早期科技、强周期、现金流波动大的企业，DCF 更适合作为情景分析，而不是精确估值工具。

#### 5.3 相对估值

| 方法 | 公式 | 适用场景 | 主要缺陷 |
|------|------|----------|----------|
| **PE** | 市值 / 归母净利润 | 稳定盈利公司 | 周期高点利润会低估 PE，亏损公司不可用 |
| **PB** | 市值 / 净资产 | 银行、保险、券商、周期、重资产 | 轻资产公司账面净资产意义有限 |
| **PS** | 市值 / 收入 | 早期成长、软件、互联网、创新药商业化前后 | 收入不等于利润，容易忽视费用和现金流 |
| **PEG** | PE / 盈利增速百分数 | 高成长公司 | 增速不可持续时会误导 |
| **EV/EBITDA** | 企业价值 / EBITDA | 资本结构差异大、折旧摊销较高行业 | 忽略维持性资本开支 |
| **P/FCF** | 市值 / 自由现金流 | 现金流稳定公司 | 自由现金流单年波动可能较大 |
| **股息率** | 每股股息 / 股价 | 高分红、公用事业、银行、能源 | 高股息可能来自股价下跌，不一定安全 |
| **SOTP** | 分部估值相加 | 多业务集团、控股平台 | 分部假设复杂，容易重复计算 |

#### 5.4 行业估值要点

| 行业 | 常用方法 | 关键调整 |
|------|----------|----------|
| **银行** | PB、ROE、股息率 | 资产质量、拨备覆盖率、净息差、资本充足率 |
| **保险** | P/EV、PB、NBV | 利率、投资收益、负债成本、新业务价值 |
| **券商** | PB、PE、周期位置 | 成交额、两融、IPO/再融资、财富管理、自营波动 |
| **消费** | PE、DCF、股息率 | 品牌生命周期、渠道库存、提价能力、费用投放 |
| **医药** | PE、DCF、管线估值 | 集采、医保、专利、临床进度、销售合规 |
| **周期资源** | PB、EV/EBITDA、吨市值 | 商品价格、成本曲线、库存、产能周期 |
| **新能源制造** | PE、EV/EBITDA、PEG | 价格战、技术路线、产能利用率、海外壁垒 |
| **半导体** | PS、PB、周期利润、SOTP | 库存周期、客户认证、国产替代、资本开支 |
| **软件/SaaS** | PS、ARR 倍数、DCF | 续费率、毛利率、销售费用率、回款质量 |
| **公用事业** | DCF、股息率、PB | 电价机制、燃料成本、资本开支、负债率 |

#### 5.5 三情景估值

估值时至少建立三种情景：

| 情景 | 假设 | 用途 |
|------|------|------|
| **悲观情景** | 需求下滑、利润率下降、估值收缩 | 判断最大亏损和是否有资产保护 |
| **中性情景** | 公司按合理经营计划发展 | 判断当前价格是否合理 |
| **乐观情景** | 景气改善、份额提升、估值扩张 | 判断潜在收益空间 |

一个理想的投资机会通常满足：

```text
悲观情景亏损可承受
中性情景收益有吸引力
乐观情景收益显著
且核心假设能够持续跟踪验证
```

### 六、技术面分析：把判断变成可执行交易

技术分析回答的是：**价格和成交已经反映了什么？当前交易是否有合适的风险收益比？**

技术分析不应替代基本面。大量实证研究提示，简单均线、突破等规则在考虑交易成本后很难稳定跑赢买入并持有策略。技术分析更适合作为交易执行、仓位管理和风险控制工具，而不是单独预测未来的“圣杯”。[tech-cost]

#### 6.1 技术分析的三大前提

1. **价格反映信息和预期**
   股价不是只反映基本面，也反映流动性、情绪和资金约束。

2. **趋势具有惯性**
   一旦形成共识，价格可能沿趋势运行一段时间。

3. **人性反复出现**
   恐惧、贪婪、追涨杀跌会形成相似的价格行为。

#### 6.2 多周期分析

| 周期 | 作用 | 典型问题 |
|------|------|----------|
| **月线/周线** | 判断大趋势和估值位置 | 是否处在长期上升、震荡还是下降？ |
| **日线** | 判断中期结构 | 是否突破、回踩、放量、背离？ |
| **60 分钟/30 分钟** | 优化买卖点 | 是否有短线确认或失效信号？ |
| **分时** | 执行交易 | 是否追高？是否有承接？是否被情绪裹挟？ |

原则：**大周期决定方向，小周期决定入场。不要用 5 分钟图否定周线趋势，也不要用周线图忽视短线止损。**

#### 6.3 K 线与价格结构

| 结构 | 含义 | 注意点 |
|------|------|--------|
| **趋势上行** | 高点和低点逐步抬高 | 回调不破关键低点，趋势仍在 |
| **趋势下行** | 高点和低点逐步降低 | 反弹可能只是下降中继 |
| **箱体震荡** | 价格在区间内来回 | 上沿不追，下沿不恐慌，突破需确认 |
| **放量突破** | 有资金推动价格越过关键区域 | 需观察突破后是否回落失效 |
| **缩量回踩** | 卖压减弱，可能形成二次买点 | 前提是基本面和大趋势未破坏 |
| **放量滞涨** | 大量成交但价格不再上行 | 可能是分歧加剧或资金派发 |
| **破位下跌** | 跌破关键支撑或平台 | 先控制风险，再讨论价值 |

#### 6.4 常用技术指标

| 类别 | 指标 | 用法 | 限制 |
|------|------|------|------|
| **趋势类** | MA、EMA、MACD、BOLL | 判断趋势方向和强弱 | 滞后，震荡市容易反复失效 |
| **动量类** | RSI、KDJ、Williams %R | 判断超买超卖和背离 | 强趋势中超买可持续很久 |
| **成交量类** | OBV、量比、换手率、VSA | 判断资金参与程度 | 数据口径和短线情绪干扰大 |
| **波动率类** | ATR、布林带宽度 | 设定止损和观察变盘 | 不能判断方向 |
| **市场宽度** | 涨跌家数、创新高/新低数 | 判断指数背后的真实强弱 | 极端行情下可能钝化 |

Williams %R 通常显示为 -100 到 0，接近 -80 以下偏超卖，接近 -20 以上偏超买；部分软件会转换为 0 到 100 显示，使用时要确认方向。

#### 6.5 经典理论的正确使用

| 理论 | 可借鉴之处 | 容易误用之处 |
|------|------------|--------------|
| **道氏理论** | 趋势分级、成交量确认、趋势持续到反转 | 机械等待确认可能错过大部分行情 |
| **K 线理论** | 观察多空力量和短线分歧 | 单根 K 线意义有限，必须结合位置 |
| **艾略特波浪** | 理解趋势和调整的层级 | 数浪主观性强，容易事后解释 |
| **江恩理论** | 强调时间、价格和周期 | 预测色彩强，实证难度高 |
| **缠论** | 多级别、中枢、背驰、买卖点体系 | 学习门槛高，容易陷入过度画线 |

#### 6.6 A 股涨跌停生态

A 股的涨跌停制度会影响短线资金行为：

- **涨停不等于强基本面**：可能只是题材、筹码、情绪或流动性推动。
- **跌停不等于便宜**：跌停会压缩流动性，可能连续无法卖出。
- **连板股更重情绪和资金接力**：必须区分龙头、跟风和补涨。
- **炸板是重要分歧信号**：要看炸板后的承接、成交额和次日反馈。
- **天地板、地天板属于极端情绪**：不适合没有纪律的普通投资者参与。

#### 6.7 交易计划模板

买入前必须写清楚：

| 项目 | 说明 |
|------|------|
| **买入理由** | 基本面、估值、技术、资金、消息中哪些因素支持？ |
| **买入价格** | 为什么这个位置风险收益比合适？ |
| **目标仓位** | 初始仓位、加仓条件、最高仓位。 |
| **止损条件** | 技术破位、基本面证伪、估值逻辑失效还是组合风险超限？ |
| **止盈条件** | 达到估值上沿、催化兑现、趋势走弱还是更好机会出现？ |
| **复盘日期** | 何时复查财报、公告、行业数据和价格走势？ |

### 七、资金面分析：理解边际定价力量

资金面分析回答的是：**谁正在推动价格，推动力是否可持续。**

#### 7.1 资金主体

| 资金类型 | 特征 | 跟踪方式 |
|----------|------|----------|
| **公募基金** | 风格相对稳定，重仓股披露滞后 | 季报、基金持仓、基金发行、ETF 份额 |
| **私募基金** | 策略差异大，调仓更灵活 | 私募排排网、托管数据、行业访谈 |
| **保险/社保/养老金** | 长期资金，偏稳健和分红 | 定期报告、十大流通股东 |
| **外资/互联互通资金** | 偏好流动性和治理较好的公司 | 沪深港通披露、持股比例、行业配置 |
| **融资资金** | 杠杆做多，风险偏好较高 | 融资余额、融资买入额、维持担保比例 |
| **产业资本** | 控股股东、董监高、员工持股、回购 | 增减持公告、回购进度、股权激励 |
| **量化资金** | 高频或中高频交易、因子轮动 | 成交结构、微盘/小盘风格、异常波动 |
| **游资与短线资金** | 追求题材、连板、情绪周期 | 龙虎榜、涨停梯队、封单和换手 |
| **散户资金** | 情绪化、追涨杀跌倾向明显 | 成交活跃度、开户、社媒热度 |

#### 7.2 常用资金指标

| 指标 | 解释 | 使用要点 |
|------|------|----------|
| **成交额** | 资金参与强度 | 放量要结合价格位置判断 |
| **换手率** | 筹码交换速度 | 高换手可能是分歧，也可能是派发 |
| **龙虎榜** | 异常交易席位披露 | 看买卖双方结构，不只看知名席位 |
| **融资余额** | 杠杆资金存量 | 与市值、成交额和自身历史比较 |
| **ETF 份额** | 被动资金流向 | 指数和行业 ETF 的申赎能反映配置力量 |
| **基金发行** | 居民资金入市意愿 | 爆款基金常出现在情绪较热阶段 |
| **股东户数** | 筹码集中或分散 | 户数下降不必然上涨，要结合基本面 |
| **回购与增持** | 产业资本态度 | 回购是否注销、增持是否真金白银 |

#### 7.3 资金数据的陷阱

- **“主力资金”口径不统一**：多数平台按大单、中单、小单估算，并不等于真实机构买卖。
- **北向资金不是全部外资**：它只是互联互通口径下的一部分资金，且披露规则会调整。
- **龙虎榜是异常交易样本**：不能代表全部资金结构。
- **融资余额升高不一定利好**：可能代表看多，也可能代表拥挤和潜在踩踏。
- **放量不一定健康**：底部放量、顶部放量、突破放量和恐慌放量含义完全不同。

#### 7.4 资金面判断矩阵

| 价格 | 成交 | 资金含义 | 可能策略 |
|------|------|----------|----------|
| 上涨 | 放量 | 多头主动进攻 | 顺势观察，避免无计划追高 |
| 上涨 | 缩量 | 卖压轻或买盘不足 | 看位置，高位缩量需谨慎 |
| 下跌 | 放量 | 抛压释放或恐慌踩踏 | 不急接刀，等承接确认 |
| 下跌 | 缩量 | 参与意愿低，阴跌可能持续 | 等催化或放量反转 |
| 横盘 | 缩量 | 分歧下降，等待方向 | 关注突破方向 |
| 横盘 | 放量 | 筹码激烈交换 | 观察谁接走筹码 |

### 八、政策与消息面分析：寻找催化与风险

中国股票市场受政策影响较强，政策分析既要看方向，也要看落地机制。

#### 8.1 政策层级

| 层级 | 示例 | 影响 |
|------|------|------|
| **中央层面** | 中央经济工作会议、政治局会议、五年规划 | 决定中长期政策方向和风险偏好 |
| **国务院及部委** | 发改委、工信部、财政部、央行、住建部、医保局 | 决定行业具体政策和资源分配 |
| **监管机构** | 证监会、交易所、金融监管总局 | 影响资本市场制度、融资、减持、退市 |
| **地方政府** | 地方补贴、招商、产业基金、限购限售 | 影响区域性行业和企业订单 |
| **国际政策** | 关税、出口管制、地缘冲突、海外利率 | 影响出口链、科技链和风险偏好 |

#### 8.2 政策影响的五条路径

| 路径 | 含义 | 示例 |
|------|------|------|
| **需求创造** | 政策直接带来新增需求 | 设备更新、以旧换新、基建投资 |
| **供给约束** | 限产、环保、准入提高 | 钢铁、煤炭、化工、稀土 |
| **成本改变** | 税费、补贴、融资成本变化 | 减税降费、贴息贷款 |
| **估值重估** | 市场风险偏好或行业定位变化 | 国企改革、新质生产力、科技自主 |
| **风险暴露** | 监管收紧或商业模式受限 | 教培、平台经济、医药集采 |

#### 8.3 消息面分类

| 消息类型 | 重点判断 |
|----------|----------|
| **业绩预告/快报/定报** | 是否超预期？质量如何？可持续吗？ |
| **重大合同/订单** | 金额、毛利率、执行周期、回款条件、客户质量 |
| **并购重组** | 标的质量、估值、协同、是否利益输送 |
| **股权变动** | 实控人变化、增减持、质押、控制权争夺 |
| **产品与技术突破** | 是否已商业化？客户验证到什么阶段？ |
| **价格变化** | 是供需改善还是短期扰动？公司能否受益？ |
| **监管处罚/诉讼** | 是否影响经营资质、财务真实性或治理信任 |
| **海外事件** | 汇率、关税、制裁、原材料、全球同行估值 |

#### 8.4 消息分析原则

1. **先看来源**：上市公司公告、交易所问询、政府官网和权威数据优先。
2. **再看预期差**：市场是否已经提前交易？利好兑现可能反而下跌。
3. **判断利润影响**：消息最终要落到收入、毛利、费用、现金流或估值。
4. **区分短期和长期**：题材刺激可能很快结束，产业趋势可能持续多年。
5. **警惕“小作文”**：未经证实的市场传闻不能作为重仓依据。
6. **跟踪兑现**：政策发布只是开始，订单、价格、利润和现金流才是验证。

### 九、情绪与行为金融：识别市场和自己的偏差

情绪分析回答的是：**市场现在是在恐惧、怀疑、共识还是狂热？自己有没有被情绪带走？**

#### 9.1 市场情绪指标

| 指标 | 含义 | 极端信号 |
|------|------|----------|
| **涨跌家数** | 市场宽度 | 指数上涨但多数股票下跌，说明结构脆弱 |
| **涨跌停家数** | 短线情绪强弱 | 跌停激增常见于恐慌，涨停扩散常见于题材高潮 |
| **成交额/换手率** | 活跃度 | 极端放量可能是趋势确认，也可能是顶部换手 |
| **融资余额** | 杠杆情绪 | 快速上升后遇到下跌，容易形成踩踏 |
| **新发基金/ETF 申购** | 居民资金热度 | 爆款产品频出时需关注过热风险 |
| **股债收益率比** | 股票相对债券吸引力 | 股票收益率明显高于债券时长期性价比改善 |
| **AH 溢价** | A/H 风险偏好差异 | 溢价过高说明 A 股情绪可能更热 |
| **VIX/海外波动率** | 全球风险偏好 | 外部冲击会传导至高估值资产 |

#### 9.2 情绪周期

| 阶段 | 市场表现 | 投资者心理 | 应对 |
|------|----------|------------|------|
| **绝望期** | 成交低迷、估值低、坏消息钝化 | 不敢买，认为还会更差 | 寻找资产质量高、现金流稳的公司 |
| **怀疑期** | 指数修复、分歧大 | 涨了不信，跌了害怕 | 分批建仓，重视基本面验证 |
| **共识期** | 业绩和股价同步向上 | 逻辑被广泛接受 | 持有强势标的，防止估值透支 |
| **狂热期** | 估值脱离盈利，题材扩散 | 害怕踏空，追高加杠杆 | 降低仓位，卖给乐观者 |
| **退潮期** | 龙头补跌、利好无效 | 从犹豫到恐慌 | 执行止损，等待新周期 |

#### 9.3 常见认知偏差

| 偏差 | 表现 | 应对 |
|------|------|------|
| **锚定效应** | 被买入成本或历史高点束缚 | 以未来价值和风险为锚 |
| **确认偏差** | 只看支持自己观点的信息 | 主动写反方观点 |
| **损失厌恶** | 亏损死扛，盈利过早卖出 | 事前设定失效条件 |
| **过度自信** | 重仓单一判断，频繁交易 | 限制单票仓位和交易次数 |
| **羊群效应** | 看到别人赚钱就追 | 只买自己能解释的机会 |
| **近因效应** | 把最近涨跌当长期趋势 | 拉长周期，看经营事实 |
| **处置效应** | 卖盈利股、留亏损股 | 按预期收益和风险重新排序 |
| **幸存者偏差** | 只研究成功案例 | 同时研究失败公司和退市公司 |

### 十、组合与风险管理：先活下来，再谈收益

风险管理不是悲观，而是承认自己会错。优秀投资体系的核心不是每次都判断正确，而是错误发生时不会造成不可逆损失。

#### 10.1 风险类型

| 风险 | 说明 | 控制方法 |
|------|------|----------|
| **市场风险** | 系统性下跌，泥沙俱下 | 控制总仓位，使用指数和股债配置 |
| **行业风险** | 行业景气或政策逆转 | 行业分散，跟踪关键数据 |
| **个股风险** | 财务、治理、产品、管理问题 | 单票仓位限制，排雷清单 |
| **估值风险** | 好公司太贵，收益被透支 | 三情景估值，设置估值上限 |
| **流动性风险** | 想卖卖不掉，尤其小盘和跌停 | 避免重仓低流动性股票 |
| **杠杆风险** | 融资或衍生品放大亏损 | 不用无法承受的杠杆 |
| **黑天鹅风险** | 无法预测的突发事件 | 分散、止损、现金储备 |

#### 10.2 仓位管理

| 仓位类型 | 适用场景 |
|----------|----------|
| **观察仓** | 逻辑初步成立，但尚未充分验证 |
| **标准仓** | 逻辑、估值和交易位置都较好 |
| **核心仓** | 高确定性、高赔率、可长期跟踪 |
| **事件仓** | 催化明确但不确定性较高 |
| **短线仓** | 只按技术和资金交易，必须严格止损 |

实操原则：

- 单一股票不要让一次错误伤及组合生存。
- 同一行业或同一逻辑不要看似分散、实则高度相关。
- 高波动、高估值、低流动性股票应降低仓位。
- 越是靠估值修复赚钱，越要重视买入价格。
- 越是靠业绩增长赚钱，越要重视跟踪变量。

#### 10.3 止损与止盈

止损不是承认自己无能，而是承认市场可能给出了新的事实。

| 类型 | 触发条件 |
|------|----------|
| **基本面止损** | 核心逻辑被证伪，如需求不及预期、竞争恶化、现金流失真 |
| **估值止损** | 买入假设过于乐观，估值不再提供安全边际 |
| **技术止损** | 跌破关键支撑、趋势破坏、放量破位 |
| **组合止损** | 总回撤超过预设阈值，需降低整体风险 |
| **时间止损** | 催化迟迟不兑现，机会成本过高 |

止盈同样需要规则：

- 股价达到乐观估值上沿。
- 市场开始用更激进的假设定价。
- 基本面边际变弱但股价仍强。
- 更好的机会出现。
- 仓位过大，组合风险失衡。

#### 10.4 事前验尸清单

买入前问自己：

1. 如果这笔投资亏损 30%，最可能的原因是什么？
2. 这些原因中哪些可以提前跟踪？
3. 哪个事实出现后我必须承认自己错了？
4. 如果明天跌停，我是否还能执行计划？
5. 如果三个月没有上涨，我是否仍然愿意持有？
6. 我的仓位是否与不确定性匹配？
7. 我是在买价值、买趋势、买事件，还是只是在买情绪？

### 十一、现代金融理论与量化分析

现代金融理论提供的是理解风险和收益的语言，不应被当成万能模型。

#### 11.1 有效市场假说

| 类型 | 含义 | 对投资的启示 |
|------|------|--------------|
| **弱式有效** | 价格已反映历史价格和交易信息 | 简单技术信号难以长期稳定赚钱 |
| **半强式有效** | 价格已反映所有公开信息 | 公开信息优势会很快衰减 |
| **强式有效** | 价格反映所有信息，包括内幕 | 现实中几乎不可验证 |

A 股并非完全无效，也不是完全有效。信息传导、投资者结构、交易限制和政策变化会造成阶段性错误定价，但错误定价不一定马上修正。

#### 11.2 CAPM

```text
E(R_i) = R_f + β_i × [E(R_m) - R_f]

E(R_i)：资产 i 的预期收益率
R_f：无风险利率
β_i：资产 i 对市场的系统性风险暴露
E(R_m) - R_f：市场风险溢价
```

CAPM 的启示：

- 分散化可以降低非系统性风险。
- 高收益通常需要承担某种风险暴露。
- 不能只看绝对收益，要看风险调整后收益。

#### 11.3 多因子模型

Fama-French 三因子模型在市场因子之外加入市值和价值因子，五因子模型进一步加入盈利能力和投资风格因子。

常见股票因子：

| 因子 | 含义 | 风险 |
|------|------|------|
| **价值** | 低 PE、低 PB、高股息 | 可能买到价值陷阱 |
| **成长** | 高收入或利润增速 | 估值容易透支 |
| **质量** | 高 ROE、高 ROIC、现金流好 | 拥挤时估值过贵 |
| **动量** | 强者恒强 | 反转时回撤大 |
| **反转** | 超跌修复 | 弱者可能继续弱 |
| **低波动** | 波动较低、回撤较小 | 牛市中可能跑输 |
| **小市值** | 小盘弹性 | 流动性和退市风险更高 |
| **红利** | 高分红、高股息 | 需判断分红可持续性 |

#### 11.4 量化策略

| 策略 | 核心逻辑 | 关键风险 |
|------|----------|----------|
| **多因子选股** | 用因子组合筛选股票 | 因子失效、拥挤、风格切换 |
| **指数增强** | 在控制跟踪误差下获取超额收益 | 超额收益衰减、模型同质化 |
| **统计套利** | 利用价差回归 | 做空限制、流动性和极端行情 |
| **事件驱动** | 捕捉公告、财报、重组等事件 | 事件落空、样本不足 |
| **趋势跟踪** | 跟随价格趋势 | 震荡市反复亏损 |
| **机器学习** | 捕捉非线性关系 | 过拟合、样本外失效、解释性弱 |

量化回测必须注意：

- 不能使用未来函数。
- 必须包含交易成本、冲击成本和停牌/涨跌停约束。
- 必须考虑退市和幸存者偏差。
- 样本内有效不等于样本外有效。
- 因子拥挤会改变未来收益。

### 十二、不同投资风格的分析侧重

| 风格 | 核心收益来源 | 最重要的分析 | 主要风险 |
|------|--------------|--------------|----------|
| **价值投资** | 价格低于内在价值后的均值回归 | 估值、资产质量、现金流、安全边际 | 价值陷阱、长期不修复 |
| **成长投资** | 盈利持续高增长 | 行业空间、竞争优势、增速质量 | 估值透支、成长降速 |
| **红利投资** | 稳定分红和低波动 | 现金流、分红政策、负债、行业稳定性 | 高股息陷阱、盈利下滑 |
| **周期投资** | 周期底部到景气上行 | 价格、库存、产能、成本曲线 | 在周期顶部误判便宜 |
| **趋势投资** | 趋势延续和资金推动 | 技术面、资金面、市场情绪 | 反转快、回撤大 |
| **事件驱动** | 特定事件带来的重估 | 消息真实性、概率、兑现路径 | 事件失败、利好兑现 |
| **主题投资** | 政策和产业趋势扩散 | 政策强度、产业验证、龙头识别 | 概念炒作、退潮踩踏 |
| **量化投资** | 模型化的概率优势 | 数据、因子、组合、风控 | 过拟合、拥挤、交易成本 |

选择风格比预测市场更重要。不同风格的买入理由、持有周期、止损方式完全不同，不能用价值投资的理由买入，却用短线技术的恐惧卖出。

### 十四、综合决策框架

#### 14.1 六维评分卡

可以用 1 到 5 分对候选股票做初筛：

| 维度 | 1 分 | 3 分 | 5 分 |
|------|-----|-----|-----|
| **行业** | 空间小、竞争恶化 | 稳定但缺乏弹性 | 空间大、格局改善 |
| **公司** | 优势不清、治理差 | 有一定优势 | 护城河清晰、管理优秀 |
| **财务** | 利润和现金流差 | 基本健康 | 高质量增长、现金流强 |
| **估值** | 透支乐观预期 | 基本合理 | 悲观情景也有保护 |
| **技术** | 下降趋势破位 | 震荡等待方向 | 趋势向上且风险位清晰 |
| **资金/情绪** | 拥挤或明显退潮 | 分歧中性 | 资金改善且未过热 |
| **政策/消息** | 有重大不确定性 | 无明显催化 | 催化明确且可跟踪 |
| **风控** | 流动性差、仓位难控 | 风险可识别 | 风险可控且失效条件清楚 |

评分不是机械买卖信号，而是帮助发现短板。真正值得重仓的机会，通常不是所有维度满分，而是核心逻辑强、风险清晰、价格合适。

#### 14.2 买入、持有、卖出的决策标准

| 决策 | 条件 |
|------|------|
| **买入** | 基本面逻辑清晰，估值有安全边际，交易位置可控，失效条件明确。 |
| **加仓** | 原逻辑被新事实验证，估值仍未过度透支，组合风险允许。 |
| **持有** | 核心假设未变，估值未显著高估，短期波动不改变长期逻辑。 |
| **减仓** | 估值接近乐观区间，市场情绪过热，或组合集中度过高。 |
| **卖出** | 基本面证伪、治理风险暴露、估值严重透支、技术破位且无修复逻辑。 |
| **不买** | 看不懂、无法估值、无法控制风险、只有故事没有证据。 |

#### 14.3 复盘框架

每笔交易结束后记录：

- 买入时的核心假设是什么？
- 哪些事实证明我对了？
- 哪些事实证明我错了？
- 盈亏来自能力、运气、市场风格，还是仓位？
- 是否遵守了原计划？
- 下次可以改进什么？

长期收益来自不断减少可重复的错误，而不是偶尔押中一次大行情。

### 十五、常用检查清单

#### 15.1 个股研究清单

- [ ] 公司主营业务是否简单清楚？
- [ ] 行业空间和增长驱动是否可解释？
- [ ] 竞争格局是否稳定或改善？
- [ ] 公司优势是否能用数据验证？
- [ ] 收入增长是否伴随现金流改善？
- [ ] 毛利率、净利率和 ROE 是否可持续？
- [ ] 资产负债表是否存在隐藏风险？
- [ ] 控股股东、质押、关联交易是否健康？
- [ ] 当前估值是否包含安全边际？
- [ ] 催化和风险是否都能跟踪？
- [ ] 失效条件是否明确？
- [ ] 仓位是否与不确定性匹配？

#### 15.2 财报阅读清单

- [ ] 收入增长来自销量、价格、并表还是会计调整？
- [ ] 毛利率变化是否符合行业价格和成本变化？
- [ ] 销售、管理、研发、财务费用是否异常？
- [ ] 经营现金流是否匹配净利润？
- [ ] 应收账款、存货和合同资产是否异常增加？
- [ ] 资本开支是否会吞噬自由现金流？
- [ ] 商誉、减值、投资收益和政府补助是否影响利润质量？
- [ ] 负债结构是否安全？短债压力如何？
- [ ] 分红、回购和融资行为是否一致？
- [ ] 管理层讨论是否解释了关键变化？

#### 15.3 交易前清单

- [ ] 我买的是基本面、估值修复、趋势、事件还是情绪？
- [ ] 当前价格相对于估值区间处在什么位置？
- [ ] 如果明天跌 10% 或跌停，我怎么处理？
- [ ] 最大亏损是否可承受？
- [ ] 是否存在更便宜或更确定的替代标的？
- [ ] 是否因为害怕踏空而买入？
- [ ] 是否已经写下止损和复盘条件？

#### 15.4 持仓跟踪清单

- [ ] 行业关键数据是否继续支持逻辑？
- [ ] 公司公告是否验证或削弱逻辑？
- [ ] 估值是否已经透支乐观情景？
- [ ] 资金和情绪是否过度拥挤？
- [ ] 仓位是否因上涨被动过大？
- [ ] 是否出现了原计划中的卖出条件？

### 结语

股票投资没有单一圣杯。真正可靠的体系，通常是把好生意、好价格、好时机和可承受的风险放在同一个框架里反复验证。

最好的分析不是让自己显得懂得很多，而是让每一次买入、持有、卖出都有清晰理由；让错误尽早暴露；让组合在不确定的市场里仍然保持行动能力。
