## 1. 本期要交付什么

用户在网页选择研究截止日，按最近三个自然年走势、最近六个自然月重点，得到**行业五个、主题五个、每个板块五只股票**的两个独立榜单。每项候选有原始指标、排名贡献、风险、反方解释、不确定性与下一步核验，最多五十个席位，显示重复关系和独立股票数。

策略方向同步从低波动多头开始，完成原始方法、适配差异、数据资格和评价协议的准备；数据与工具合格的部分可以先测试。E/P 价值在免费历史财务时点合格后进入，红利低波为储备，不要求一期凑齐五类。策略研究不等待网页建成。

本期完成的直接证据是实际免费数据上的网页研究闭环与可接续的策略研究资产。完整账户回测、完整样本外经济验证、全部工作台功能分别归入二期、三期；一期候选榜不代表策略已有效。

## 3. 数据准备先证明什么

先核验总方案第 4.7 节候选：BaoStock 个股日线/状态，AKShare 申万行业及主题数据，合法免费本地文件作为补充。每个数据产品单独确定主源、使用权限、字段、单位、覆盖与时点，候补源先核验再明确切换，不能逐行混源。

| 用途 | 所需证据 | 数据不合格时 |
| --- | --- | --- |
| 行业榜 | 同一申万一级分类版本、对应行业指数的价格和成交额、当期可知成员、共同基准 | 标明缺失产品；不能静默换成其他行业体系或成员合成指数 |
| 主题榜 | 单一提供方主题目录、原始代码/定义、当前可知成员及合格个股序列 | 没有历史成员时，只做当前成员群体的回溯特征；不能称历史主题收益 |
| 板块内选股 | 个股原始/连续价格口径、量额、日历、上市退市及适用交易状态 | 缺必要行情、公司行动或状态时，限制相应指标与入选资格 |
| 低波动准备 | 历史股票池、公司行动、状态、市值权重所需字段、36 个月月收益预热及另列的检验区间 | 保存具体缺口，不缩短预热后声称复现原方法；不扩大一期展示窗口 |
| E/P 准备 | 历史原始财务、公告和修订可得时点、原规则的盈利与市值字段 | 不用当前 PE 或最新财务回填历史；保留待补候选，继续合格低波动工作 |

数据资格按“对象、期间、用途、字段”判断。取得时间与历史公开时间分别保存；当前成员接口不能伪装成历史成员接口。港股、美股、期货的请求明确报告未支持。

股票范围展示沪、深、北及各上市板块覆盖；缺失子集单列，不能以沪深子集声称全 A 股已覆盖。若无法满足正常两榜目标，保留已有局部结果并说明未满足项；不得自行取消主题榜、减少正常目标数量或采购补齐。

## 4. 冻结的研究口径

### 4.1 时间、分类和资格

一次任务固定研究信息截止时点、共同行情截止交易日与三个自然年/六个自然月窗口。行情未到齐时展示缺口，不能按每个对象最近有效日平移窗口或静默回退整个截止日。指标所需 60 个交易日不替代六个自然月。

行业采用单一申万一级口径，主题采用单一提供方产业主题目录。风格、上市板块、融资融券、指数成员等标签分别分类并展示排除依据，不依名称相近自动混榜。

先排除已退市、当时风险警示、价格/量额无法核实或不满足研究状态的对象。短于三年者显示实际历史；不足半年或所需指标窗口者单列观察。停牌与采集缺失分开处理，不能填平序列制造低风险。流动性、缺失比例、主题成员覆盖等具体阈值须在看到真实排名前冻结，不能为凑齐数量调整；已批准并落实的协议见 [ranking-defaults.json](../quant/config/ranking-defaults.json)，摘要见[一期实现第 3 节](2026-10-17-quant-research-platform-phase-1-implementation.md#3-冻结研究规则)。

过去日期任务必须有当时可知成员和分类；无法重建则拒绝该范围的历史排名。保存当前新快照用于未来研究，不倒填未知历史。

### 4.2 四维排序及解释

| 维度 | 沿用总方案的初始方法 |
| --- | --- |
| 趋势 | 近三个月、近半年相对共同市场基准收益，各自同组百分位后取均值 |
| 回撤 | 近半年最大回撤的反向百分位 |
| 量能 | 最近 60 个交易日上涨日成交额占全部有效日成交额比例的同组百分位 |
| 风险 | 最近 60 个交易日已实现波动率的反向百分位 |

四维各占 25%。行业统一用合格行业指数特征；主题先取合格当前成员各原始特征的中位数，再在主题之间做百分位；股票在所属板块内独立排序。缺失值不补零，不跨组比较总分，不把股票分数加到板块上。并列分数保留并列，展示顺序不能暗示统计差异。

先选板块，再在各板块内选股。重复股票保留席位与关联、共用事实，不自动去重补位；显示主题重叠，不能暗示五十席位等于五十个独立机会。成员覆盖不足或合格对象不足时保留受限状态，不能以受限输出通过正常五乘五验收。

报告提供原值、贡献、共同基准、三年相对走势/回撤/历史位置、短历史限制、宽度和贡献集中度。缺历史成员时，相关诊断标明当前群体口径。整体环境不利时明确说明“相对优先但整体环境不利”，百分位不是上涨概率。

每张研究卡回答入选依据、反证、缺口与下一项核验，并保留景气、政策、估值、资金、事件五类线索的解释边界。没有基本面证据时不生成景气事实；行业 Gate 只接受线索输入并由人工决定，未覆盖组合默认观察，价格高分不能抵消基本面反证。无 LLM 时使用相同结构生成完整数值证据摘要。

## 5. 系统组成和跨期合同

采用总方案的同仓独立 Python 子项目、Streamlit 个人网页、Parquet/DuckDB 数据与 SQLite 任务索引，先按本地部署设计。子项目目录、精确依赖、函数与字段由本期计划落实；量化依赖不加入旧单股环境，不在本期预建通用插件平台。

| 对外能力 | 本期语义与后期承接 |
| --- | --- |
| 数据准备与资格查询 | 返回冻结输入引用、来源、权限、字段单位、时点、覆盖、修订与缺口；二期按同一含义补充历史制度和账户所需数据 |
| 研究定义与计算 | 固定市场、分类、对象、窗口、参数、资格、基准和用途；网页与 Notebook 调用同一实现，不填无关的持仓参数 |
| 任务提交/查询/取消 | 独立进程计算，持久化提交标识防止同次提交重复；定义变更新建实验，失败重试新建尝试，取消请求与实际完成分开 |
| 结果读取/导出 | 两榜、成员关联、独立股票、原值/贡献、排除原因、风险和限制；保留结构化表及说明，后期不靠解析自然语言恢复数值 |
| 独立策略资产 | 来源与原规则、适配差异、代码/Notebook、数据取得、协议及已执行试验；尚未测试部分明确标记，二期继续补齐，三期读取复用 |

运行顺序为保存定义、资格检查、发布输入引用、计算、保存结构化结果、展示/导出。中断保留已写产物与真实状态，不自动重跑已通过任务；源失败只限制依赖项，最后成功数据不能冒充今天更新成功。免费模式在公共入口生效，网页、Notebook、worker、缓存和本地导入均不得绕过。

## 6. 本期计划组应拆成哪些交付单元

下列为原计划拆分依据，保留各单元的交付边界；单元已完成，现行结果见[一期实现与验收](2026-10-17-quant-research-platform-phase-1-implementation.md)。

| 单元 | 用户可观察的交付 | 依赖与并行关系 |
| --- | --- | --- |
| P1-A：免费数据可行性与资产 | 看到真实来源、字段/时点/覆盖和用途资格，能保留原始材料并增量补缺 | 最先证明正常场景能否成立；不依赖排名 UI |
| P1-B：两榜计算与证据 | 合格输入产生两榜、板块内五股、重复关联及完整解释 | 依赖 P1-A 合格数据；可先用合成输入验证机制 |
| P1-C：网页研究闭环 | 网页导入/更新、提交、找回/取消任务、查看图表与导出 | 依赖 P1-A/B；基本持久化本期交付，不能全留三期 |
| P1-D：成熟策略独立准备与测试 | 低波动原规则与本地差异、可执行独立文件、冻结协议、数据探查和实际完成的部分测试 | 从本期开始与 A/B/C 并行，仅具体数值测试依赖其实际数据和工具 |
| P1-E：一期真实场景验收 | 正常真实免费两榜成立，关键反例有效，缺口和后期输入可交接 | 复用前述有效证据；不为验收重复计算已通过结果 |

本期通过需要 P1-A 至 E 的本期结果成立。只有链接、合成榜单、漂亮页面或受限数量输出不能代替真实正常场景；本期通过不代表 V5 完整经济验证、V6 执行复用或三期所有验收已完成。

## 8. 成本、停止与恢复边界

- 数据费用当前为零。真实排名前先统计候选全集及去重股票数，计算规模可能远大于最终五十席位；不把五十席位当成只计算五十股。公司深研、数值任务和数据请求分别估算。
- 预计实际执行两家及以上公司的股票分析时，第一次启动前按 AGENTS.md 询问是否切换性价比模型；本期设计或计划批准均不豁免，不以“打分/扫描”改名绕过。当前文档工作没有执行股票分析。
- 免费覆盖、来源权限或数据语义不足时，停止依赖该缺口的正式输出，保留合格部分和问题；不静默缩范围、补造或转收费。核心正常场景未满足须报未完成。
- 新 `as_of` 是新研究，旧结果仍对原时点有效。版本、哈希、日期、阶段或供应商身份变化不触发失效；具体语义错误先说明影响，再做最小修复。
- 整批重跑或重跑已通过真实结果前，必须列直接影响证据、股票分析次数和成本，并取得本次明确批准。回退恢复明确版本的程序/配置，不删除或改写历史研究。
- 不创建分支、worktree 或自动提交。后续执行在用户指定分支；main 提交仍需操作前确认。停止某一数据研究不阻断不依赖它且已获授权的其他单元。
