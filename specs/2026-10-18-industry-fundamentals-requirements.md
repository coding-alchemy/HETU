## 1. 核心目标

独立回答：**该行业的需求、供给、库存、价格、成本与竞争发生了什么变化，景气处于什么状态，证据和判断边界是什么。**

用户只需给出研究对象、地区与观察时点，即可获得可回查原始来源的行业报告。对象存在歧义时先澄清产品、区域及产业链环节，不默认扩展为所有行业或全球全覆盖。

实现须从请求中确定研究问题与上述边界，区分分析时点和数据观察期。用户提供的数据或其他报告属于可选材料，不作为必需输入；具体研究行为、输出和验收以本文为准，宏观理论仅用于相关背景解释。

## 2. 独立开发与独立使用

1. 行业工具与中国宏观、全球宏观工具分别开发、分别使用；任一宏观工具尚未开发、未运行或没有报告时，行业研究仍须可独立完成。
2. 行业工具自行发现、取得、核对必要原始来源，并独立组织证据、形成判断和完成报告。
3. 不要求共用资料库、接口、会话、运行顺序或调用链；其他工具的可用性不作为本工具的启动或完成条件。
4. 其他工具的报告仅在用户主动提供时作为可选证据；不自动调用、读取或等待其他工具的报告，不把其结论当成已核实事实。
5. 研究确需利率、汇率等背景变量时，行业工具可自行取得相关原始数据，不要求先生成宏观分析报告。

## 3. 核心研究要求

| 维度 | 核心问题 | 证据与解释边界 |
| --- | --- | --- |
| 需求 | 谁在购买，实际需求如何变化，来自哪些用途和地区 | 区分终端消费、渠道采购、出口与补库存；产量不能直接代替需求 |
| 供给 | 产出、有效产能、利用率、扩张和退出如何变化 | 区分规划、在建、投产与有效产能；新增供给受认证、良率及资源约束 |
| 库存 | 库存位于何处，为何积累或消耗 | 联合需求、产出和价格区分主动补库与被动累库；仓单不等于全行业库存 |
| 价格 | 同口径价格、折扣、区域与品类价差如何变化 | 保留规格、地点、税运、币种和成交／报价属性；均价变化须区分结构变化 |
| 成本 | 材料、能源、人工、运输等成本如何变化，能否传导 | 识别成本结构、合同调价、时滞与替代条件；不得将成本上涨固定解释为利润下降 |
| 竞争 | 集中度、进入退出、替代品和上下游议价权如何变化 | 精确份额须有同口径分子、分母和覆盖范围；行业标签或企业自述不能代替独立验证 |
| 景气 | 供需、库存、价格、成本与竞争共同指向何种状态，哪些信号冲突 | 区分领先、同步、滞后信号及季节性；给出成立条件、反证和下一观察点，不强制单一评分 |

每项主要判断应连接“观察事实 → 条件化机制 → 行业影响 → 反证或限制”，不能仅排列新闻和数据。

## 4. 可选领域示例

| 领域 | 可按研究问题选择的观察内容 |
| --- | --- |
| 工业金属与关键矿产 | 终端用途、矿山及冶炼供给、品位、库存地点、加工费、回收与材料替代 |
| 农产品、食品与养殖 | 种植／养殖周期、天气、单产、存栏、饲料成本、加工需求、库存与损耗 |
| 航运与供应链 | 货量、有效运力、船队交付拆解、拥堵、绕航、港口周转、燃料成本和运价 |
| 能源 | 消费结构、生产与备用能力、季节性、储存、运输、发电利用及政策约束 |

以上是领域示例，不构成首期同时覆盖清单。每次仅研究选定范围，按实际证据说明覆盖和缺口；首个交付领域尚未确定。

## 5. 原始来源与证据

优先使用主管部门、统计机构、交易所及具名行业组织的原始发布。企业披露可作局部供需证据，但须保留主体与自述边界。搜索片段只用于定位，转述材料不替代支持关键判断的原文。

每条主要证据保留发布机构、原文链接及定位、指标定义、地区／品类／样本、单位、数据期间、发布日期、修订和取得状态；明确事实、推断、预测及用户提供报告的区别。

以下为来源入口及其状态，记录日期为 2026-10-18，不代表行业来源清单完整；“已读”只说明取得对应正文，“仅定位”不说明正文已核对，“候选”不代表接入或用途已验证，所有列示 API 均未测试。

| 来源入口 | 可支持的资料 | 当前状态与限制 |
| --- | --- | --- |
| [国家统计局发布](https://www.stats.gov.cn/sj/zxfb/)、[海关查询](https://online.customs.gov.cn/mySearch/) | 行业生产、利用率、进出口量价 | 发布／服务目录已读；具体细分表待选，海关统计子站此前读取受限；总量不能代替目标品种，价值口径利用率不能当实物产能 |
| [上期所](https://www.shfe.com.cn/)、[大商所](https://www.dce.com.cn/)、[郑商所](https://www.czce.com.cn/) | 所覆盖金属、农产品等的价格、库存和仓单 | 候选；具体表格、许可和更新方式待核；交易所库存不等于全市场库存 |
| [USDA WASDE](https://www.fas.usda.gov/data/wasde)、[农业农村部](https://www.moa.gov.cn/) | 农产品供需估计及农业养殖统计 | WASDE 仅定位，未完整下载；农业农村部为候选；地区、品种及预测版本须逐项核对 |
| [上海航运交易所](https://www.sse.net.cn/) | 航运市场与运价指数 | 候选；具体航线、指数方法和数据权限待核，运价指数不能单独说明供需原因 |
| [EIA Open Data](https://www.eia.gov/opendata/)、[国家能源局电力工业统计](https://www.nea.gov.cn/20250723/d7a5d6cc916e40bcb04c7d7e74d03213/c.html) | 能源生产、消费、库存及电力工业统计 | EIA 目录与 API 说明已读，需注册、未实测；能源局表格已读；按研究地区和品类选择数据 |
| [中国气象局开放共享目录](https://www.cma.gov.cn/zfxxgk/gknr/wjgk/qtwj/202302/P020230224377864419023.pdf) | 农业或运输问题需要的天气背景 | 已读目录；具体序列未取得，数据集为候选；不能据目录判断具体行业损失 |

不同来源冲突时先核对期间、地区、定义和样本，不能挑选有利值或直接平均。缺少必需证据时准确限制对应结论，不以其他行业、其他期间或代理指标冒充。

## 6. 独立报告输出

报告须包含：研究对象与时点、核心结论、相关维度的分析、主要变化及传导、反证与替代解释、后续观察点、原始来源和资料缺口。

按研究问题选择必要维度，不要求每次遍历全部维度或产业链；支撑核心判断的资料未取得时保留缺口。报告必须自足，读者无需另开其他报告才能理解证据与结论。

## 7. 明确排除范围

公司治理、法律尽调、企业资本配置、个股财报与估值、单券条款、具体期货合约的收益和交易策略均不在本需求内；不输出个股推荐、目标价或下单动作。

行业准入、环保、贸易和采购政策仅按其对供需、成本与竞争的影响研究，不扩展为具体公司的法律意见。行业价格和库存研究不等于持有工具回报分析。

## 8. 成功标准

| 要求 | 后续应能直接观察的结果 |
| --- | --- |
| 独立启动、取证和完成 | 没有中国宏观、全球宏观工具或其报告，仅提供行业问题，仍能自行取证并产出自足报告 |
| 原因与影响可核查 | 主要结论可回到同口径原始证据，说明条件、矛盾、反证与资料缺口 |
| 范围生效 | 仅回答选定行业问题，排除证券与公司分析任务 |
| 可选报告不成为依赖 | 未提供其他工具报告时不索取、不等待；用户提供后仍标注其来源与核验状态 |

验收须直接验证上述研究行为与结果。新增来源和新时点不使既有结果追溯失效；需要重验时遵循影响分析与最小范围要求。
