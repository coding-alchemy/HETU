## 1. 交付范围与使用路径

研究者可在现有 Streamlit 应用中阅读因子、手算教学样例，再选对象、观察日、信息截止、获准数据与参数。运行前可查覆盖，运行后可从读数、中间量或缺口回到实际采用的输入。缺证时注明受影响的对象、日期、字段或窗口，独立有据的结果继续可读。

从「因子库」可直接开始试算，也可在「数据 → 因子输入」从可定位的数据行带入证券、日期和发布。从试算进入数据页时按原请求和证据定位，返回后恢复原因子、对象、日期、截止、来源及有效编辑。用户可在同一会话中调整一个条件，显式运行后分别查看两次结果。

一次试算使用一种来源、一个观察日和一套参数，可包含多个对象、历史窗口或序列。核心状态保存在会话内。多日期批跑、参数网格搜索、未来收益标签、IC 和效果研究另行评估。数据维护、采购、定时采集、任意 SQL、策略回测和券商操作归各自流程。三项建议见 §8。

| 术语 | 工作台口径 |
| --- | --- |
| 因子与读数 | 因子是可复算的规则。读数属于特定对象、参数、来源与时点。 |
| 观察日与信息截止 | 观察日 T 是研究日。信息截止是事实可知的实际时刻，默认 T 日北京时间 15:00。公式可要求更早的截止，例如历史分位使用各历史观察日自己的收盘截止。 |
| 实际数据日期 | 参与输出的行情日期、报告期、实施日等，可以早于 T。报告期、公开时刻及数据发布时间分别记录。 |
| 教学样例与自测收据 | 教学样例提供可手算的原始事实。收据记录某用例的事实、参数、独立预期及实际结果。同名材料仍可分别定位。 |
| 逻辑核对与效果验证 | 前者回答事实代入公式后的读数，后者评估因子对后续收益的解释力。各因子保留效果假设、对象、对照、期限和证据位置，状态为「效果未验证」。 |

同一个动量样例使用证券 A 在 2024-01-29、30、31 日的可比收盘 10、12、30 元。观察日为 1 月 31 日，窗口为 1 个交易日。只改跳期，显式运行并核对取价日期。[价格动量档案](../quant/src/hetu_quant/factors/cards/price_momentum.md)

| 跳期 | 起点 | 终点 | 读数 |
| --- | --- | --- | --- |
| 1 | 1 月 29 日，10 元 | 1 月 30 日，12 元 | `12 / 10 − 1 = 20%` |
| 0 | 1 月 30 日，12 元 | 1 月 31 日，30 元 | `30 / 12 − 1 = 150%` |

改选缺少 1 月 30 日可比收盘的本地发布时，两组配置都指出缺失的锚点，并保留所选发布。

## 3. 因子目录与档案

目录展示注册表中 103 个因子及其 114 套默认或具名参数。以中文名称、简称、别名、英文标识或调研章节检索，按分类、适用对象、结果形态筛选。显示当前筛选、命中数、无结果状态及清除入口。列表包含名称、用途、对象、主要输出与单位，选中项以稳定标识定位并明确区分。来源、用途、对象、观察日、信息截止与有效参数均确定且已有对应预查时，才展示带条件的数据可用性。

| 档案内容 | 展示规则 |
| --- | --- |
| 含义与适用范围 | 描述衡量的量、对象、频率、方向、使用前提和边界。中文长名、英文标识和公式可完整阅读或复制。 |
| 公式与演算 | 展示变量、分子分母、价格与收益口径、单位、窗口、前置点及目标日是否纳入。可查手算输入。 |
| 参数 | 展示中文名、字段名、类型、单位、默认值、具名预设、有效及相互约束，说明修改影响。 |
| 依赖数据 | 区分必需与可选字段、对象和样本、历史窗口、日历、公司行动、行业及其他口径凭据，标明缺证影响。 |
| 验证证据 | 展开定义版本、实际 Python 函数与相关共用模块、匹配参数的自测状态、独立预期、实测及收据。无相应收据显示「未测」。 |

档案可直接带教学或本地配置进入试算。教学配置带入该样例的来源、日期、对象和参数。教学事实、独立手算和运行输出分别标明来源，随包事实与收据精确输入各自提供下载。专项收据沿自己的参数与输入复算，只有显式操作才执行。自测只覆盖收据所证的定义、参数和用例。

## 4. 配置、预查与会话执行

### 4.1 有效配置

| 项目 | 行为 |
| --- | --- |
| 来源 | 区分教学、已发布快照与已发布库，显示名称及具体版本。引用采用 `TeachingSource`、`SnapshotRef` 或 `LibraryRef`，本地来源含数据根和引用类型。同名显示文本不能充当原件身份。切换后重查覆盖，仅保留仍适用的选择并提示需重选的项目。当前来源缺证时保留选择。 |
| 对象 | 按公式显示单证券、指定集合、行业／主题／市场、ETF 与基准或有序配对。名称和代码搜索仅使用获准字段，重名时列出可披露的市场与标识。明确配对两腿的角色和顺序，按角色写入 `subjects` 或相关参数。单腿带入时保留已选对象并提示补选。截面注明成员来源、有效日期和实际样本。 |
| 日期 | 分开选观察日与当日北京时间截止，提交用带时区时刻。区分请求日、实际数据日、结果所属日与截止。明确休市、停牌、日历缺证、数据未到及所需锚点不足。改用其他日期须显式选择。 |
| 参数 | 支持默认、全部具名预设、自定义、查看差异、复制完整有效参数及恢复默认。按类型显示整数、数值、布尔、枚举、对象及分量控件，标明交易日／自然日／月、百分数／小数和受影响输出。固定项只读并附理由。 |

从定义复用 `subject_kind`、`fields`、`defaults`、`presets`、`unit`，按相应定义解释角色、枚举与输出语义。组合配置可核对和编辑可选分量、方向、权重与子参数。实际合法键随公式定义，包括动量自然月预设的 `months` 和盈利超预期的 `forecast_aggregation`。普通控件与高级 JSON 共用实际草稿和请求校验。按类型核对，布尔值不能充当整数。未知键、非法值、约束冲突或不可选分量定位到字段及嵌套路径，保留原编辑。解析失败时原 JSON 文本可继续修正，普通控件也可就地纠错。生产计算保留公式端防御，共用校验识别的纯参数错误在读取事实前返回。

### 4.2 覆盖预查

`build_trial` 固定数据根及来源、用途、因子与定义版本、有序对象、观察日、截止和完整有效参数，`parameter_identity` 区分类型。同一有效请求供表单、预查、执行及结果回看使用。条件改变后，旧检查和读数分别归原请求，新草稿显示「待计算」。

预查只读，从生产字段依赖及窗口规则展开分量、基准、分组／中性化所需的输入，核对获准日历、成员和字段登记。例如 N 次收盘涨跌需要 N+1 个连续可比收盘。窗口待证时列出估算范围与待核事实，实际样本从运行结果读取。原价可读、产品已登记或文件存在可说明部分覆盖，是否可算以生产返回为准。

| 预查依据 | 提交与说明 |
| --- | --- |
| 配置非法或缺必需对象角色 | 禁止提交，定位参数或角色并保留其余编辑。纯参数错误不进入预查、取数或尝试。 |
| 所选来源完全无本次用途许可 | 禁止提交，说明受限产品和用途，受限明细读取数为零。 |
| 部分对象、产品或字段缺证／受限 | 可显式运行。保留原请求及独立可算输出，列出产品、字段、对象、期间或窗口缺口。要求完整分母的输出在分母待证时暂停。 |
| 来源获准但全部输出缺必要输入 | 显示「缺证」并列出所需事实。可前往数据页核对，也可显式运行取得生产缺口。 |
| 表已登记，实际表值、日历、单位或版本待核 | 显示「待计算核对」。覆盖已证时给出可用字段、范围、数量和限制，正式读数以执行结果为准。 |

预查与生产按证券使用对应市场日历，核对已知冲突及定位窗口所需的缺日。板块使用已登记代理时先确定实际取价证券，指数报价核对价格／全收益口径。配对取共同交易日，β 的训练截至 T−1。回归和相对强弱按相同起止日对齐收益；样本不足报告缺口。行情只到 T−1 时，需要 T 日收盘的输出指出缺行，全部依赖止于 T−1 且已证的输出仍可在 T 计算。[序列与日历](../quant/src/hetu_quant/factors/series.py) · [配对](../quant/src/hetu_quant/factors/pairs.py) · [风险计算](../quant/src/hetu_quant/factors/stock_risk.py)

### 4.3 提交、后台执行与重试

每个已访问因子的编辑保存在各自草稿。显式选择来源或重新带入影响当前配置。首次带入后可再选目标因子，导航和切换保留已确认的草稿。

显式提交时记录尝试标识、时间及「进行中」，后台线程按冻结的来源根读取并调用生产入口。每会话同时运行一项，进行中重复点击复用原尝试；可继续浏览或编辑其他配置。界面轮询已登记任务并接收一次结果。迟到结果归原尝试及其配置，完成后显示可算、部分可算或缺证，读取失败按原请求显示原因和重试入口。显式重试核对当时许可，使用原来源、截止及参数另记尝试。关闭会话后线程完成当前调用并释放资源，跨会话不恢复进行中任务。

选择、编辑、打开证据、翻页、返回或下载既有材料均不启动试算。试算与复算不接正式研究队列、模拟引擎或台账，也不写入自测收据、研究结论及正式预算。

## 5. 本地数据、许可与证据

### 5.1 固定发布浏览

列出已发布快照、库及可披露的资产、产品、来源、发布时间、最近成功更新时间。查询按对象、市场、日期区间、数据类别和字段限定，覆盖日线、日历、停复牌、证券身份、历史成员、财报、股本／市值、公告、公司行动与实际登记的其他输入。产品无数据、表或字段未登记、当前用途受限分别说明。

普通日线档案沿用原价查询用途。「因子输入」及从试算进入的视图明确显示所用用途，后者用冻结请求中的 `factor_calculation` 与信息截止。分别按来源资产、产品、用途、证券、市场、字段与期间核验，读取前限制受限明细。公告公开时间可作查询轴，付费授权按事实的业务日或报告期核验；如 2023Q4 与 2023-12-31 表示同一业务期，原始写法仍可追溯。静态身份按适用期间处理，补证登记按其原件、字段与业务范围核对。名称搜索、排序、预览与下载也遵守各字段的许可。

固定发布内先按已登记的替代关系选择有效版本，再应用展示字段和排序权限。已替代行无论排序、选列或范围如何变化均不能复活。普通浏览按选定发布，试算还按请求截止核对修订可知性。相同报价可合为一行，各可见字段、出处及带入坐标须分别追到提供方。等价副本和档案裁决写回均保留此绑定。有独立获准的金额依据时，日线出处撤权仍可保留据实核验的币种和单位。数据页可用有据坐标带入试算；若代码或日期无获准定位依据，保留可读行情并停用该行的相应带入。

服务端使用 `selected_snapshot_assets` 和 `read_scoped_product` 限定资产、分区和范围，原价复用 `query_library`、`query_archive` 与市场日历、停复牌、生命周期和裁决规则。筛选、总数、排序和页预览基于实际可读记录。稳定排序以已有业务键及来源坐标补齐同值次序，只返回当前页。超出可有效限定的范围时提示缩窄查询。翻页保留已提交的发布和查询；对可复用的产品范围避免重复扫全历史，许可变化后按当前范围核对。

### 5.2 日期、覆盖与缺口

分开显示产品获准数据范围、本次查询范围、本页实际日期、截至请求日的最近有据日期和发布／维护时间。产品起止日取自获准的业务日期行或可信覆盖摘要，分区名仅供定位。日期未获准时标受限，证据不足时标未知。最近有据日按所选有效字段的可用值判断，有据的 0 可推进日期，空值、被替代行和受限记录不能推进。窗口内和历史补查使用同一版本及授权规则，即使 T 日缺行也保留请求日。

有独立的对象全集或应有行情依据才计算覆盖率。交易属性、生命周期或适用边界未知时，展示可核实的数量及待证原因；独立的适用休市或停牌证据仍可说明该日无需行情。交易日缺行、缺字段、时点或口径不足、休市、停牌、当前用途受限和独立原件冲突分别显示。缺口起止日等衍生信息沿用实际产生该缺口的原件权限。保留独立可读行情和缺口原因。

### 5.3 回看、截止与下载

从结果行、中间量或缺口进入数据页时，沿冻结请求及 `inputs`、`components`、`gaps` 核对来源根、发布、资产、产品、对象、字段、日期或报告期、版本、时点和原件。缺少可定位行时显示限定条件、空结果与原因。回看按当前许可核验该输出实际依赖的材料，保留独立获准读数，遮蔽依赖已撤权事实的输出及受限详情。被撤权的参与成员可影响整个派生排名。旧结果维持原输入与原时点，重开不重新计算，也不用其他发布补写。

可知性以带时区的实际瞬间比较，等于截止可用。只有日期不足以证明收盘前已知。历史分位的各历史截止、首披及更正、原件身份、单位币种、冲突分支与同源佐证沿生产语义。截止时尚未可知的事实及能透露其值或公开时刻的线索均排除在本次视图、计数、导航和下载之外。获准的当时字段及引用仍可查看，混有其他时点事实的整份原件按相同边界限制。最新报告已登记但表值未能核对时，E/P 定位到证券、当期报告和 `net_profit_ex`，保留获准登记而不回退到旧季度。[E/P 档案](../quant/src/hetu_quant/factors/cards/earnings_yield.md)

原价 CSV 沿用固定查询的现有下载合同。随包教学事实和收据精确输入有各自的档案入口。下载本地证据明细或原件须有覆盖该内容、范围、用途和信息截止的下载／分发依据。只有读取与计算用途许可时可查看获准字段或引用，下载处提示缺少的许可。任一产品或原件受限时保留同批中独立获准的资料。[产品操作许可](../data/src/hetu_data/access.py) · [来源用途判定](../quant/src/hetu_quant/backtest_data.py)

## 6. 结果阅读与页面可用性

结果显示因子与版本、定版来源、有效参数、对象与有效样本、观察日、信息截止、实际数据日期、计算时间及状态。实际日期按输出及产品各自的输入标明，区分财年／报告期、事件生效日、行情／股本日期、公开时刻与发布时间，缺证时显示未知。

| 输出形态 | 页面行为 |
| --- | --- |
| 单值、布尔、类别 | 展示读数和单位或明确标签。真实 0、否与空值分别呈现，原值、中间量和换算值可核对，支持按足够精度复制读数以复算。 |
| 截面或配对 | 可排序地显示对象标识、角色、分值／排名及有效样本。展开成员、分母和缺口，部分样本的排名说明适用范围。 |
| 有日期的序列 | 趋势图和表格使用同源获准点并标单位，缺点留空。配对极端价差可从 `components.scores` 展开逐日 z 值；有日期序列的市场和行业历史分位也可回查。普通日线输入本身不生成历史因子曲线。 |
| 多分量或部分可算 | 每项显示自身的值、单位、状态与缺口。可展开窗口起止、样本数、原字段、单位、版本、公开时点和相互印证或冲突的原件。 |

配置校验、输入覆盖、该次读数、逻辑自测和市场效果分别展示。例如同一页面可显示「本次读数缺证」「对应参数逻辑自测通过」「效果未验证」。缺币种、冲突或无有效分母的读数不会默认取 0、等权或上一期。

桌面按目录与档案、配置与覆盖、读数与缺口组织，窄窗口沿相同顺序纵向阅读，宽表独立滚动。控件与图表使用明确标签，键盘焦点可见，状态有文字说明，颜色辅助。空库可查档案和运行教学。无匹配、无结果、权限遮蔽、读入失败各注明原因。长公式、源码、原件、完整 JSON 和技术诊断按需展开，诊断同样遵守字段许可和信息截止。默认反馈保护访问凭据，用业务语言说明受影响的对象、字段、日期及下一步可用操作。浏览和分页保持有界，长计算期间可查看配置、结果归属和运行状态。

## 8. 三项独立建议

三项分别待单独决定。并排对比和结果导出可使用会话内的完成结果，跨会话找回依赖持久保存。已获准的教学事实、收据输入和证据明细下载沿用 §3、§5.3。

| 建议 | 获选后的交互和验收 |
| --- | --- |
| 并排对比 | 可复制基线，也可并排选两次完成结果。展示各侧因子版本、参数、对象、日期、截止、来源、单位口径、有效样本、读数与缺口，按稳定对象标识对齐。含义、单位与口径可比时显示第二次减第一次及单位，类别显示标签变化。E/P 6% 到 8% 显示 +2 个百分点。单侧缺值、分母或样本变化、无法对齐或同时改变多项条件时列出差异与限制。口径无法对齐时并列两侧原值。对比只读。 |
