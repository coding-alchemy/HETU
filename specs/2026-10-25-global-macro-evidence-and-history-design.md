## 1. 目标、假设与范围

用户下一次正常调用全球宏观 Skill 时，无需额外提醒，即可观察到以下结果：重要原始事实实际支持或限制判断；已有兼容输入完成逐期比较；缺失历史经过针对该指标的定位与适用替代；资产价格窗口适合所回答的问题；缺口准确对应未完成的观察，表旁说明让人读懂数据。

本次优化对象是 Skill 的后续研究行为。旧报告及其原件保留为问题依据，不以修改旧报告代替能力修复。既有 Skill 验收继续对其原范围和时点有效，本次报告中的遗漏不使先前通过项整体失效。

沿用独立四文件 Skill、宿主现有工具、公开或已授权资料及两份 Markdown 交付。设计不增加采集服务、数据库、第五份规则文件、固定工作包或新的必交付审计表。设计已批准并编写执行计划；批准计划后才能实施。

假设目标宿主能读取原文、表格及必要计算结果；具体网站、历史接口和许可是否可用仍须按实际证据判断。自然语言规则可以改善执行行为，不能保证模型永不遗漏或外部来源永远可达；以本轮明确场景的实际行为验收，不承诺无限覆盖。

## 4. 研究过程设计

### 4.1 选定问题时同时确定证据范围

在既有证据记录中，为支撑主要判断的指标明确：回答什么问题、统计定义、观察末期、历史窗口、所需比较基数及相关原表。无需新增固定字段合同或另建工作表。

保留月度12个自然月、季度8个完整季度、年度5年及用户指定窗口，累计采用上年相同期间。基数可在展示窗口之外，取数范围应包括适用的上期和上年同期。研究中新增加的主要指标沿用相同要求，不因先前没有选它就省略历史。

### 4.2 取得材料后完成提取与判断采用

在材料取得后、据其形成判断前，读取与该问题相关的正文、表及附注，完成以下工作：

1. 提取可用的当期事实、期间、覆盖与重要分项，包括反向事实；不能只保留解析摘要或最初搜索命中的栏目。
2. 对兼容输入完成必要计算，把结果用于对应判断；已提取但不采用的重要事实须有相关性、时点或可比性理由。
3. 另行处理历史与基数缺口。缺历史不取消当前事实，当前事实已采用也不表示历史完成；在正文表旁和附录一致说明剩余缺期。

对本次问题的具体约束：日本家庭消费调查与工资统计保留各自样本，不能互相替代或直接相减；SLOOS区分贷款标准、条款、需求及部门，回顾期和历史标准水平分别使用；财政按全球需求与商品外溢需要采用民生、建设等相关用途，不扩为完整中国财政全景。上述是取证读法，不固定未来数据方向。

### 4.3 历史不足时按目标系列定位，失败不跨指标传播

发布稿只含近期值时，先核已取得的附表与下载文件，再定位原发布方的历史表／时间序列；原路径受限时核适用的公开转载或当期归档。每个动作均围绕当前缺期或基数，有可用线索才继续；不要求每项机械走完所有渠道。

| 对象 | 本轮需落实的具体定位动作 |
| --- | --- |
| 美国非农、工资及工时 | 从BLS就业发布与CES系列目录分别定位对应指标的历史表、系列及说明；需要时核FRED中可追溯至BLS的对应转载。核就业范围、季调、单位及版本，不把总非农与私人部门工资／工时当成相同覆盖，不凭记忆拼造系列地址 |
| 总体／核心CPI | 分别核所需的总体、剔除食品能源及季调／未季调系列；总体API失败只能归属于实际请求，不能作为核心CPI或就业系列失败的证据 |
| TIC | 区分当期新闻稿、历史证券交易与银行流表、证券持仓表；针对缺少月份找对应历史文件或归档，核净流入、长期、短期及银行分项定义、符号和修订，不把滚动12月总额拆成单月 |
| 日本消费、银行调查、财政用途 | 先采用当前已读正文的相关事实，再进入所链历史表或附件；不能把“未提取完整序列”登记为“当前正文未取得” |

失败记录在已有证据条目中明确目标指标、实际URL／表或系列、请求期间和原结果；同一机构的失败不自动传播到其他系列、网页、文件或工具。只记录影响核心问题的失败，不增加全量调用日志门槛。

替代须核原来源、观察定义、单位、季调、版本及截止时点；同源转载不增加独立证据数量。当前研究可采用截止前可比修订版，历史研究仍须用当时可知材料；版本不能衔接时限制对应比较，不拼接成连续历史。

无可用工具、已尝试的相关路径失败且没有新增线索，或达到获准的取证预算时停止，说明具体停止原因与未完成项。未尝试路径不得记为失败；因预算停止不称公开不可得。必要商业资料仍提交字段、用途、候选来源与预期改善供审批，不自动采购或试用。

### 4.4 比较落实到每条指标和每个可比期间

在形成正文表时，逐条核所选主要指标的原值、上期、上年同期及适用比较。已有兼容输入先算再展示；部分基数缺失只留空对应比较。原值、计算及正文相互核对，不能用“表中已有同比列”代表各分项均已处理。

社融总量、人民币贷款和政府债券分别列适用逐月比较；年度财政收入、支出和赤字分别列同比。表过宽可按主题拆表并共享说明，不以省略分项比较换简洁。累计同期比较继续保留，但不替代月度或季度比较。

正数兼容基数按适用口径给出增长率，可同时列差额；零或负基数不强算百分比，保留有意义的差额及解释。比率／增速用百分点、利率用基点、景气指数用指数点。未季调流量的相邻期变化说明季节性限制，不能自动解释为趋势加速。

例如问题样本的9月贷款同比少增3347亿元、政府债券同比多增3469亿元，可以解释总量背后的分化；这些数值只作为评审回查依据，不作为测试输入中的答案或运行时固定示例。

### 4.5 资产价格窗口与研究命题匹配

取得行情前说明要回答当期水平、区间变化、趋势还是事件反应，并按该问题选择同场所／同基准、同定义的观察。实际返回的首末时点、覆盖和限制决定证据用途，不能仅凭请求参数或返回1000笔成交认定已取得所需历史。

- 季度背景的BTC和黄金分析，需要与该尺度相称的价格观察及相关实际利率／美元条件。可采用近期数周至一季等有解释的窗口；不设统一90天门槛，不把预测一季度解释成历史只能取一季度。两个端点可说明该区间净变化，声称持续趋势还须有相应期间观察。
- 仅返回几分钟成交或单日两点时，保留为短时事实，并继续定位适合所需窗口的历史报价、日线或基准文件。仍未取得则明确季度背景未回答，不能用通用机制替代完成。
- 黄金市场价与官方储备数量、估值分开：恢复基线设计中“同期间黄金价格、实际利率与美元”的观察要求。储备金额除数量得到的隐含单位估值，不冒充独立市场价格；有储备证据即可回答该样本配置问题，但不能据此宣布市场表现已分析完整。
- BTC／黄金资金归因或宏观反馈，仍按具体命题核申赎、交易、杠杆或敞口；不要求每篇取得全市场全部字段。资产与宏观观察期不同或没有可比重叠时披露差异，不能据其精确归因。
- 明确的日内事件专题可使用匹配的短窗口，不强制扩成季度或全球全景。日／周数据月度化时仍执行原月度窗口及汇总定义，不以抽样规避既有规则。

来源导航补足BTC历史行情与方法定位，以及黄金价格原发布／基准路径；具体产品和许可先核，未实读保持候选。此前两点来源核验仍有效，其用途不自动升级为完整历史或季度趋势。

### 4.6 主权融资与金融压力按命题补证

沿用既有研究范围，在组织风险判断时，把需要回答的问题与能分辨解释的证据对应：

| 实际采用的命题 | 对应取证与判断 |
| --- | --- |
| 赤字使净融资需求维持 | 核收入、支出与赤字；不能进一步用赤字证明当期拍卖失灵 |
| 付息负担加重 | 核相同政府范围及期间的利息、收入或适用分母；市场收益率不能替代存量平均成本 |
| 某期限供给或滚续承压 | 核该期限净发行、到期或再融资安排，不把总发行直接当净供给 |
| 承接转弱或成员国风险分化 | 按命题取可比拍卖、主权利差或相关融资条件，采用已有改善的反证；一次结果不证明持续危机 |

这些是命题与证据的对应关系，不是每国必取清单。只有风险暴露时可说明潜在渠道；只有机制存在时不得声称工具已经使用；缺当前压力或交易证据时不得宣布被迫出售或危机已经发生。缺项保留局部未完成，不因它们否定已成立的增长或资产事实。

### 4.7 释义和定稿核对

表旁按实际列名分别说明：

- **季调年化水平**是把经季节调整的月／季流量表达为年度规模，不是增长率，也不是未来一年预测。按发布方定义年化的月、季水平可分别除12、除4表达对应期间的季调量；不能称其为未季调名义支出。
- **2017年链式美元**以2017年为参考年衡量剔除价格变化后的实际量；“十亿”为单位，不能读成当年现价金额。链式分项也不能机械相加。
- **季调环比折年增长率**把当季增长速度复利折成年率，与普通季环比、同比及上述年化水平分别解释。

表头继续简写，说明只覆盖实际采用的指标，不增加词典章节。定稿从主要判断回查已取得的相关正文与附件，再从实际表格逐指标核原值、比较、释义和具体缺口；发现漏用、漏列、漏算时处理现有材料并同步判断，不只追加“受限”声明。

采用状态、历史覆盖和核心问题回答分别说明：当前事实已采用不等于历史齐全；历史未齐不等于当前一无所知；正确停止与披露缺口不等于对应分析能力已得到充分验证。无需向用户展示内部检查过程或增加第三份交付。

## 6. 最小验证与完成标准

### 6.1 行为验证

设计三个短场景，同一输出验证多个相关行为。研究输入只包含正常业务任务、原始事实、原件或工具可读材料，不提供本设计、问题答案、评分规则或“请采用某条反证”等修复提示。原始事实与独立评审答案分离；实际正文、计算及必要调用记录构成行为证据，模型自述完成不算通过。
