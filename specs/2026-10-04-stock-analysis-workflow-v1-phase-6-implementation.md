## 0. 当前结果

六期已交付逐用途资料标准、四组资料细则、合法补救、同根因缺口追溯与部分补齐后的同步规则，

到何时、失败如何补救，以及仍缺什么、影响哪些结论**。

六批按已证范围限定验收。第 02 批未满足项获限定接受，第 04／05／06 批的 17 组资料后置到

六期收尾不等于五期性能验收、完整宿主认证或 V1 全部长期要求完成。

## 2. 公共实现

### 2.1 按需读取、owner 与记录位置

[material-coverage.md](../skills/hetu-stock-analysis/references/material-coverage.md) 只定义公共标准。
公司、经营、风险、市场四份细则按用途加载，并引用既有质量、来源和产物合同，不复制状态定义。
W1 唯一核验后形成共通、深度与特殊状态必需项；W4 形成经营模型后补模型特有内容。
W1–W8 选择资料时读取对应细则，启动时不加载全部资料规则；W9/W10 只消费 owner 最新定稿。

每个用途只有一个实际 owner。同一原件指定唯一取数责任，按五期规则只读共享并避免重复解析；
各 owner 分别核验自己的正文、表格、附注和用途。来源独立性按原始生产链判断，镜像、转载、
重复下载及旧资料复用均不增加独立证据数。

| 现有位置 | 职责 |
|---|---|
| [owner 十二节与五列必需项表](../skills/hetu-stock-analysis/references/work-package-result.md) | 用途判断的权威记录：要求、七状态、满足关系、原文／查询、影响与回访 |
| `evidence.md` | 证据和查询依据、U 类缺口定位与统一引用关系，不另存用途状态 |
| `checkpoint.md` | 当前采用结果的质量摘要、用户决定、恢复点与下一意图 |
| `manifest.json` | 文件、实际输入与采用关系，不增加质量或缺口状态键 |
| 报告首页、正文与第 11 章 | 质量、结论附近的引用、限制和追溯；不新增报告字段 |

共同流程为：明确问题及满足条件 → 合法取得原件 → 核验所需正文／表格／附注／附件 → owner
定稿用途判断与下游输入 → 汇总及直接受影响回访。许可允许时保存原件，否则保留允许的定位、
时间和限制；取得、解析、用途满足与最终研究有效性各自判断。

### 2.2 三档内容与投入

三档沿用[报告指引](../skills/hetu-stock-analysis/references/report-guidance.md)、
[公司模型](../skills/hetu-stock-analysis/references/company-models.md)及四期完整性／降级规则：

- quick：主体状态、核心业务、最新财务、近期公告、股本行情、基础估值输入、支持、反证、未知、验证点与缺口。
- standard：追加控制关系、经营驱动、行业竞争、治理审计、资本配置、调整后多年财务与最新一期、情景和监控。
- deep：全量继承 standard，追加更长历史、完整年报与重要附注、分部产业链、更多独立来源、资本配置效果、敏感性、估值交叉与更细证伪条件；历史起点按周期、重大变化或方法说明。

standard 及 deep 均保留：非重复有效事实 ≥8；序列 ≥5 组，含跨 ≥4 报告期及最新季报的多指标
财务主表；计算 ≥4，含估值倍数与三情景；重要事件 ≥3；反证 ≥5；监控 ≥6。原定位、日期、
阈值、窗口和复查动作等配套条件不变，不编造凑数，不扩成长期完整监控要求。

每个必需问题说明 owner、要求来源、正文／表／附件、主体、期间、范围、单位、原文等级、
独立验证、历史长度、新鲜度、合法首选与等价替代、投入及满足条件、不能得出的结论。
找到文件、取得正文、取得本用途所需表／附注和完成分析分别判断；文件存在或主表齐全不代表
完整年报、审计、分部及调整附注已满足。

按用途、准备／收尾、失败与替代估算投入。继承三档外部调用默认 120／120／260、同类重试 3、
并行度 3；不新增付费授权，不承诺实时精确计数、完整费用观测或请求内硬截断，未知如实记录。
时间目标超出仍继续必要研究；充分实测校准和性能配对不作为资料标准的前置。

### 2.3 时效与覆盖

| 数据域 | 满足时点和覆盖的依据 |
|---|---|
| 公告、监管 | 最新已用披露基准至 as_of 的适用窗口、证券映射、分段并集、分页、正文及重要附件 |
| 上市、交易状态 | 正式文件生效、后续变更与截至 as_of 的核验覆盖 |
| 行情、股本、市场明细 | as_of 前当日或最近交易日的观测，价格时间、正式股本、复权与币种对齐 |
| 财务、审计、附注 | 截至 as_of 最新合法披露的年度及适用中期／季度；序列采用当时最新正式调整后的可比列 |
| 行业量价、份额、代理 | 原生产者发布日历、统计期、区域和方法，逐指标选择时点内最新适用版本 |
| 登记、司法、制裁、债务 | 登记／生效、修订、撤名、到期与兑付链，对象、法域和窗口明确 |
| 指引、共识、历史估值 | 当时可得截面、成分、去重及修订，价格、股本与财务披露基准匹配 |

区分事件、数据归属、市场可得、采集与研究截止五类时间；同日只有日期时沿用
[证据规则](../skills/hetu-stock-analysis/references/evidence-rules.md)的保守判断。
默认阈值为截至 as_of 最新已合法发布且满足用途的版本；延迟按官方更新机制或当前许可解释，
不虚构统一天数或历史年数。未到发布日不把未来期当缺失，已知已发布却未取得则保留缺口。
窗口断档、最新披露缺失、过期、历史版本或当时可得性未证均明确记录；当前共识、事后更正值和
调整后历史序列不冒充 PIT，也不追溯使旧时点结果失效。

### 2.4 原文、替代与限定检索

[七状态与满足关系](../skills/hetu-stock-analysis/references/research-quality.md)不变：`有`须满足
内容、来源、时点、口径与分析；`替代取得`须证明同一用途等价。需要监管／发行人正式原文时，
可用等价原文定位路径，不能用 L2 转述降低要求。`不适用`须有公司事实支持。

`无`只用于核验有界范围内不存在，且对象及已证别名、渠道、窗口、分页／总数、分段并集、
实际查询词、正文和适用附件的覆盖及排除依据完整。开放筛查、标题零命中、HTTP 404／403、WAF
或分页未闭合不能证明不存在；有标题命中却未取得正文仍待核实。`未发现`、`未取得`和
`存在冲突`不满足必需项，技术 `not_found` 不直接转换为业务 `无`。
影响质量的否定结论须核对 owner 当前 adopted 产物中主题词及合理同义词的全部命中；未抽取或
未定位不能改写为公司未披露。A2 原质量、实际 quick 及 standard 资格不成立的结论保持。

## 3. 四组十六用途

细则承接[数据源指南](../docs/theory/A股个股分析数据源指南.md)与
[来源合同](../skills/hetu-stock-analysis/references/source-contracts.md)。来源适用性由公司事实和
研究问题决定，不要求每家公司使用全部来源；候选、人工可用或授权库不自动升级为正式自动采用。

| 组／细则 | 用途与实际 owner | 必需核验与使用边界 |
|---|---|---|
| [公司](../skills/hetu-stock-analysis/references/material-company.md) | 主体与证券状态：W1，市场观测引用 W8 | 沪深北官方列表／文件按代码、发行人、板块、上市和交易状态逐主张核验；成交、简称和聚合页不补全部状态 |
| 公司 | 公告、财报、审计：W2 事件／W4 治理／W5 财务 | 正式披露、问询回复及重要附件；三表、附注、合并／单体、调整、审计和单位；各 owner 核验各自内容，W2/W5 使用一致披露基准 |
| 公司 | 业务、产品、分部、产能：W4 | 年报、招股书或公告原文；设计产能不当产量，分部与集团不互换 |
| 公司 | 工商股权与子公司历史：W4，身份引用 W1 | 正式披露序列、登记原文或许可内图谱；逐变更核验关系与生效日，当前快照、A/H 或 LEI 不替代控制及并表历史 |
| [经营](../skills/hetu-stock-analysis/references/material-business.md) | 行业价格、库存、产能：W3，W4 消费公司映射 | 细分原始序列，品种、地域、税运及报价方法；宏观方向和可达主页不证明公司经营或具体序列 |
| 经营 | 独立竞争、市场份额：W3 | 独立生产链与透明方法，产品、地域、期间、币种、分子和分母可比；自述、同业或方向性替代不补精确独立份额 |
| 经营 | 客户、供应商、招投标：W4，增量事件引用 W2 | 正式披露和采购／公共资源原始记录，实体、项目、合同及履约阶段对应；前五大、关系图和中标不证明完整结构或收入贡献 |
| 经营 | 跨境贸易：W3，主体产品映射引用 W4 | 海关、Comtrade 或获授权记录，HS、报关主体、别名、中间商及产品对应，缺报与修订保留；国家贸易不冒充公司数据 |
| 经营 | 领先经营指标：W4，科目引用 W5 | 披露、行业原始输入与合法代理分层；存货、合同负债、流量及卫星不补成未披露订单、收入、产量或销售 |
| [风险](../skills/hetu-stock-analysis/references/material-risk.md) | 研发、专利、临床：W4，主体引用 W1 | 申请人、申办方、产品、申请／授权／法律状态、登记与批准逐项核验；城市或 sponsor 字串不作消歧，数量不证明批准、疗效、成功或价值 |
| 风险 | 司法、处罚、环保：W4，增量事件引用 W2 | 法院、监管及环保原发文书，当事人、别名、案号、文号、法域和窗口对应；标题零命中及风险数量不替代逐案核验 |
| 风险 | 跨境披露、制裁、管制：W4，证券引用 W1 | 正式披露与适用清单，主体、别名、地址、所有权规则、生效及撤名历史核验；单清单不当全法域覆盖，证券、准则、币种、时区不混合 |
| 风险 | 债务、评级、兑付：W4，金额口径引用 W5 | 按债券代码和发行人串联注册、发行、评级、存续与兑付；额度不当融资，发行不当正常兑付，评级版本不跨时点混用 |
| [市场](../skills/hetu-stock-analysis/references/material-market.md) | 行情、股本、市值、公司行动：W8，行动事实引用 W2 | 价格时点、量额、流动性、总／流通股本、复权、币种及原值复算；同日异时、标签或基准不同不混算，情绪与成交不证明基本面因果 |
| 市场 | 官方融券及明细：W8 | 官方或具有该数据集权限的明细，交易日和历史退出标的覆盖；门户转载不作独立来源，当前明细不补历史空档 |
| 市场 | 指引、共识、历史估值：W6 指引预测／W7 估值输入 | 指引原文及许可内共识成分、去重、修订、PIT，历史输入按适用行情、股本和披露复算；预测不当指引，当前共识不回填历史，不新增估值方法 |

## 4. 失败补救与缺口闭合

### 4.1 查询和合法补救

沿用来源合同九种技术状态、七种资料状态及五期重试／停止规则。owner 或 `evidence.md` 保存
目标、查询词、证券／主体映射、日期范围、来源／工具、查询时间、返回状态、选用／排除理由、
替代路径、停止原因和下一动作，可引用原始响应或可核验宿主日志；不扩展适配器固定信封。

故障分别记录未找到、无权限、工具不可用、限流、连接／维护、结构变化、下载失败、解析失败、
分页未闭合、查询不足、口径冲突、时点不符与过期；PDF 进一步区分加密／损坏、文本层、版式、
编码和页级读取。保留已取得部分、原值、冲突双方及影响，不强行填值或由代码自动换源／采用。

无安全、授权或预算阻断时至少尝试一种合理合法替代：原始附件、合法镜像、既有提取、宿主 OCR、
格式替代、同口径来源、代理指标或缩小范围。核验主体、期间、范围、单位、时点及用途；不等价
继续保留缺口，解析补救须核对页级覆盖。阻断时只停止相关尝试，写明最小合法前提与未完成项；
不无限重试，不改记不适用，不绕登录、验证码、付费墙、反爬或许可。
故障处理合格不证明资料取得目标完成，不能以受限报告自动判全期完成。

### 4.2 同根因与全部用途

U 定位沿用当前任务的 `evidence.md`，编号稳定，不重排、不批量迁移旧研究。按主体、所需原件
或同一查询目标、期间、范围和直接失败根因判同一缺口；同网站失败但对象或内容不同不机械合并。
同根因计一次，来源去重与缺口去重分别判断。

首次 owner 维护问题和查询，主 Agent 合入首次位置、类别、严重度、原问题、查询、全部影响及
各用途 owner／采用位置、用户决定、下一动作和复查时点。owner 必需项及缺口节引用同一定位，
分别说明满足关系、受影响方法、不能得出的结论与回访条件；证据、缺口、结论双向可定位。
最大未知按核心论点影响、时效和补齐成本排序并说明依据，不新增统一评分或另一份状态存储。

### 4.3 部分补齐、同步与恢复

新资料由实际 owner 判断满足哪些用途，只回访直接受影响 owner 及依赖下游。取得财务主表
可以满足 W5 相应用途，但不自动满足仍缺分部附注的 W4 或盈利调整输入的 W7；根因仍计一次，
全部影响保留。只有全部受影响用途满足，或有事实依据判不适用后，才关闭当前缺口。

当前 owner、报告首页、正文、第 11 章和 checkpoint 与最新采用结果同步；W9/W10 消费重新
定稿后的结果。原失败、旧事实、修订及用户决定保留。完整性、有效性和实际深度继续按四期规则
判定，任何适用必需项未满足不得自动升级完整。

同任务恢复沿用原目录与稳定定位；独立重试或新时点使用独立目录、许可内本地副本，保留来源
任务、原取得时间和复制时间，重新核验当前用途。关闭复用时不得回退旧输入。同步仅限当前任务
实际采用链，不回写旧任务、失败运行或历史锁定报告；跨任务建立本地缺口并保留原任务关系，
不能用同编号证明缺口相同。新资料不追溯否定旧结果或自动启动历史重评分。
