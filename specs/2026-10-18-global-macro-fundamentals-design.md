## 1. 目标、假设与设计边界

独立回答全球增长、通胀、政策与金融条件如何形成，相关经济体之间怎样传导，以及这些变化与股票、债券、商品、汇率、比特币及美元支付融资体系的双向作用。完成依据是问题得到证据支持的回答，主要判断可回查原始资料、影响规模、条件与反证；文件齐全不能替代这一结果。

全球包含中国，按研究问题选择经济体，不自动逐国遍历。中国宏观入口侧重中国制度与本土传导，本入口侧重全球共同驱动、地区差异和跨境影响；二者允许研究对象重叠，但不存在调用依赖。

沿用已采用的独立 Agent Skill、四文件组织、输入默认值和交付合同。本次增强比特币、美元稳定币、黄金、美债与汇率的明确覆盖、双向机制和来源路径；新增内容已获批准，既有有效验收不重新判定。假设宿主能加载 Skill 相对路径，并提供公开或用户已授权的搜索、浏览、文档读取及必要计算；新增来源与能力须按实际取得核验，不能由设计声明推定。

不开展行业供需竞争、公司经营财报／治理／法律／资本配置／个股估值、单券契约与偿付顺位／发行人尽调、具体期货交割展期、基金穿透、合约或持仓收益计算。宏观代表性价格与总量变量不改变这些边界。

数字资产以比特币与美元储备支持型稳定币为主，后者按覆盖选择 USDT、USDC 等代表样本；ETF 申赎、发行方储备及赎回披露仅用于核宏观渠道，不开展产品选择、发行商经营尽调或全部币种研究。代币化黄金、代币化存款仅在直接影响当前机制时解释。指导材料提供问题线索，实际数字、政策、相关性与动机仍须核证。

## 2. 方案选择

沿用已确定的短入口与三份 reference。本次只比较能力增强的组织方式：

| 方案 | 取舍 |
| --- | --- |
| 现有四文件增强（采用） | 在同一研究内连接数字资产、美债与美元融资；需要同步入口、研究规则、来源和交付要求 |
| 独立数字资产 Skill | 可单独使用，但会拆开稳定币与美债／美元融资的同一条链，增加运行协作范围 |
| 仅增加报告摘要 | 改动少，但不能保证实际取证、计算和判断采用 |

保留原始来源、时点、事实与判断分离、反证和缺口处理的研究方式；不调用个股 Skill，不复制其适配器状态体系或报告合同。不新增固定工作包（包括个股 W 工作包）、深度档位、第五份规则文件、专用采集器、共享 engine、数据库、服务、manifest／产物锁定、定时监控或界面。

## 3. 触发、输入与默认值

触发描述应覆盖全球宏观全景、全球专题、主要经济体比较及跨境宏观传导，并能识别比特币的宏观驱动、稳定币与美元／美债、黄金储备、美债抵押及汇率反馈等专题。仅研究中国本土制度时应说明中国宏观入口更匹配；用户明确指定本入口时，可在宏观边界内研究中国及其全球关系，不静默切换或调用其他 Skill。

| 输入 | 默认与处理 |
| --- | --- |
| 研究方式与问题 | “分析全球宏观”等宽泛请求按全景；明确冲击、政策或跨境问题按专题，先写明要回答的问题 |
| 经济体 | 用户指定优先；未指定时按问题的生产、需求、贸易、融资与政策关联选择，并解释纳入和未展开的理由 |
| `as_of` | 未指定时取研究开始的可知信息截止时间，记录时区；历史日期涉及日内先后而未给截止时刻时先澄清 |
| 时间尺度 | 未指定时按核心问题选择并披露采用的短、中或长期尺度；缺少期限会改变判断时先澄清，不机械固定区间 |
| 参考材料 | 仅采用用户主动提供且与问题有关的材料，回查其来源、日期与边界；没有材料仍须独立取证 |
| 输出位置 | 有文件能力时默认 `.hetu/research/global-macro/<独立研究标识>/`；用户指定目录优先 |

经济体同名／范围、币种或货币对、事件与历史截止等存在两种会改变结论的合理解释时先澄清。一般缺少来源不是输入歧义，应自行取证或报告缺口，不反复要求用户补充可公开取得的资料。

全景默认覆盖增长、通胀、政策、金融条件、主要跨境风险及需求§4.4五项，无需用户点名。专题回答用户的核心问题，仅展开相关对象、经济体与渠道，保留同一证据和交付标准；不要求补齐全景状态及全部五项。两种方式均考虑中国的相关性，不预先排除，也不强制每篇专题展开中国。

## 5. 问题到报告的研究流程

1. **确认问题。** 确定全景／专题、信息截止、尺度和边界，列出必须回答的核心问题；不以删掉缺证问题使任务看似完成。
2. **选择经济体。** 依据冲击发生地、贸易需求、融资货币、政策与反馈选范围；全景检视主要共同驱动与差异，专题只展开相关经济体。
3. **建立取证路径。** 将问题对应到观察面、原发布方、具体表／序列／政策原文和方法说明；五项按§6.1选择能回答命题的观察。指标按相关性选择，不将 A01–A21、S01–S18 或本设计的候选观察变成每次全取清单，也不以旧目录排除新增对象。
4. **取得并核对证据。** 使用宿主工具读取正文或数据，记录定位、口径、时点、版本及取得状态；目录、搜索摘要和 API 文档不能替代实际观察值。
5. **形成条件判断。** 连接“观察事实 → 成立条件与机制 → 宏观及资产影响 → 反证或限制”，说明尺度、滞后与替代解释；独立子问题可并行，但汇合时按证据解决冲突。
6. **检查地区、资产与美元支付融资。** 应用对应制度机制；保留原四类资产分析，按范围落实比特币、稳定币、黄金、美债与汇率，区分宏观驱动、资产反馈与共同冲击；弱相关或缺证时明确限制，不硬填方向。
7. **交付与自检。** 完成报告和证据附录，核验引用及核心问题状态；核心问题仍未回答时如实交付未完成部分，不能标为研究成功。

观察面须支持增长／就业／需求、通胀／相对政策／曲线、流动性／美元融资／信用、财政／主权融资、贸易／外部头寸／资金流、供给／政策／长期结构、预期差／金融稳定／跨资产反馈。全景对核心状态作出有边界的判断，专题说明选用哪些观察及原因。

## 6. 地区机制、传导与反证

| 经济体或问题 | 必须保留的判断约束 |
| --- | --- |
| 美国 | 区分美元国际融资、财政发债／国库现金／Fed 流动性；考虑资本市场融资与固定利率按揭如何改变政策传导 |
| 欧元区 | 区分统一货币政策与成员国财政，核对主权利差、银行持债、信贷反馈及区内金融条件分化 |
| 日本 | 核对国债供给、央行操作和市场流动性；联系工资物价、日元融资及进口成本，不能由借款直接认定套利仓位 |
| 中国外溢 | 自行取得内需、进口、出口、商品价格、人民币与资金流证据，构造“中国内部变化 → 外溢渠道 → 全球影响” |
| 中国城投与地方债务 | 仅有可定位显著全球外溢证据时展开；区分城投债、平台全部融资、地方政府债、隐性债务，不相加、不推定政府全偿、不制造精确全量 |
| 英国及其他经济体 | 依据问题识别财政金融结构、外币债务、资源依赖、汇率制度和政策空间；不照搬其他地区，也不强制首期全部覆盖 |

同幅降息、扩表或财政变化在不同地区可能产生不同结果。扩表不等于入市资金；发债不等于支出；持仓变化须分净交易与估值；本外币债务约束分别判断。需求、价格与基数效应分开，调查与硬数据相互核对，成因不足时给条件情景。

每条主要判断分清传导、共同驱动、统计关系和反馈；不重复归因同一冲击，不重复加总同一资金或债务。政策动机、生产率改善、系统性危机不能仅由政策标题、投入热度或价格波动推出。预期差须有事前材料，没有则明确不能判断，不能事后补造共识。

将[需求§4.3](2026-10-18-global-macro-fundamentals-requirements.md#43-分别解释资产影响与宏观反馈)的股票、债券、商品、外汇及比特币判断路径实质保存在研究规则中；新增对象按下节细化，原有盈利／折现率、曲线／信用分化、宏观供需及两侧汇率分析继续适用。

资产判断以条件化情景表达，不设永久股债对冲关系，不强制同向判断或统一评分。稳定币按支付、储备与融资机制分析，不以升值预测代替。对可比时点、币种、尺度和定义作核对，标明官方参考汇率、拟合曲线、指数与成交价格的性质。反证应是可观察的变化或替代解释，并说明它会改变哪项判断。

### 6.1 五项的观察选择与判断采用

先确定要解释的当期变化或风险，再选下表对应观察、取得原文并计算必要变化，最后将支持与相反事实写入正文和判断。表内是能力范围，只有与命题直接相关的资料才须取；缺少关键观察时说明具体受限问题，不能只写通用机制即判该项已回答。

| 对象 | 取证和必要计算 | 正文应形成的判断与限制 |
| --- | --- | --- |
| 比特币 | 核可比时点价格、相关实际利率／美元融资变化；涉及资金驱动时查 ETF 份额、申赎或可复算交易数据，涉及去杠杆时查对应市场持仓、融资／清算及覆盖 | 分开宏观共同驱动与比特币特有变化；ETF 规模变化先分估值与申赎，币价／市值不当净流入。反向影响须有相关机构敞口、抵押融资或财富暴露依据；缺证时不声称已传向全球信用或消费 |
| 美元稳定币 | 核流通量与发行／赎回定义、储备资产及期限、现金可得性、赎回条件和可得脱锚／使用资料；区分发行总量、实际流通及跨链统计覆盖 | 按资金流向解释存款、短债与回购需求变化，区分直接持债、经基金间接持有与回购敞口，避免重复加总；可核发行方新增持债，但资金来源与原持有资产未知时不能算全市场净新增需求或新增美元。赎回压力结合储备变现安排判断；支付／货币替代须有用途或当地证据，不能仅凭链上总额 |
| 黄金 | 对照同期间黄金价格、实际利率与美元；按命题查官方储备数量及交易、投资基金持仓／流量或流动性压力 | 区分储备配置、投资及现金需求，解释相反驱动能否抵消；数量、估值与其他调整分开，数量变化也须核统计说明再判断交易。增配黄金是否伴随美元资产调整须有交易证据；金价与美元同涨不自动否定机制，黄金下跌不自动证明被操控或失去避险作用 |
| 美债 | 核名义／实际曲线、相关期限的净供给与拍卖、持有人交易、财政付息／收入及再融资；抵押链另核回购融资条件、相关敞口、保证金或市场交易证据 | 将定价基准、储备配置、抵押融资与全球金融条件连接；短债需求不外推为长端承接，持仓变化不直接等于交易。收益率变化先辨政策路径、通胀／期限风险和供给，不从单一曲线变化推定保证金出售 |
| 汇率 | 固定货币对和报价方向；广义美元判断另核适当篮子指数及权重范围；按命题查两侧政策、贸易／金融流、外币负债、对冲成本、基差或干预 | 分开价格变化、资金交易和共同冲击，追踪进口购买力、外币偿债、贸易与政策反馈；日元融资只在相关时展开。远期点不作即期预测，单一美元货币对不代替广义美元，借款总量不等于套利仓位 |

对主要反馈说明其影响的部门、期限与规模依据，可使用相关市场占比、持有人敞口或交易量级，不设固定“系统重要性”阈值。取不到分母或资金来源时保留局部事实与待证条件，不制造精确影响，也不把未知写成无影响。全景五项覆盖不自动赋予五项同等宏观重要性。

### 6.2 将对象连接为有条件的传导链

按主要问题选择相关链条，不要求穷举全部资产配对或证明所有箭头均已发生：

| 链条 | 判断时须核的条件与反证 |
| --- | --- |
| 实际利率／美元融资 → 美债、黄金、比特币定价 → 配置与金融条件 | 核共同观察期、增长／通胀驱动、风险偏好与资产特有资金变化；价格同向不证明彼此资金转移，实际利率不能简单用名义利率减当期 CPI 代替市场预期口径 |
| 稳定币发行／赎回 → 储备配置 → 存款、短期美债与回购 | 核资金原来源、资产期限、持有方式和赎回安排；可能是存量资产转移，现金缓冲也可能减少被迫出售，不由发行量或一次脱锚推全局流动性变化 |
| 美债价格／回购条件 → 抵押融资与保证金 → 去杠杆及美元需求 | 区分抵押暴露、当前融资压力与实际出售；核市场反证和适用缓冲，工具存在、宣布及实际使用分开，不能由收益率上涨推定已发生连锁抛售 |
| 汇率变化 → 进口成本／外币偿债／贸易 → 支出与政策 | 核币种、进出口身份、对冲、债务期限、汇率制度及滞后；对冲与收入币种可抵消压力，利差和干预不保证固定方向 |

股票与能源等既有链条继续使用；五项的补充不替代增长、消费、财政和其他原有观察。需求、主权融资及金融压力沿用需求§4.5：核 GDP 后的重要事实、相反承接证据，以及暴露／当前压力／市场反应／缓冲状态。

## 7. 最小证据记录、时点与缺口

使用 Markdown 记录，不新增复杂 JSON 合同或多层状态机。每条证据有本次研究内的简单编号，报告按编号引用；字段可写成表或条目，但不能省略影响判断的内容。

| 记录 | 必需内容 |
| --- | --- |
| 研究范围 | 核心问题、全景／专题、经济体及选择理由、带时区 `as_of`、时间尺度、报告生成时间 |
| 证据身份与定位 | 编号、原发布机构、具体链接和表／页／段／序列定位、转载渠道（如有）、本次取得状态与是否采用及理由 |
| 观察及口径 | 原始值或原文、经济体／覆盖范围、单位币种、季调、实际／名义、累计／当期、流量／存量、实绩／估计／预测 |
| 时间与版本 | 观察期、公开时间、修订时间或版本、获取时间；无法确认的字段明确记未知，不由获取时间推定公开时间 |
| 计算与判断 | 事实、计算、假设和解释分别标识；必要公式及输入编号、成立条件、影响、尺度／滞后、反证及限制 |
| 缺口 | 未取得或冲突的资料、尝试的来源、直接受影响问题、可采用替代及其差异、尚不能成立的结论 |

从主要判断与关键反证回查已取得的正文、附件和工作簿，区分已得未提取、已提取未采用及理由、缺计算、尚未取得与不可比。先完成兼容输入的必要提取和计算，再用于支持或限制正文判断；不能将已得未用登记为未取得，也不能因历史不完整舍弃重要当期事实。

PIT（时点可得性）按公开／可得时间和历史版本判断。今天取得不证明历史当时可得；同日而无发布时间不能假定日内已公开。历史研究只采用截止时点已知事实；有 vintage 时保留对应版本，无历史 vintage 时寻找可定位当期发布材料，仍不可得则限制该历史判断，禁止用最新修订序列冒充。

来源目录的既有状态只是选源线索。本次观察分别记录“已取得正文／数据、仅定位、候选、读取失败、许可待核”；取得与采用分开，公开、可下载、允许使用、HETU 已接入也分开。本文及目录更新不自动改变此前运行中的证据状态。

冲突先核对经济体、期间、定义、覆盖、单位、季调、名义／实际、累计／当期、流量／存量与修订，不盲目平均。同源转载仅算一个底层来源；替代必须匹配本次用途、时点与许可，不能用其他地区资料代填。

缺口只限制直接受影响的观察与判断，不连带否定已有充分依据的结论；核心问题未回答则整体研究不能标成功。结论错误或证据语义改变时说明直接影响并做最小复查；日期、版本、哈希或 `as_of` 改变本身不使旧结果失效，新时点结论也不追溯取消旧时点结果。

## 9. 报告与交付

最小产物为 `report.md` 与 `evidence.md`。前者供用户阅读，后者保留来源、观察、计算和缺口；只有回查需要且权限允许时才保存原始文件到 `raw/`，不以强制保存网页或完整数据集作为完成前提。

`report.md` 按以下顺序组织；专题沿用组织职责，只展开核心问题相关内容：

1. **范围与状态：** 核心问题、截止和尺度、经济体及理由；全景列出增长、通胀、政策、金融条件及跨境风险，专题说明相关观察和范围。
2. **核心驱动与地区差异：** 证据编号、成立条件、地区机制、中国等经济体的相关外溢及尚未确定项。
3. **传导、资产情景与美元支付融资：** 按§3确定的全景／专题范围落实§6。全景保留股票、债券、商品与外汇，比特币独立呈现，稳定币按支付与融资机制呈现，黄金单列，美债和汇率落实§6.1；不以结构齐全代替判断成立。
4. **来源、反证与缺口：** 连接证据记录，给出替代解释、改变判断的观察项、尚不能回答的问题及对结论的具体限制。

`evidence.md` 使用第 7 章字段，包含实际采用证据及影响核心问题的失败／冲突记录，保证主要结论可由报告回查至原始材料。无需保存无关搜索轨迹，也不把外部报告的观点当作本次事实。

### 9.1 历史对照与表旁解释

新增对象沿用[现有历史规则](../skills/hetu-global-macro/references/research-rules.md#41-历史对照)和[表旁释义](../skills/hetu-global-macro/references/report-contract.md#21-正文历史表与指标解释)，必要规则继续实质保存在包内，不引入运行时仓库依赖：

| 观察频率 | 正文窗口与适用比较 |
| --- | --- |
| 月度 | 最新已发布观察月向前12个自然月，用户指定或必要季节性对照可用24个月；逐月数值、同比及适用环比 |
| 季度 | 最近8个完整已发布季度，逐季数值、同比及适用季环比，普通环比与季调折年率分开 |
| 年度 | 最近5个完整已发布年度，遵从用户指定3年等窗口；逐年数值与同比，不设环比 |
| 年内累计 | 本期与上年相同累计期间并列，列水平、可比差额及同比；比较增长速度时列两年同期增速及百分点变化 |
| 日／周频行情和头寸 | 按研究尺度说明观察窗口、取样时点和可比定义；不新增全量高频采集门槛。汇成月度时区分月末存量、均值与期间流量，再按月度窗口展示 |

主要周期性指标在对应正文分析附近呈现，新增主要指标同样纳入。月／季流量、期末存量、均值、累计及季调分别使用；可加、同口径且版本兼容的累计量才可差分，不将累计点充作单期或虚拆合并期。已有兼容基数完成逐期比较并回查输入，基数可在窗口之外；仅有增速则展示增速序列，不倒推精确水平。比率／增速变化用百分点、利率／利差用基点、景气指数用指数点，零或负基数不强算增长率。历史窗口与预测期限独立，保留各来源发布滞后及版本。

表头保留简写，表旁解释实际出现指标的完整名称、衡量对象及必要读法；例如 BTC、ETF、稳定币流通量、实际收益率、回购利率及基差按采用口径解释，不另建大词典。相邻表可共享说明。表注写单位、期间、时点／口径和来源，明确具体缺期、缺基数或不可比原因；部分缺值不缩窗、补零或省略其余可完成比较。一次性政策／事件不造连续序列，正文与附录缺口一致。

### 9.2 定稿核对

从实际报告回查五项的当期依据、机制、反证与影响规模；对主要判断核关键原文／附件已提取、必要计算已完成、事实已进入正文及判断，金融链条分清暴露、压力、反应和缓冲。再从实际表格核窗口、逐期比较、名称解释与具体缺口。不得删除重要观察、降为背景或缩短窗口避开要求。缺证只限制对应命题；不能用“尚缺全部市场数据”否定已回答的问题，也不能凭五项标题齐全宣布核心问题已解决。

### 9.3 保存与完整交付

目录标识仅用于避免覆盖及区分研究，不承担过期、批次绑定或旧成果失效判断。复查在保留原结果的基础上明确修改范围；已通过结果只按直接语义影响复验，整批重跑或重跑已通过结果须遵守项目的证据、成本说明及本次授权门禁。

无文件写入能力或保存失败时，在回复中交付完整报告和完整证据附录，保持相同内容与引用要求，并说明实际落盘状态。有文件能力时核实文件内容可读后再提供路径。不得只返回文件名、模板、摘要，或声称已写入不存在的文件。
