## 1. 核心结果

至少一项非基准候选在合格真实数据上完成规则、机制、历史样本外、成本与稳健性评价；网页和独立工具能追查同一产物，给出经济目标是否达到以及继续／补证／调整／停止的依据。

新二期的软件通过、新三期的数据准入均不能代替本期真实研究；有成本后的有效负结果可以完成研究，全部受阻、只有基准或合成曲线不算完成。经济目标未达到时必须直说，不承诺盈利。

## 2. 保留的研究定义与执行边界

| 项 | 必须保留的行为 |
| --- | --- |
| 股票池与窗口 | 原沪深普通股历史池，不从一期 Top 50 或少量可得样本替代；2019-11-01 至 2026-10-13，预热按原定义，最早数据需求至 2016-04；不因新日期自动扩大窗口 |
| 低波动规则 | 36 个完整月收益、ddof=1、最低十分位、N≥10、市值加权、月末信号、次一可执行时点；N≥10 是信号条件，不能替代原池完整资格 |
| 邻域与时间切分 | 开发／验证比较 30／42 月邻域；开发 2019–2021、验证 2022–2023、最终 2024 至原截止日，具体边界和选择规则消费原冻结协议 |
| 资本、成本与账户 | 100 万 CNY、普通现金多头不加杠杆；原佣金、最低费用、滑点、历史税费与数量／价格规则不变；原价成交、行动记账与总收益特征分离 |
| 八次预算 | 沿用原协议具体定义、依赖及阶段选择，不因新分期重置；包括开发／验证主策略与基准、邻域，以及最终候选／基准、成本压力、容量情景，执行顺序以调度清单为准 |
| 诊断与评价 | 同口径基准、收益／风险／成本／换手／成交／容量、分区间、规模／行业暴露；成熟 1／3／6 月标签、IC／RankIC、分组／衰减／漂移、块区间及样本量；不适用项逐项说明 |
| 目标与结论 | 沿用预设净收益、匹配超额、波动／回撤和统计支持条件；点估计、置信区间、研究结论与投入决定分开，不看结果后改阈值 |

策略顺序继续低波动优先，E/P 有合格财务时点才进入，红利低波储备。其余已收集方向按增量证据决定，不新增七类全部实跑门槛。数据从纯免费调整为用户已批准的免费／付费组合时，记录真实模式与来源，不伪装免费成果；规则、股票池和评价目标不随供应商更换。

现有协议文件仍保留 `mode=free` 及原冻结记录。用户批准付费产品后，按实际来源另存执行定义和来源变更说明，不原地覆写旧定义，不新建空预算账本绕开原八次上限；协议行为字段和既有 trial 的继承关系逐项可核查。

## 3. 数据接入后的接缝与真实执行

接收三期的已发布快照、原八次定义所需的用途资格、来源／许可及限制清单，直接使用，不重新选供应商或从头下载。核对研究实际涉及的行动、退出处置和限制价格参考；真实数据揭示的接缝问题按对象／日期定位并最小修复。未支持事件不能默认变现、删除持仓或按零收益填平；不能以本设计概括授权降级。

正式执行前生成一次具体范围文件：原池、逐信号合格数、预热与回测边界、八次定义、复用部分、真实数据请求、数值研究及费用。按 AGENTS.md 说明多公司分析并询问模型选择，取得当前任务的运行授权；不将分期设计批准当作真实运行授权。默认公司深研和 LLM 业务调用均为零。

正式运行使用独立研究入口，不等待完整工作台；保留全部成功、失败、受阻与负结果。来源身份或 `as_of` 变化不触发重算已通过定义；行为等价与复用依据按现有语义规则核对，具体错误只重验直接影响部分。最终检验已查看记录继续保留，不把旧市场数据重新宣称为完全未见样本。

按原调度依赖执行，阶段选择消费原协议；成功产物就地复用，失败尝试按现有规则计入预算。八次是上限，不是允许额外补跑的配额；若预算耗尽或关键输入仍受阻，列明已完成／未运行定义和具体缺口，不新建 study 逃避台账。一次获批计算产出的结果同时用于报告、网页、导出和 Notebook。

## 4. 从原三期合入的小任务

只合入本期已有真实产物能够顺手完成的交接，不新增第二套执行器或额外真实研究名额。

| 原三期内容 | 四期范围 | 保留给五期 |
| --- | --- | --- |
| §3.1 既有研究只读纳入 | 登记本期独立策略产物、原规则／适配差异、全部 trial、失败和证据引用；不计算 | 更广策略库筛选与日常交互打磨 |
| §3.1／§6 状态区分 | 展示执行状态、研究进度／结论、经济状态、证据导入与执行适配；互不冒充 | 其余工作台管理体验 |
| §4 比较与导出 | 对本期实际结果展示兼容性及差异；网页／ZIP／Notebook 读同一结果，零额外信号／引擎／LLM 调用 | 完整实验复制、跨研究日常工作流 |
| §3.2 代表策略实际在平台继续运行 | 不用只读纳入代替，不以独立脚本运行自动勾选该项 | 至少一项选定代表策略经平台入口真实执行与追溯，保持为五期必需结果 |

原二期 04 的真实网页查看与导出、05 的真实研究验收均在本期完成。使用既有运行结果检查展示，不为网页验证重新执行八次研究。

## 6. 交付单元与设计取舍

后续计划按“数据与实际制度接缝、原协议真实研究、只读交接及验收”拆分。先复用有效软件测试和已有研究证据，真实数据缺口由三期负责补齐，四期只处理实际研究直接暴露的接缝，不再启动无边界资料搜集。

本设计选择复用三期数据和二期机制，只补真实运行及结果交接；原研究范围、八次上限和经济目标不变。只读纳入不增加研究运行，平台真实执行仍由五期证明。数据合格而经济目标未达时，本期可以完成研究，收益目标仍未达到。
