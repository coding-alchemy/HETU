## 新增计划约定

1. 设计文档先按 `specs/YYYY-MM-DD-<topic>-design.md` 创建并获批。
2. 在本目录创建独立子目录，子目录名与设计主题一致。
3. 子目录以 `README.md` 作为路线图，链接回对应设计。
4. 分阶段文件命名为 `YYYY-MM-DD-NN-<step-title>.md`，按文件名排序即执行顺序。
5. 每阶段写明准确范围、前置条件、验证命令、停止门和回退边界；不得复用已删除的历史路径。
