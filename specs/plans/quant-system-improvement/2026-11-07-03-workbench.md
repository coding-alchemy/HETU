# 量化系统完善阶段03：完整工作台

> 文档版本：v1.0
> 文档状态：已完成，工程范围通过；策略状态及维护表单复评关闭，真实覆盖和策略执行各自验收
> 创建日期：2026-11-07；修订日期：2026-11-08
> 适用范围：W1–W6、S1/S4/S5的工作台机制与已有证据复用
> 执行者：使用 `subagent-driven-development` 或 `executing-plans` 逐任务执行；以下勾选项在执行时记录。

**目标：** 用户无需修改源码、编辑JSON或复制内部标识，即可查询固定版本的数据、管理维护、找策略、配置和复制实验、找回任务、比较与导出已有结果。

**架构：** 独立数据页与研究页共用阶段01的库范围查询和阶段02的维护合同。研究页仅补策略元数据、表单与结果导航，继续消费 `ExperimentStore`、`JobService`、共同资格检查和既有发布产物；不新增数据库、执行器或收益公式。

**技术栈：** 现有 Python 3.11、Streamlit、pandas、Parquet／DuckDB、SQLite与隔离RQAlpha；版本沿用锁文件。

**规格：** [需求§4–5](../../2026-11-07-quant-system-improvement-requirements.md#4-完整工作台需求)、[设计§4–6](../../2026-11-07-quant-system-improvement-design.md#4-完整工作台的操作流程)、[路线图](README.md)。
