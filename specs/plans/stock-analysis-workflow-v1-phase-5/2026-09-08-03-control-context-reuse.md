## 4. 任务 03.2：预算、自然语言控制与恢复

- [x] 将 02 获批三档默认预算写入 orchestration；W0 在访问旧资料前解释并记录实际值和复用
  开关。无可观测消耗写缺口，不把已有订阅误记为新增费用授权。
- [x] 写明同对象／来源／失败原因的重试计数；到限换合法路径、缩小问题或留缺口。深度满足、
  继续检索价值过低、非时间预算耗尽、取消、能力不足、授权不足、安全阻断分别停止对应工作。
- [x] 加入超时后的进度模板：目标值（如有）、实际耗时、卡点、已完成域、剩余工作、关键缺口、
  预算与下一动作；不请求续时，不停止或降低深度。用时未知不造数值。
- [x] 由原生接口接收取消：停止新工具和新子任务，安全停止可中止在途任务，其余迟到返回
  留作未采用，未经恢复不进入 owner。改关注点／深度只调整剩余工作，保留无冲突证据。
- [x] 提前交付在满足适用独立核验和安全要求后披露实际深度与缺口。恢复按会话关联、公司、
  日期、深度和研究目标筛选候选，再按需读检查点；有真实歧义才让用户辨认，不索要内部 ID。
- [x] 对同一任务当前恢复和 `false` 新研究作区分：前者使用本任务记录，后者不查找或载入旧
  任务。恢复核对主体、时点、模式、授权与最新要求，不重新执行无影响的已完成项。
