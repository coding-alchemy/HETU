## 1. 核心目标与范围

独立回答：**全球增长、通胀、政策与金融条件由哪些因素驱动，经济体之间如何相互影响，这些变化怎样传到股票、债券、商品和外汇，证据与反证是什么。**

研究单位是全球、经济体、货币区及资产类别。全球包含中国；工具关注全球共同驱动、地区差异及外溢，不把“全球”解释为“中国以外”，也不要求每次遍历所有国家或首期同时覆盖全部地区。

不开展行业供需与竞争细节、公司经营与财报分析、公司治理、法律尽调、企业资本配置或个股估值；也不开展单券契约与偿付顺位、发行人信用尽调、具体期货交割／展期、基金穿透、具体交易合约或持仓收益计算。代表性价格、总量信用与资产类别表现仅用于宏观解释。

## 2. 输入与研究范围

| 输入 | 工具须明确的内容 |
| --- | --- |
| 研究方式与问题 | 支持全球全景或宏观专题；专题须明确需要回答的问题，全景须判断增长、通胀、政策、金融条件及主要跨境风险 |
| 经济体范围 | 接受用户指定经济体；未指定时按问题选择相关经济体，并在报告说明理由，不静默扩为全世界逐国研究 |
| 分析时点与时间尺度 | 明确截至何时可知的信息，以及短期、中期或长期作用；历史研究不得混入当时尚未公开的事实 |
| 可选参考材料 | 用户主动提供的宏观、行业或其他报告；缺少这些材料不得阻止独立取证 |

研究对象或范围存在影响结论的歧义时先澄清；资料只按当前问题的相关性采用，不以覆盖输入材料篇目为目标。

## 3. 独立开发与运行

1. 全球宏观与中国宏观是两个独立分析入口，各自开发、选择原始来源、运行研究并形成完整报告；理论指南统一方法和证据标准，不要求共同运行组件。
2. 中国宏观或行业工具尚未开发、不可用、未运行或没有报告时，本工具仍须可直接取证并完成自身研究，不以其为安装、启动或完成前置条件。
3. 不要求共同资料库、共享库、服务、会话、调度或相互调用接口，也不自动调用、读取或等待其他工具的报告。
4. 用户主动提供其他报告时，仅作可选证据；核对相关来源、日期和判断边界，不自动继承结论。缺少报告不改变本工具取证责任。
5. 需要中国或行业背景变量时，自行取得与全球问题直接相关的原始资料；不因取得背景数据而扩展为另一套完整研究。

## 4. 必需研究行为

### 4.1 选择并核对宏观观察

因素定义与机制参考理论指南第 2、4 章的 A01–A21，来源编号对应第 8 章的 S01–S18。工具按下表选择观察，并保留各经济体定义；全景须交代核心状态，专题按问题选取相关部分，不把所有指标变成每次必取清单。

| 观察面 | 实现须支持的取证与判断 | 理论定位 |
| --- | --- | --- |
| 增长、就业与需求 | 核对实际／名义增长、消费投资、就业工时、实际收入、景气和总量订单；区分需求、价格与基数效应，调查与硬数据相互核对 | A01–A03、A14 |
| 通胀、相对政策与曲线 | 核对总体／核心物价、工资、预期、政策原文及两侧利差；区分政策路径、期限溢价和债券供给，不能由降息直接推出资产方向 | A04–A07、A15 |
| 流动性、美元融资与信用 | 核对央行资产负债、准备金、财政存款、回购、美元负债、融资基差、信贷供需和偿债压力；不能把扩表视为入市资金或把借款视为套利仓位 | A08–A11、A16 |
| 财政与主权融资 | 核对收支执行、债务币种与期限、利息、净发行及储备；区别发债、支出、偿债，以及本币与外币约束 | A12–A13 |
| 贸易、外部头寸与资金流 | 核对贸易量价、经常账户、国际投资头寸、证券流和汇率制度；分开估值与净交易，持仓变化不能直接当净流入 | A14–A16 |
| 供给、重大政策与长期结构 | 按问题取得能源食品代表性价格、进口成本、供应链压力、政策原文、人口及生产率；成因未证时给条件情景，不推定政策动机或将投入热度视为生产率结果 | A17–A19 |
| 预期差、金融稳定与跨资产反馈 | 对照事前材料、实际发布、修订、融资压力和市场反应；无事前资料不得补造共识，价格波动不得单独证明系统性危机 | A11、A20–A21 |

每条主要判断须连接“观察事实 → 成立条件与机制 → 宏观及资产影响 → 反证或限制”，注明时间尺度与可能滞后。区分传导、共同驱动、统计关系和反馈；不因多个指标反映同一冲击而重复归因，也不将同一资金或债务重复加总。

### 4.2 应用地区机制并识别中国外溢

| 地区 | 需要辨别的宏观机制 | 因素／来源 |
| --- | --- | --- |
| 美国 | 美元国际融资地位；财政发债、国库现金与 Fed 流动性相互作用；资本市场融资和固定利率住房贷款改变政策传导 | A06–A10、A12–A13、A16；S06–S08、S12 |
| 欧元区 | 统一货币政策与成员国财政分立；主权利差、银行持债及信贷条件反馈；区内金融条件分化 | A06–A07、A09–A13；S09、S12–S13 |
| 日本 | 国债供给与央行操作、债券市场流动性、工资物价传导、日元融资与进口成本 | A02、A04、A06–A08、A13、A15–A16；S11–S13 |
| 中国 | 内需及进口影响全球需求与商品价格，出口影响全球贸易和价格，人民币及资金流形成跨境反馈 | A01、A04、A14–A18；S01–S05、S12–S13、S17 |
| 英国及其他目标经济体 | 按问题识别财政与金融结构、外币债务、资源依赖、汇率制度和政策空间，不照搬其他经济体机制 | A06–A18；S10、S12–S13 及当地原发布方 |

中国城投与地方债务只在有可定位证据表明其对全球需求、跨境融资或风险偏好产生显著外溢时展开，说明“中国内部变化 → 外溢渠道 → 全球影响”，不默认每份全球报告都研究城投。

展开时仍须区分城投债、平台全部融资、地方政府债与政府隐性债务，不能直接相加或推定全部由政府偿还；公开资料不足时说明覆盖范围，不制造精确全量。中国本土制度全景由中国宏观入口负责，全球研究无需先取得其报告。

### 4.3 分别解释四类资产的宏观影响

| 资产类别 | 研究落点与条件 |
| --- | --- |
| 股票 | 宽基市场总量盈利预期、折现率和风险溢价；需求走弱与利率下降可能产生相反作用，不直接推出指数必涨必跌 |
| 债券 | 主权名义／实际曲线、期限溢价、总量信用利差与供给；无风险利率下降时信用利差仍可能扩大 |
| 商品 | 代表性价格／指数对应的总需求、美元、通胀与供给冲击；黄金关注实际利率、储备及避险渠道，品种供需细节归行业研究 |
| 外汇 | 双边相对基本面、政策路径、外部融资和货币制度；远期点含利差与融资条件，不直接当作未来即期预测 |

逐类说明与当前问题有关的条件化影响；证据不足或相关性弱时明确说明，不强行填方向。比较固定时点、币种、时间尺度及指标定义；官方参考汇率、拟合曲线、指数与成交价格分别标注，不设永久股债对冲关系，也不计算具体工具的可实现回报。

## 5. 原始来源、证据与缺口处理

工具须自行选择具体统计表、序列、政策原文及方法说明，不能只返回来源目录。来源范围按研究对象选择：中国外溢使用 S01–S05，美国使用 S06–S08，欧洲／英国／日本使用 S09–S11，全球信用与跨国比较使用 S12–S13，供给冲击及政策使用 S14–S16，跨资产参照使用 S17；S18 按需补充中国金融体系或地方财政债务的相关外溢证据。不用其他地区数据代填缺项。

完整来源核验状态集中记录于理论指南；现有记录仅支持部分入口或说明已读，列示 API 均未实测，不代表 HETU 已接入。宽基股市、全球信用利差等数据产品尚待确定，也未取得完整全球行情、可比城投融资或隐性债务全量数据。实现不得将这些缺口改写为已有能力。

每次取证须分清已取得正文／数据、仅定位、候选、读取失败和许可待核；公开、可下载、允许使用与已接入分别判断。关键来源不可得时记录受影响观察与结论，不以搜索摘要、目录存在或其他报告的判断代替原始证据；仅有部分证据时限定结论范围。

每条主要证据记录发布机构、具体链接及定位、经济体、定义与单位、观察期、公开／修订／获取时间、季调、实际／名义、累计／当期、统计覆盖及取得状态；保留事实、计算、假设、解释、实绩、估计和预测的区别。

数据冲突先核对口径与修订，不盲目平均；多个转载只算一个底层来源。不用最新修订值冒充当时已知信息，也不以时间、版本或目录变化判有效旧结果失效；仅对直接语义变化影响的判断做必要复查。

## 6. 完整报告输出

完整报告至少包括：

1. **范围与状态：** 研究问题、分析时点、时间尺度、纳入经济体，以及增长、通胀、政策和金融条件判断。
2. **核心驱动与地区差异：** 重要因素、原始证据、适用制度和中国等经济体的相关外溢；说明关键未确定项。
3. **传导与四资产情景：** 主要路径、成立条件、可能滞后及反馈；分别交代股票、债券、商品与外汇，不强制统一评分。
4. **来源、反证与缺口：** 可回查引用、替代解释、使判断改变的观察项及缺证据导致的结论限制。

缺少关键证据时明确哪些问题尚不能判断，不以报告结构齐全冒充结论成立。外部材料仅作与当前问题有关的线索，不要求覆盖原始材料全部内容；自动采集、定时监控、界面和技术栈不在本需求范围。

## 7. 行为验收标准

| 输入或场景 | 必须观察到的结果 |
| --- | --- |
| 中国及行业工具均无报告或不可用 | 全球入口仍自行取证、形成宏观判断和完整报告；不发生隐性调用或等待 |
| 分别提出全景和专题问题 | 全景交代核心宏观状态，专题选择相关路径并说明经济体范围；不会机械遍历所有国家，也不会将中国排除出全球 |
| 不同经济体出现相同利率或财政变化 | 结合目标经济体结构说明不同传导，不以统一指标模板代替判断 |
| 有中国需求／贸易外溢证据，或涉及城投融资 | 纳入相关商品、贸易、人民币和资金影响；城投只按可定位显著外溢证据展开，且保持债务口径和单券边界 |
| 同一增长、通胀或融资冲击涉及四类资产 | 逐类说明相关作用路径、条件和分化；不能判断时明确限制，不强制单向预测 |
| 历史时点研究、缺少事前共识或数据被修订 | 使用当时可知事实，标明版本；不以最新值重写历史，不补造预期差 |
| 关键数据未取得、来源冲突或仅有转载 | 准确报告状态与缺口，核对口径，限定未成立的结论；不将 API 说明、重复转载或报告结构当成充分证据 |
| 复核任一主要判断，或仅改变日期／版本 | 判断可回查来源、假设及反证；旧结果继续对原时点有效，只复查直接语义变化影响的判断，不因元数据变化整批重跑 |

验收以研究行为与可观察结果为准，静态编号映射、字段齐全或文件存在不能替代行为验证。
