## 1. 核心目标与范围

独立回答：**全球增长、通胀、政策与金融条件由哪些因素驱动，经济体之间如何相互影响；这些变化与股票、债券、商品、汇率、比特币及美元支付融资体系如何双向传导，证据、影响规模与反证是什么。**

研究单位是全球、经济体、货币区及资产类别。全球包含中国；工具关注全球共同驱动、地区差异及外溢，不把“全球”解释为“中国以外”，也不要求每次遍历所有国家或首期同时覆盖全部地区。

不开展行业供需与竞争细节、公司经营与财报分析、公司治理、法律尽调、企业资本配置或个股估值；也不开展单券契约与偿付顺位、发行人信用尽调、具体期货交割／展期、基金穿透、具体交易合约或持仓收益计算。代表性价格、总量信用与资产类别表现仅用于宏观解释。

加密资产以比特币为主要观察对象；稳定币以美元储备支持型为主要对象，按覆盖选择 USDT、USDC 等代表样本并披露代表性，不遍历全部币种、协议或发行商。ETF 申赎、稳定币储备和赎回条款可作为宏观资金与风险渠道证据，不扩展为基金选择、发行商经营尽调、代币估值、挖矿或交易策略。代币化黄金、代币化存款等仅在与本次传导直接相关时辨别，不设为每次必查对象。

《金融分析知识总结.md》第1.4、1.7、2.5、2.8、第3章和第5章提供资产联动、储备、抵押与跨境融资线索；其中数值、事件及政策动机须另行核证。本次扩展以§4.4五项为界，不受理论指南原四类资产目录限制，也不因指导材料包含更多内容而自动扩围。

## 3. 独立开发与运行

1. 全球宏观与中国宏观分别开发、取证、研究并交付完整报告；理论指南统一方法和证据标准，不要求共同运行组件。其他工具不存在、不可用或没有报告，不影响本工具独立安装、启动和完成自身研究。
2. 不要求共同资料库、共享库、服务、会话、调度或相互调用接口，不自动调用、读取或等待其他工具及其报告。
3. 用户主动提供的报告仅作可选证据，核对原来源、日期与判断边界，不继承结论。所需中国或行业背景变量自行取证，不扩展为另一套完整研究。

## 4. 必需研究行为

### 4.1 选择并核对宏观观察

因素定义与机制参考理论指南第 2、4 章的 A01–A21，既有来源编号对应第 8 章的 S01–S18；新增对象按§4.4和第5章补充。工具按下表选择观察，并保留各经济体定义；全景须交代核心状态，专题按问题选取相关部分，不把所有指标变成每次必取清单。

| 观察面 | 实现须支持的取证与判断 | 理论定位 |
| --- | --- | --- |
| 增长、就业与需求 | 核对实际／名义增长、消费投资、就业工时、实际收入、景气和总量订单；区分需求、价格与基数效应，调查与硬数据相互核对 | A01–A03、A14 |
| 通胀、相对政策与曲线 | 核对总体／核心物价、工资、预期、政策原文及两侧利差；区分政策路径、期限溢价和债券供给，不能由降息直接推出资产方向 | A04–A07、A15 |
| 流动性、美元融资与信用 | 核对央行资产负债、准备金、财政存款、回购、美元负债、融资基差、信贷供需和偿债压力；不能把扩表视为入市资金或把借款视为套利仓位 | A08–A11、A16 |
| 财政与主权融资 | 核对收支执行、债务币种与期限、利息、净发行及储备；区别发债、支出、偿债，以及本币与外币约束 | A12–A13 |
| 贸易、外部头寸与资金流 | 核对贸易量价、经常账户、国际投资头寸、证券流和汇率制度；分开估值与净交易，持仓变化不能直接当净流入 | A14–A16 |
| 供给、重大政策与长期结构 | 按问题取得能源食品代表性价格、进口成本、供应链压力、政策原文、人口及生产率；成因未证时给条件情景，不推定政策动机或将投入热度视为生产率结果 | A17–A19 |
| 预期差、金融稳定与跨资产反馈 | 对照事前材料、实际发布、修订、融资压力和市场反应；无事前资料不得补造共识，价格波动不得单独证明系统性危机 | A11、A20–A21 |

每条主要判断须连接“观察事实 → 成立条件与机制 → 宏观及资产影响 → 反证或限制”，注明时间尺度与可能滞后。区分传导、共同驱动、统计关系和反馈；不因多个指标反映同一冲击而重复归因，也不将同一资金或债务重复加总。

### 4.2 应用地区机制并识别中国外溢

| 地区 | 需要辨别的宏观机制 | 因素／来源 |
| --- | --- | --- |
| 美国 | 美元国际融资地位；财政发债、国库现金与 Fed 流动性相互作用；资本市场融资和固定利率住房贷款改变政策传导 | A06–A10、A12–A13、A16；S06–S08、S12 |
| 欧元区 | 统一货币政策与成员国财政分立；主权利差、银行持债及信贷条件反馈；区内金融条件分化 | A06–A07、A09–A13；S09、S12–S13 |
| 日本 | 国债供给与央行操作、债券市场流动性、工资物价传导、日元融资与进口成本 | A02、A04、A06–A08、A13、A15–A16；S11–S13 |
| 中国 | 内需及进口影响全球需求与商品价格，出口影响全球贸易和价格，人民币及资金流形成跨境反馈 | A01、A04、A14–A18；S01–S05、S12–S13、S17 |
| 英国及其他目标经济体 | 按问题识别财政与金融结构、外币债务、资源依赖、汇率制度和政策空间，不照搬其他经济体机制 | A06–A18；S10、S12–S13 及当地原发布方 |

中国城投与地方债务只在有可定位证据表明其对全球需求、跨境融资或风险偏好产生显著外溢时展开，说明“中国内部变化 → 外溢渠道 → 全球影响”，不默认每份全球报告都研究城投。

展开时仍须区分城投债、平台全部融资、地方政府债与政府隐性债务，不能直接相加或推定全部由政府偿还；公开资料不足时说明覆盖范围，不制造精确全量。中国本土制度全景由中国宏观入口负责，全球研究无需先取得其报告。

### 4.3 分别解释资产影响与宏观反馈

| 资产类别 | 研究落点与条件 |
| --- | --- |
| 股票 | 宽基市场总量盈利预期、折现率和风险溢价；需求走弱与利率下降可能产生相反作用，不直接推出指数必涨必跌 |
| 债券 | 主权名义／实际曲线、期限溢价、总量信用利差与供给；无风险利率下降时信用利差仍可能扩大 |
| 商品 | 代表性价格／指数对应的总需求、美元、通胀与供给冲击；黄金按§4.4单列分析，品种供需细节归行业研究 |
| 外汇 | 双边相对基本面、政策路径、外部融资和货币制度；远期点含利差与融资条件，不直接当作未来即期预测 |
| 比特币 | 实际利率、美元融资与风险偏好对其定价和资金行为的作用，以及有证据支持的杠杆、机构敞口或财富反馈；不预设避险属性或与股票的固定相关性 |

逐类说明与当前问题有关的条件化影响；证据不足或相关性弱时明确说明，不强行填方向。比较固定时点、币种、时间尺度及指标定义；官方参考汇率、拟合曲线、指数与成交价格分别标注，不设永久股债对冲关系，也不计算具体工具的可实现回报。

### 4.4 比特币、稳定币、黄金、美债与汇率的双向作用

全景默认覆盖以下五项，无需用户逐项点名。分别交代当期状态、宏观关系、证据与限制：比特币独立呈现，稳定币按美元支付、储备与融资机制呈现，黄金单列，美债和汇率可在对应资产分析中展开。同一事实可交叉引用，不重复计算或要求重复成章。按命题选择必要观察并实际取证；已得关键事实须用于支持或限制判断，不能以通用机制或笼统缺证代替。关键证据缺失时记录尝试和未回答问题。专题仅展开相关部分。

| 对象 | 必须具备的分析能力 | 必要分辨 |
| --- | --- | --- |
| 比特币 | 连接实际利率、美元融资、风险偏好与价格、ETF 申赎、杠杆／清算等相关观察；判断其变化是否经机构敞口、抵押或财富渠道反馈金融条件和支出 | 市值增长不等于净流入；ETF 资产规模增长不等于净申购；价格相关不证明宏观因果，不能由币价大跌直接推定系统性危机 |
| 美元稳定币 | 连接流通量、发行赎回、储备构成与银行存款、短期美债及回购需求；分析跨境使用、货币替代，以及脱锚／集中赎回向储备变现和传统金融的可能传导 | 区分稳定币持有人、发行方与储备托管主体；新增发行可能是已有美元资产重新配置，不自动等于新增美元或净新增美债需求；链上转账额不等于真实支付或跨境资本流 |
| 黄金 | 结合实际利率、美元、央行储备数量与交易、投资持仓／资金及现金需求，区分储备配置、投资与避险驱动；判断储备组合调整的跨资产作用，说明美元与黄金同涨或流动性紧张时黄金被出售的条件 | 储备市值变化分价格、数量及其他调整，不能直接当净购金；增配黄金不自动等于减持美债，不以涨价证明美元体系衰退，不以降息或通胀单项确定方向 |
| 美债 | 同时解释全球定价基准、储备资产及回购抵押品角色；联系曲线、发行期限、付息／再融资、拍卖与持有人需求、对冲和回购条件，追踪全球融资反馈 | 分清短期国库券与中长期债券、存量与边际交易；稳定币购短债不等于同额支撑长债；发债不等于创造美元，抵押品价值变化不等于已发生被迫出售 |
| 汇率 | 核相对增长与政策、贸易／金融流、制度及对冲成本；追踪进口价格、外币债务、贸易竞争力与政策空间的反馈，并按需分析日元融资和跨境去杠杆 | 明确货币对、报价方向及指数构成；美元对单一货币变化不代替广义美元变化；利差、远期点和总借款不能直接推定汇率走势或套利仓位 |

主要链条须分辨共同驱动与实际传导、宏观对资产的作用与资产对宏观的反馈。根据命题核相关规模、占比、期限或交易证据；若要称其为重要宏观驱动，须说明相对于相关市场或部门为何重要，不将大额名义数值直接等同重大影响。规模或资金来源未证时保留机制和局部事实，明确不能判断影响强度，不将未知当作无影响。

不要求穷举两两相关性或每次取得表内全部指标。对主要判断须采用可得的反向事实，并写明会改变结论的条件；不把“黄金受人为压制”“基差交易稳赚”等材料观点固化为研究规则。

### 4.5 取证采用与历史展示

新增对象与既有宏观观察使用同一证据标准，不以增加新章节替代既有行为：

- 主要需求判断结合 GDP 后相关消费、就业／工时、实际收入及必要储蓄或融资观察，保留方向差异与发布滞后；主要主权融资判断区分付息、收入／名义增长、期限与承接，市场收益率不代替存量平均成本。
- 主要金融链条区分风险暴露、当前压力、市场反应及缓冲；工具存在、宣布、实际使用分别核实，滞后存量不代替当前融资压力。
- 从判断及反证回查已得正文、附件和工作簿，区分未取得、已得未提取、未采用及理由、缺计算和不可比；兼容输入完成必要提取、计算并进入正文与判断，不把漏用改写成数据不可得。
- 支撑主要判断的周期性指标，在正文分析附近展示月度最近12个自然月（按用户要求或必要季节性对照可用24个月）、季度最近8个完整已发布季度、年度最近5年（遵从用户指定3年等窗口）；累计并列上年相同期间。逐期给出同比及适用环比，已有兼容基数须计算；只有增速则展示增速序列，比率用百分点、利率／利差用基点。保留流量／存量、当期／累计、季调、版本和各自发布滞后，不将累计点充作单期，不因部分缺值缩窗、补零或省略其余可完成比较。
- 表头可简写，表旁说明完整名称、衡量对象及必要读法，并明确具体缺期、比较基数与限制；相邻表可共享说明。一次性事件不造历史序列。日度行情、周度头寸等按判断尺度选择有说明的观察窗口与可比时点；若汇成月度，明确月末、均值或期间流量后沿用月度规则，不新增每次全量高频采集要求。

## 5. 原始来源、证据与缺口处理

工具须自行选择具体统计表、序列、政策原文及方法说明，不能只返回来源目录。来源范围按研究对象选择：中国外溢使用 S01–S05，美国使用 S06–S08，欧洲／英国／日本使用 S09–S11，全球信用与跨国比较使用 S12–S13，供给冲击及政策使用 S14–S16，跨资产参照使用 S17；S18 按需补充中国金融体系或地方财政债务的相关外溢证据。不用其他地区数据代填缺项。

理论指南保留早期来源记录，Skill 的来源导航保留后续实际核验及其时点；既有核验只支持当时实际取得的范围，不代表全部 API、全球行情或全部宿主已接入。本次修订没有新增来源实测，不改变旧记录或认证其未覆盖能力。

新增来源导航须覆盖比特币行情与 ETF／衍生品公开披露、稳定币发行方储备与鉴证资料、黄金价格／储备数量／投资持仓，以及美债和汇率的对应原始数据。沿用相关 S06、S08、S12、S13、S15、S17 条目并按对象补充具体定位动作；候选来源及用途见设计第8章，未实际读取前保持候选。发行方披露、第三方鉴证、审计和监管文件须按各自覆盖使用，不能互称；链上聚合与其他估计须说明方法和覆盖。

仅使用公开或已有授权资料。确实不足且影响关键判断时，说明缺什么、公开路径与替代、建议商业来源及预期改善，交用户审批；未经批准不采购、试用、付费调用或联系供应商。

每次取证须分清已取得正文／数据、仅定位、候选、读取失败和许可待核；公开、可下载、允许使用与已接入分别判断。关键来源不可得时记录受影响观察与结论，不以搜索摘要、目录存在或其他报告的判断代替原始证据；仅有部分证据时限定结论范围。

每条主要证据记录发布机构、具体链接及定位、经济体、定义与单位、观察期、公开／修订／获取时间、季调、实际／名义、累计／当期、统计覆盖及取得状态；保留事实、计算、假设、解释、实绩、估计和预测的区别。

数据冲突先核对口径与修订，不盲目平均；多个转载只算一个底层来源。不用最新修订值冒充当时已知信息，也不以时间、版本或目录变化判有效旧结果失效；仅对直接语义变化影响的判断做必要复查。

## 6. 完整报告输出

全景报告按以下顺序交付；专题保留相同的组织职责，只展开与核心问题有关的内容，不要求补齐全景状态及全部对象：

1. **范围与状态：** 研究问题、分析时点、时间尺度、纳入经济体；全景交代增长、通胀、政策、金融条件及主要跨境风险，专题说明相关观察与未展开范围。
2. **核心驱动与地区差异：** 重要因素、原始证据、适用制度和中国等经济体的相关外溢；说明关键未确定项。
3. **传导、资产情景与美元支付融资：** 主要路径、成立条件、可能滞后及反馈；按§4.3–§4.4及本次全景／专题范围呈现，不强制统一评分。
4. **来源、反证与缺口：** 可回查引用、替代解释、使判断改变的观察项及缺证据导致的结论限制。

缺少关键证据时明确哪些问题尚不能判断，不以报告结构齐全冒充结论成立。外部材料仅作与当前问题有关的线索，不要求覆盖原始材料全部内容；自动采集、定时监控、界面和技术栈不在本需求范围。

历史表、指标释义与具体比较缺口按§4.5放在正文相应分析附近，证据附录保留计算及定位。定稿从实际正文回查：五项是否按范围覆盖、关键事实及反证是否实际约束判断、影响强度是否有依据、表格是否漏列／漏算／漏解释。核心问题未回答时标明局部未完成；缺少与该判断无关的全量资料不构成新增门槛。

## 7. 行为验收标准

| 输入或场景 | 必须观察到的结果 |
| --- | --- |
| 中国及行业工具均无报告或不可用 | 全球入口仍自行取证、形成宏观判断和完整报告；不发生隐性调用或等待 |
| 分别提出全景和专题问题 | 全景交代核心宏观状态，专题选择相关路径并说明经济体范围；不会机械遍历所有国家，也不会将中国排除出全球 |
| 不同经济体出现相同利率或财政变化 | 结合目标经济体结构说明不同传导，不以统一指标模板代替判断 |
| 有中国需求／贸易外溢证据，或涉及城投融资 | 纳入相关商品、贸易、人民币和资金影响；城投只按可定位显著外溢证据展开，且保持债务口径和单券边界 |
| 同一增长、通胀或融资冲击涉及四类资产 | 逐类说明相关作用路径、条件和分化；不能判断时明确限制，不强制单向预测 |
| 提出全球全景问题，未逐项点名五个重点对象 | 默认覆盖五项；材料足以回答时，关键事实实际进入各项判断，不能只写标题、机制或受限说明。缺证时明确对应未回答问题；既有股票与其他债券／商品分析保留 |
| 资产规模、价格、发行、赎回及交易方向不同 | 区分市值与净流入、ETF 资产规模与净申购、稳定币发行与新增美元、储备估值与交易；结合相关规模／占比和期限判断反馈，不因材料暗示而固定相关性 |
| 主要金融链条存在相反事实，或缺资金来源／敞口 | 采用反证改变或收缩对应判断，区分暴露、压力、反应与缓冲；已知事实保留，未知规模不量化为全局冲击 |
| 比特币、稳定币或某货币对的窄专题 | 在宏观边界内回答核心问题，仅展开相关对象和地区；不自动铺开所有币种、全部五项或完整全球全景 |
| 主要指标有可比历史、部分缺基数或仅有日／周频数据 | 按§4.5展示适用窗口与比较，已有可算值不能漏算；表旁有完整释义和具体缺口，高频样本不冒充完整月度历史 |
| 历史时点研究、缺少事前共识或数据被修订 | 使用当时可知事实，标明版本；不以最新值重写历史，不补造预期差 |
| 关键数据未取得、来源冲突或仅有转载 | 准确报告状态与缺口，核对口径，限定未成立的结论；不将 API 说明、重复转载或报告结构当成充分证据 |
| 复核任一主要判断，或仅改变日期／版本 | 判断可回查来源、假设及反证；旧结果继续对原时点有效，只复查直接语义变化影响的判断，不因元数据变化整批重跑 |

验收以研究行为与可观察结果为准，静态编号映射、字段齐全或文件存在不能替代行为验证。材料充分的场景验证实际分析能力，材料受限的场景验证结论收缩与缺口处理；后者通过不代表缺失分析能力已证，交付受限报告也不代表全部核心问题已回答。

本次增强只验证新增行为和修改直接影响的最小回归；旧通过结果继续对原范围与时点有效，不据新范围追溯判失败。未核真实来源只能证明材料内行为，不能认证公网全量能力。达到本轮通过条件后收尾，不为补齐所有市场、时期或宿主而追加研究。
