## 2. 产品目标、独立性与边界

独立回答：**全球增长、通胀、政策与金融条件由哪些因素驱动，经济体之间怎样影响；这些变化与股票、债券、商品、汇率、比特币及美元支付融资体系如何双向传导，影响规模、证据、条件与反证是什么。** 每条主要判断连接“观察事实 → 成立条件与机制 → 宏观及资产影响 → 可观察反证或限制”，说明时间尺度、滞后和替代解释。

全球包含中国。按问题选择相关经济体，不将全球解释为中国以外，也不机械逐国遍历。全景交代增长、通胀、政策、金融条件及主要跨境风险，默认覆盖比特币、美元储备支持型稳定币、黄金、美债与汇率，无需用户点名；同时保留股票、其他债券和商品分析。比特币独立呈现，黄金单列，稳定币按支付、储备和融资机制呈现，美债与汇率可在原资产分析中展开，同一证据不重复计算或强制重复成章。专题只展开核心问题相关的对象、经济体和渠道，不补成全景。

与[中国宏观](2026-10-24-china-macro-fundamentals-implementation.md)、[行业基本面](2026-11-07-industry-fundamentals-implementation.md)及个股工具独立开发、安装、取证、运行和验收；不自动读取、调用或等待其他 Skill、共享会话及既有报告。用户主动提供的报告仅作可选待核证据，核原来源、日期和范围，不继承结论。必要的中国或行业背景变量自行取证，不扩展为另一套完整研究。

排除行业供需竞争细节、公司经营财报、治理、法律尽调、企业资本配置、个股估值、单券契约与偿付顺位、发行人信用尽调、具体期货交割／展期、基金穿透、交易合约或持仓收益计算。代表性价格、总量信用和资产表现只用于宏观解释。数字资产以比特币和USDT／USDC等美元储备支持型稳定币代表样本为主，披露代表性；ETF、储备及赎回条款只是宏观渠道证据，不扩为产品选择、发行商经营尽调、代币估值、挖矿或策略。代币化黄金／存款仅在直接相关时辨别。

仅中国本土制度问题优先说明中国宏观入口更匹配；用户明确指定本入口时，在宏观边界内研究中国及其全球关系，不静默切换或转派。仅排除领域的请求说明边界，不以宏观报告冒充完成。

## 4. 输入与七步研究流程

| 输入 | 默认与处理 |
| --- | --- |
| 问题与方式 | 宽泛“分析全球宏观”按全景；明确冲击、政策、比较或跨境问题按专题，保留全部核心问题 |
| 经济体 | 用户指定优先；未指定按冲击发生地、生产、需求、贸易、融资货币、政策和反馈选择，并解释纳入及未展开理由 |
| 信息截止 | 未指定时固定研究开始的可知信息截止 `as_of`，记录时区；历史日内先后会改变结论而截止时刻不明时先澄清 |
| 时间尺度 | 按问题选择短、中或长期并披露；期限、币种、货币对等有两种会改变判断的合理解释时澄清，明确部分继续 |
| 材料及输出 | 资料不是必需用户输入，用户主动提供的材料按相关性核对；指定输出目录优先，否则使用独立研究目录 |

一般来源缺失不是输入歧义，应自行定位或准确报告缺口，不反复索取可公开取得的资料，也不以覆盖所有输入篇目为目标。

1. **确认问题：** 固定全景／专题、截止、尺度与边界，不删除缺证核心问题来缩小完成标准。
2. **选择经济体：** 依关联确定范围，全景检视共同驱动与地区差异，专题保持主线。
3. **建立取证路径：** 将命题对应到指标、原发布方、具体表／系列／政策和方法，明确定义、观察末期、窗口及窗口外比较基数；行情先明确回答水平、区间变化、趋势还是事件反应。
4. **取得并核对：** 实读相关正文、表、工作簿、附件和附注；先提取重要当期事实及反向分项，完成兼容计算并采用，再处理历史与基数缺口。发布稿只有近期值时沿实际链接和历史表定位，不停在目录。
5. **形成条件判断：** 区分事实、计算、假设、解释及实绩／估计／预测；区分传导、共同驱动、统计关系和反馈，避免同一冲击重复归因、同笔资金重复加总；无事前材料不补造预期差。
6. **核地区与资产反馈：** 应用本地制度与融资结构，按全景／专题落实四类资产和五项观察，采用规模证据及反证，不强制同方向或统一评分。
7. **交付与自检：** 从实际判断回查原文、表、计算、图片、定义和缺口，确认核心问题状态；完成两份完整内容及适用图片，未回答问题不能称研究成功。

## 5. 宏观观察、地区机制与统计覆盖

| 观察面 | 实际取证与判断要求 |
| --- | --- |
| 增长、就业与需求 | 核实际／名义GDP、消费投资、就业与工时、实际收入、景气和总量订单。需求为主要判断时核GDP后相关消费、就业／工时、收入及必要储蓄／融资的支持与反向变化；保留样本、部门和发布滞后，不由总量推全部家庭状况 |
| 通胀、相对政策与曲线 | 核总体／核心物价、工资、分项、预期及政策原文；分需求、供给、基数和修订。调查、盈亏平衡通胀、市场实际收益率及政策目标不同；降息不保证长端下降 |
| 流动性、美元融资与信用 | 核央行资产负债、准备金、财政存款、回购、美元负债、融资基差、贷款标准与需求、杠杆及偿债。扩表不是入市资金，总借款不是套利仓位，宽货币不必然宽信用 |
| 财政与主权融资 | 核宣布与执行、收支及用途、付息与分母、期限净供给／到期、拍卖和储备。发债、拨付、实支、偿债及清欠不重复计刺激；区分本外币约束，按第9节命题完成必要读取 |
| 贸易与外部头寸 | 核贸易量价、经常账户、国际投资头寸、证券及银行流、外债与储备；存量、估值与净交易不同，贸易顺差可被资本流出抵消，持仓市值变化不是净流入 |
| 供给、政策与长期结构 | 核能源食品代表价格、进口成本、供应链、正式政策范围／实施时点、人口、劳动参与、生产率与资本形成；成因不足保留情景，不由投入热度或标题推生产率及动机 |
| 预期差与金融稳定 | 对照事前材料、初值、修订、融资压力、市场反应及工具使用；价格下跌不独立证明系统危机、资金撤离或出售原因 |

统计覆盖贯穿原始指标、简称、摘要、正文、资产影响与跟踪信号。所有制、机构部门和融资工具不能互代；社融人民币贷款不能直接改称居民贷款、民企贷款或未经定义的私人信用。只有总量时只解释实体经济人民币贷款等实际覆盖；要保留主体判断，须有部门数据或明确代理口径、采用依据及局限。来源明确使用private sector等概念时按其原定义解释，不另造分类，也不只在附录加免责声明而保留越界判断。

| 地区 | 必须辨别的机制 |
| --- | --- |
| 美国 | 美元国际融资、财政发债／国库现金／Fed流动性共同作用；银行和资本市场融资不同，固定利率按揭使存量与新增借款重定价时间不同 |
| 欧元区 | 统一货币政策、成员分立财政；主权利差、银行持债、融资及信贷反馈可能分化，同一政策不等于各国同等宽松 |
| 日本 | 国债供给、央行操作和债市流动性共同解释曲线；工资物价、实际收入、进口成本和日元融资相联系，不由日元或总借款单独推去杠杆规模 |
| 中国 | 自行核内需与进口、出口量价、商品、人民币及资金流，连接“中国内部变化 → 外溢渠道 → 全球影响”；不等待中国宏观报告 |
| 英国及其他经济体 | 按财政金融结构、按揭重定价、外币债务、资源进出口身份、汇率制度和政策空间判断，不照搬其他经济体 |

中国城投及地方债务只在有可定位显著全球外溢证据时展开，标明渠道和受影响判断。城投债、平台全部融资、地方政府债和隐性债务不能直接相加、互代或推定政府全偿；余额、发行、净融资、到期、置换、展期、降息和清欠分别判断，覆盖不全不制造精确全量，不转为单券尽调。

## 6. 资产、五项观察与双向传导

股票分总量盈利预期、折现率与风险溢价；需求走弱压盈利与降息降低折现率可能抵消。债券分名义／实际曲线、期限溢价、信用与供给，不能由无风险利率下降推全部信用宽松。商品分需求、美元、通胀和宏观供给，品种供需细节不扩围。外汇核两侧增长、政策、外部融资与制度，远期点不当即期预测。比较固定时点、币种、尺度与定义，官方参考、拟合曲线、指数和成交价分别标注；不计算具体工具可实现回报，不设固定股债或股币相关关系。

| 对象 | 取证、采用与必要分辨 |
| --- | --- |
| 比特币 | 取得可比场所／基准、币种、时区和时点的价格，联系实际利率、美元及风险偏好。资金命题另核ETF份额／申赎或可复算交易，区分规模估值与交易、拆分和份额类别；市值或资产规模不当净流入。杠杆／清算保留场所覆盖；向信用、消费等反馈须有机构、抵押或财富敞口，不预设避险属性 |
| 美元储备支持型稳定币 | 分持有人、发行方和托管主体，核流通、发行赎回、储备分类／期限、现金和赎回资格。直接短债、基金间接持有和逆回购不重复加总。发行可能是已有美元资产重配，资金来源未知不能算新增美元或全市场净新增美债需求；链上额不代真实支付或资本流，用途／当地证据支持货币替代。区分发行方披露、鉴证与财报审计，按原文核保证程度、对象及覆盖期 |
| 黄金 | 取得同期间市场价、美元和市场实际利率，按命题核官方储备数量／交易、投资持仓／流量或现金压力。储备市值拆价格、数量和调整；数量变化须核说明再判断交易，金额除数量不是独立市场价，缺成交价不精算购金花费。增配黄金不自动等于减美债；同涨、现金紧张卖金等反向条件分别解释，不固化操控、美元衰退或单项利率方向 |
| 美债 | 同时解释全球定价基准、储备和回购抵押角色。曲线联系政策、通胀／期限风险、期限净供给、拍卖、持有人交易及对冲；短债需求不外推长端承接。收益率不代存量付息成本，持仓变化不代交易；抵押价值变化、收益率上升不独立证明保证金出售或融资危机 |
| 汇率 | 固定货币对、方向和可比时点；广义美元另核指数篮子及名义／实际。联系两侧政策、贸易／金融流、外币债务、对冲成本、制度及滞后，追踪进口购买力、偿债、贸易和政策空间。单一货币对不代广义美元，借款不还原套息仓位，干预及利差不保证方向 |

主要反馈核受影响部门、期限、相关市场占比、敞口或交易规模，大名义数不直接等于重要宏观驱动。缺分母、资金来源或交易只限制强度及对应命题，不把未知写成零，也不机械要求每篇取得表内全部资料。

## 9. 市场定价、美元融资与主权融资增强

### 9.1 P1：预期、实际与定价

政策路径固定参考利率、合约／目标月份或会议、观察日和报价／结算定义，同一目标跨观察日比较。自行换算记录参考期、已实现天数与假设；联邦基金期货月均EFFR隐含率不直接叫会议加息概率，SOFR路径不等同政策目标区间，转载舍入隐含率不能倒造精确结算价。

数据预期差核事件前已公开预测／调查、对应首次公布值及同定义市场观察；调查完成不代首次公开，总体／核心、同比／环比、季调和单位须一致，初值与修订单列，单机构预测不叫市场共识。实际减预期及事件前后市场变化各按正确单位，价格共同变化不证明全部由该事件造成。

宽基定价核指数价格／估值、总量盈利预期和兼容前版，固定覆盖、完整盈利目标期及版本，分静态／TTM／前瞻PE和滚动NTM；窗口滚动或成分变化不当固定年度盈利修订。价格上涨不证明盈利上修，盈利收益率减国债收益率不直接叫已测股权风险溢价；预期和价格共同约束“已计价”，单指标不判高估或必然反转，不增公允价值或精确概率模型。

### 9.2 P2：融资价格、信用溢价与资金行为

JPY/USD三个月基差核两侧参考利率、加点侧、符号、报价性质／时区、期限与起息规则和版本，解释对借入美元相对成本的含义；不同报价不能仅凭正负比较。普通远期点、一年基差、FX swap premium或推算成本均不冒充该三个月基差。

IG／HY的OAS核币种、评级、指数覆盖、基准和期权调整方法，变化用BP，百分数换BP保留换算，已是BP不再乘100。总收益率、OAS、纯违约概率与贷款标准不同；IG收窄不代表全部信用宽松，HY走扩不等于系统危机。

两类指标采用共同可比窗口，保留各自末期及节假日；结合SOFR、准备金和适用工具区分政策利率、境外融资溢价与信用分化。SOFR平稳不证明境外无压力，滞后BIS／TIC存量不代当前价格；资金撤离、强卖和全球去杠杆另需交易／敞口，缺证仅限制该命题，不舍弃已核价格或反证。

### 9.3 P3：美国供给与欧洲分化

主要主权融资风险先把命题对应到证据：赤字／净融资需求核收支和赤字；付息负担核同政府范围、同期间利息与收入或适用分母；期限供给核净发行、到期或已公布安排；承接或成员分化核自身可比拍卖、主权利差及融资条件。有公开线索和工具时须实际定向定位／读取，不能只取收支总额即将其余未尝试字段当一般缺口。高债务、高赤字或一次弱拍卖不独立证明危机，一次强拍卖也不消除持续风险，不要求每国全取。

美国市场化国债按美元面值、工具、原始期限、实际结算期计算发行减到期偿还及必要调整，至少区分国库券与名义固定利率中长期债；TIPS、FRN、回购注销及本金调整有涉及时单列，子集不叫全期限。余额变化只核对，不替代净发行；面值净供给不等于久期供给，私人吸收另核SOMA等调整，缺证只称发行人供给。续发按CUSIP核各次发行与调整，获配空值不填零，不能漏整笔到期或重复累计续发。

适用历史保持完整窗口，未来一季另列正式公布发行／到期与未定部分；计划、实际和未公布分开，未知发行不填零，回购计划上限不扣作已执行。未来未公布发行、SOMA及范围外期限不追加为必取，不冒称完整未来净供给。正式拍卖获配与可比结果只支持相应初级承接；尾差需同次拍卖前报价，投标类别不直接解释为国籍或最终持有人，旧拍卖不当新时点承接。

欧洲成员样本为法国、意大利，德国作基准；按同币种EUR、同类约10年、共同观察日／时点和报价性质取得收益率，说明基准及必要切券，以成员减德国计算BP利差。本国收益率上升与相对利差扩大不同，不把德国自身变化归为成员风险恶化。财政优先Eurostat同版一般政府执行与债务，适用季度窗口和累计完全同期保持；中央现金或预算不拼成一般政府。各国各两次自身可比名义固定利率拍卖／续发核制度、原始／剩余期限、投标／获配及收益率，不跨国用投标倍数排名。财政、利差和拍卖反向事实实际限制结论，主权—银行损失已发生另需持债、融资或信贷证据，不新增银行全量敞口门槛。
