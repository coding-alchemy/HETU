## 1. 本期用户结果与完成含义

用户能够从网页运行已接入的透明规则策略，追查信号如何变成目标权重、订单、成交、持仓、现金与净值，并比较毛收益、成本后收益、基准和风险。策略方向同步用独立 Notebook/脚本完成至少一项真实免费数据上的非基准候选验证，不等待工作台全部建成。

首批低波动多头优先；E/P 价值仅在免费历史财务时点合格后进入。结果应回答：规则是否实现正确，样本外结果能否支持预设经济目标，下一步继续、补证、调整还是停止。

本期分别报告软件行为、实际验证与经济价值。完整检验得出未通过，可以完成对应研究工作；没有达到经济目标的候选时，不能宣称已找到有收益的策略。只有链接、基准，或全部候选因数据缺口未做评价，不满足真实验证目标。

## 2. 范围、依赖与排除条件

| 类别 | 本期边界 |
| --- | --- |
| 必须交付 | 一个经验证的正式模拟语义、组合研究所需免费历史数据资格、基本网页回测入口、至少一项非基准完整研究资产 |
| 保留的一期结果 | 行业/主题两榜、三年背景/半年重点、证据与重复关系；不把最多五十个席位直接变成等权组合 |
| 条件研究 | E/P、行业轮动等只在各自财务/历史成员域合格后正式评价；缺口只影响依赖该域的研究 |
| 后续打磨 | 全流程工作台和代表策略平台执行复用由三期完成；一期已有的持久化、失败显示和防重复提交继续有效 |
| 不包含 | 自动实盘、真实账户、采购数据、多市场实现、强制 ML、影子研究等待期、全候选同时实施 |

输入沿用一期形成的来源准入、原始输入、标准数据、数据资格说明、冻结研究定义及任务记录。组合研究新增历史制度、公司行动和适用财务域的证明；一期“可用于排名”不能自动升级成“可用于正式组合回测”。

独立来源核查、规则卡和协议工作可以先行；具体数值验证只依赖实际所需的数据、规则与工具，不以一期网页验收为前提。二期不能用无关量价策略通过替代未满足的主题历史研究。

首批范围已随二期计划批准为普通现金账户、只做多、不加杠杆；沪深普通股票含创业板／科创板，北交所／ETF 保留缺口。此为拟实施范围，来源、引擎和历史数据资格仍须实际核验，不能把范围批准解释为能力通过。

## 3. 历史数据与引擎准入

### 3.1 按用途证明数据资格

数据资格绑定“股票池、区间、用途与所需字段”，保留实际来源和原始记录。日线仍负责调仓之间的估值、状态和公司行动；周/月策略不能只取周/月价格。

| 数据域 | 必须证明的行为 | 缺口处理 |
| --- | --- | --- |
| 行情、日历与身份 | 原始成交价与连续特征价分工，量额单位明确，停牌/无交易/采集失败分开 | 不能靠前值填充制造低波动或可成交性 |
| 历史股票池 | 上市、退市、调入/调出及其可得时间可追查 | 当前存续对象不回填过去；有限池结果不宣称全 A 股有效 |
| 公司行动与交易状态 | 分红、股数变化、停复牌、风险警示、限制价格和申报规则覆盖实际区间 | 关键域不足不形成合格组合结论，保留其他合格研究 |
| 财务历史 | 原始披露、公告可得时间、修订版本、盈利与市值口径可重建 | 最新财报加公告日期不自动算 PIT；不合格只限制 E/P 等依赖项 |
| 基准 | 定义、成分用途及价格/总收益口径明确 | 不匹配口径不混排；指数收益不冒充可交易账户收益 |

沿用当前免费模式：接口、数据包、缓存和本地导入均核验来源权限与费用，额度耗尽不收费回退。来源声明不是实际可用证明；免费数据缺口不触发采购、静默换源或静默缩小对象/区间。

### 3.2 一个正式引擎及已证支持边界

优先评估 RQAlpha 的使用许可、免费数据导入和目标 A 股行为。个人使用不自动证明符合许可；日线默认撮合配置也不自动证明次日成交语义。通过具体用途许可核验与行为验证后，才能确认采用。

许可或核心行为不满足时，按总设计评估 LEAN 的最小适配范围及代价；新增未批准成本、能力或范围须提交取舍，不自动展开第二套系统。未取得合格路线时保留阻塞项，不能自研完整引擎替代或将演示曲线标成通过。其他工具可以辅助定位具体差异，不以多个框架收益相近作为正确性证明。

## 4. 信号、订单与账户语义

策略定义分清信号、组合决策、执行和评价四层，独立保存原值及轨迹。最低规则包括股票池/过滤、信号公式、权重与上限、调仓日历、时点、退出、未成交、现金、资本、基准、成本及终止处理。

1. 收盘数据完整可得后生成信号，在下一交易日允许时点模拟成交；若用次日开盘价，明确它是日线近似，不利用次日全天量提前确定开盘决策。
2. 停牌、零成交、一字涨停买入和跌停卖出按预设规则拒绝或延迟；日线触及限制价不证明排队成功。事后成交量上限只能作为披露的模拟假设，不能反馈给当时决策。
3. T+1 使用实际可卖持仓；申报数量、价格限制、税费及生效变更按证券类型与历史日期处理，不将当前统一规则回填全部年份。
4. 未成交保留实际持仓与现金，并记录原因；订单延续、撤销或下一调仓日重算在协议中预先确定，不无条件达成目标权重。
5. 公司行动更新股数、应收和现金，连续价用于特征，原始价用于成交；禁止总收益价格与现金分红重复计收益。停牌估值不等于可以成交，退市不按最后价格无条件变现。

核验从可独立计算的小型事件账本开始：给定输入直接算订单、成交、现金、持仓与净值，再核对引擎输出。验证应能发现忽略成本或交易约束但仍输出文件的实现；合成账本只证明机制，不证明市场收益。

## 5. 从成熟方法进入真实验证

| 顺序 | 本期处理 | 原方法与本地适配边界 |
| --- | --- | --- |
| 第一优先：低波动多头 | 以原论文多头分组为起点，完成机制及真实经济评价 | 保留 36 个月月收益估波动、月调仓及市值权重等原规则；原股票池、美元口径无法取得时逐项登记差异，不能继承杠杆多空因子收益 |
| 第二优先：E/P 价值 | 免费财务时点合格后检验单一估值信号 | 对照原盈利定义、最小市值 30% 排除等样本规则、排序及权重；不静默换用当前 PE、TTM 或质量价值组合 |
| 储备：红利低波 | 保留公开完整编制方法与数据缺口 | 所引用 H30269 版本年度调样，不擅自改成月频并沿用原结论；公开规则不等于收益有效 |
| 二期扩展 | 定向扩大检索，按增量证据、数据资格与验证成本选择 | 周频多头反转、中期动量、行业轮动及质量/价值组合分别登记；改写版独立验证，参数近邻不冒充多种策略 |

低波动所需三年预热位于实际检验区间之前，不能将只有三年的行情同时计作预热与三年回测；这不扩大一期三年/半年展示窗口。原样本不可得时，结论标为本地适配，不承诺复现论文数字。

不要求一期五类全测，也不强制本期验证全部储备。E/P 数据不合格时保留缺口，不自动用周频反转替补成“成熟已验证策略”。至少一项真实免费非基准完整验证的底线不变；所有候选都缺关键数据时，本期该目标未完成。

## 6. 冻结评价协议与经济决定

首次查看最终检验结果前，研究协议须给出可执行的股票池、区间、预热、参数族、资本、基准、成交与成本、时间划分、稳健性情景、试验预算，以及经济目标和容忍范围。本设计不凭空指定年化收益、Sharpe 或胜率门槛；后续研究协议须依据策略目标具体化，不能留空执行后补写。

采用时间顺序的开发/验证/最终检验或滚动样本外；预处理与训练只用过去信息，跨期标签按跨度隔离。已反复查看的数据重新切分不会成为新独立证据；规则调整另存实验并保留选择记录。

评价同时包含绝对成本后收益、可比基准超额、回撤/波动、换手、行业/规模等暴露、成交率、容量情景，以及不同区间/市场状态、参数邻域和更高成本的结果。适用的因子评价保留覆盖、IC/RankIC、分组、衰减、漂移、置信区间与有效样本量，考虑重叠收益和多次试验的不确定性；不适用项说明原因，不把 IC 好当盈利。因子合并按 horizon 分开、保留原值与贡献，只使用当时已经成熟的评价，LLM 不决定正式权重。

研究进度、结论和平台接入分别保存；执行失败、有效检验未通过、证据不足也分别记录。低波动风险改善通过不能自动写成收益目标达到。每次完整评价明确经济目标是否达到，以及继续、补证、调整或停止的依据；允许没有策略通过，不通过无限追加试验找赢家。

## 7. 基本网页入口与交给三期的产物

网页复用总设计的共享研究内核和任务运行：选择已接入策略与股票池，配置区间、参数、资本、基准和成本，查看启动资格，再提交回测。刷新后任务可找回且不重复运行；失败/中断/取消状态如实显示，不以三期打磨为由延期这些已有底线。

结果先展示结论及限制，再逐层查看净值、成本、持仓、成交、未成交和原始信号；可导出同一份结构化产物。不同样本、基准或评价口径显示差异，不混排；Notebook 使用相同数值语义。关闭 LLM 后冻结研究仍能执行。

交给三期的是总设计第 14 节的语义合同：策略卡及原规则/本地差异、代码或 Notebook 与环境、数据引用与时点/许可/缺口、冻结协议、全部试验、信号及完整账户轨迹、经济结论与后续决定。保留市场身份，不将未支持市场解释为已经适配。

真实数据、执行样本及结果保存在独立研究产物区域，不把市场数据作为代码样例提交。三期先读取这些证据，不重算历史；至少一项代表策略的实际平台运行和适配差异由三期另行证明，二期导出文件不冒充该目标完成。

## 8. 期内交付单元与验收依据

下列是后续执行计划的划分依据，非实施步骤。单元可独立审阅；二期整体须同时取得机制、真实研究与基本网页证据。

| 交付单元 | 用户可观察证据 | 对应要求与验收 |
| --- | --- | --- |
| D2-1：历史数据及正式引擎资格 | 特定股票池/区间可做什么、缺什么；采用路线的许可及具体制度行为可追查 | R2/R3/R6/R16/R17；V2/V9/V11/V12 |
| D2-2：订单与账户闭环 | 独立账本与模拟轨迹吻合，时点、成本、交易限制实际改变结果 | R1/R4–R7；V3/V4/V7 |
| D2-3：成熟策略独立验证 | 至少一项真实非基准完整产物，全部试验、经济目标判定和投入决定可复查 | R11–R14/R19；V5/V14 |
| D2-4：基本网页回测及交接 | 不改源码完成支持范围内的回测和导出，产物供三期读取，旧结果保持有效 | R7–R10/R15；V1/V6（仅交接部分）/V8 |

| 关键场景 | 正向证据与反例处理 |
| --- | --- |
| PIT 与股票池 | 使用历史可知值；晚公告、后续修订和当前新增成员不能改变更早信号。财务失败限制 E/P，合格低波动仍可运行 |
| 信号及历史制度 | 收盘信号延后成交；T+1、停牌、限制价和制度生效变更改变实际成交，不只显示提示 |
| 账户与公司行动 | 手算现金/持仓/净值一致；成本提高或可成交量下降引起相应变化，分红重复计收益必须被检出 |
| 原规则与预热 | 原法及适配差异可追查；改周频不沿用原策略验证标签，预热不足不伪造完整检验期 |
| 经济与失败 | 毛收益为正但净收益不达协议目标，判未达标并记录决定；执行失败不判策略无效，缺数据不伪装完成 V5 |
| 免费与任务 | 即使配置收费凭据，免费额度耗尽也无收费调用；刷新不重复执行，LLM 关闭仍可计算 |
| 历史结果与迁移 | 只读导出/导入不重算；日期、版本、路径或哈希改变不使旧结论失效，具体错误只定位直接受影响结果 |

行为验收必须运行待测能力，输入仅含事实，期望和评审答案留在验证侧；合成材料按[测试材料方法论](../docs/engineering/test-fixtures-methodology.md)复用并标明用途，不由生产实现反生成正确答案。真实免费研究证据与合成机制证据分别成立。

## 9. 停止、成本与最小重验

许可、数据资格或核心行为未满足时保留具体缺口，不扩大为其他阶段全部失败，也不以未证明能力验收。缩小股票池、区间或改写方法要明确影响并另存定义；若降低已批准目标，须由用户批准，不在执行时静默接受。

数据费用当前为零；后续计划分别列证券/区间/数值运行数、真实公司分析数、模型及人工成本。预计实际分析两家及以上公司时，在第一次分析启动前询问是否切换性价比模型；计划批准不豁免，不用“扫描/打分”改名绕过门禁，不自行切换模型。

数值验证同样优先复用有效结果。版本、日期、`as_of`、哈希或阶段变化不触发失效与重跑；只有具体语义影响证据支持的最小范围列待重验。整批或已通过结果重跑前，说明影响、范围、次数和成本，取得本次明确批准；批准前保留既有有效状态。
