## 1. 核心结果与研究顺序

第一项完整研究是**低波动多头**。用户应能回答：按每个月末当时可知的信息选出低波动股票，在相同资金、交易和成本条件下，组合能否比持有同池市值基准取得更好的净收益和风险表现？用户可以从策略原始来源查到本地规则、实际输入、实现、全部试验和继续、补证、调整或停止的依据。

| 顺序 | 可审阅的交付物 | 用户据此作出的判断 |
| --- | --- | --- |
| 1. 低波动资格（§2） | 逐信号资格与缺口表，关联已有证据及八次冻结试验 | 哪些定义的输入已经合格，哪些应补来源证据或修复读取逻辑，哪些仍受阻 |
| 2. 独立研究（§3—4） | 可复做的策略包、账户基准、全部试验台账及样本外评价 | 至少一项真实非基准候选完成原协议下的评价，收益、风险和统计支持分别有结论 |
| 3. 交接与平台执行（§5） | 同一发布物的网页、ZIP 和 Notebook，以及用户选定代表从正式平台入口运行的账户轨迹 | 独立研究和平台运行各有直接证据，规则、输入及执行差异可以解释 |

《A股日线量化策略全景分析》v1.0（2026-11-18）提出了低换手多因子和 ETF 趋势／轮动两个试点。结合项目现有账户和数据，股票方向从低波动开始，后续按 §3 检验单因子及组合的新增贡献。ETF 路线单独立项。当前股票研究、真实产物交接及平台执行的完成条件见 §6。

本需求承接原四期的全部研究和真实产物交接，以及原五期的策略资产、执行适配和复用验收。沿用已交付的工作台、独立数据模块、日线库、任务治理和正式引擎。原一期、二期软件与三期修订范围的验收继续有效。三期档案的历史结论为 `limited`。现行日线库的初始化、首次追补和限定范围验收分别为 `accepted_with_exceptions`、`complete`、`passed_scoped`，含七日接受例外及独立历史全集限制。系统交接记录的原研究资格仍为 `blocked`、`can_start_formal_research=false`，已用预算 **0/8**。详见[系统交接 §1.1](2026-11-07-quant-research-platform-implementation.md#11-当前正式库与目标)。

## 2. 研究输入与不能替代的前置条件（S1）

首项交付用已发布快照和既有资格记录编制。按冻结窗口内每次调仓所用的月末信号（含首次交易前一月末），列出当时历史池的名单依据与对象数、按事前规则排除的上市预热对象、已核验对象数及未知范围。每项结论关联证券（含跨码身份）、期间、字段、证据出处和受影响的试验。选股字段核验在信号时是否已公开，持仓期间的公司行动和退出核验在实际发生时如何入账。原池分母未知时如实标注，合格子集不能替代原池。30／36／42 月预热分别判断。

**验收方式。** 任选一个受影响月末，读者能从试验追到对象、字段和快照或来源记录。缺事实或许可时，列出最小补证范围及目前受阻的试验。证据齐备而程序未正确使用时，定位读取或账户逻辑。证据与软件均满足时，标记该项合格。例如，历史收盘价和重建股本可以算出市值，采用前还须证明该股本在信号时已经公开。后来取得的资料可用于证明当时的公开时点。最后按八个试验定义汇总各自的输入资格、尚未完成的前序试验及可采取的下一步。运行授权见 §6。

| 输入 | 必须满足的要求 |
| --- | --- |
| 原股票池 | 沪深普通股历史池，含主板、创业板、科创板及期间退市、调出对象，使用逐信号当时可知身份。按事前规则逐日登记合法上市预热排除。不得用当期存续名单、一期 Top 50 或少量可得股票替代，不得依据未来退市或后续事件事前排除。 |
| 原研究窗口 | 2019-11-01 至 2026-10-13；30／36／42 月预热分别核对，最早数据需求至 2016-04。数据库扩展历史或当前日期变化不自动改变冻结窗口。 |
| 用途资格 | 逐对象、逐期间、逐信号核验价格、真实完整月末和实际预热、时点可知的历史身份及股本／市值、完整公司行动、适用状态和交易规则。依赖受阻时，回测准备、策略信号和正式引擎均不得放行，缺口及影响可查。 |
| 数据公共接口 | 复用独立数据模块、合法已发布快照、来源／许可／覆盖／修订记录。完整行情档案与策略用途资格分开；最新市值、最新财务或完整日线均不能替代历史时点证据。 |
| 来源边界 | 后续仅 Tushare 和公开信息，Q1 已取消，不恢复其他商业来源路线。既有合法资产按许可复用，免费与获准付费来源如实标记。来源许可不自动证明历史时点或事件完整。 |
| 策略专用缺口 | 历史全集／特殊标识及价量／状态冲突中直接影响日线完整的部分，由系统侧按已批准的日线库范围维护；策略仍独立核验历史身份的逐信号可知性。历史股本／市值公开修订、完整特殊行动及退出账户事实为相应研究前置，补证范围尚未获授权，不因完整日线库建成而视为解决。原 331 个对象日成交额的档案主源选择已完成，原值及差异保留，其他用途仍需各自依据，见[系统交接 §3.2](2026-11-07-quant-research-platform-implementation.md#32-原价主源状态审计与七日接受例外)；订阅到期后未知权利按实际依赖保留限制，不以本需求恢复已取消采购或未授权补采。 |

历史财务公告及修订时点不足限制 E/P 等依赖策略；行业历史未知按已证范围报告，不阻断本身合格且不依赖它们的纯量价任务。无法证明的用途继续受阻，不自动缩池、缩窗、改权重、替换策略或降低完整性要求凑成可运行。

数据阻塞不等于所有研究工作停下。规则收集与核验、代码准备、机制和合成边界验证可在其自身审批与授权满足后推进，分别记录软件就绪、研究资格和真实评价状态；合成结果不得写成真实策略证据。

## 3. 策略资产与独立可复做证据（S2）

### 3.1 研究顺序、对照与进入条件

[候选登记](../quant/research/phase2-candidates.md)保留七个股票方向。低波动及其同池市值基准已接入共同信号计算，也是原八次试验采用的两个账户策略。选择后续候选时，须说明它能回答哪个新问题、对照账户是什么、还缺哪些事实、需要多少额外运行。

| 候选及当前基础 | 独立研究问题与比较对象 | 进入条件 |
| --- | --- | --- |
| 低波动多头，已登记月频信号 | 同池、同资本、同成本下，与可交易的 `universe_vw` 比较，分别评价收益、风险和统计支持 | §2 的资格满足后，按 §4 冻结定义执行 |
| E/P 价值，已有[独立排序脚本](../quant/research/ep_value.py) | 先验证 E/P（扣非盈利／总市值）单因子多头与同池基准的差异。现有排序尚缺持仓及账户结果 | 核验信号日已公开的扣非盈利、修订版本及可知总市值，冻结多头组合规则并另报范围。当前 PE／TTM 不能代替历史版本 |
| 质量／价值组合，低换手多因子的后续方向 | 一次只检验一个事前选定的增量，例如给 E/P 增加质量或低波动条件。固定股票池、调仓频率、执行和成本，对比基准、单因子与组合，区分选股贡献、行业／规模暴露和换手变化 | 先用合格历史数据完成单因子相对同池基准的独立账户评价，保留正、负结论。组合所需时点数据齐备后，预先确定指标、权重、调仓和评价口径，单列运行预算 |
| 红利低波，公开规则储备 | 按 H30269 v1.1 的分红筛选、股息率权重和年度调样复现，核对与低波动的持仓和风险重叠。多处规则共同变化时，不能将收益差单独归给分红 | 当时的分红、筛选资格和调样证据齐全。改月频须另列变体，重叠结果不重复计为独立证据 |
| 中期截面动量、行业轮动，已登记两个方向 | 在可比口径下区分行业间强弱和行业内个股强弱。现有行业／主题两榜提供评分及读取经验，单期榜单不能证明轮动收益 | 个股规则预先确定形成期、持有期和换仓方式。行业归因或轮动另需历史分类、当时成员及可交易组合，禁止用现行主题成员回填 |
| 周频多头反转，已登记改写设想 | 比较反转信号与实际成交后的多头净收益，重点解释高换手、跳空、无法退出及尾部亏损 | 冻结原文每日轮换、多空口径到本地周频多头的改写，具备相应状态和成本证据 |

**单独立项的条件。** 若股票历史时点证据长期受阻，且用户将目标转向验证较少依赖个股财务的可交易账户，可单独评估宽基 ETF 趋势／轮动。立项时核定历史可交易基金池（含上市、清盘）、基金分红、流动性、交易费用、产品规则及平台品种适配。以买入持有、同池等权再平衡及单一趋势规则为对照，区分绝对趋势降仓与相对强弱选基的贡献。ETF 的样本、预算与验收另定，不能抵算当前沪深普通股独立研究或平台交付。

低波选股回答持有哪些股票。组合波动率目标回答持有多少风险，后续若研究，应比较同一策略开关该仓位规则的增量。指数增强依赖历史指数成分和权重，事件驱动依赖首次公告时间及版本。这些是另选研究方向时的前置条件，不增加本需求的必跑项目。

### 3.2 每项策略的可复做证据

可先登记候选的来源、规则、适用范围、缺口和下一步。作者、许可、公式或收益未知时如实标记。规则不全的候选保留该状态，研究者补充的规则单列。完整验证资产须包含：

1. 来源、作者、原始链接、公开时间、代码许可，以及原文市场、样本和频率。
2. 经济或行为假设、预测目标和可证伪条件，分别记录论文结论与本地判断。
3. 股票池、过滤、信号公式或模型、参数族、信号时间、调仓、权重、退出和现金处理。
4. 数据域、历史可得性、清洗／缺失规则、基准、交易制度、成本和容量假设。
5. 实际代码或 Notebook、运行环境、数据取得和运行步骤，包括能够复做的人工操作。
6. 全部已执行试验及失败原因、样本内外划分、统计与经济评价、结论和适用边界。
7. 平台输入输出、所用引擎、依赖、规则／实现／执行差异及适配缺口。

相对原方法的股票池、币种、总收益口径、调仓、窗口、权重及方向变化须逐项记录。改写后的策略另行验证，不继承原文收益或验证标签。

## 4. 冻结研究、账户及评价（S3）

### 4.1 规则与执行

| 项目 | 冻结要求 |
| --- | --- |
| 低波动主规则 | 37 个真实完整月末形成 36 个完整月总收益；样本波动 `ddof=1`。合格池 `N≥10` 才取最低十分位 `max(1, floor(N/10))`，同值按代码稳定截取，使用信号时点可知市值加权。停牌或缺采不得前填凑预热。 |
| 信号与成交 | 月末收盘形成信号，首次交易须有前一月末信号；按冻结时钟于次交易日开盘近似成交。以此前 20 日成交量中位数的 1% 限量。无法成交保留现金或原持仓，日终撤销未成交订单，下次调仓重算。期末持仓估值，披露日线成交假设。 |
| 资本与费用 | 100 万 CNY，普通现金多头、不加杠杆，现金利率 0，投资者税务口径 `cn_individual_research`。佣金 0.0003、最低 5 元、滑点 0.0005，沿用 `phase2-trading-rules` 的历史税费、价格步长和申报数量规则。 |
| 制度与账务 | 次一可执行时点、T+1、停牌、涨跌停、容量、行动、税及退出依实际历史证据处理。已证除权参考价用于申报／撮合，账户行情保留原价；未知参考拒单并登记限制。滑点计入成交价，不重复扣现金；毛净值只加回显式费用。税前除息再投资研究序列与原价成交、行动记账及成本后账户净值分开。 |
| 原软件接缝 | 跨码价格／预热接续、账户持仓接续和特殊退出撮合仍须按对象、日期及已证规则最小补齐。未证事件不得假定变现、删除持仓、用零收益填平或缩池绕过。软件修复不等于外部事实已经补齐。 |

### 4.2 时间隔离与八次预算

- 开发：2019-11-01 至 2021-12-31；验证：2022-01-01 至 2023-12-31；最终：2024-01-01 至 2026-10-13。预热与正式窗口分开，开发和验证为同次运行并延续持仓。
- 开发＋验证四次。先取得同池账户基准，再对照 36 月主规则与 30、42 月邻域。邻域分别核验预热，仅在开发／验证比较。
- 开发＋验证四个定义完成后进入最终四次。先取得最终账户基准，再评价 36 月主规则，随后分别运行两项压力对照。一项仅将佣金率、最低佣金和滑点加倍，法定税费仍按历史规则。另一项仅将成交量参与率从 1% 降至 0.25%。
- 沿用原定义和调度依赖，先有可比基准轨迹再评价。全部尝试、失败、受阻和复用均入原台账；失败和已执行后受阻按原规则占用预算，预算拒绝记录不计实际运行。八次上限不重置，不以新 study、分期或平台迁入绕过。
- 保留一期已看市场和榜单，以及最终区间实际查看记录。最终区间不能用于选择，不通过重新切分将已看数据变成独立证据。新增参数或语义变化另存定义，保留旧结果。
- 原 `mode=free` 冻结记录不覆写。获准付费来源另存实际执行定义和变化说明，逐项保留行为与 trial 继承关系，不把付费成果写成免费成果，不允许免费失败后收费回退。

### 4.3 统计、经济与后续判断

最终区间年化净收益必须严格大于零，且同区间候选净 CAGR 减同池、同资本、同交易与成本口径 `universe_vw` 账户基准净 CAGR 严格大于零，才能达到收益目标；两项容忍度均为零。风险目标单列：年化波动不超过基准的 90%，最大回撤不劣于基准。沪深 300 价格指数仅作背景。

使用同批产物对照信号入选、目标持仓、实际成交和净值，说明收益集中在哪些股票或市场阶段，费用和未成交如何影响账户表现。证据只能支持部分归因时标出限制。延迟成交、滚动窗口或增加成本档位均属于新增试验定义，另报预算和范围。

评价保留毛／净收益、匹配超额、波动／回撤、换手／费用、成交率及限制、容量、规模／行业暴露、子区间／市场状态、参数邻域和压力结果。低波动因子诊断使用 `-sigma` 和未来 1／3／6 个完整月总收益，分别保存覆盖、IC／RankIC、分组、衰减／漂移与有效样本数。标签成熟并按跨度隔离，诊断不得回流正式信号或权重。

净超额与风险改善给 95% 区间；采用月度连续块配对 bootstrap，块长 3 月、1,000 次、随机种子 20261017，披露标签重叠与多重试验。区间跨零不能宣称统计支持；不适用与证据不足分开。点估计、统计支持、研究结论、经济目标及后续投入决定分别记录。

至少一项非基准在合格真实数据上完成规则、代码、机制、历史样本外、成本和稳健性评价，才能满足独立研究核心结果。有效负结果或统计证据不足可完成研究，不能写成盈利达标；毛收益为正或风险改善不改变净收益未达标结论。有效未达标默认停止本轮追加，风险改善只作为有条件后续研究依据。只有链接、合成轨迹、基准，或全部候选因缺数据未获评价，都不算真实研究完成。

## 5. 真实交接与平台执行复用（S4—S6）

| 编号 | 用户可观察的结果 |
| --- | --- |
| S4 · 只读交接 | 原四期真实产物及全部 trial、失败、限制、规则差异、协议、代码／Notebook、数据／环境说明和原结论，经系统侧工具在正式网页可查、可比较、可导出；网页、结构化 ZIP 和 Notebook 读取同一已发布产物。读、导入、比较和导出均零额外信号／引擎／LLM 调用，不执行导入文件代码。 |
| S5 · 代表策略运行 | 用户选定至少一项代表，明确市场、股票池、期间、信号时点、频率、权重和执行边界，完成审核登记的本地适配，实际通过正式平台入口在合格免费输入上运行。信号、目标持仓、订单、成交／未成交、实际持仓、现金、净值与费用可追溯；与独立研究规则、输入和执行差异明确。原四期独立验证先行，沿用样本外、成本、稳健性和经济结论。 |
| S6 · 执行与复用语义 | “证据已导入”和“平台已适配可执行”分开；其余策略的缺字段及不支持项具体可查。使用系统侧配置与复制功能另存冻结定义，保留原定义、输入及结果；参数／成本等实质变化必须进入实际执行定义，并以实际运行轨迹证明生效。比较显示区间、样本、基准、成本、试验次数、可比性和不确定性，不混排不可比结果。 |

若用户选定低波动作为代表，可复用原规则和适用的研究证据，并按 S5 核对正式入口的实际轨迹。S5 不能由只读导入、合成案例、独立脚本或基准展示替代。已有同一平台入口、同一规则且完整的真实执行证据可复用；否则另报最小代表运行范围、次数及成本并取得实际运行授权，不为验收页面重复八次研究。复制的只读行为可用原产物检查，证明新定义实际生效的必要运行纳入已获批试验和成本范围，不另开隐性研究预算。

执行状态、研究进度、研究结论、经济状态、证据导入及执行适配分别展示。关闭 LLM 后冻结数值任务仍能计算，结构化证据仍可读取。策略收益来自确定性计算，外部实证不冒充本地结果。

保留 V12：无付费凭据时证明声明范围的真实免费闭环；免费任务即使配置收费凭据、额度耗尽或来源失败也无收费请求，拒绝付费文件伪装免费导入。系统侧负责通用准入和双模式边界，本需求负责真实代表策略的合格输入与执行证据。实际付费使用另按获准产品核验，标明来源和模式；模式切换只作用于明确的新任务，不改写旧结论、许可或资格。

## 6. 成本、有效证据与完成判断（S7）

本次文档修订的授权仅限需求。联网、采购、原件回放、真实运行及重跑均按各自的实际授权执行。正式运行前说明去重对象、期间、逐信号合格数、定义、复用结果、实际数据请求、数值运行、公司分析次数、数据费及人工复查。公司深研和 LLM 业务调用默认零。预计实际分析两家及以上公司，第一次分析前按 [AGENTS.md](../AGENTS.md) 询问是否切换性价比模型，除非当前任务已有明确豁免，不自行换模型。

旧结果保留原适用时点。日期、分期、路径、版本、哈希、环境、`as_of` 或来源身份变化本身不触发重跑。只有具体语义变化和定位证据才能界定待重验规则、字段、对象和日期；仅重验失败项及直接影响最小范围。整批或已通过结果重跑须另报影响、预计分析次数及成本并获本次明确授权。

S1—S7 的适用必需项均须有直接证据；独立研究和代表策略实际平台执行分别成立，才能完成本需求。某项缺少资格、适配或运行能力时，保留已完成单元和最小缺口，不将整个已有系统判失败，也不把局部完成写成整体完成。需求和设计分别获批后方可编制计划，计划获批后实施；真实操作仍按本次范围授权。
