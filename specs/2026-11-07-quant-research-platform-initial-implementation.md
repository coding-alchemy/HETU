## 2. 模块与执行链

| 模块 | 职责和边界 |
| --- | --- |
| [独立数据模块](../data/README.md) | `data/` 提供可单独安装的 `hetu_data`／`hetu-data`。管理来源、存储、授权、计量、实际覆盖、离线查询和维护任务。独立网页、CLI 与 Python／SQL 共用资产及规则，不依赖研究包或引擎。 |
| [研究模块](../quant/README.md) | `quant/` 保留研究侧兼容接口，消费相同快照、任务队列和额度账本。按对象、期间、时点和用途判定排名、策略研究和回测资格，冻结定义，发布可复查的结果。 |
| [本地回测引擎](../quant/engine/runner.py) | RQAlpha 6.4.1 运行在隔离环境，依赖由[引擎锁](../quant/engine/requirements.lock)记录。研究侧准备本地 bundle、信号、执行与成本规则；引擎产出订单、成交、持仓、现金和净值。普通现金多头、不加杠杆，正式模拟范围为沪深普通股。档案包含北交所数据，模拟市场范围保持原批准边界。 |

取数链为**批准计划 → 持久任务 → worker → 来源适配、原件与标准化 → 发布快照**。本地查询、筛选和导出消费明确的快照或已登记资产，零外部请求。覆盖与研究资格分别核验。一期排名在固定范围、时点和资格下计算四维指标并发布两榜。回测链为**冻结定义 → 用途资格 → 共同信号 → 引擎 → 发布**。查看、比较与导出读取适用的已发布产物。冻结的数值任务可独立于 LLM 运行，LLM 可辅助规则、代码和解释。

## 3. 有效的产品与研究合同

### 3.1 数据、许可和维护

- `DataRequest`、`SnapshotRef`、用途资格报告分别表达请求、锁定资产和当前可用范围。原始响应保留原形，标准表与原件分开。事实生效、历史公开及取得时间分别记录，保存来源、修订、实际覆盖与未知。操作前核验模式、产品、对象、期间和授权。免费模式无收费回退，已有凭据、缓存或文件不会扩大许可。
- 标准表为 Parquet，DuckDB 查询，SQLite 保存定义和任务。新 Tushare 日线支持按年存储，旧代码／月份及导入分区仍可读。以本机已证授权读取、导入和保存；备份或订阅到期后的使用需各自依据。样本备份恢复已验证，长期保留、全库备份和灾备不据此成立。详见[数据字典](../quant/DATA.md)。
- 查询、实际行与状态覆盖分开。成功空保留原查询证据，失败或传输不确定不登记覆盖。日历、生命周期和明确全天停牌解释适用缺行。正成交证据与无交易证据冲突时保留冲突。复权因子不替代行动证据，行情档案不应用原策略的股本或预热门槛。跨来源价量差异保留原值，等值归一需有准确依据。
- 更新按已登记资产和实证缺口处理。15 自然日恢复含周末和期间退出对象，日线按交易日、事件按自然日，保留修订回看与不可恢复版本。已证成功空可从校验后的原件恢复，截面范围扩大可在当前许可内从匹配原件重新标准化。原快照、额度账本和证据继续保留。
- 档案目标为 2006-10-13 至 2026-10-13 的沪深北普通股、含期间退市，保存原价 OHLC、股数、人民币成交额及必要复权辅助。实际已登记覆盖仍 `limited`。分钟 1／3／10／20 年仅保留容量评估，未启用采购或采集。

### 3.2 排名、证据与交易规则

- 两榜独立，按三自然年背景、近六自然月重点和共同 `cutoff`／上海时区 `as_of` 执行，月锚点取当日或以前最近市场交易日。不能为单股缺行情静默移动日期。必需半年、三月／半年锚点与 60 个日收益窗口完整，必要窗口未知比例为 0。ST／退市排除，截止日或半年内明确停牌列观察。最近 20 日成交额中位数至少 2,000 万元且 60 日总额为正。
- 行业按申万一级合格指数比较。概念须经题材库名称命中与 v2 逐条核验为产业主题，主题至少 5 个合格成员且合格率至少 80%，行业也须至少 5 股可选。四维各占 25%。趋势取 3／6 月相对沪深 300 超额收益的百分位均值，回撤取半年最大回撤的逆百分位，量能取近 60 个交易日上涨日成交额占比的百分位，风险取同期日收益波动率的逆百分位。参数以[排名配置](../quant/config/ranking-defaults.json)及冻结结果为准。先选板块再选股，重复席位保留，未舍入分数用于排名，并列按稳定边界处理。
- 排名使用价格收益，连续处理送转或拆并股，保留现金除息影响。低波动准备另用税前除息再投资总收益。当前主题成员回溯特征不能当成历史主题收益，无历史成员时不报历史宽度。板块强弱、宽度、贡献集中度、量能及风险须带来源时点、反方和复查条件。研究优先级不转成交易指令，不自动改变人工行业 Gate。缺数或席位不足按实际发布 `limited`，九表结构可查询和导出。
- 回测区分信号价、可成交原价、账户和评价。按历史制度约束次日成交、T+1、停牌、涨跌停、价格步长、申报单位、容量及成本。已证除权参考价用于申报和撮合，账户行情保留原价，未知参考拒单并登记限制。滑点计入成交价，不再扣一遍现金，毛净值仅加回显式费用。分红、送转、税和退出按登记、除息、到账、可卖等证据入账，未知处置不猜测。
- 策略储备以[候选登记](../quant/research/phase2-candidates.md)为准。低波动优先，E/P 在历史财务时点合格后第二，红利低波为储备。公开方法与本地适配差异分开，改规则不继承原验证标签。透明市值基准可作周／月机制验证，正式低波动仍按冻结月频。未来标签不得用于当前信号或权重，因子诊断、板块线索和组合经济结果分别披露。

### 3.3 任务、发布、旧结果和成本

保存策略、参数、池、区间、资本、基准、时点和成本。复制定义保留原任务及差异。同一提交标识幂等，终态后的新提交使用新标识。取消经请求边界确认，重开找回中断状态，显式重试保留失败历史及累计批准额度。单根排他锁避免并行写同一队列。`--once` 会排空可执行的队列，不能当成仅执行指定任务。

数据快照和结果原子发布，重开、刷新、查询、导出及 Notebook 读取同一已发布产物。哈希用于同一锁定文件的完整性核验。仓库、日期、路径、版本或 `as_of` 变化不撤销旧结论。真实语义变化须有定位证据，才核对最小受影响范围。比较需显示对象、时间、执行、基准、成本及不确定性，不混排不可比结果。保留全部试验和失败，以及成本、敞口、换手、可成交性和毛净收益证据。

数据取数、采购和正式研究各按本次授权。实际执行两家及以上公司的股票分析前，须说明范围、次数、费用、可复用结果并按 [AGENTS.md](../AGENTS.md) 落实模型选择与授权，不以阶段批准或批次变化重置费用及研究额度。
