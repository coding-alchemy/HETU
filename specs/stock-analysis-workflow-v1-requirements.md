本章保留剩余要求；六期总设计 v0.2 及已证范围的限定验收已获批准，实际范围见
[六期设计 §11.2](2026-10-04-stock-analysis-workflow-v1-phase-6-design.md#112-交付状态与证据入口)与各批记录。

### 1.1 分深度的资料覆盖与投入标准（P0；六期已获限定验收，剩余要求保留）

**用户结果：** 选择 quick、standard 或 deep 后，能知道必需资料是什么、查到什么程度才足够、
何时需要独立来源，以及当前还差哪一项。

1. 沿用现行三档覆盖下界和公司模型规则，将每档适用必需问题进一步对应到具体内容、必要来源、
   独立交叉验证要求、适用期间及投入预算。已批准的覆盖和数量下界不重新发明或降低；预算能力
   直接继承五期已批准策略默认与停止规则，六期补来源用途与投入的对应，不以重新完成性能
   配对或三档实测校准为前置，也不新增时间到点停止行为。
2. 对每个信息用途区分已有有效内容证据、仅可访问／仅有目录、部分覆盖、未取得、待授权和待补验，
   引用原有证据，只补剩余缺口。必须证明实际取得并解析了能回答问题的内容，不能以网址、规则
   或文件存在代替完成；每个支持能力组合的 quick 必需披露、财报、交易状态、股本和行情须有证明。
3. 适用范围覆盖证券状态、公告监管及问询附件、行业竞争、经营产品、财务分部、股东与公司行动、
   估值输入、成交与流动性。结合公司模型和特殊状态按需补齐下列资料，不要求每股使用全部来源，
   不要求全部自动采集或购买全部商业库。来源名称是选择参考，不代表已取得、授权或验收。
4. 将“取得存在事实的原文”和“完成规定范围的检索”分开定义满足条件；明确合法等价替代能
   支持哪个用途，哪些只提供背景。监管原文、阴性检索、官方状态组合证据的具体边界按
   [A2 诊断](validation/2026-10-03-phase-5-acceptance-evidence.md#53-a2-深度资格诊断)纳入六期需求评审。
   不因接口不可得机械降低已满足用途，也不因有替代材料就放宽原文、独立性或覆盖要求。
   现行七种状态及满足关系继续生效，改变其含义必须明示差异并取得需求批准；A2 原结论保持。

### 1.3 获取失败后的实际补齐与查询追溯（P0；六期已获限定验收，剩余要求保留）

**用户结果：** 能查明找过什么、失败在哪里、换过什么路径，以及最终是真正补齐、受限替代还是仍未取得。

2. 对剩余故障补齐可执行的合法处理与行为证据，区分未找到、无权限、下载／解析失败、口径冲突、
   时点不符、过期及工具不可用；PDF 进一步区分下载、加密／损坏、文本层、版式、编码及页级读取。
   既有解析或替代成功场景不重新开发，只处理尚缺的细分场景。
3. 对适用故障，由 Agent 尝试合法镜像、原始附件、替代解析、OCR、替代格式、同口径来源、代理指标

   不等价时保留缺口或冲突，不绕过登录、验证码、付费墙、反爬或许可。
4. 将各用途的实际失败与首选、替代、内容采用对应起来，保留限流、连接／维护、权限、结构、分页及
   主体／期间／范围／单位不符的具体依据。只有检索面闭合且无结果才记“未找到”；原值不覆盖、
   冲突不强行裁决、未命中不证明不存在，均沿用既有规则。
