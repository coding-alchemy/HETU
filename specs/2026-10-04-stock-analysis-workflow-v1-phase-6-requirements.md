## 1. 核心目标

让用户看清并实际得到本次研究所需的资料：**需要什么、去哪里找、取得多少才够、失败如何补救、
还缺什么以及影响哪些结论。** 在已有研究质量判断能力上，补齐来源与实际内容之间的缺口，
使更多适用必需问题能由真实、可定位、符合时点与口径的资料回答。

六期同时要求“实际资料补齐”和“完整性判断有据”：新增网址、扩大来源目录、增加记录字段或
正确交付一份缺资料的报告，均不能单独证明资料补齐目标已经完成。

本期范围承接原整理版第二章“资料是否充分可信”，并按用户已同意的组织方式纳入原第三章的
失败补救、缺口去重和影响追溯，完整对应长期 §1.1–1.5。六期只处理扣除一至五期有效成果后的
剩余增量，不重建已交付的执行、质量或来源通则，不重新要求已验收功能。五期限定接受和未证
能力保留原范围，不把停止投入的性能、预算校准或完整宿主认证自动转入六期。

本期实际执行及验收范围同时遵守 §6.1 的用户后置决定；后置只改变阶段安排，不证明资料已取得，
不改变研究运行中的完整性、满足关系或使用限制。

## 2. 已有能力与剩余工作

### 2.1 直接继承的能力

| 已有能力 | 依据 | 六期使用方式 |
|---|---|---|
| 十二章报告、三档覆盖下界及 standard 数量下界 | [报告指引](../skills/hetu-stock-analysis/references/report-guidance.md)；二期实现 §2 | 保持原要求，补“问题—资料—来源—独立验证—投入”的对应 |
| 来源目录、用途级采用、生产链独立性、信息 owner 和部分来源的真实内容证据 | 三期实现 §2–4、§11；[来源合同](../skills/hetu-stock-analysis/references/source-contracts.md) | 复用正式组合、样本和取得路径，不把候选来源一律升级为已接入 |
| 共通底线＋深度＋公司模型＋特殊状态的必需项形成 | 四期实现 §1–2；[研究质量规则](../skills/hetu-stock-analysis/references/research-quality.md) | 在实际 owner 上补资料要求，不新增中央质量状态 |
| 七种资料状态、完整性与有效性判断、实际深度降档、首页缺口和不能得出的结论 | 四期实现 §1、§2.5、§4 | 资料增量直接使用既有判定，不重新设计另一套完整状态 |
| 失败分类、合法等价替代、点时、来源回链与独立核对 | [证据规则](../skills/hetu-stock-analysis/references/evidence-rules.md)、来源合同；三、四期实现 | 只补尚未覆盖的数据域和实际行为场景 |
| 取消、调整、恢复、默认复用、独立副本、任务血缘与唯一采用 | 五期 §3；[恢复规则](../skills/hetu-stock-analysis/references/recovery.md)、[产物合同](../skills/hetu-stock-analysis/references/artifact-contract.md) | 直接使用实际复用开关、许可内副本及原始取得时间；只补用途或缺口关系未闭合部分 |
| 正式子任务、任务内共享取数、串行合入、同源去重和局部失败隔离 | 五期 §4；[编排规则](../skills/hetu-stock-analysis/references/orchestration.md) | 相同适用原件不重复取得／解析；只派发剩余问题，不把来源去重当缺口去重 |
| 三档策略默认、同类重试与对应工作停止 | 五期 §8.1；编排规则 | 继承外部调用 120／120／260、重试 3、并行度 3、不新增付费授权；默认未充分校准，时间目标超出仍继续必要研究 |
| 安装维护、扩展管理、计量与统一验收工具 | 五期 §2、§5–6 | 使用现有工具与安全边界，不新建入口；工具交付不等于四宿主均获研究认证 |
| G2 五报告／三模型／三域切换与深度专项 | 五期 §7.2、验收证据 §5.1 | 已有专项不列六期待办；保留 D5／B 类例外及各场景实际证明范围 |

已有覆盖下界继续有效：quick 保留主体状态、核心业务、最新财务、近期公告、股本行情、基础估值
输入、支持、反证、未知、验证点和缺口；standard 追加控制关系、经营驱动、行业竞争、治理审计、
资本配置、调整后多年财务和最新一期、情景与监控；deep 追加更长历史、完整年报与重要附注、
分部产业链、更多独立来源、资本配置效果、预测敏感性、估值交叉及更细证伪条件。

standard 已批准的非重复有效事实 ≥8、时间序列 ≥5 组（其中一组跨 ≥4 个报告期并含最新季报的
多指标财务主表）、计算 ≥4 项（含估值倍数和三情景）、重要事件 ≥3、反证 ≥5、监控 ≥6 的要求
保持原意与原配套条件；本段只用于防止分层时弱化基线，完整口径仍以报告指引为准。缺证据不得
编造以凑数量；现有监控下界不扩展为长期 §1.7 的完整监控规则。

### 2.2 需要继续补齐的资料

所有适用研究问题按长期 §1.1 的四组来源表覆盖，不另复制一份来源目录：

| 资料组 | 内容范围 | 六期着重补齐什么 |
|---|---|---|
| 公司事实 | 主体状态、公告财报与审计、业务产品分部、股权及子公司历史 | 官方状态、完整披露与附注覆盖、历史关系，以及已有材料之外仍缺的内容 |
| 经营与竞争 | 行业量价库存产能、独立份额、客户供应商、招投标、贸易、领先指标 | 可用细分数据、公司／产品映射、独立生产链、原始输入与代理指标的分层 |
| 风险与外部约束 | 专利临床、司法监管环保、跨境披露制裁、债务评级兑付 | 主体／法域／时间覆盖、登记与批准区分、逐案和存续事件的实际证据 |
| 价格与预期 | 行情股本公司行动与流动性、官方融券明细、指引与历史预期／估值输入 | 官方明细与口径、历史截面、修订及成分证据，补输入而不新增估值研究方法门槛 |

三期已有记录提供具体起点，以下只说明原记录的适用时点与边界，不声称这些来源现在仍不可访问，
也不因进入六期而重做已通过样本。五期现行有效内容按用途核对后直接承接，不等待整体完成。

| 既有记录中的缺口 | 证据定位（三期实现 §11.5 的 information_id） | 后续应回答的问题 |
|---|---|---|
| 行业价格、库存、产能未取得完整适用内容 | `info-industry-price-inventory-capacity` | 对适用行业是否已有合法、细分且可核验的实际数据？ |
| 公司产品与跨境贸易数据映射未闭合 | `info-trade-crossborder` | HS、报关主体及产品能否对应，能支持何种公司层面判断？ |
| 独立公司份额受来源／授权限制 | `info-competition-market-share` | 是否存在独立且同口径的内容，仍只有自述时如何保留缺口？ |
| 境内专利及临床实体／单品证据仍不完整 | `info-rd-patent-landscape`；五期恒瑞临床登记部分证据 | 继承已取得查询和抽样，剩余主体消歧、变体排除、单品管线及境内资料是否实际闭合？ |
| 工商股权变更历史未闭合 | `info-subsidiary-ownership-history` | 是否有实际变更序列，不能只拿当前快照或多地上市映射替代？ |
| 领先指标只有部分代理输入 | `info-leading-operating-indicators` | 哪些是直接披露，哪些只是代理，哪些经营事实仍不能验证？ |
| 指引与共识缺成分、修订及历史截面 | `info-guidance-consensus-pit` | 能否证明当时可得内容、成分去重和修订，权限允许怎样使用？ |
| 司法制裁监管覆盖有法域与渠道限制 | `info-legal-sanctions-events`、`info-disclosure-regulatory-history` | 是否覆盖本次问题所需对象、法域、窗口及正式文书？ |
| 官方融券明细及历史范围不足 | `info-securities-lending-supply` | 是否取得官方明细，门户转载和历史退出标的的限制是什么？ |

五期新增内容的核对起点如下，不将局部取得扩大为整个数据域已完成：

| 有效内容或行为 | 直接依据 | 六期仍需处理的边界 |
|---|---|---|
| 恒瑞 ClinicalTrials.gov 查询、三份响应存档与五条申办方抽样已进入研究 | 五期 §7.1.2、验收证据中的恒瑞原件入口；本地锁定树 `恒瑞医药-600276.SH-standard-20260930T004320+0800` 的 `evidence.md` E20、W4 必需项表及缺口节 | sponsor 字串计数，不证明全部实体消歧；存档 total 件仅计数存根，抽样以当时响应为据；单品进度、境内专利等剩余要求不删除，合同仍为仅适合人工研究 |
| 官方状态、独立行业竞争、公告分页三域的首选受控禁用及替代行为已限定验收 | [五期 §7.2](2026-10-02-stock-analysis-workflow-v1-phase-5-implementation.md#phase5-depth-model-source) | 组合快照不证明全部官方状态；行业替代只支持方向性判断，不证明精确份额或独立原始统计取得；公告“未发现”不扩大为没有公告 |

这些条目用于定位剩余问题，不恢复三期“所有候选来源全绿才可交付”的旧门禁。来源是否适用由
本次公司事实和用途决定，不能仅因列在表里就要求每家公司全部取得；也不能凭“已接受三期限制”
把六期已列明的适用必需缺口当成已完成。

## 3. 六期功能需求与完成标准

### 3.1 R6-01：每档研究有具体的资料完整标准（P0）

1. 将已有三档覆盖下界和公司模型、特殊状态必需项对应到：具体研究问题、必需内容、来源要求、
   独立验证要求、适用期间与最新披露要求、投入依据和满足条件。复用现行标准，只补未明确部分。
2. 明确 quick 查到哪里、standard 增加哪些内容、deep 在哪些问题上追加历史、附注、分部及独立
   证据；不通过减少适用必需项、将必选改可选或套固定行业标签来制造完整。
3. 对财报区分找到文件、取得正文、取得所需表与附注及完成分析；对公告区分能搜索、窗口／分页
   闭合及重要附件实际核验；对行业份额区分独立统计、自述和线索。其他域同样按内容与用途判定。
4. 继承五期已批准调用、重试、授权费用与并行策略，准备／收尾按任务估算；补各用途投入依据，
   不默认每类来源相同，不把性能配对或充分实测校准作为资料标准的前置。不承诺外部调用实时
   精确计数、费用实时观测或请求内硬截断，观测未知如实保留。
5. 每项标准区分“取得事实原文”和“完成规定范围的检索”，明确要证明什么、合法替代何时等价、
   如何判满足或保留缺口。状态、来源等级和满足关系仍按现行规则，不能按网站、接口或成功次数
   机械决定，也不能为了减少降档删掉适用必需内容。

[A2 诊断](validation/2026-10-03-phase-5-acceptance-evidence.md#53-a2-深度资格诊断)
揭示了下列用途边界，六期沿用现行规则明确，而非看已有结果倒定标准：

| 具体问题 | 必须明确的满足条件 | 不能采用的捷径 |
|---|---|---|
| 监管指标及正式披露 | 必需指标、期间、口径和原文等级；可接受的监管／发行人正式原文及等价定位路径 | 需要正式原文时，以 L2 媒体转述直接替代；无依据降低原文要求 |
| 负面事件与阴性检索 | 区分取得已存在事件事实和完成规定检索范围；对象、渠道、窗口、分页、正文／附件覆盖及留痕明确 | 标题层零命中、WAF 或未查先写不存在；用没有结果伪造事实证据 |
| 上市与交易状态 | 每一状态主张对应的 L0 正式文件、有效时点及组合依据；允许证明同一用途的正式公告／文件，不强求单一枚举字段 | 用同日成交、简称或聚合行情直接证明全部上市／交易状态 |

现行[研究质量规则](../skills/hetu-stock-analysis/references/research-quality.md)已允许支撑同一用途的
“替代取得”逐项满足；“无”仅在问题本身是核验限定范围内不存在，且规定查询面完整、有可核验
依据时满足。“未发现”继续不满足，开放筛查无命中不能证明没有风险。不改变七种状态及满足
关系，不新增状态或质量分数，不把“查询完成”说成“风险不存在”。
A2 原质量通过、实际 quick、standard 资格不成立的结果保持，不因此重评分或启动后续样本。

**完成标准：** 对同一研究问题，用户能解释不同深度为何需要不同资料、现在满足哪些内容、仍差
哪一项，以及替代材料／规定范围的检索分别能支持什么。仅有网站、摘要或一份未读完的年报时，
不能通过相应完整性判断；资料实际缺失和特定取得路径不可用能按用途及证据区分。

### 3.2 R6-02：剩余适用资料实际取得并能支撑研究（P0）

1. 按 §2.2 和长期来源表逐用途核对原有效证据及五期已交付增量，明确需要补内容、补路径、补授权
   还是只补验；不将全部来源统一标成“未实现”。
2. 对需要补齐的用途取得实际内容，核对主体／产品／子公司、期间、范围、单位、来源独立性、授权
   和原文定位；新增内容由现有实际 owner 采用，并能支持对应研究问题。
3. 记录原始生产者、传播渠道、取得材料及支持主张的关系。同源镜像不计为新增独立证据，重复下载
   或把旧文件说成新取得不计资料增量；合法复用须如实标注。
4. public 和 authorized 遵守现有边界。授权库、人工可用路径或另类数据按实际需要与许可采用，
   不要求购买全部数据库、全部自动采集或建立通用数据平台；不能取得的内容保留精确缺口。
5. 逐用途交付清单明确剩余内容、适用范围、合法取得路径及授权前提、取得与采用证据、受限的
   未完成项；保留四组内容和九类缺口，不以渠道清单替代资料补齐。

**完成标准：** 本期列明需补齐的适用用途有内容级证据和实际采用结果，能与继承材料区分。只有
目录、技术可达、解析器、规则文字或失败记录时，不能宣称资料取得目标通过。每个声明支持组合
的 quick 必需披露、财报、交易状态、股本和行情来源须有可访问、可解析的有效证据。

### 3.3 R6-03：每类资料都有可解释的时效与覆盖范围（P0）

1. 保留已有点时规则，明确各域发布周期、可接受延迟、历史范围和新鲜度阈值及其依据。
2. 公告及交易状态覆盖到 as_of；行情到当日或此前最近交易日；财务到当时最新合法披露期。
   行业、专利、司法等其他域按实际更新机制确定，不能用一个统一天数掩盖差异。
3. 区分事件、数据归属、市场可得、采集和研究截止时间；核对修订／更正与当时版本，当前查到的
   历史数值不能直接作为 PIT 证据。窗口断档、最新披露未取得或历史版本不可证明时保留具体缺口。

**完成标准：** 用户能知道各域覆盖到何时、为何足够或不足。过期或缺最新财务资料的输入触发
既有不完整与实际深度判断；不得因新日期或版本变化追溯否定旧时点结果。

### 3.4 R6-04：补齐三所及特殊状态的官方证据（P0）

1. 补沪深北证券、发行人、板块、上市及当前交易状态的剩余 L0 证据路径，正式公告或文件可用，
   不强求官方单一枚举字段。已有有效主体映射直接复用。
2. 风险警示、停复牌、新上市、长期亏损、退市风险、同股不同权、多地上市、重大重组、股本变化及
   财务重述均按适用性处理；只补仍缺的资料可得性、可比性、交易时间和估值口径影响证据。
3. 境外主体、证券类别、会计准则、币种和披露时区对齐，组合证据、同日成交快照及聚合行情不冒充
   完整官方状态核验。

**完成标准：** 剩余适用状态能回到官方原文，实际影响进入相关 owner 和报告；缺官方证据时准确
保留限制，不能只靠交易快照或名称命中判通过。

### 3.5 R6-05：获取失败后能补救，并留下真实处理依据（P0）

1. 保留已有分类和合法替代行为，逐项补齐尚缺的查询明细、故障细分和实际处理场景。记录目标、
   查询词、证券映射、日期范围、来源／工具、查询时间、返回状态、选用／排除理由、替代路径、
   停止原因和下一动作；可引用既有原始响应、错误输出或宿主日志。
2. 覆盖未找到、无权限、下载失败、解析失败、口径冲突、时点不符、过期和工具不可用；PDF 细分为
   下载、加密／损坏、文本层、版式、编码与页级读取。保留限流、连接／维护、结构变化及分页未闭合
   等具体原因，不以笼统“不可用”掩盖仍可处理的问题。
3. 对适用故障，由 Agent 尝试合法镜像、原始附件、替代解析、OCR、替代格式、同口径来源、代理指标
   或缩小范围，沿用五期同类重试和对应工作停止规则；合理替代完成后仍无法满足的才形成缺口。
   预算、授权或安全阻断导致替代未完成时，如实记录停止和未满足项，不无限重试、不改不适用。
   不得绕过登录、验证码、付费墙、反爬或许可。
4. 替代核对主体、期间、范围、单位与用途；不等价保留缺口或冲突。检索面闭合且无结果才记未找到，
   未命中不等于不存在；冲突双方原值和影响保留，不强行填值，不让代码自动决定换源或采用。

**完成标准：** 正常补齐、受限替代和仍未取得能由实际行为及结果区分，停止依据可复核，单个来源
失败不损坏其他研究。正确保留受限结果只证明故障处理合格，不证明 R6-02 的取得目标已经满足。

### 3.6 R6-06：一个缺口关联全部影响，补齐后判断同步（P0）

五期任务关系、副本来源、唯一采用、输入链和直接下游复查直接继承，不再作为新增开发。
本项补的是同根因缺口的稳定标识、全部影响关联、排序及状态闭合；同源证据去重或已有回访
规则不能单独证明这些结果成立。

1. 在已有 owner、必需项、证据和缺口记录上补齐稳定标识、首次位置、类别、严重度、原问题、查询、
   影响、状态、用户决定、下一动作及复查时点；同根因只计一次，全部受影响主题保留。
2. 证据与缺口的引用类型、目标双向有效；最大未知按对核心论点的影响、时效性与补齐成本排序。
3. 缺口变化同步到当前研究的相关 owner、报告及恢复结果；一个缺口影响行业、预测和估值时，
   三处采用关系均能追溯。各用途分别判断，部分补齐不全局升级，不能只修正文一处。
4. 沿用四期完整／不完整、有效／受限、实际深度和降级规则。每个未满足的适用必需项能指出受影响
   方法与不能得出的结论，取得替代材料后仍须核验是否满足用途，不能自动升级完整状态。
5. 同步限当前任务及其实际采用链；独立重试、新时点研究使用独立目录及本地副本，不回写原任务
   或历史锁定报告，新资料不追溯使旧结果失效。

**完成标准：** 用户从任一受影响结论可定位同一缺口及进展；补齐或受限后，owner、首页、正文和
恢复结果一致。无需新增质量分数、中央状态存储或另一套报告字段。

## 5. 验收要求与能力限制

以下是需求层的行为验收条件，技术方案见已批准总设计；具体样本、材料与运行次数在获批计划
及运行授权中确定，不据本稿启动股票分析。

| 需求 | 必须能观察到的正向结果 | 必须识别的失败或受限情况 |
|---|---|---|
| R6-01 | 不同深度的具体资料要求与既有下界一致，采用证据能逐项对应 | 用网站数、篇幅、摘要或缺附注的年报冒充完整 |
| R6-02 | 剩余必需用途实际取得内容，主体／口径／许可正确，并进入研究判断 | 只有目录／渠道可达／失败日志；同源镜像伪装独立；候选冒充正式采用 |
| R6-03 | 最新可得披露、覆盖空档及历史版本有依据 | 用旧年报忽略最新披露，用当前共识倒灌历史 |
| R6-04 | 官方状态原文及实际影响可定位 | 聚合行情冒充官方核验，多地上市／同名主体错误合并 |
| R6-05 | 真实合法替代取得同用途资料，或准确保留受限结果与停止理由 | 未查先报无、分页断档、解析漏页、无授权绕过、不等价替代升级 |
| R6-06 | 同根因缺口只计一次，全部影响及修订／恢复状态一致 | 漏掉受影响主题，正文承认缺口而首页完整，材料补齐后错误继承旧结论 |

1. 先按“要求／用途／case → 已有有效证据 → 具体缺口 → 最小补验”建立可审阅对应；直接复用
   三至五期适用成果，不因本期编号、模型、版本或 as_of 改变重验已通过结果。
2. 必须验证实际取得、解析、采用及最终研究行为。静态映射与行为证据同时成立、互不替代；能力
   缺失时对应验证失败，研究输入不包含评审答案。沿用四期完整与降级交付行为，只回归直接受影响部分。
3. 原有九类补齐用途和四组内容不得无依据删除、缩小或改可选；每个声明支持范围的适用必需项
   均须达到对应完成标准。不适用必须由公司事实或研究用途支持，不能为通过验收临时改定义。
4. 授权或渠道限制无法通过合理合法替代解决时，分别列明“故障处理已验证”和“资料取得未完成”，
   说明最小缺口，不能自动以受限交付判六期全部完成。必要能力延期或降级须用户批准，不要求无限
   重试、购买全部数据库或穷尽互联网来源，也不推翻三期已接受的原时点结果。
5. 验收支持范围逐项声明，不默认四宿主、所有模型／模式／深度均已认证；本批限定研究支持仅
   ZCode×GLM-5.3-Flash×standard×public 的获证类别。已有 quick／deep 等原时点质量成果仍可
   按原范围复用，不机械凑完整组合认证。不重做五期完整性能或宿主认证；六期的具体语义变化
   直接影响已有要求时，定位受影响范围再补验。
   整批重跑或重跑已通过结果须事先说明直接影响、股票分析次数与成本，并取得本次明确批准。
6. 预计实际分析两家及以上公司时，首次启动前按 AGENTS.md 说明次数并询问是否切换性价比模型；
   当前任务没有“如有股票分析直接执行”的授权，不得自行切换模型或启动研究。
