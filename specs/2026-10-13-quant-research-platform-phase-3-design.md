## 1. 本期用户结果与边界

本期让用户在网页完成数据准备、选择已接入策略、配置研究、运行、追查、比较和导出，并证明独立研究产物能够进入平台继续使用。完整结果包含两件事：原研究及全部试验能够只读查看；至少一项用户选定的代表策略实际在平台运行，信号、交易和净值可追溯。

只读导入、执行适配和研究结论分别显示。导入成功不能变成“策略验证通过”，代码登记不能代替实际执行，平台可用也不能代替收益目标达成。经济价值仍按原协议与实际结果判断，保留未通过、证据不足及继续/补证/调整/停止依据。

本期承接总设计第 8、9、14、15 节，保持同仓独立 Python 子项目、共享研究内核、个人网页和单一正式回测引擎。沿用前期技术选择；不新增通用插件平台、任意代码在线执行、多用户管理、自动实盘、ML 或多市场实现。

每一期独立设计、独立计划、逐期执行和验收。总方案批准不等于本分期设计批准；本设计获批后，才在 `specs/plans/quant-research-platform-phase-3/` 编写路线图及多个编号计划。本次不创建该目录或实现代码，确切文件、接口与命令留给获批后的计划。

## 2. 前期输入与最小语义合同

本期依赖一期已验收的研究入口、数据与任务基础，以及二期已验收的组合模拟和独立策略验证产物。按实际能力消费前期产物，不要求仅为本期组织调整重做前期工作。

| 前期输入 | 必须保留的语义 | 不满足时的本期边界 |
| --- | --- | --- |
| 数据快照及质量说明 | 来源与模式、市场、字段/单位、观察/可得时点、原始输入、成员用途、缺口和修订关系 | 只限制依赖缺口的任务；不能用付费标签或旧更新日期弥补 |
| 冻结研究定义 | 对象、截止时点、方法、参数、资格规则、基准；组合另含资本、成本、成交与现金规则 | 未明确的规则先补证，不能由网页默认值悄悄改写 |
| 独立策略资产 | 来源与许可、原规则/本地适配、代码或 Notebook、环境与人工步骤、数据说明、评价协议、全部试验和结论 | 不完整资产仍可登记缺口，但不能冒充完整验证或可执行适配 |
| 已有结果与完整轨迹 | 信号、目标持仓、订单/成交、实际持仓、现金、净值、经济评价及失败记录；筛选结果保留两榜与成员关系 | 因子结果不冒充组合结果；已有证据按原适用范围保留 |
| 任务与实验记录 | 定义、提交标识、运行尝试、状态、原因、起止时间、结果引用和参数变化 | 沿用同一状态语义修复接入问题，不再建立第二套任务系统 |

前期只有条件性缺口，例如免费财务 PIT 不足以支持 E/P，不自动阻断已合格的低波动策略接入；V5 所要求的至少一项真实非基准完整验证仍须由二期完成。前期未完成的核心目标不能以三期网页包装改判通过。

## 3. 策略资产接入与实际复用

### 3.1 只读纳入研究库

导入保留来源、原方法与适配差异、研究协议、代码/Notebook、数据说明、全部试验及原结论。界面提供可追查的原产物入口，缺失项如实显示；不只导入最佳曲线，不覆盖原研究，不执行导入文件中的代码，不自动发起回测。

研究进度、研究结论、经济目标是否达到与平台接入状态分别展示。可准确表达“证据已导入、平台执行未适配”和“已在平台执行、经济目标未达到”。路径、版本或导入时间变化不触发历史结果失效。

### 3.2 明确支持范围后登记执行

在适配前由用户选定至少一项代表策略，建议优先选择二期已有完整免费数据证据的低波动多头本地适配版。选择须明确原规则、支持的股票池、输入、频率、权重及执行边界，不能验收时再把全部候选排除为不支持。

登记的是经过规则审核的本地实现；网页只选择已接入策略，不从上传的 Notebook 或来源文本任意加载执行。现有引擎可复用时优先复用；必要适配对照原规则逐项说明，股票池、币种、窗口、权重或调仓变化形成明确的新研究定义。

先用已有完整轨迹和小型合成边界案例核验适配，再完成代表策略的真实平台运行。正常的新研究与重跑已通过旧研究分别登记；两者均须使用合格免费数据和明确协议。真实执行须留下信号到净值的完整证据，只读查看及合成测试都不能替代此项。

## 4. 完整网页流程与可比性

| 用户任务 | 网页行为 | 必须避免的误判 |
| --- | --- | --- |
| 准备数据 | 查看来源、覆盖、最后成功时点与缺口；导入或增量更新已支持免费数据 | 来源失败不显示更新成功，不静默混源或收费回退 |
| 找到策略 | 查看来源、完整规则、适配差异、全部试验、结论与执行状态 | 已收集、已验证和已接入不混为一个“可用”标签 |
| 配置与启动 | 选择已接入策略，配置股票池、期间、参数、资本、基准、成本与成交语义；保存定义后检查资格 | 有缺口时先说明允许用途，不以默认配置改写原研究 |
| 跟踪任务 | 独立进程计算；查询进度、失败、取消请求及取消完成；刷新和重新打开后找回任务 | 同一提交标识只执行一次；进程中断不显示成功，也不自动重跑已通过任务 |
| 复制研究 | 复制定义、明确修改内容并另存实验，保留原定义、输入和结果 | 参数相同或哈希相同不代表不同提交等价；新日期不撤销旧时点结果 |
| 追查与比较 | 先看结论及限制，再追查信号、交易、现金、持仓与净值；显示定义差异、区间及试验次数 | 样本、基准或收益口径不兼容时不混排；成本/参数的有意变化可在差异清楚时比较 |
| 导出与深入研究 | 导出结构化结果、定义、来源、限制及报告，Notebook 读取同一份产物 | 不另写一套数值公式，不仅导出截图或丢失失败与限制 |

一期行业/主题各五个、各五股及三年/半年窗口继续可用，原有重复关系、候选解释和成员用途不因工作台整合而弱化。候选清单不是组合权重，平台不自动据此下单或触发多家公司深研。

## 5. 免费模式与受控付费兼容

当前仍只启用免费数据源，数据费用为零。网页、Notebook、worker、缓存与本地文件导入共用来源准入；环境存在付费凭据、免费额度耗尽或接口失败都不能绕过免费模式。新来源先核验许可、字段与时点，不以文件导入掩盖付费来源。

受控测试适配器可证明模式权限和共用产物：模拟收费请求、额度耗尽、来源失败及模式选择，检查实际调用记录和结果合同。此证据只支持“付费模式接口兼容、权限边界生效”，真实付费供应商保持“未接入/未验收”。不得联系采购、调用收费接口或以试用替代免费闭环。

将来用户授权的模式切换只影响其明确选择的新任务，不更改旧任务的来源、输入、结论或评价等级，不自动重跑。三期验收完成也不自动启用付费。

## 6. 期内交付单元与依赖

下列是供后续计划拆分的可独立验收单元，不是实施步骤或执行授权。

| 单元 | 用户结果与必要依赖 | 独立完成证据 |
| --- | --- | --- |
| A：策略证据接入 | 依赖前期策略资产；能够只读查看原规则、全部试验、结论和缺口 | 导入前后原产物不变，无回测执行；失败试验可找到，接入不升级研究结论 |
| B：研究日常流程 | 依赖前期数据/任务/回测能力及 A；完成网页配置、任务管理、复制、比较和导出 | 用户不改源码走通流程；刷新、失败、中断、取消与不可比口径反例正确处理 |
| C：代表策略执行复用 | 依赖用户选定代表、合格免费数据、已核验适配及 B 的运行入口 | 至少一项策略真实从网页运行，信号/成交/现金/净值完整；差异可解释，旧证据保留 |
| D：兼容与本期验收 | 依赖 A–C；汇总真实免费闭环和受控付费边界 | 当前零收费、共用产物、旧结果保护及本期缺口有直接证据；只复验直接受影响行为 |

B 的比较/导出和 D 的模式边界核验可在不依赖真实策略运行的部分独立推进；C 不得被无限推迟后用 A/B 宣称整期完成。本期整体验收须同时覆盖用户流程与实际复用。

## 7. 产物与正反验收

交付产物包括可操作工作台、导入资产及原证据入口、代表策略的适配说明与真实执行记录、可比性/导出结果、模式行为记录和本期验收结论。软件行为、经济价值与真实付费接入分别列状态。

| 验收场景 | 可观察的通过条件 | 需求映射 |
| --- | --- | --- |
| 原资产含失败试验及缺口 | 全部记录可读；原件不被改写，导入不计算，不提高研究结论 | R12/R14/R15，V6/V8/V14 |
| 代表策略的真实执行 | 用户选定策略通过平台产生信号、交易、现金及净值，追溯到冻结定义与免费输入，适配差异明确 | R5/R7/R15/R19，V1/V6/V11/V14 |
| 刷新、重开、同次重复提交、取消及中断 | 找回同一任务；重复提交不增加运行，取消完成与请求区分，中断/失败不冒充完成 | R1/R9，V1 |
| 修改成本或参数、混入不同基准/样本 | 新定义及差异可见；可比变化可比较，不兼容项不混排；旧结论不被改写 | R1/R8，V1/V8 |
| 关闭 LLM、导出并用 Notebook 读取 | 确定性任务与证据摘要仍可用，导出数值、定义和限制与网页一致 | R7/R9/R10，V1/V7 |
| 有付费凭据但免费失败；付费源伪装本地文件 | 无收费调用；显示真实缺口并拒绝绕过，其他合格任务不受牵连 | R3/R16/R17，V2/V12 |
| 受控付费适配及新任务切换 | 相同研究/结果合同可用，真实服务仍未验收；旧任务不改写、不重跑、不升级 | R17，V8/V12 |

反例必须由实际系统处理，不能只检查预填的成功报告。合成材料注明合成，原始输入与测试断言/评分分离，遵循[测试材料方法论](../docs/engineering/test-fixtures-methodology.md)；不得用合成轨迹声称代表策略已在真实市场数据上执行。

R2/R4/R6/R13 的信息时点、交易规则、研究用途及协议继续沿用前期验收依据；涉及适配或接口整合的具体变化才验证其直接影响。R18/V13 的两榜目标保留；不因进入三期自动整批重跑一期结果。U2/V9 仍保存市场身份并明确未支持市场，不扩大为多市场实现。

## 8. 成本、旧结果、停止与回退

本期真实运行预期为至少一项代表策略，不预先承诺股票数量、期间或回测次数。执行计划须按选定策略列出去重证券数、区间、数值运行次数、数据费与公司分析次数；纯证据导入和合成测试单列。实际涉及两家及以上公司股票分析时，第一次启动前仍须询问是否切换性价比模型，计划或阶段批准不豁免该门禁，不自行切换模型。

| 触发情况 | 必须采取的处理 | 旧结果及重验边界 |
| --- | --- | --- |
| 仅路径、版本、日期、哈希或 `as_of` 改变 | 记录来源与适用时点；检查同一锁定产物是否被修改 | 不判旧结果失效，不要求重跑或重新绑定批次 |
| 只读导入或网页展示出现错误 | 停止受影响展示/接入，修正引用或字段语义 | 保留原研究；复验错误项及直接受影响读取，不重算原策略 |
| 适配改变交易或信号语义 | 指出规则、案例、范围和直接证据，隔离本次未验收适配 | 旧研究保持原状态；只把证据证明受影响项列待重验，不扩大为全部失效 |
| 需要重跑已通过结果或整批运行 | 先说明直接语义影响、预计股票分析次数与成本，取得本次明确批准 | 批准前保留成果有效；不能以迁移、阶段验收或升级自动重跑 |
| 免费数据、执行能力或代表策略缺口 | 暂停依赖该缺口的新任务，保留已完成单元与准确限制 | 不采购补齐，不撤销前期结果；C 未完成时不宣称三期整体通过 |
| 本期实现需回退 | 恢复本期受影响入口到已验收行为，保留任务、原始产物、失败及修订记录 | 不删除一期/二期成果；分支、提交、worktree 与回退操作另按实际授权 |

## 9. 批准范围与自检结论

按 `karpathy-guidelines`，本期只完善已有研究流程并打通策略复用，保留一个研究内核和一个任务状态来源。未冻结尚未实施的代码签名、资产字段或目录细节，也未引入超出总设计的新能力。

负向差异审计：本次只将原三期范围单独设计，未把真实策略执行降为文件导入，未推迟二期 V5，未删除一期两榜目标，未改免费模式、经济目标及历史有效性约束。全套需求的完整状态以总需求和各期实际证据为准，三期通过不冒充可选能力或真实付费服务已验收。

本分期设计批准后，结合一期/二期实际产物编写独立计划组，逐单元实施并完成本期验收。若前期具体实现与本文语义合同不同，按行为影响调整接入设计；不能只因版本变化认定其成果失效。本次尚未运行数据、股票分析、策略或产品测试。
