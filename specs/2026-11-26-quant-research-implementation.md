## 2. 冻结策略研究与账户准入

第一项独立研究问题为沪深普通股现金多头的低波动选股，在同池、同资本、同成本的可交易市值加权账户上比较净收益、风险和统计支持。正式冻结研究、真实产物三端交接、免费代表实跑及复制定义的真实可比性验收按用户决定退出本期。以下协议和验收条件仍供后续追溯及获准执行。

### 2.1 逐月资格与执行门禁

[数据交接与资格](../quant/src/hetu_quant/data_research.py)读取合法已发布快照、`requirements.json`、`coverage.json` 和适用的 `qualification.json`、`universe.parquet`、`exclusions.parquet`。默认 `qualification_mode=reuse`。逐应有月末（含首次交易的前一月末）记录原池名单依据、原池分母、上市预热排除、合格及未知对象、30／36／42 月各自起点和月末点。以已公布日历证明月末，保留日历待证月份。原池采用信号时点可知的沪深普通股历史身份，涵盖主板、创业板、科创板、窗口内退市和调出对象。跨码用已证证券身份，未知分母标明未知。当前存续名单、一期 Top 50、按后来的退出排除或分析中途缩池缩窗均不能替代原池。

每条字段证据关联证券、代码段、日期、用途、公开或生效时间、来源、许可、原因及受影响的试验。月末价格、身份、股本／市值和总收益须证明在北京时间 15:00 可知。后取得资料可以证明原公开时间。公司行动的预热收益用途与持有期账务分别核对。持有期按实际登记、除息、到账、可卖及退出核验；开发转验证延续持仓和账务，最终账户另起。区间覆盖、跨码接续、特殊退出和除权参考价按实际受影响窗口判断。有证的一比一更名、非一比一换股、现金退出按适用原件处理。核对有效处置、修订、比例、整股、零碎股、解锁、批次与应收；冲突时保留可证权益，未知款项不提前入账。信号截止和账户执行截止分别取证。具体口径与消费者见[账户处置取证](../quant/src/hetu_quant/account_evidence.py)、[准备包](../quant/src/hetu_quant/backtest_data.py)和[引擎数据源](../quant/engine/datasource.py)。

[调度入口](../quant/research/run_validation.py)区分直接输入、未完成依赖和可复用账户。`full_scope_ready`、跨月去重的 `eligible_ids` 或准入目录存在均不足以单独放行。网页预检和正式执行共用待执行定义、相应准入记录和逐日股票池核对，worker 在信号和引擎启动前复核。只读 `--plan-only` 与 `--execute` 互斥。整份旧基准复用须匹配冻结区间和可比口径；候选需要旧基准前缀时核对相同区间和输入，包括能改变有效持仓的接续、退出及最终处置。显式绑定照原归属核验，未绑定时逐一检查候选引用。仅复用符合条件的账户返回原 `run_id`，即使当前引擎停用。新执行仍需有效准入、冻结定义、依赖、授权和预算。代表任务的重试沿可证原提交关系核验单次授权；零启动失败可按原门禁恢复，已消耗的授权保持原计数。

历史日线库负责其获准范围的历史目录、特殊状态及价量覆盖。研究仍需独立历史全集、绑定模拟输入的用途许可、收盘前已公开股本／市值版本和实际行动及退出原件。E/P 的公告与历史修订、行业历史分类各约束其依赖任务。来源边界为 Tushare、公开信息及获许可的既有资产，Q1 已取消。原 331 个对象日成交额主源选择只适用于已验收的档案用途，详见[系统实现 §3.2](2026-11-07-quant-research-platform-implementation.md#32-原价主源状态审计与七日接受例外)。

### 2.3 账户评价与真实交付合同

[评价入口](../quant/src/hetu_quant/backtest_evaluation.py)按有效交易日和相邻期末锚点评价整个区间、子区间、市场状态和月度统计。日历未知或冲突、任一侧应有日缺净值均保留具体日期及账户。明确休市的行不参与期末选择。压力比较使用 `final_main`，市场方向使用同区间同池 `universe_vw`。目标与实际持仓分别展示，有账务证据的全现金股票暴露为零，实际缺证保留已知目标。时间、样本、基准、费用及统计证据不足时限制相应结论和比较排序。

使用同批 `bundle/signals.parquet` 的入选分数和排名、目标、订单、成交、费用、持仓、现金与净值解释股票和市场阶段的收益集中、换手及无法成交原因。按信号、证券或订单号追溯，目标权重不能当作选股得分。披露毛／净收益、匹配超额、波动／回撤、成交率、容量、规模／行业暴露、子区间、市场状态、参数邻域及压力。只按有证行业归因，不能从受阻数量推定反事实收益。沪深 300 价格指数只作背景。

净收益达标须最终区间候选净 CAGR 与减同池账户净 CAGR 的超额同时严格大于零，容忍度为零。风险目标单列为年化波动不超过基准的 90%、最大回撤不劣。统计对净超额和风险改善给 95% 月度连续块配对 bootstrap 区间（3 月、1,000 次、种子 20261017），披露重叠、多重试验和有效样本；区间跨零不宣称统计支持。低波诊断采用 `-sigma` 及未来 1／3／6 个完整月总收益，分别记录成熟标签覆盖、IC／RankIC、分组、衰减／漂移与有效样本。未来标签按期限和样本切分隔离，不能进入信号或权重。点估计、统计支持、研究结论、经济状态和后续决定分别保存。有完整真实证据的负结果可以完成独立研究，未达标默认停止追加。延迟成交、滚动窗口和新增成本档位各需另定试验及预算。

| 后续真实验收 | 生效条件 |
| --- | --- |
| 非基准样本外评价 | 至少一项候选用合格真实输入完成规则、代码、账户、成本及稳健性评价，全部 trial 和失败可追溯。 |
| 同一产物三端交接 | [发布及只读交接](../quant/src/hetu_quant/backtest_reporting.py)按 `study_id`、`trial_id`、`run_id` 对齐正式网页、结构化 ZIP 和 Notebook。保留规则差异、协议、代码、数据／环境及全部台账、失败、限制和结论。关闭 LLM 仍可查看和计算冻结数值。导入不执行附件代码，读取、比较和导出不新增信号、引擎、网络或 LLM 调用。 |
| 代表策略平台运行 | 独立验证先行。用户选定代表，登记市场、池、窗口、时点、频率、权重、退出及适配边界。由[正式页面](../quant/src/hetu_quant/ui/backtest_page.py)提交，经队列、worker 和 `run_formal_job` 在合格免费输入上实际执行。按同一调仓日核对完整账户轨迹及独立研究和正式执行差异。可用的既有同定义、同入口证据优先复用；新运行须单列次数、费用和授权。 |

### 2.4 候选与另立研究范围的条件

[候选登记](../quant/research/phase2-candidates.md)保留七个股票方向。低波与同池基准复用共同信号。每项独立验证资产包括①原始来源、作者、公开时间、许可、原市场／样本／频率，②假设、预测目标与可证伪条件，③历史池、过滤、公式、参数、时点、频率、权重和退出，④数据域、清洗、交易、基准、成本及容量，⑤代码或 Notebook、环境和复做步骤，⑥全部试验、失败、样本内外、统计及经济结论，⑦平台适配和原规则、输入及执行差异。未知内容如实标注，研究者自定规则独立登记。

| 后续方向 | 进入条件和比较问题 |
| --- | --- |
| E/P 价值 | [已有排序](../quant/research/ep_value.py)依赖当时已知扣非盈利、修订和总市值，先冻结多头权重、调仓和退出，比较同池基准。当前 PE／TTM 无法代替历史版本。 |
| 低换手质量／价值组合 | 先保留单因子相对同池基准的合格账户结果，固定池、执行、频率、窗口和成本，只变一个有事前依据的条件。分辨选股、行业／规模、换手及净收益变化。 |
| 红利低波 | H30269 v1.1 的分红资格、股息率权重及年度调样先取证，比较同日持仓和风险重叠。月频另为变体，重叠证据只计一次。 |
| 中期个股动量、行业轮动 | 个股先冻结形成期、持有期和换仓；行业另证历史分类、成员、权重及可交易组合，区分行业间与行业内效应。现行板块榜不能证明历史轮动收益。 |
| 周频多头反转 | 公开每日轮换和多空规则到本地周频多头的差异可查，具备相应状态、成本和退出规则。对比信号与多头账户，解释高换手、跳空、退出限制及尾部损失。 |

《A股日线量化策略全景分析》v1.0 的 ETF 趋势／轮动是另立研究方向。需要具有上市／清盘历史的可交易池、分红、流动性、交易费用、产品规则及平台适配。用买入持有、同池等权再平衡、单一绝对趋势作对照，再区分相对强弱选基和绝对趋势降仓，另定样本、预算和验收。组合波动率目标比较同一选股规则开关仓位缩放；指数增强需要历史成分与权重；事件策略需要首披及修订时序。各项不增加冻结八次的必跑定义。实盘、任意代码在线执行器、策略无代码编辑器、ML 或持续影子评价均无本期扩围。

## 3. 盘后日线研究

### 3.1 生成与结果内容

[盘后入口](../quant/src/hetu_quant/ui/app.py)消费合法本地已发布输入。显式选择 T 和数据源后，[盘后发布](../quant/src/hetu_quant/after_close.py)生成请求交易日、行情实际截止、策略信息截止、生成时间、输入来源、覆盖名单及数量和各部分缺口。原价观察呈现当日原价及量额、已证连续交易日的价格变化和波动，以及可用的 20 日成交额中位数、60 日波动等观察口径。使用范围内获许可的日历、报价版本凭据和停牌状态；分别按来源、产品、证券及许可期间读取，保留同组免费数据和获准付费当日数据。证据不全时显示有效部分和未知范围，成交额冲突并列双方原件，保留独立可证的收盘。原价波动与分红送转调整后的总收益分别标识。行业榜和主题榜按 T 调用[既有排名入口](../quant/src/hetu_quant/ranking.py)，各自保留时点、规则、收益口径、资格、覆盖和限制。

| 场景 | 页面行为 |
| --- | --- |
| 已证普通日 | 显示「今日无新调仓信号」，按最近有效信号日查目标及权重。较近月末未保存但已有可追溯的当时事实时，可回算并标明历史目标的原信号日与实际计算时间。同日默认最早成功原发布，记录实际采用的上期版本。无合格上期时说明原因。 |
| 已证月末 | 使用 §2 的冻结低波规则，先给出可证排名和入选者，再核对全部入选者的时点市值。缺任何入选者权重依据时保留可证排名和具体字段缺口。显示权重、与上期入选／退出／保留的原因和权重变化，同一已证身份更名仍为保留，列出两期代码；身份不明则保留缺口。无可比较上期标明首次可证信号。 |
| 行情止于 T 之前／月末未证 | 报告实际行情截止及受影响的结论，旧发布仍可以原日期打开。月末资格未知时仅发布有证观察并指明日历缺口。 |
| 下一交易日与适用日期 | 月末由事先已公布的完整日历或等价证据证明。有已知后继交易日时，无需后继行情即可给出适用日；缺后继日历仍发布已合格的目标，适用日待定。 |

### 3.2 时点隔离与发布关联

以 T 日北京时间 15:00 的可知版本计算低波，仅消费截至 T 的适用行情、身份、代码段、行动与市值和实际预热窗口。后取得但有证据证明收盘前已公开的事实可用。未来价格、未来已定日期换码和行动、晚披露字段、未到期标签均隔离。首次回看历史收盘选择当时已知的版本。例如 1 月 31 日收盘 10、2 月 2 日首次更正为 12，两版可证时正式信号用 10。仅余后修值时，回看观察可列 12 及修订首次公开时点，正式信号指出缺原收盘的证券、日期及收益窗口。后修时间也缺证时显示公开时点未知。[共同信号](../quant/src/hetu_quant/strategies.py)保留月末目标和历史模拟成交适配两层，未来标签只在独立评价链计算。

每次显式生成以独立发布标识原子保存，榜单与原价观察、信号和原件定位一并在成功发布后可见。请求 `trade_date`、新 `signal_date` 和上期目标自己的日期分别记录。刷新或按 ID 重开只读，导出取所选发布；失败不公开半成品或孤立榜单。修订另存并引用原发布，列影响对象、日期和字段。后续模拟的订单、成交、费用和到期的 1／3／6 月收益各自发布并按原发布版本、策略和信号日关联；同策略同日的另一发布不能共用关联。到期评价可独立于模拟生成，依据各自到期日、评价截止和冻结样本切分，区分到期、待到期和缺证。重开、修订或后取证据保持原判断和原时点。新模拟遵循 §2，盘后发布本身不依赖经纪账户、个人资金或持仓、模拟引擎、次日行情和正式预算。

## 4. 因子库、公共取数与独立复算

工作台按名称、别名、类别和对象检索。一个因子标识关联中文档案、定义版本、适用对象、频率、参数、公开公式和实际可调用函数。档案解释考察的量、假设、边界、方向与单位、所需数据、失败条件、手算的中间量和预期、代码入口及自测记录。例：60 日上涨成交额占比用 61 个连续可比收盘判断 60 次涨跌，上涨日 4 亿元除以总额 10 亿元得 40%，平盘进入分母，零分母为缺口。

[公共计算入口 `compute_factor`](../quant/src/hetu_quant/factors/__init__.py)接受因子标识、对象、观察日、信息截止、参数和教学材料或获准本地原件。结果附标识和版本、实际参数、对象、日期、截止、单位、数值或类别、输入中间量、来源、可用状态及结构化缺口。布尔假值、真实零值和未知分别记录。区分原价、行动调整的连续价格和含分红的总收益。截面按当时成员、行业、身份、权重和交易日历。独立分母未知时只显示经核实的范围。仅取公式所需的期间、证券及字段。合成样例以原始事实驱动同一生产入口，既有两榜、冻结策略和账户保留各自业务口径。

### 4.1 时点、修订、财报与事项

[共用取数与版本选择](../quant/src/hetu_quant/factors/sources.py)先核验所选用途和来源，再认原件、可知时刻、字段单位、修订关系与业务事项。[财报](../quant/src/hetu_quant/factors/statements.py)、[公告](../quant/src/hetu_quant/factors/disclosures.py)和[股东事件](../quant/src/hetu_quant/factors/shareholder_events.py)计算消费相同的证据语义，组合因子沿用相应分量。[因子页面](../quant/src/hetu_quant/ui/factor_page.py)展示同一次计算的读数、中间量和缺口。

1. **按实际信息截止取证。** 工作台默认选定交易日北京时间 15:00，读数按用户本次所选截止及公式自有的更早限制计算。历史分位按各历史观察日的截止分别重建。比较带时区的实际瞬间，等于截止时可用；仅有日期或含糊时区不足以证明当日已知。区分报告期、首次公开、修订公开、实施日和采集时间，分别检查表值、字段凭据与替代声明。用户可见的输入摘要、缺口双方及嵌套诊断同样受截止限制。若 15:00 只可证旧原件而缺匹配表版本，可显示当时的原值与原件，18:00 才披露的金额、时刻及据此推得的匹配状态不进入结果。
2. **首披与最新报告各按自身用途选择。** 超预期保留首次可用值、时间、字段和原件，并取首次公开前同报告期同口径的一致预测。明确非首披字段不能补首披区间。有效更正可补首次出现的字段，保留更正自己的时点；按第一个首披字段决定 `first_known_at`，按区间可用时间记录 `released_at`。同一公告可分表登记，先核对共同发行人原件或稳定登记证据。证实了下限副本只为该下限佐证。聚合 CSV、重复导入路径、HTTPS 形式或资产本地短编号本身不能建立公告身份。已知最新有效报告期作为 E/P 的选择对象；已有登记而表行缺失、表值未证或两值不合，保留这一期的字段缺口。
3. **逐字段核对原值、单位和口径。** 每个实际使用值附证券、期间、字段、原值、单位、币种、公开版本及原件位置。字段声明优先，明确覆盖该字段的同一原件表头或报告说明可作回退。其他独立原件不能提供借用单位或会计范围。同字段、同口径原件先按已证单位换算，等值互证并保留各自原值和出处，实质冲突列双方。跨资产核对先证明同一登记；已证共同发行人公告及同证券、报告期、字段、修订、时点和口径时，本地行号可留在各自出处。一致预测需已发布共识或事前声明的机构聚合办法，不能从单家、机构名未知或每期恰一条推定。跨年度同比还原单季后核对合并范围及会计期间。跨市场序列用所属日历、带时区收盘、币种和可比的有效收益窗；无关历史不扩大实际依赖。
4. **按可证登记解修订，再核对事项。** 在实际来源所有者、产品、适用表和证券下核对稳定登记及明确的替代关系。跨表、跨资产副本按有据的同一公告和字段互证，保留完整登记坐标、原表、资产和原件。局部行号、短版本号、事件编号和文件名相同都不能单独撤销其他原件。只在截止前沿明确关系淘汰旧版本，当前值选择和历史首披的用途分别保留。对循环列出参与原件及方向，只限制实际依赖的字段。每种有效分支保留全部相关独立原件，按已证身份去重，再判断类别、日期、窗口、可比口径及贡献；各分支都有依据且当前读数一致时使用该结果，保留候选日期。得数不同或仍有影响当前公式的冲突时报告具体字段、原件、分支及前版。解禁用预告窗口及事件前流通股，股息率用已实施的观察窗及同股本口径；精确实施日或其他公式所需字段仍各自核查。无关窗口、字段和导入备注不改变读数。原生登记缺原生表行时按登记保留缺口，不能当作没有该事件。

### 4.3 逻辑自测与效果预留

档案分别显示公式的逻辑自测、所选对象和数据的实际可用性及市场效果。自测按因子、版本及类型敏感的实际参数关联。每项以独立手算或独立数学基准给出有区分度的正常及边界案例，逐一核对具名参数和各输出。收据包含测试节点、样例事实、对象、日期、截止、受验预设、实际运行参数和预期／实际值，下载和复算共用请求校验。工作台提供读取实际代码、教学与本地选源、数值与中间量及可复算的证据。历史收据对原时点和适用口径继续有效；没有相应收据时显示未测。不能用固定示例值、空函数、空输入或生产函数自身生成预期替代公式验证。

实际页面的验收覆盖单证券日线、财务或公告、跨对象三类样例。用户可分别查看公式、实际代码和演算，复算后核对独立预期。切换到缺原件的真实来源时仍可浏览档案，自测状态独立显示，当前计算指出具体缺失字段。

每个档案继续保留 `effect_validation.status=not_evaluated`、假设、对象、拟用对照和期限及 `evidence_refs=[]`。以后可按标识、定义版本和完整参数关联样本、方法、结果及限制。因子自测不执行历史预测效果、未来标签、IC、成本压力、建模、回测或盈利评价，正式台账不记次。冻结研究诊断仍按 §2.3 的独立合同。

### 5.1 趋势、配对、个股基本面与截面信号

| 来源和因子 | 计算标识或去向 | 定义与输入 |
| --- | --- | --- |
| §4.1 均线、趋势过滤、双均线交叉 | `sma`、`sma_filter`、`sma_cross` | 同口径连续价格 P 最近 N 次收盘的算术均值。过滤值为 P 大于均线时 1、否则 0。交叉比较短长均线差，昨日非正今日正记 +1，昨日非负今日负记 −1，其余 0。短窗须小于长窗。 |

| §4.5 质量 | `roe`、`roic`、`gross_margin_stability`、`accruals`、`leverage` | 本地口径依次为近四季归母净利/期初期末平均归母权益；近四季税后经营利润/同期平均投入资本（有息债务+股东权益−现金，税后经营利润=EBIT×(1−有效税率)）；最近八个单季毛利率样本标准差的相反数；近四季合并净利减同期经营净现金流后除以平均资产；最近披露总负债/总资产。 |
| §4.5 成长 | `revenue_growth_yoy`、`profit_growth_yoy`、`expected_growth`、`rd_intensity` | 可比单季营业收入、归母净利分别与上年同季比较（本期−同期）/绝对值(同期)，同期为零给缺口，负基数标记；同一截止时点、同币种和范围下按未来两个相邻财年一致预期净利作同式增长比较；近四季研发投入/营业收入，披露口径和资本化范围随档。 |
| §4.5 低波、低贝塔及回撤风险 | `realized_volatility`、`residual_volatility`、`market_beta`、`max_drawdown`、`low_volatility_36m` | 日收益样本标准差×√252。市场模型以对齐日收益含截距回归于基准收益，另报残差年化波动（残差平方和除以 N−2 后开方×√252）和斜率 β。区间最大回撤取 max(1−价格/截至当日区间内峰值)，保留已有的半年价格回撤预设。项目原低波独立保留 37 个完整月末的 36 个月税前总收益样本标准差与负向评分；收盘原价年化观察与总收益口径分别标识。 |
| §4.5 规模 | `total_market_cap`、`free_float_market_cap` | T 可知的总股本、自由流通股本分别乘同期原收盘；可用同口径已证市值。自由流通股本的定义须由来源明确。 |
| §4.5 流动性与成交结构 | `turnover_rate`、`amihud_illiquidity`、`traded_amount`、`up_amount_share` | 日成交股数/历史时点流通股数；近 N 日绝对日收益/当日成交额的均值（档案写明币种及倍率）；日成交额，同时实现 §8.2 的过去 20 日平均成交额及项目既有 20 日成交额中位数，日值、均值、总额与中位数有各自预设；连续 60 日中上涨日成交额合计/全部成交额，平盘日计入分母。盈利预测调整和公告后漂移按 §4.9 统一登记。 |
| §4.5、§5.2 因子处理与合成 | `robust_cross_section_z`、`weighted_factor_score` | 同一时点截面 (x−中位数)/(1.4826×MAD+ε)，MAD 使用绝对离差的中位数。合成分数为 Σω·z。对同一 T 日各必需分量作上述稳健截面标准化，然后按档案声明的方向统一高分端（每项符号只用一次），按事前权重求和。缺项给出受限分量。保留原始值、z 值、符号和权重。去极值、行业／规模中性化是可复核的前置变换。等权可直接算；历史 IC 权重和风险优化权重只作为带来源的既定输入使用，本期不估计效果或求解组合。 |
| §4.6 指数增强输入与输出边界 | 复用 §4.5 的因子与合成分数 | 选股信号使用上述确定性算子。证券对同日基准的行业、规模、β和风格暴露可依已证成分、权重及因子值计算并注明聚合对象。组合优化、主动权重约束、预期跟踪误差约束和成本属于策略构建；后验跟踪误差、信息比率和归因进入效果验证预留。 |
